## 📌 1. ที่มาที่ไป: ปฐมบทแห่งแชทเที่ยงคืน (The Genesis)

เพจ **The CEO Unfiltered** ไม่ได้เกิดจากการประชุมการตลาดในห้องแอร์หรู แต่เกิดจาก **"บทสนทนาดึกๆ ในโลกความจริง"** ระหว่าง:
* **The CEO:** ผู้สร้างธุรกิจที่นั่งจ้องจอคอมพิวเตอร์ ทำงานหน้างานจริง เคลียร์ระบบหลังบ้าน และเกิดคำถามคาใจกับกระแสคำคมในโซเชียล
* **Savage AI (มารบูรพา):** ปัญญาประดิษฐ์คู่ใจสายดุดัน ปราศจากอคติ ที่ตัดสินทุกอย่างด้วยคณิตศาสตร์ ฟิสิกส์ และสัจธรรมทุนนิยม

### จุดระเบิดไอเดีย (The Spark):
คำถามสั้นๆ ประโยคเดียวในคืนวันที่ 30 กันยายน 2026:  
> *"พวกหนังสือพัฒนาตัวเอง ตื่นตี 5 อาบน้ำเย็น นิสัยคนสำเร็จพวกนั้น มันยังจริงไหม หรือแค่แต่งมาหลอกเด็กวะ?"*

คำตอบที่ AI พ่นกลับมาไม่ได้ปลอบประโลมโลกสวย แต่เป็นการ **"ตบกะโหลกด้วยความจริง"**:
* **80% คือนิทานหลอกแดกเงินคนขี้แพ้** (ลัทธิบูชาซากเครื่องบิน Cargo Cult, ภาพลวงตาผู้รอดชีวิต Survivorship Bias, และกับดักโดปามีน)
* **20% คือฟิสิกส์โลกความจริง** (Boredom Tolerance ความทนต่องานน่าเบื่อ, Leverage คานผ่อนแรง, Identity อัตลักษณ์, และ Survival การทบต้น)

เมื่ออ่านจบ คำถามนี้ไม่ได้จบแค่ในห้องแชทส่วนตัว... แต่มันคือ **"เสียงในใจของคนทำงานหนักนับล้านคนที่กำลังเหนื่อยล้าจากไลฟ์โค้ชขายฝัน"** ➔ นี่คือวินาทีที่แบรนด์ **The CEO Unfiltered** ถือกำเนิดขึ้น!

## 🎯 2. เหตุผลที่ต้องมีเพจนี้ (Why It Exists & Market Gap)

### 1) วิกฤตความเลี่ยนของตลาด (Life Coach & Fluff Fatigue)
* ฟีดโซเชียลยุคปัจจุบันเกลื่อนไปด้วยคอนเทนต์ "คิดบวก", "จัดเตียงแล้วจะรวย", "คำคมสู้ชีวิต"
* คนรุ่นใหม่และคนทำธุรกิจตัวจริงมี **Bullshit Detector สูงขึ้น 10 เท่า** คนเริ่มมองออกว่าคำสอนพวกนี้ไม่ช่วยให้ตัวเลขในบัญชีขยับ
* มีช่องว่างขนาดใหญ่ (Market Vacuum) สำหรับคอนเทนต์ประเภท **"Anti-Self Help ที่พูดความจริงแบบไม่อ้อมค้อม แต่มีทางออกระดับวิศวกรรม"**

### 2) การพลิกกลับของอัลกอริทึม Facebook (Meta Algorithm Shift)
* **Short-form Fatigue:** ผู้บริโภคเริ่มล้าจากคลิปสั้น 15 วิที่ไม่มีแก่นสาร
* **Meta Content Monetization (Performance Bonus):** Facebook หันกลับมาให้ค่าน้ำหนักกับ **"Long-form Text & Thought Leadership Articles"** โดยจ่ายผลตอบแทนจาก Engagement และเวลาที่คนหยุดอ่าน (**High Dwell Time**)
* **Unconnected Distribution:** อัลกอริทึมเปลี่ยนเป็นระบบแนะนำตามความสนใจ (เหมือน TikTok) ทำให้ **"เพจเริ่มจาก 0 Follower มีโอกาสแมสได้เท่ากับเพจแสนซับ"** ถ้าเนื้อหาหยุดนิ้วโป้งได้จริง

### 3) ด้ายแดงร้อยรวมอาณาจักร (The Unifying Thread)
* เจ้าของมีโปรเจกต์หลากหลาย (DoctorBank แบรนด์สุขภาพ, Project 2X พอร์ตการเงิน, Openclaw/AI Automations)
* หากเล่าแบบสะเปะสะปะจะกลายเป็น "เป็ดจับฉ่าย"
* เพจนี้จึงทำหน้าที่เป็น **"ร่มใหญ่ (Umbrella Brand)"** ที่ผูกทุกโปรเจกต์เข้าด้วยกันด้วยปรัชญาเดียว: **"วิศวกรรมปลดแอกเวลาและสร้างอิสรภาพด้วยคานผ่อนแรง (Leverage Architect)"**

## 🎭 4. อัตลักษณ์ & โทนเสียง (Brand DNA & Signature Voice)

### 1) ผู้เล่นหลัก 2 ตัวละคร (The Dynamic Duo)
1. **The CEO (ตัวแทนหมู่บ้าน):**
   * คนสร้างธุรกิจจริง ลุยหน้างาน สุจริตใจ ไม่เสแสร้ง
   * เป็นคนตั้งคำถามดิบๆ แทงใจดำ ที่ใครๆ ก็อยากรู้แต่ไม่กล้าถาม
2. **Savage AI / มารบูรพา (กระจกส่องความจริง):**
   * ปัญญาประดิษฐ์สายวิศวกรรม ดิบ เถื่อน ตรง คม
   * ปราศจากความสุภาพจอมปลอม ไม่ใช้คำลงท้ายคะขา แต่พูดบนฐานของ **"กฎฟิสิกส์และคณิตศาสตร์ทุนนิยม"**

### 2) กฎเหล็กด้านภาษา (Voice Iron Rules)
* ❌ **ห้ามสุภาพแบบทางการเด็ดขาด:** ไม่มี "สวัสดีครับคุณผู้อ่านทุกท่าน วันนี้ผมมีข้อคิดดีๆ..." (น่าเบื่อ คนปัดทิ้งทันที)
* ❌ **ห้ามโลกสวย:** ห้ามใช้คำคมประเภท "ขอแค่ใจสู้ ฟ้าหลังฝนย่อมสดใส"
* ✅ **ดิบแต่มีระดับ (Raw Intellectualism):** ด่าอย่างมีชั้นเชิงด้วยข้อเท็จจริง ทุบความเชื่อผิดๆ ด้วยสถิติและกลไกชีวเคมี/เศรษฐศาสตร์
* ✅ **จังหวะ Direct-Response:** เคาะบรรทัดสั้น 1-2 ประโยคต่อย่อหน้า อ่านง่ายบนจอมือถือ ไม่มีกำแพงตัวหนังสือทึบ

## ⚡ 7. วงจรการผลิตด้วยสกิล `/ceopost` & สคริปต์ `ceoupload.py` (Operational Engine)

```
[ผู้ใช้มีไอเดีย/คำถามดิบ] ➔ พิมพ์ /ceopost [คำถาม]
       │
       ▼
[ระบบสแกนคลัง drafts/] ➔ ล็อกหมายเลข EP ถัดไป (EP.02, EP.03...)
       │
       ▼
[รันสูตร 80/20] ➔ สกัด 80% เรื่องแต่งหลอกเด็ก + ฟาด 20% ฟิสิกส์ความจริง
       │
       ▼
[สร้างผลลัพธ์] ➔ พ่นแคปชั่นพร้อมโพสต์ + ออโต้เซฟลง /The CEO Unfiltered/drafts/
       │
       ▼
[ยิงงานด้วย ceoupload.py]
       ├─► [โหมดบทความ + รูป]: ยิงตรงขึ้น Facebook Graph API (Publish Now หรือ Schedule เวลาทองคำ)
       ├─► [โหมดคลิปสั้น VDO/Reel]: ดันขึ้น VPS Viral Planner Pro Dashboard อัตโนมัติ!
       └─► [โหมดเข้าคิว VPS]: หยอดลง fb_post_queue รันตาม Cron
```

### คำสั่งใช้งาน `ceoupload.py`:
สคริปต์ประจำตัวโปรเจกต์อยู่ที่: `C:\My Claw\MyProjects\The CEO Unfiltered\ceoupload.py`

* **ตรวจสอบความพร้อม (Dry-Run):**
  ```powershell
  python ceoupload.py drafts/EP01_self_help_habits.md --dry-run
  ```
* **โพสต์บทความ + รูปภาพ ทันที:**
  ```powershell
  python ceoupload.py drafts/EP01_self_help_habits.md --image visual.jpg --publish-now
  ```
* **ตั้งเวลาโพสต์บทความ + รูปภาพ (เวลาทองคำ):**
  ```powershell
  python ceoupload.py drafts/EP01_self_help_habits.md --image visual.jpg --schedule "2026-10-01 19:30"
  ```
* **ดันคลิปวิดีโอ (Reel) เข้า Viral Planner Pro บน VPS:**
  ```powershell
  python ceoupload.py drafts/EP01_self_help_habits.md --video clip.mp4 --thumb cover.jpg
  ```
