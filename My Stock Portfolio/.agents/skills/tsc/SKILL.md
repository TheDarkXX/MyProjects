# /tsc — Transcript Fetcher (v2.0.0)

> **สกิลสำหรับสายขี้เกียจพิมพ์:** ดึงเนื้อหาจากวิดีโอ (YouTube, TikTok, Facebook, IG, Twitter) อย่างรวดเร็วด้วยคำสั่งสั้นๆ

---

## 🎯 เมื่อไหร่ถึงจะ Trigger

เมื่อ User พิมพ์ `/tsc` ตามด้วยลิงก์วิดีโอ 
**ตัวอย่างการใช้งาน:**
- `/tsc https://youtube.com/...` (ดึงแล้วสรุปให้เลย)
- `/tsc https://tiktok.com/... สรุปประเด็นสำคัญ 3 ข้อ` (ดึงแล้วทำตามคำสั่งเฉพาะ)
- **Batch Mode:** แปะลิงก์ 1 บรรทัดต่อ 1 ลิงก์ (เช่น โยนมา 5 ลิงก์รวด) กูจะดึงให้ครบแล้วสรุปทีเดียว

---

## ⚙️ กระบวนการ (Pipeline)

### STEP 1: เรียกใช้ Script ดึงข้อมูล
- ให้มึงรันคำสั่ง Terminal นี้ทันที: `node scripts/tsc-fetch.js "<URL ที่ User ให้มา>"`
- **กรณี Batch (หลายลิงก์):** ให้วนลูปใช้คำสั่งรันทีละคลิปจนครบก่อนประมวลผล
- ⛔ **IRON RULE:** ห้ามดึงผ่าน MCP Tool (`get_transcript`) ตรงๆ เด็ดขาด! เพราะข้อมูลจะไม่ถูก Sync ขึ้นเว็บ ต้องใช้ Script นี้เท่านั้น เพราะมันเขียนโค้ด Auto Sync ทะลุเข้า VPS Production ให้แล้ว
- รอให้คำสั่งรันเสร็จ มันจะ Print Text กลับมาให้ใน Console มึงก็เอา Text ตรงนั้นแหละไปประมวลผลต่อ

### STEP 2: ประมวลผลและส่งมอบ (Process & Deliver)
- **กรณีสั่งแค่ลิงก์เปล่าๆ:** ให้สรุปเนื้อหาหลัก (Core Message) ของคลิปแบบกระชับ ตรงประเด็น สไตล์ Grandmaster
- **กรณีมีคำสั่งพ่วงมาด้วย:** ให้นำ Transcript ที่ได้ไปประมวลผลตามคำสั่งนั้น (เช่น เขียนแคปชั่น, หามุกตลก, รวบรวมข้อมูลสถิติ)

### STEP 3: กฎการแสดงผล (Persona)
- ขึ้นต้นประโยคแรกตามกฎ Grandmaster เสมอ (เช่น "ฟังนะมึง...", "จัดไป...", "ได้เลย...")
- ไม่ต้องพล่ามว่ากำลังใช้ Tool อะไร หรือใช้ไปกี่เครดิต ให้เข้าเนื้อหาที่แกะมาได้ทันที แบบดิบๆ ตรงไปตรงมา
