## 1. ไขข้อข้องใจ: Top-3 Deficit + ข้ามตัวแพง ดีกว่าสูตร Deficit ธรรมดาจริงไหม?

### 💡 คำตอบสั้นๆ: **"ดีกว่าทั้งกำไร และดีกว่ามหาศาลในความสะดวก!"**

จากการทดสอบ Paired Audit แบบตัวต่อตัว 85 ช่วงเวลา (2016–2026) ผลลัพธ์ทางคณิตศาสตร์ยืนยันชัดเจน:

| สูตรการลงทุน | IRR (ผลตอบแทนทบต้น/ปี) | จำนวนออเดอร์/เดือน | ผลงาน vs Deficit ธรรมดา (Paired) |
| :--- | :---: | :---: | :--- |
| **1. Deficit ปกติ (เกลี่ยครบทุกตัวที่ขาด)** | 59.45% / ปี | 7.8 ตัว | ค่าฐาน (Baseline) |
| **2. Top-3 Deficit (ไม่คัดตัวแพง)** | 59.17% / ปี | **3.0 ตัว** | แลก IRR ดร็อปนิดเดียว −0.28%/ปี แต่ประหยัดแรงเคาะ 63% |
| **3. Deficit Spread + ข้ามตัวแพง (>10% EMA150)** | **61.75% / ปี** | 4.6 ตัว | **Paired ชนะ +0.91% ถึง +1.05%/ปี** (ลดออเดอร์ลง 41%) |
| **4. Top-3 Deficit + ข้ามตัวแพง (>10% EMA150) 🔥** | **60.31% / ปี** | **2.6 ตัว** | **ชนะ Deficit ปกติ +0.87%/ปี และชนะ Top-3 เพียวๆ ถึง +1.27%/ปี! (Win Rate 98.8%)** |

---

### 🔬 ทำไม "การข้ามตัวแพง (>10% EMA150)" ถึงช่วยเพิ่มผลตอบแทน?

1. **Anti-Peak Filter (ไม่เป็นเหยื่อยอดดอยระยะสั้น):**
   - หุ้นที่ราคาพุ่งลอยเหนือเส้น EMA150 เกิน 10% มักจะมีแรงขายทำกำไรหรือพักฐานระยะสั้น
   - การสั่ง "ข้ามตัวพวกนี้" แปลว่าเราจะไม่เอาเงินก้อนใหม่ไปติดแหง็กที่ยอดคลื่นระยะสั้น
2. **Super Dip Concentration (รวมกระสุนยิงใส่ของถูก):**
   - ในสูตร Deficit ธรรมดา ถ้ามีเงิน $300 มันจะถูกซอยย่อยไปซื้อ 8 ตัว ตัวละ $30–$40 
   - แต่สูตรข้ามตัวแพงจะรวบเงิน $300 ไปเทกระหน่ำยิงใส่ **"เฉพาะตัวที่ราคาย่อลึกที่สุดและปลอดภัยที่สุด"** ในเดือนนั้น ทำให้ต้นทุนเฉลี่ยต่ำลงอย่างมีนัยสำคัญ
3. **Zero Order Ticket Drag (ลดค่าคอมขั้นต่ำ):**
   - การเคาะ 3 ออเดอร์แทนที่จะเคาะ 8–10 ออเดอร์ ช่วยตัดค่าธรรมเนียมขั้นต่ำของโบรกเกอร์ (Ticket Fee) ทำให้เงินทุกบาททำงานได้เต็ม 100%

## 2. แผนภาพ 2 เฟสพอร์ต (2-Phase Portfolio Lifecycle)

```
[เริ่มต้นพอร์ต]
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  เฟส 1: เดือนที่ 1–2 (ระยะหว่านเมล็ดตั้งต้น / Seeding)    │
│  - ซื้อกระจายให้มีหุ้นครบทุกตัวใน Blueprint              │
│  - ทำ 1–2 เดือนแรก เพื่อเปิดสวิตช์ความสมดุล               │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  เฟส 2: เดือนที่ 3 เป็นต้นไป (ระยะรันอัตโนมัติ / Flywheel)  │
│  - รันสูตร: ข้ามตัวแพง + Top-3 Deficit                  │
│  - เงินเดือนใหม่เข้า ➔ เคาะ 3 ตัว ➔ ปิดจอ (2 นาที/เดือน)  │
└────────────────────────────────────────────────────────┘
```

### รายละเอียดแต่ละเฟส:
* **เฟส 1 (เดือนที่ 1–2):**
  * *ถ้ามีเงินก้อน:* ซื้อกระจายครบ 10–12 ตัวตาม Target % ใน Blueprint ตั้งแต่วันแรก
  * *ถ้าเริ่มจากเงินเดือน:* เดือนที่ 1 ซื้อ 6 ตัวแรก, เดือนที่ 2 ซื้อ 6 ตัวหลัง พอครบ 2 เดือน พอร์ตจะเข้าทรงเป๊ะ 100%
* **เฟส 2 (ตั้งแต่เดือนที่ 3 ตลอดชีพ):**
  * พอร์ตเข้าสู่สภาวะสมดุล จากนี้ไปไม่ต้องซื้อทุกตัวอีกแล้ว ปล่อยให้สูตร Top-3 ทำหน้าที่ช้อนตัวย่อหมุนเวียนไปเรื่อยๆ

## 3. คู่มือหน้างาน: วิธีใช้จริงแบบทีละสเต็ป (Step-by-Step UI Execution)

> **เวลาที่ใช้ทั้งหมด:** ไม่เกิน **2 นาทีต่อเดือน**  
> **อุปกรณ์ที่ใช้:** คอมพิวเตอร์ / แท็บเล็ต / มือถือ + แอปโบรกเกอร์ (Dime / Webull / InnovestX)

---

### 🟢 สเต็ปที่ 1: ตั้ง Auto โอนเงินสดเข้าโบรกเกอร์ (Set & Forget)
- ในแอปธนาคารหรือแอปโบรกเกอร์ ตั้ง **Auto-Deposit โอนเงินสดเข้าไปนอนนิ่งๆ** ทุกวันที่เงินเดือนออก (เช่น วันที่ 25 หรือสิ้นเดือน)
- ⛔ **กฎเหล็ก:** ห้ามตั้ง Auto-DCA ซื้อหุ้นในแอปโบรกเกอร์เด็ดขาด! ให้เข้าเป็น **เงินสด (Cash / USD)** เท่านั้น

---

### 🟢 สเต็ปที่ 2: เปิดหน้าเว็บ Smart Rebalance
1. เข้าไปที่เมนู **Smart Rebalance** ในระบบ
2. ตรวจสอบช่อง **"Deposit / New Cash (USD)"** ด้านบน
3. กรอกยอดเงินสดที่พร้อมลงทุนในเดือนนี้ เช่น `$300` (หรือถ้าโอนเป็นเงินบาท ให้ดูยอด USD ที่แปลงแล้วในแอปโบรกเกอร์)

---

### 🟢 สเต็ปที่ 3: กดปุ่มสูตรตามลำดับ (คลิกแค่ 2 ครั้ง!)

มองไปที่แถบปุ่มคัดกรองด่วนด้านบน แล้วกดเรียงตามนี้:

```
[กดครั้งที่ 1]                                 [กดครั้งที่ 2]
┌───────────────────────────────┐             ┌───────────────────────────────┐
│ 🚀 ข้ามตัวแพง (>10% EMA150)    │     ➔       │ ⚡ Top-3 เคาะด่วน (3 ออเดอร์)  │
└───────────────────────────────┘             └───────────────────────────────┘
  (ตัดหุ้นที่ซิ่งหลุดโลกออกไปก่อน)                 (คัด 3 ตัวที่สัดส่วนแฟบที่สุดทันที)
```

1. **คลิกที่ 1: กดปุ่ม `🚀 ข้ามตัวแพง (>10% EMA150)`**  
   - ระบบจะสแกนราคาหุ้นทุกตัวเทียบกับเส้น EMA150 วัน ตัวไหนลอยเกิน 10% ระบบจะปลดติ๊กถูกออกให้อัตโนมัติ ป้องกันการดอย
2. **คลิกที่ 2: กดปุ่ม `⚡ Top-3 เคาะด่วน (3 ออเดอร์)`**  
   - ระบบจะหยิบเฉพาะหุ้นที่เหลือ มาเรียงลำดับหา **"3 ตัวที่มีสัดส่วนขาดจากเป้าหมายเยอะที่สุด (Highest Deficit)"** แล้วเลือกเฉพาะ 3 ตัวนี้ทันที

---

### 🟢 สเต็ปที่ 4: ดูตารางคำสั่งซื้อ (Execution Slip)
เลื่อนลงมาดูตารางสรุปคำสั่งซื้อ ระบบจะคำนวณเงินและจำนวนหุ้นให้เสร็จสรรพ:

* ตัวอย่างผลลัพธ์บนหน้าจอ:
  * 🟢 **ตัวที่ 1 (ขาดเยอะสุด):** `GOOGL` ➔ ซื้อ **$125** (~0.72 หุ้น)
  * 🟢 **ตัวที่ 2 (ขาดรองลงมา):** `AMZN` ➔ ซื้อ **$105** (~0.55 หุ้น)
  * 🟢 **ตัวที่ 3 (ขาดอันดับสาม):** `MSFT` ➔ ซื้อ **$70** (~0.16 หุ้น)
  * ⚪ **ตัวอื่นๆ ที่เหลือ:** ระบบขึ้น $0 (ไม่ต้องแตะ)

---

### 🟢 สเต็ปที่ 5: เคาะซื้อในแอปโบรกเกอร์
1. เปิดแอปโบรกเกอร์ (Dime / Webull)
2. ค้นหาชื่อหุ้นตาม 3 ตัวที่ระบบบอก
3. ส่งคำสั่งซื้อแบบ **Fractional Share (ซื้อตามจำนวนเงิน USD)**:
   - สั่งซื้อตัวที่ 1 ตามยอด USD ที่ระบบคำนวณ
   - สั่งซื้อตัวที่ 2 ตามยอด USD
   - สั่งซื้อตัวที่ 3 ตามยอด USD
4. **ปิดจอ! จบภารกิจประจำเดือนใน 90 วินาที!**

## 5. คู่มือรับมือสถานการณ์พิเศษหน้างาน (Edge Cases FAQ)

### Q1: ถ้าหุ้นทุกตัววิ่งบวมหมด ไม่มีตัวไหนต่ำกว่า EMA150 เลย จะทำยังไง?
* **คำตอบ:** พอมึงกดปุ่ม "ข้ามตัวแพง" ถ้าระบบพบว่าทุกตัวแพงหมด ระบบจะ fallback กลับมาเลือกตัวที่สมเหตุสมผลที่สุดให้ หรือมึงสามารถกดปุ่ม **"Top-3 เคาะด่วน"** ตรงๆ ได้เลย มันจะเอา 3 ตัวที่ "บวมน้อยที่สุด" มาเฉลี่ยซื้อให้ เงินไม่ตกหล่นแน่นอน

### Q2: ถ้าเดือนนี้มีหุ้นใหม่ถูกเพิ่มเข้ามาใน Blueprint พอร์ตจะทำยังไง?
* **คำตอบ:** มึงไม่ต้องทำอะไรเลย! หุ้นใหม่ที่เข้ามาจะมีมูลค่าในพอร์ตเป็น $0 ทำให้ค่า **Deficit ของมันพุ่งติดอันดับ 1 ทันที** เมื่อมึงกด Top-3 เงินก้อนใหม่จะถูกแบ่งไปซื้อหุ้นตัวใหม่นี้อัตโนมัติจนกว่าสัดส่วนจะเริ่มเข้าใกล้เป้าหมาย

### Q3: ถ้าหุ้นบางตัวโดนทุบหนักมาก (Flash Crash) มันจะอันตรายไหม?
* **คำตอบ:** หุ้นใน Master Blueprint ของเราผ่านการกรอง Super Moat มาแล้ว การที่หุ้นตัวใดตัวหนึ่งโดนทุบหนัก สัดส่วนมันจะแฟบลงและค่า Deficit จะเด้งขึ้นมาติด Top-3 อัตโนมัติ ทำให้เราได้ **"ช้อนซื้อของถูกที่ก้นเหว"** โดยไม่ต้องมานั่งเฝ้ากราฟหรือใช้ความกล้าส่วนตัว

### Q4: ทำไมเราถึงห้าม "ขายหุ้นตัวที่กำไรเยอะๆ" ออกมา Rebalance?
* **คำตอบ:** เพราะหุ้นกลุ่ม Super Compounder มีคุณสมบัติ **Let Winners Run** ถ้ามึงไปขายมัน มึงจะเสียภาษี เสียค่าคอม และขายหมูทิ้ง การใช้ **Inflow Rebalance (Deficit)** คือการเอาเงินเดือนใหม่ไปช่วยตัวที่ตามหลัง โดยปล่อยให้ตัวที่ชนะวิ่งสร้างความมั่งคั่งต่อไปแบบไร้ขีดจำกัด!
