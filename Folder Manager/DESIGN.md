# 🏗️ DESIGN — Folder Manager

## Architecture
- **Language/Platform:** (รอยูสเซอร์กำหนด เช่น Python, Node.js, หรือ PowerShell)
- **UI:** (CLI เบื้องต้น, อาจพัฒนาเป็น GUI ภายหลัง)

## Key Features
1. Search Files/Folders (ค้นหาตามขนาด, นามสกุล, วันที่)
2. Batch Move/Delete (จัดการทีละเยอะๆ)
3. Clean Empty Folders (สแกนและลบโฟลเดอร์เปล่า)
