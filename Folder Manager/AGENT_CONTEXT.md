# 🧭 Folder Manager — Agent Context

## 📋 Project Objective
จัดการ เคลียร์ ค้นหา ย้าย ลบ โฟลเดอร์และไฟล์ต่างๆ

## 📁 Directory Structure
- `src/` : ซอร์สโค้ดหลักสำหรับ Script หรือแอปพลิเคชัน
- `Modules/` : โมดูลแยกตามฟังก์ชันการทำงาน (เช่น การค้นหา, การย้าย, การลบ)
- `DESIGN.md` : การออกแบบระบบและ Flow
