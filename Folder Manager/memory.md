# 🧠 Folder Manager — Memory

## 🎯 Core Rules
- **ความปลอดภัยสูงสุด**: ก่อนที่จะรันสคริปต์สำหรับลบ (Delete) หรือย้าย (Move) ไฟล์ใดๆ ต้องมีระบบ Preview (Dry-run) หรือ Log ให้เห็นก่อนเสมอ ห้ามลบทิ้งเงียบๆ เด็ดขาด
- รองรับ Windows Environment เป็นหลัก (ใช้ PowerShell, Node.js หรือ Python ตามความเหมาะสม)
