| แหล่ง Respond (แทนคอมเมนต์ตัวเอง) | วิธีใช้ |
|-------------------------------------|---------|
| **คลิปคู่แข่ง + คอมเมนต์ใต้คลิปคู่แข่ง** | ดูว่าคนถามอะไร บ่นอะไร → ทำคลิปตอบ |

| **คำถามคนไข้ที่คลินิก** | คำถามที่โดนถามบ่อย → แปลงเป็นคลิป (ห้ามเปิดเผยข้อมูลคนไข้!) |

## 🔀 7. SPLIT DEFINITION — เหตุผลเชิงลึกว่าทำไมต้องมีคนอยู่ใกล้

### กลไกจริงของ Split Definition

ในแผนผัง Bodygraph ของมึง Center ที่ถูก activate มันแบ่งเป็น **2 กลุ่มที่ไม่มี Channel เชื่อม**:

```
กลุ่ม A                              กลุ่ม B
[Center ●]══[Center ●]          [Center ●]══[Center ●]
                        ↕
                   ช่องว่าง (Gap)
              ← ไม่มี Channel เชื่อม →
```

**ทำไมต้องมีคนอยู่ใกล้?**

ทุกคนมี **"Aura" (สนามพลังงาน)** แผ่รอบตัว ~2-3 เมตร เมื่อ aura ของ 2 คนทับกัน พลังงานจะ "ผสม" กัน

ถ้าคนที่อยู่ใกล้มี **Gate หรือ Channel ที่ "ต่อ" ช่องว่าง** ระหว่าง 2 กลุ่มของมึงพอดี → วงจรจะ **ปิดครบ** → ข้อมูลไหลเวียนสมบูรณ์ → คิดอะไรออก ตัดสินใจชัด รู้สึก "ครบ"

เปรียบเทียบ:
- **Single Definition** = วงจรไฟฟ้าครบในตัว → เสียบปลั๊กติดเลย
- **Split Definition (มึง)** = วงจรขาด 1 จุด → ต้องมี "สายไฟ" จากคนอื่นมาต่อ → ถึงจะติด

**ไม่ได้แปลว่าอ่อนแอ** = ออกแบบมาให้ทำงานร่วมกับคน ← ตรงกับ Line 4 (Networking) เป๊ะ

**ในทางปฏิบัติ:**
- แฟนนั่งทำงานห้องข้างๆ = **ใช้ได้ ✅**
- วันที่แฟนไม่อยู่ = ไป Coworking / ร้านกาแฟ
- ไม่ต้องคุยกัน แค่อยู่ใน aura range ก็เพียงพอ
