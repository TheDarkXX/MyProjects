# Google Flow Tools — Quick Reference Guide

## What is Google Flow Tools?
Google Flow (flow.google) มี built-in feature ชื่อ **Tools** ที่ให้ user สร้าง custom mini-apps/workflows แบบ no-code ผ่าน natural language prompts

## How to Create a Tool
1. เข้า [flow.google](https://flow.google)
2. เปิด Project หรือสร้างใหม่
3. Sidebar ซ้าย → **Tools** → **Create Tool**
4. พิมพ์ prompt อธิบาย tool ที่ต้องการ (English recommended)
5. กด **Generate** → AI สร้าง interface + code
6. Review ผลลัพธ์ → **Save**

## How to Edit a Tool
1. เปิด Tool ที่ต้องการ
2. กด **Edit** ด้านบน
3. พิมพ์สิ่งที่ต้องการแก้ไขใน prompt box
4. กด **Generate** อีกครั้ง

## How to Find Your Tools
- **Tools** → **My Tools** ใน sidebar

## Sharing & Remixing
- Tools สามารถ share publicly ได้
- สามารถ remix tools ของคนอื่นมาปรับใช้ได้

## Tips
- Prompt ที่ดี = ชัดเจน, ระบุ input/output, ระบุ UI ที่ต้องการ
- ลอง browse Gallery ก่อนสร้างใหม่ — อาจมี tool ที่ใกล้เคียงให้ remix
- Media ที่ generate ใช้ credits — ระวังการใช้งาน

## Limitations
- ทำงานภายใน Google Flow platform เท่านั้น
- ไม่ support external API/third-party integrations
- Generated media ใช้ Flow credits
