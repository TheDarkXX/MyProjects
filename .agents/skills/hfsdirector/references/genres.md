# Genres

> **TL;DR:** Each genre gives a default length, spine shape (SKILL.md §2), look (`looks.md`), signature shots (`shots.md`) and CTA. They are starting points: the command can override any of them. A clip that mixes genres takes the spine of its goal (selling → Problem → Fix; teaching → Myth → Truth).

<a id="product"></a>
## Product ad
- **Hook:** the problem or the product's single best number on frame 0.
- **Spine:** the moment of need (stock or own footage) → the product revealed in black → 2–3 feature beats, each one a metric shot → logo lockup with tagline → CTA.
- **Rule:** the real product only. With no images, ask for them (the one allowed question), or build the clip around the benefit with no packshot.

<a id="app"></a>
## App & SaaS demo
- **Hook:** the pain as a visual ("notification-pile" + one word).
- **Spine:** chaos → "แค่บอก" + command-bar → the app sorts it (2–3 fix beats: schedule, reply, summary) → the result on a device-insert in a real scene → the app name, platform badges and price.
- **Rule:** show the real UI if there is one (`capture`); else a generic UI in the brand's tokens.

<a id="ai"></a>
## AI & tech showcase
- **Hook:** the claim ("ไฟล์เดียว ทำคลิปแบบที่คุณดูอยู่") or a question ("ทายสิ ใช้คนทำกี่คน").
- **Spine:** the claim → credits-roll ("one file did every job") → the request typed → the made thing plays as an embedded mini-ad → "every frame you just watched came from…" → CTA.
- **Rule:** the made thing must be good enough to stand alone. That embedded result is the proof.

<a id="news"></a>
## News
- **Hook:** the headline in 5 words with the one striking number.
- **Spine:** what → why it matters → the number (chart-story) → what's next. Source on screen as a small line ("ภาพ: Tesla").
- **Rule:** no invented facts. Every figure comes from the command or a cited source; when unsure, drop it.

<a id="explainer"></a>
## Explainer & health
- **Hook:** the common belief stated, then "ไม่ใช่".
- **Spine:** myth → mechanism (one diagram or bento) → evidence (number + source chip) → what to do (step list) → save CTA.
- **Rule:** health and money claims cite a source on screen. Never promise outcomes.

<a id="finance"></a>
## Finance & numbers
- **Hook:** the number that hurts or surprises, as a dot-number or digital-readout.
- **Spine:** number → why → chart → the move → the risk line.
- **Rule:** add a "not financial advice" line when the clip suggests action.

<a id="story"></a>
## Story & personal
- **Hook:** the end state or the most emotional line first.
- **Spine:** the before (footage) → the turn (punch-in, word-behind-head) → the after → split-compare.
- **Rule:** keep the overlays light. The face and voice carry it.

<a id="lead"></a>
## Lead magnet
- **Hook:** the free thing and what it does, in one line.
- **Spine:** the promise → proof (a short demo) → the profile card → "comment 'X'" typed in → scarcity (dot-number "200 คนแรก ฟรี") → "after that, paid" flip → endcard.
- **Rule:** the keyword is one easy word, shown at least three times (prompt, comment, endcard).

<a id="list"></a>
## Listicle
- **Hook:** "N things…" with N huge.
- **Spine:** one item per beat (2–4 s each); the best item last; a different shot per item.
- **Rule:** the item number stays on screen in a corner the whole time.
