# Quick Upload (qu)

เมื่อผู้ใช้เรียกคำสั่ง `/qu` ให้รันคำสั่งต่อไปนี้:

```bash
cd "C:\My Claw\Openclaw-VPS\Quick Upload"
node pull_discord.js "C:\My Claw\MyProjects\Quick Upload\QuickQuick"
```

จากนั้นให้รายงานผู้ใช้สั้นๆ ว่า "✅ ดึงรูปให้เรียบร้อยแล้ว!" (ถ้าคำสั่งรันสำเร็จ)
และบอกผู้ใช้ว่าตอนนี้รูปอยู่ในโฟลเดอร์ `Quick Upload\QuickQuick` ของโปรเจกต์เราแล้ว ให้เราทำงานต่อได้เลย
