## 📖 คู่มือการใช้งานสกิลหลัก (Detailed Usage)

### `/tt` — TikTok Trend Intelligence Engine
สกิลนี้ใช้สำหรับดึงข้อมูลสดจากระบบ TikTok Trend Intelligence บน VPS (brain.doctorbankonline.com) แบบเรียลไทม์ ผ่าน 5 ขุมพลังการวิเคราะห์: Engagement DNA (Share Rate %, Velocity), จัดเกรด Authority Pyramid (L1-L6), เช็ค Topic Dedup ชนคลังสคริปต์ DoctorBank และ XBrain, วิเคราะห์ Posting Heatmap ช่วงเวลาทองคำ และออก War Brief สไตล์มารบูรพา

**วิธีเรียกใช้งาน:**
- `/tt [keyword]` ➔ วิเคราะห์คีย์เวิร์ดย้อนหลัง 30 วัน (เช่น `/tt นอน`, `/tt แมกนีเซียม`)
- `/tt [keyword] [timeframe]` ➔ กำหนดช่วงเวลาเอง (เช่น `/tt ผิวขาว 7d`, `/tt กรดไหลย้อน this_month`)
- รองรับ timeframe: `today`, `yesterday`, `3d`, `7d`, `14d`, `30d`, `this_month`, `all`

**XBrain Chaining Pipeline (พลังผสมผสาน):**
1. ส่องเทรนด์ด้วย `/tt` ได้ตารางคลิป + หมัดเด็ด L4 Hooks
2. ก๊อปปี้ลิงก์คลิปไวรัลตัวท็อปไปรันต่อด้วย `/tsc [URL]` เพื่อแกะสคริปต์คำพูดจริง
3. รัน `/gcons [keyword]` หรือ `/gdeep 5 [keyword]` เพื่อขุดงานวิจัย PubMed เสริมความหนักแน่นให้มุม L4
4. สลับไปเขียนสคริปต์เต็มใน DoctorBank-Brand ด้วย `/devilscript`
5. จบด้วย `/save` เพื่อบันทึกความรู้และสคริปต์ทั้งหมดลงคลัง Quick Save เสมอ

### `/tsc` — Transcript Fetcher
สกิลนี้ใช้สำหรับแกะเนื้อหาวิดีโอสั้นหรือยาวจากแพลตฟอร์มหลัก (YouTube, TikTok, Facebook, IG) ได้อย่างรวดเร็ว โดยเรียกใช้ API ของ Supadata แบบอัตโนมัติ

**วิธีเรียกใช้งาน:**
- `/tsc [URL]` ➔ ดึง Transcript จากลิงก์ที่ระบุ แล้วสรุปเนื้อหาหลักให้แบบรวบรัด
- `/tsc [URL] [คำสั่งเพิ่มเติม]` ➔ ดึง Transcript แล้วทำตามคำสั่ง (เช่น `/tsc [URL] ขอ 3 ประเด็นเด่นที่คนฟังเอาไปใช้ได้เลย`)
- **Batch Mode (หลายลิงก์):** ก๊อปปี้ URL มาแปะเรียงกันบรรทัดละ 1 ลิงก์ แล้วสั่ง `/tsc` ทีเดียว ระบบจะวนลูปดึงข้อมูลจนครบทุกคลิป แล้วค่อยสรุปภาพรวมทั้งหมดรวดเดียวจบ (ช่วยประหยัดเวลามาก)

**จุดเด่นการทำงาน:**
1. **Auto Key Rotation:** ระบบมีโควตา API Key ทั้งหมด 3 ตัว สลับการทำงานให้อัตโนมัติ หากตัวแรกเต็ม (402) จะสลับไปตัวถัดไปทันทีโดยที่งานไม่สะดุด
