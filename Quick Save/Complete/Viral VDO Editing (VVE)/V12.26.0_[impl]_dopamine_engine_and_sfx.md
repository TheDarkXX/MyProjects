# VVE Dopamine-driven Engine (High Density SFX, Dynamic Layout, Minnie Transitions)

## 📌 Context (Compiled Truth)
The goal was to upgrade the VVE Python pipeline to emulate the highly engaging "Dopamine-driven" editing style of Top TikTokers, specifically referencing Dr. Jade's pacing.
We implemented a multi-faceted upgrade across three python scripts (`06-footage-assembler.py`, `07-sfx-placer.py`, `08b-capcut-auto-style.py`) and injected new behaviors via `08-capcut-inject.py`.

Key Features Implemented:
1. **Dynamic Layout Shuffling**: Automatically shifting between Split-Screen (Speaker at Y=0.625, B-Roll at Y=-0.29) and Full-Screen (Y=0.0). Note: User later requested a "Basic Style" which forced all layout to Full Screen temporarily, but the Split-Screen logic was archived in `layout_analysis_report.md`.
2. **Minnie Transitions & Beauty Face**: Dynamically mapped CapCut `resource_id`s for premium transitions (Zoom Shake, Rotate & Change, Pull Out, etc.) and applied Beauty Face (preset_id: `7134260905470001153` rate_map: 30%) and Noise Reduction (level: 1) directly via JSON modification.
3. **High-Density SFX Engine**: Upgraded `07-sfx-placer.py` to use keyword-based triggers (`ไต, แคลเซียม, พัง` -> Pop, `1, 2, 3` -> Slide, `สนใจ, พิมพ์` -> Ding).
4. **Dynamic Transition SFX**: Added random selection of transition sounds (Whoosh, Swoosh, Sweep, Slide) on every layout shift/zoom event.
5. **Safety Mechanism**: Implemented `Stop-Process -Name CapCut` in the python pipeline to prevent file lock errors when modifying `draft_content.json`.

# 🚀 อัปเกรด High-Engagement Viral Features สำเร็จเรียบร้อย!

- เมื่อใดก็ตามที่ B-Roll ปรากฏขึ้น: วิดีโอคุณหมอ (Main Clip) จะถูกซูมลงมาอยู่ข้างล่าง (**Y: +0.625, Scale: 1.26**) และ B-Roll จะไปอยู่ข้างบน (**Y: -0.29**)
- เมื่อ B-Roll จบลง: วิดีโอคุณหมอจะเด้งกลับมาเป็น **Full Screen (Y: 0, Scale: 1.0)** เหมือนเดิม
- *อัปเดตที่ไฟล์: `08b-capcut-auto-style.py`*

- **Beauty Face (หน้าเนียน):** เปิดใช้งานหน้าเนียนระดับ 30% และ Noise Reduction Level 1 ให้กับ Main Clip อัตโนมัติ เพื่อให้ภาพดูพรีเมียม
- *อัปเดตที่ไฟล์: `08b-capcut-auto-style.py`*
