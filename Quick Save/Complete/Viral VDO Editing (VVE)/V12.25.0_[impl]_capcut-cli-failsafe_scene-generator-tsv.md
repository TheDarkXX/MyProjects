# Phase 5: AI Scene & B-Roll Generator (Masterpiece Implementation)

This phase will transform the 141 punchy SRT cues into dynamic visual scenes, guided entirely by the new `doctorbank_masterprompt.yaml` and `doctorbank.yaml` memory files.

## Goal
Create `05-scene-generator.py` to group subtitles into ~3.5-second visual scenes and use an LLM to generate precise `Image Prompts` and `Motion Prompts` based on the 8 strict categories defined in the Master Prompt (A: People, B: Organs, C: Micro, D: Metaphor, E: Food, F: Product, G: Lifestyle, H: Herbs).

## Proposed Changes

### 1. `scripts/05-scene-generator.py` [NEW]
This new script will act as the "Art Director" AI.
*   **Scene Grouping:** It will read `video_20250929_145057.transcript.srt` and group the cues so that each scene lasts approximately 3.0 - 4.0 seconds.
*   **Context Assembly:** For each scene, it aggregates the text to form a coherent thought (e.g., "เจ็ดสุดยอด อาหารบำรุง ไต ที่หมอยืนยัน ว่าใช้ดีจริง").
*   **LLM Integration:** It will send the Scene Text + `doctorbank_masterprompt.yaml` to an LLM (Gemini/Claude).
*   **Output Parsing:** The LLM will return a JSON object containing:
    *   `category`: e.g., "E: อาหาร (Food)"
    *   `image_prompt`: e.g., "High-end food photography, a basket of vibrant red apples and green broccoli..."
    *   `motion_prompt`: e.g., "Slow push in, soft steam rising..."
    *   `layout`: "Full Screen B-Roll" or "Split Screen" (based on `doctorbank.yaml`)
*   **JSON Output:** Saves all data to `video_20250929_145057.scenes.json`.
