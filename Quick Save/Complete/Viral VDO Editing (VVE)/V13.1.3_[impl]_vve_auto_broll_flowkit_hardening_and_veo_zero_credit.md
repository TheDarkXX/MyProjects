# VVE Auto B-Roll Generator & FlowKit Pipeline Hardening (07d + Veo 3.1 Zero Credit)

## 📌 Context & Implementation (Compiled Truth)
Following the initial prototype of `07d-auto-broll-flow.py` in V13.1.2, a comprehensive RFC Plan V2 was designed, audited via GPT-5.6-Sol / Codex, and tested end-to-end against live Google Flow infrastructure.

### Key Architectural Resolutions & Implementations:
1. **Primary Engine Selection: Veo 3.1 Lite Low Priority (0 Credits):**
   - User directive: *"ใช้ตัวนี้เป็นหลักนะ เพราะ 0 credit"*.
   - Because Veo 3.1 in Google Flow operates as an Image-to-Video (I2V) batch RPC (`eb1hJf` / `veo_3_1_i2v_lite_low_priority`), direct text-to-video was failing validation.
   - Built automated 2-step orchestration in `FlowKitClient.submit_broll()`:
     - **Step 1 (Text-to-Image)**: Invokes `POST /api/flow/generate-image` to generate a high-fidelity anchor frame in ~15s and extract `mediaId`.
     - **Step 2 (Image-to-Video)**: Submits `start_image_media_id` to `POST /api/flow/generate-video` with `user_paygate_tier="PAYGATE_TIER_FREE"` and `model_family="veo"`.
   - Verified live: Generates 720x1280 8.0s (192 frames @ 24fps) 4.5 MB MP4 in ~45-55s total with **0 credit consumption**.
2. **Chrome Extension Multi-Account Routing Fix:**
   - Identified silent failure (`0 envelopes`) when Google Flow users are on multi-account profiles (`/u/3/`).
   - Patched `P:\AI\The Viral\FlowKit\extension\background.js` to preserve and prepend the `/u/\d+/` prefix to all batchexecute RPC URLs.
3. **Robust Status Polling & Wire Schema Alignment:**
   - Aligned response parsing with actual FlowKit batch RPC wire data:
     - Veo operations return CDN URL in `operation.metadata.video.fifeUrl` under status `MEDIA_GENERATION_STATUS_SUCCESSFUL`.
     - Omni workflows return in `workflows[].media.url` / `encoded_video_url`.
4. **Atomic Download Safety (`.part` Pattern):**
   - Video downloads now stream to `<filename>.part` first.
   - Upon successful download and size verification, it atomically renames via `os.replace` to `<filename>.mp4`, preventing downstream tools (Step 08) from reading incomplete files.
5. **Quality Gate Enforcement in Step 08 (`08-footage-assembler.py`):**
   - Updated `08-footage-assembler.py` to inspect `intermediates/broll_qa_manifest.json`.
   - If a clip failed L1 QA (`l1_passed: false`), Step 08 explicitly skips it and logs a warning instead of blindly injecting corrupted footage onto Track 2.
6. **Structured Prompt Contract in Step 07c (`07c-broll-prompt.py`):**
   - Step 07c now outputs a structured `broll_prompts.json` mapping `scene_id -> prompt` alongside `scene_table.md`.
7. **Readiness Verification in Finish CLI (`run_finish.py`):**
   - `run_finish.py` checks for pending B-Roll before executing Step 08.
   - Added `--generate-broll` flag to automatically run Step 07d ahead of assembly if needed.
8. **Channel Configuration Updated (`doctorbank.yaml`):**
   - Set `broll.model: "veo3.1"`, `broll.priority: "low"`, and `flow_project_id: "853a1b94-e647-4a28-b4ea-818053159000"`.

## 📜 2. Architecture Decision Record (ADR)

### 📌 ADR-01: Primary Model Selection — Veo 3.1 Lite Low Priority (0 Credits)
- **Decision:** กำหนดให้ **`veo_3_1_i2v_lite_low_priority`** เป็นโมเดลหลักเริ่มต้น (Default Production Engine) ผ่านระบบ **Automated 2-Step Orchestration (T2I -> I2V)** โดยรองรับ `omni_flash` เป็น Secondary Alternative ผ่าน `--model omni_flash`
- **Rationale & Live Evidence:**
  1. **Zero Cost**: โมเดล Lite Low Priority ใช้ **0 Credits** (`PAYGATE_TIER_FREE`) ทำให้สเกลการผลิตได้ไม่จำกัดค่าใช้จ่าย
  2. **Superior Visual Fidelity**: ภาพที่ได้จาก Veo 3.1 ผ่านการทดสอบซีน S02 (Bone Density) ให้ผลลัพธ์เป็น 3D Organic Microscopic สวยงาม สมจริง และคมชัดกว่า T2V ปกติมาก
  3. **Acceptable Latency**: ใช้เวลา Step 1 (~15s) + Step 2 (~30s) รวม ~45-55s ต่อคลิป 8.0s ซึ่งรับได้ใน Background Pipeline
- **Consequences:** Pipeline ต้องจัดการ State 2 ขั้นตอนอย่างโปร่งใส และจัดการเก็บ Image Anchor ชั่วคราว

### 📌 ADR-02: L2 QA Gating Architecture
- **Decision:** ให้ `07d` ทำงานแบบ Deterministic L1 (OpenCV) -> สร้าง `broll_qa_manifest.json` + Keyframes -> ส่งสัญญาณ Exit 100 (PAUSE) เพื่อให้ AG Agent (Gemini 3.8 Flash High) ตรวจ L2 Vision -> บันทึก `broll_l2_verdict.json` ก่อนปล่อยให้ Step 08 ดึงไปประกอบ
- **Consequences:** คุณภาพผ่านการตรวจ 2 ชั้น (เชิงเทคนิค + เชิงสายตา) ไม่มีคลิปผิดสเปกหลุดไป CapCut

### 1. Veo 3.1 2-Step Contract (Live Verified)
- **Step 1 (T2I)**: `POST /api/flow/generate-image`
  - Body: `{"prompt": str, "project_id": str, "aspect_ratio": "IMAGE_ASPECT_RATIO_PORTRAIT", "user_paygate_tier": "PAYGATE_TIER_FREE"}`
  - Response: `{"media": [{"name": "<MEDIA_ID>", "image": {"generatedImage": {"mediaId": "<MEDIA_ID>", "fifeUrl": "<CDN_URL>"}}}]}`
- **Step 2 (I2V)**: `POST /api/flow/generate-video`
  - Body: `{"start_image_media_id": "<MEDIA_ID>", "prompt": str, "project_id": str, "scene_id": str, "aspect_ratio": "VIDEO_ASPECT_RATIO_PORTRAIT", "model_family": "veo", "duration_s": 8, "user_paygate_tier": "PAYGATE_TIER_FREE"}`
  - Response: `{"operations": [{"operation": {"name": "<OP_ID>"}, "status": "MEDIA_GENERATION_STATUS_PENDING"}]}`
- **Step 3 (Polling)**: `POST /api/flow/check-status`
  - Body: `{"operations": [{"operation": {"name": "<OP_ID>"}}]}`
  - Success Response: `{"operations": [{"operation": {"metadata": {"video": {"fifeUrl": "<CDN_URL>"}}}, "status": "MEDIA_GENERATION_STATUS_SUCCESSFUL"}]}`
