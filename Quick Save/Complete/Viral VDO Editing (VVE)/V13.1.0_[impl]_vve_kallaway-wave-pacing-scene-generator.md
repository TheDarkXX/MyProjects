# VVE Kallaway Wave Pacing & Idempotent Path Fixes

## 📌 Context (Compiled Truth)
The Viral VDO Editing (VVE) pipeline (`05-word-segment`, `06-generate-srt`, `07-scene-generator`) previously failed due to hardcoded/incorrect path handling when passed a project name ("Test Auto") instead of a full absolute path.
1. **Idempotent Path Resolution (`capcut_utils.py`)**: All scripts now uniformly use `get_project_path(sys.argv[1])` to resolve CapCut directories securely, preventing `FileNotFoundError`.
2. **Kallaway Wave Pacing (`07-scene-generator.py`)**: We implemented "Controlled Volatility" (Wave Pacing) inspired by Top TikToker Kane Kallaway. Instead of generating AI B-Roll for every scene (which causes visual fatigue), `07` now automatically assigns a `Visual Type` based on an alternating pattern: `A-Roll -> B-Roll -> B-Roll -> A-Roll`.
   - **A-Roll**: Main clip (Face) for Authority/Intimacy. AI is explicitly instructed to skip these rows in the TSV.
   - **B-Roll**: AI Generated for Proof/Novelty.
