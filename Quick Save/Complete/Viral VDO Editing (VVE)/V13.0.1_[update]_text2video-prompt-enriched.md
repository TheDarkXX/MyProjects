# VVE v13 Patch: Text-to-Video Prompt Enrichment

## 📌 Context (Compiled Truth)
Following the initial V13.0.0 release, a side-by-side comparison between the original `image+motion.yaml` and the new `text2video.yaml` revealed that the text-to-video prompts lacked critical descriptive detail (quality tags, nuanced background descriptors, mood, and explicit forbidden parameters).

This update brings the `doctorbank_broll_text2video.yaml` up to parity with the legacy image+motion generator by enforcing comprehensive rules for every single AI generation. 

**Key Enhancements in the YAML:**
1. **Mandatory Quality Tags:** Injected tags like `8K`, `cinematic`, `Unreal Engine 5`, and `extremely detailed textures` depending on the category.
2. **Explicit Character Constraints:** Added descriptors like `clean sleepwear`, `casual comfortable activewear`, and `well-groomed` to avoid generic stock AI appearances.
3. **Deep Context Backgrounds:** Replaced generic "clean setting" with nuanced locations like `clean modern Thai condo bedroom` or `marble surface`.
4. **Cinematography Directives:** Added explicit lens instructions like `rack focus shift`, `volumetric light rays`, and `cinematic shallow depth of field`.
5. **Length constraints:** Added a strict system rule to reject overly short prompts (`Prompt ที่สั้นเกินไป (น้อยกว่า 3 บรรทัด) — ต้องละเอียดเสมอ`).

## 🔬 Timeline & Debugging Log
- **Update 1:** Evaluated 4 test generations across Categories A, B, C, and D. Identified output brevity compared to the image-centric legacy system.
- **Update 2:** Rewrote all 8 categories inside `channels/doctorbank_broll_text2video.yaml` to ensure minimum prompt lengths of 4-6 lines and inclusion of high-fidelity cinematic keywords.
