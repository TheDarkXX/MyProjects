# VVE: Perfecting Silence Cut with TimeBolt Parameters

## 📌 Context (Compiled Truth)
The user was experiencing issues with the initial silence cut (`01b-silence-cut.py`) where cuts were either missing small gaps, cutting mid-word, or leaving too much trailing silence. 
We refined the Silero VAD parameters to perfectly mimic TimeBolt:
- **Remove Silences Longer Than:** 150ms (`min_silence_duration_ms = 150`)
- **Ignore Detections Shorter Than:** 100ms (`min_speech_duration_ms = 100`)
- **Threshold:** 0.5 (Standard, preventing trailing breaths from being detected as speech)
- **Pre-padding (Left):** 0.08s
- **Post-padding (Right):** 0.0s (to keep cuts snappy without trailing gaps)

**Important Rule Added (`AGENTS.md`):** We also implemented a strict project-level rule to **never auto-run `03-transcribe.py`** or other API-billing scripts after tweaking `01b`. We must wait for the user to verify the CapCut timeline first to prevent wasting ElevenLabs API credits.
