# VVE Auto B-Roll Generator & FlowKit Pipeline (07d)

## 📌 Context & Implementation (Compiled Truth)
The user identified a major operational bottleneck in the Viral VDO Editing (VVE) Pipeline between stage `07c` (B-Roll prompt generation) and `08` (Footage Assembler). Previously, generating B-Roll required a human-in-the-loop step where prompts were manually copied to Google Flow/FlowKit, rendered, downloaded, and renamed to `[Sxx]_*.mp4` in the project's Footage directory.

### Key Architectural Decisions:
1. **FlowKit Direct HTTP API Integration:**
   - Switched from relying on an outdated Drive P Python environment to calling FlowKit's REST API directly (`http://127.0.0.1:8100`) via Python standard `urllib`.
   - Supports Veo 3.1 (`model_family="veo"`) and Gemini Omni Flash (`"omni_flash"`) on Google Flow's free/low-priority tier (0 credit cost).
2. **Deterministic L1 QA (OpenCV-Powered):**
   - Independent of external system `ffmpeg` binaries.
   - Checks file size (> 100 KB), video duration, and frame dimensions.
   - Runs black-frame detection (`mean_brightness > 8.0`) and freeze-frame detection (`absdiff.mean() > 2.0`).
   - Extracts 3 keyframes at 15%, 50%, and 85% timestamps into `intermediates/qa_frames/`.
3. **Native AG IDE L2 Vision Judge:**
   - Instead of requiring an external `google-genai` pip package and separate API key, the script outputs a structured `broll_qa_manifest.json` and keyframe list.
   - The Antigravity Agent (Gemini 3.8 Flash High) acts as the Multimodal Vision Judge directly inside the IDE pair-programming loop using native `view_file` capabilities.
4. **Viral Video Aspect Ratio Strategy:**
   - Defaulted to **9:16 (Full-screen Vertical Cutaway)**: In talking-head channels like DoctorBank, 9:16 B-Roll cutaways provide critical pattern interrupts (resetting viewer attention every 3–4s) and seamlessly hide jump cuts.
   - Configurable for **16:9** (for split-screen mode with doctor speaking below) via `channels/doctorbank.yaml` or `--aspect-ratio 16:9` CLI parameter.
5. **FlowKit Offline Protection:**
   - Returns exit code 100 (`PAUSE`) with troubleshooting instructions when FlowKit is offline, allowing `pipeline.py` to pause cleanly without crashing.
   - Includes `--dry-run` mode for pipeline verification without server connectivity.
6. **Path Resolution Failsafes:**
   - Made `CAPCUT_PROJECTS_ROOT` dynamic to detect current user profile (`The Dark`) or fallback to `Admin`.
   - Fixed `config_loader.py` root resolution so `channels/` is always loaded accurately.
