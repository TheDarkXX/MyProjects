# CapCut CLI Integration & Subtitle Injector Fix

## 📌 Context (Compiled Truth)
- Transitioned away from manual modification of `draft_content.json` which resulted in duplicate layers and errors, to using `capcut-cli` for stable operations.
- CapCut CLI natively validates JSON structure and handles standard CapCut tasks via commands like `add-text`, `import-srt`, `add-audio`, etc.
- Identified that CapCut 8.8.0 actually uses `template-2.tmp` as the canonical file instead of `draft_content.json`, meaning our manual edits were being ignored by CapCut.
- Created `capcut_injector_v4.py` which translates `editorial_result.json` subtitles into a standard SRT file and uses `capcut-cli import-srt` to inject them natively into the CapCut timeline.
- **Critical Requirement:** CapCut must be closed completely before any modification, as it actively locks the draft files.
- **Transcription Engine Switch:** Replaced Whisper with ElevenLabs Scribe v2 for Thai transcription due to Whisper's translation hallucinations and lack of per-character timing.
- **Zero-Overlap Subtitles:** Implemented `word_segment.py` (using `pythainlp/nlpo3`) and `generate_srt.py` to chunk subtitles into 10-15 character blocks. Enforced strict zero-overlap (subtracting 1ms from end times that touch the next start time) to prevent CapCut's 10-layer track inflation bug.
- **Workspace Architecture:** Re-architected `C:\My Claw\MyProjects\Quick Save` from a global symlink into an isolated folder containing discrete symlinks only for projects actually inside `MyProjects` (`DoctorBank-Band`, `HyperCut`, `VVE`).

# Implementation Plan
# Switch Transcription Engine to ElevenLabs Scribe v2

This plan replaces Whisper with ElevenLabs Scribe v2 for Thai video transcription in the VVE workflow, replicating the `bizdrive-video-workflow` standard. It addresses the CapCut multiple-layer issue by enforcing strict zero-overlap timings.

## Design Decisions
- **Character-based Grouping**: As per user feedback, subtitles will be grouped to a target of **10-15 characters** instead of word counts. This ensures consistent text width on vertical screens.
- **Cost**: ElevenLabs STT is $0.39/hour ($0.0065/minute). OpenAI Whisper API is $0.36/hour ($0.006/minute). The price is virtually identical, but ElevenLabs provides the crucial per-character timing needed for Thai.

## Proposed Changes

### VVE Scripts Layer
We will introduce the transcription toolchain directly into the VVE project directory.

#### [NEW] transcribe_elevenlabs.py
- A streamlined Python script to extract audio via `ffmpeg`, call the `ElevenLabs Scribe v2 API`, and save the raw character-level timestamps to a JSON file.

#### [NEW] word_segment.py
- Reconstructs the character-level JSON.
- Groups text by **characters (10-15 chars per phrase)**, cleanly splitting at natural word boundaries using `nlpo3` so words aren't cut in half.

#### [NEW] generate_srt.py
- Takes the grouped JSON and generates a standard `.srt` file.
- **Zero-Overlap Logic**: Modifies timestamps to ensure consecutive subtitles do not touch, preventing CapCut from creating multiple text tracks.

# Walkthrough: VVE ElevenLabs Subtitle Pipeline

I have successfully replaced the Whisper transcription pipeline with an **ElevenLabs Scribe v2** integration, specifically optimized for Thai character timing and CapCut compatibility.

## Changes Made

### 1. ElevenLabs API Integration
- Created `transcribe_elevenlabs.py` to handle audio extraction (16kHz mono WAV) and API communication with `https://api.elevenlabs.io/v1/speech-to-text`.
- The script uses `ELEVENLABS_API_KEY` from your `.env` or system environment variables.
- It returns **per-character timestamps**, which is critical for syncing Thai subtitles accurately.

### 2. Thai Word Segmentation & Grouping
- Installed `pythainlp` and `nlpo3` for ultra-fast, accurate Thai NLP tokenization.
- Created `word_segment.py` which takes the character-level JSON and chunks it into natural Thai phrases based on your requested length (~10-15 characters).

### 3. Zero-Overlap SRT Generation
- Created `generate_srt.py` to fix the notorious CapCut "10+ layer" bug.
- **How it works:** If a phrase ends at `00:00:01,700` and the next phrase starts at `00:00:01,700`, the script mathematically trims the first phrase to `00:00:01,699`. 
- This guarantees **absolute zero overlap**, tricking CapCut into rendering the entire SRT within a **single subtitle track**.
