# [Sysclean] Drive C Reclamation

## 📌 Context (Compiled Truth)
The user initiated the session intending to start the **Folder Manager** web app project but was completely blocked by critical low disk space on Drive C (initially 0.76 GB free out of 231.8 GB). We executed a massive, multi-phase system cleanup to reclaim space safely without breaking applications or losing browser profiles.

The Drive C free space was successfully restored from **0.76 GB to 57 GB**. 
The cleanup was executed with surgical precision targeting deep caches, temp files, and old versions left behind by application installers.

### Cleanup Breakdown
1. **Initial Temp/Cache Flush**: Cleared `C:\Users\The Dark\AppData\Local\Temp`, NPM cache, Recycle Bin, and simple proxy caches. (Freed ~14 GB).
2. **Deep Cache Hunt**: Scanned for hidden AppData bloat. Targeted specific unneeded components:
   - Leftover NVIDIA Downloader installer cache.
   - Deep browser caches (`Code Cache`, `Cache`, `GPUCache`, `Service Worker/CacheStorage`) for Sidekick and WaveboxApp. 
   - *Safeguard Note: We intentionally did NOT delete `User Data` wholesale to protect passwords, extensions, and bookmarks.*
3. **Hibernate Fix**: Found `hiberfil.sys` taking 4.76 GB. Since the user doesn't use Hibernate, executed `powercfg.exe /hibernate off` to instantly reclaim 4.8 GB.
4. **Targeted Bloat Eradication (Specific Requests)**:
   - CapCut Drafts/Temp/Proxy (`AppData\Local\CapCut\Videos\Proxy` and `Cache`).
   - Dropbox `.dropbox.cache`.
   - Microsoft Edge deep cache.
   - Windows Store Apps (`Packages`) `LocalCache` and `INetCache`.
   - *This surgical wipe reclaimed 3.21 GB without breaking the actual software.*
5. **App Version Hoarding Wipe**: Identified several applications hoarding old versions (gigabytes of dead weight):
   - CapCut `8.0.1.3366` (1.52 GB).
   - Package Cache (Installers).
   - Logseq `app-0.10.14`.
   - Discord `app-1.0.9250`, etc.
   - Wiped these old version directories and cleaned up 14 orphaned empty folders. (Freed ~3.9 GB).

### Remaining Large Footprints (Identified, but untouched per user boundaries)
The user halted further cleanup, recognizing that remaining space sinks are legitimate data or installed applications that require manual decision-making:
- **Google Drive (`serveravatar`)**: Contains 2021-2022 backup `.tar`/`.sql` files totaling **21.5 GB**.
- **Desktop / Downloads**: ~9.3 GB and ~8 GB respectively.
- **Heavy Software (`Program Files`)**: Adobe (13.3 GB), Visual Studio (6 GB).
- **Massive AppData Storage**: `AppData\Local` holds ~50 GB (mostly Google, Wavebox, Sidekick active profiles, CapCut main projects, and LINE chat history).
