# AirKeys UI Overhaul & Rebranding (P1-P4)

## 📌 Context (Compiled Truth)
- Project formally evaluated as "OpenPud" and decided to rebrand as **AirKeys**.
- We overhauled the UI to make it a premium desktop app (Arc/Linear/Raycast style) using Glassmorphism, Inter font, custom scrollbars, and a deep dark theme.
- **Architectural Cleanup**: Fixed critical listener memory leaks (`history.ts`), deduplicated `escapeHtml` into `src/utils.ts`, and merged redundant `closeToTray` logic.
- **Packaging**: Packaged as a portable EXE using `electron-builder` (`target: "portable"`) and created an accessible `AirKeys.bat` desktop shortcut.
- **UI Redesign**:
  - Re-architected Dictionary into multi-tabs (System, Custom Corrections, Auto-Tune Logs).
  - History redesigned to use a Timeline UI with integrated search functionality.
  - Settings completely restructured into categorical grid layouts.
- **Recheck Passed**: Replaced risky fallback emojis (⏳✅❌) with safe Lucide-style SVG icons to prevent blank box rendering issues on Windows.

## Part A: 🐛 Bugs & Inconsistencies (ต้องแก้ก่อน)

### A1. Legacy Name "OpenPud" ยังหลงเหลือ
- self-improving/memory.md — Title ยังเป็น `# OpenPud`
- self-improving/corrections.md — Title ยังเป็น `# OpenPud`
- AGENT_CONTEXT.md — น่าจะยังเป็น OpenPud
- โฟลเดอร์โปรเจกต์ยังชื่อ `OpenPud` (ไม่ใช่ AirKeys) — อาจจะ rename ได้ถ้ามึงต้องการ

### A2. `closeToTray` กับ `showOnTaskbar` Logic ซ้ำซ้อน
- `showOnTaskbar` กับ `closeToTray` ทำงานคล้ายกันมาก — `mainWindow.on('minimize')` ยังอิง `showOnTaskbar` แต่ `mainWindow.on('close')` ตอนนี้อิง `closeToTray` แล้ว ถ้า user ไม่ติ๊ก `showOnTaskbar` แต่ติ๊ก `closeToTray` จะเกิดพฤติกรรมแปลกๆ ได้
- **แก้:** Merge เป็น dropdown เดียว: "เมื่อกดปิดหน้าต่าง" → `ซ่อนลง Tray` / `ปิดแอปทันที`

### A3. `onHistoryUpdated` Listener Leak
- history.ts:57 — `window.typeless.onHistoryUpdated(render)` ถูกเรียกทุกครั้งที่ `mountHistory()` ถูก mount แต่ไม่เคย cleanup เมื่อเปลี่ยนหน้า → ทุกครั้งที่ navigate ไป History แล้วกลับมาอีกที listener จะถูกเพิ่มซ้ำ

### A4. Dictionary Error Recovery ผิดสี
- dictionary.ts:187-189 — `classList.replace("border-emerald-200",...)` ใช้ class ที่ไม่มีอยู่จริงในตัว element (element ใช้ `border-indigo-500/30`) → Error case จะไม่เปลี่ยนสี

### A5. `escapeHtml` ซ้ำ 2 วิธี
- home.ts:5-12 ใช้ regex replace
- history.ts:61-65 ใช้ DOM `.textContent`
- ควรรวมเป็น utility เดียวใน `src/utils.ts`

## Part B: ⚡ Optimize & Improve (ทำให้ดีขึ้น)

### B1. Startup Performance — Cold Start ช้า
- `getForegroundProcessName()` และ `sendCtrlV()` ทั้งคู่ spawn `powershell.exe` ทุกครั้ง → PS startup ~300-500ms
- **แก้:** เปลี่ยนไปใช้ `pwsh` (PowerShell Core) ถ้ามี หรือดีกว่านั้นคือเขียน compiled C# helper `.exe` ตัวเล็กๆ (หรือใช้ `ffi-napi` เรียก Win32 API ตรงๆ ถ้า native module ทำได้)

### B2. Clipboard Restore Race Condition
- pasteText.ts:61 — `delay(300)` เป็น magic number — บางแอปที่หนัก (Word, Teams) อาจยังไม่ทัน consume paste ก่อนที่ clipboard จะถูก restore → ข้อความหาย
- **แก้:** Poll clipboard ทุก 50ms (สูงสุด 500ms) ถ้า clipboard ยังเป็นข้อความเดิม = ยังไม่ถูก consume

### B3. Auto-Tune ไม่ Retry เมื่อ API Fail
- ถ้า LLM fail ระหว่าง auto-tune, entries จะไม่ถูก mark as tuned (ดี) แต่ก็ไม่มีกลไก retry — ครั้งถัดไปมันจะลอง entries ชุดเดิมอีกที (ก็ดี) **แต่** ถ้า API ตาย permanent (key หมดเงิน) มันจะพยายาม auto-tune ทุกครั้งที่ transcribe ซึ่งเปลือง
- **แก้:** Exponential backoff — หลัง fail ต่อเนื่อง 3 ครั้ง รอ 1 ชั่วโมงก่อน retry

### B4. History ไม่มี Search/Filter
- หน้า History แค่ render ทุก entry แบบ flat list — พอมี 100+ entries จะ scroll ยาวมาก
- **แก้:** เพิ่ม search box + pagination/virtual scroll

### B5. Widget ไม่ Show Error State
- ถ้า transcription fail, widget กลับไปเป็น idle เฉยๆ — user ไม่รู้ว่าพัง
- **แก้:** เพิ่ม `error` state ให้ widget แสดงข้อความ error สั้นๆ 3 วินาทีแล้วค่อย fade กลับ idle

### B6. Export/Import Settings & Dictionary
- ไม่มีทางให้ user backup/restore config ข้ามเครื่อง
- **แก้:** ปุ่ม Export (ดาวน์โหลด JSON) และ Import (อัปโหลด JSON) ในหน้า Settings

### C4. Usage Stats Dashboard (เสริม)
- ตอนนี้ Home แสดงแค่ 4 สถิติพื้นฐาน
- **แก้:** เพิ่ม daily usage chart (7 วันย้อนหลัง), streak counter, ภาษาที่ใช้บ่อยสุด

## Part D: 🎨 UI Modernization (ยกระดับ Top-Tier)

> [!IMPORTANT]
> ส่วนนี้คือหัวใจของ Request — ปรับ UI จาก "functional dark theme" ให้กลายเป็น **premium desktop app** ระดับ Arc Browser / Linear / Raycast

### D1. Typography System
- ตอนนี้ใช้ `Segoe UI` เป็น body + `JetBrains Mono` เป็น numbers
- **แก้:** เปลี่ยน body เป็น **Inter** (Google Fonts) — มาตรฐาน premium app + ยังคง JetBrains Mono สำหรับตัวเลข/code
- เพิ่ม `font-feature-settings: 'cv02', 'cv03', 'cv04'` สำหรับ Inter ให้ดู cleaner

### D2. Sidebar Redesign
- ตอนนี้ sidebar ดู flat เกินไป — ไม่มี depth, ไม่มี visual hierarchy
- **แก้:**
  - เพิ่ม **User Avatar / App Logo area** ด้านบนพร้อม subtle gradient glow
  - Nav items: ปรับเป็น pill-shaped active indicator (แถบสีม่วงเล็กๆ ด้านซ้ายแทนที่จะเป็น bg สีจาง)
  - เพิ่ม **quick action buttons** ที่ก้น sidebar (เช่น Dictate / Translate ปุ่มลัด)
  - Divider ระหว่าง sections ใช้ gradient fade แทนเส้นตรง

### D3. Dashboard (Home) — Hero Card Upgrade
- ตอนนี้ hero banner ดู generic — glows ใหญ่เกินไป, stat layout แน่นเกินไปบนหน้าจอเล็ก
- **แก้:**
  - Stats ทำเป็น **individual glass cards** (glassmorphism: `backdrop-blur-xl bg-white/[0.03] border border-white/[0.06]`) แทนที่จะอยู่ใน banner เดียวกัน
  - แต่ละ card มี icon + subtle animated gradient border on hover
  - เพิ่ม **"Quick Start" section** — ปุ่มกด Dictate/Translate ขนาดใหญ่ พร้อม hotkey badge (แทนที่จะต้องไปจำ hotkey เอง)

### D4. History Page — Timeline Design
- ตอนนี้เป็น flat list ของ cards ธรรมดา
- **แก้:**
  - เพิ่ม **date group headers** ("วันนี้", "เมื่อวาน", "23 ส.ค.")
  - Timeline line ด้านซ้าย (vertical line + dot per entry) ให้ดูเป็น timeline จริง
  - Expandable entries — กดแล้ว expand เห็นเต็ม + metadata (duration, word count, provider)
  - Copy animation: ripple effect เมื่อกด copy

### D5. Settings Page — Segmented Layout
- ตอนนี้เป็น long scrollable form ที่ดู overwhelming
- **แก้:**
  - แบ่งเป็น **sections** พร้อม heading cards:
    - 🔌 **Connection** (Provider, API Key, Base URL)
    - 🎤 **Voice** (Model, Language, Mic, Duration, Fillers)
    - 🤖 **AI** (Chat Model, Auto-Tune Model, Polish, Threshold)
    - 🔥 **Hotkeys** (Dictate, Translate)
    - ⚙️ **App** (Startup, Taskbar, Close behavior, Sound)
  - แต่ละ section เป็น collapsible card with smooth animation
  - API Key field: เพิ่ม "Test Connection" button ที่ ping API แล้วแสดง ✅/❌

### D6. Dictionary Page — Better Visual Hierarchy
- ตอนนี้ 3 sections (Dictionary, Corrections, Auto-Tune Log) ซ้อนกันยาว
- **แก้:**
  - ใช้ **Tab bar** ด้านบน: `Dictionary` | `Corrections` | `Auto-Tune Log`
  - Dictionary chips: เพิ่ม drag-to-reorder + batch delete mode
  - Corrections: table view ที่สวยกว่า พร้อม inline edit

### D7. Micro-Animations & Polish
- `transition-colors` ที่ใช้อยู่ดู basic เกิน
- **แก้:**
  - Page transitions: `opacity + translateY` fade-in เมื่อเปลี่ยนหน้า
  - Button press: `active:scale-[0.97]` + subtle shadow change
  - Stat numbers: **count-up animation** เมื่อ Dashboard load (0 → 142 words)
  - Nav active state: smooth pill slide animation ตามตำแหน่ง active item
  - Skeleton loading: แสดง shimmer placeholder ขณะ fetch data

### D8. Custom Scrollbar
- ไม่มี custom scrollbar — ใช้ default Windows scrollbar ที่ดูหนาและเทา
- **แก้:** เพิ่ม CSS custom scrollbar: thin, semi-transparent, glow on hover

### D9. Custom App Icon & Tray Icon
- ตอนนี้ใช้ default Electron icon + tray icon เป็น base64 สี่เหลี่ยมสีม่วงเล็กๆ
- **แก้:** ออกแบบ AirKeys logo icon ใหม่ (keyboard + air/wave motif) → ใส่เป็น `icon.ico` ใน build config + ปรับ tray icon ให้สวยขึ้น

# 🔬 Dev Proposal Review: OpenPud

**Source:** [github.com/gotzastory/OpenPud](https://github.com/gotzastory/OpenPud)
**Author:** gotzastory
**Version:** 0.1.1
**Stack:** Electron 43 + TypeScript + Vite 8 + Tailwind CSS v4
**Review Date:** 2026-08-23

---

## Quick Summary

**OpenPud** — โปรแกรม Windows desktop แปลงเสียงพูดเป็นข้อความ (Speech-to-Text) แบบ system-wide hotkey คล้าย Typeless:

- กดปุ่มลัด → พูด → ปล่อยปุ่ม → ข้อความถูก paste ตรง cursor ของแอปที่กำลังใช้อยู่
- รองรับ OpenRouter / OpenAI / Gemini เป็น STT backend
- มี AI polish (ขัดประโยค) + Translate mode
- Floating pill widget ไม่แย่ง focus
- Dictionary + Correction rules สำหรับศัพท์เฉพาะ
- History 500 รายการ
- เก็บข้อมูลทั้งหมด local (electron-store), API key เข้ารหัส DPAPI

| Dimension | Score | Reasoning |
|---|---|---|

## ข้อดี / ข้อเสีย

### ✅ ข้อดี

1. **UX ออกแบบมาดี** — Floating pill ไม่แย่ง focus, keyboard-driven ทั้งหมด, hotkey binding แบบกดจริง ไม่ต้องจำ syntax
2. **Multi-provider** — OpenRouter คีย์เดียวใช้ได้ทั้ง STT + Chat, รองรับ Gemini native API ด้วย, หรือ self-host whisper.cpp ก็ได้
3. **Dictionary + Correction rules** — แก้ปัญหาชื่อเฉพาะ/ศัพท์เทคนิคที่ STT มักถอดผิด ฉลาดดี
4. **Privacy-first** — ข้อมูลทั้งหมดอยู่ local, API key เข้ารหัส DPAPI, ไม่มี telemetry ส่งกลับ
5. **Architecture สะอาด** — Context isolation, preload bridge, แยก main/renderer ชัดเจน, TypeScript strict
6. **เขียนเป็นภาษาไทย** — README, UI, onboarding ภาษาไทยทั้งหมด เหมาะกับ user base ของเรา
7. **ติดตั้งง่าย** — NSIS installer, ไม่ต้อง admin, ไม่ต้อง Node.js
8. **Default model ดี** — `whisper-large-v3-turbo` + `gemini-3.5-flash-lite` คือ combo ที่ performance/cost ratio ดีมาก

### ❌ ข้อเสีย

1. **ไม่มี License** — ยังไม่ระบุ license อย่างเป็นทางการ. ถ้าจะ fork/modify ต้องถามเจ้าของก่อน
2. **ไม่มี test/lint** — No test setup, no linting. ถ้าจะ contribute หรือ fork ต่อ ต้อง invest เพิ่ม
3. **Windows only** — ไม่รองรับ macOS/Linux. ถ้าเปลี่ยน OS ต้องหาทางเลือกอื่น
4. **Version 0.1.1** — Early stage, อาจมี bug ที่ยังไม่เจอ, API อาจเปลี่ยนเยอะ
5. **ไม่มี plugin/extension system** — ถ้าอยากต่อ custom pipeline (เช่น dictate → auto-create task ใน Planner) ต้อง fork แก้
6. **Paste ใช้ Ctrl+V ผ่าน clipboard** — มี edge case ที่บาง app อาจ override clipboard หรือ block synthetic paste
7. **ไม่มี API/webhook output** — ไม่สามารถ pipe transcription ไปที่อื่นได้ (เช่น log to file, send to server)
