### สมการคำนวณค่าคอมมิชชั่นและภาษี (Data & Financial Logic)
1. **Base Commission (ติดเพดาน Cap):** `min(Price * (BaseRate / 100), CapTHB)` (ค่าเริ่มต้น Cap 250 บาทต่อชิ้นสำหรับ Shopee)
2. **Extra / Brand Commission (ไม่ติดเพดาน):** `Price * (ExtraRate / 100)`
3. **Gross & Net Commission:** `Gross = Base + Extra` และหักภาษี ณ ที่จ่าย (WHT 3%) เหลือ `Net = Gross * (1 - WHT/100)`
4. **Facebook Ads Spend + VAT 7%:** `NetSpend = RawSpend * 1.07` บันทึกลง `pnlLedger` พร้อม `dedupKey` ป้องกันการกดซิงก์ซ้ำในวันและแคมเปญเดียวกัน
5. **Affiliate Redirect Builder:**
   - Shopee: `https://s.shopee.co.th/an_redir?origin_link=<clean_url>&affiliate_id=<id>&sub_id=<sub1-sub2-sub3>`
   - Lazada: แนบพารามิเตอร์ `aff_id`, `sub_aff_id` และ `sub_id1..3` บน Clean URL
