  - `seller_commission_detail.default_exist_commission_rate` (**EXTRACOMM**)

  - แยก `live_streaming_default_exist_commission_rate` ออกไปแสดงเป็น Metadata อ้างอิงเท่านั้น ห้ามนำไปคำนวณรวม

  - รองรับ fallback URL parsing ใน `sidepanel.js` แม้ content script บนแท็บเดิมยังไม่รีเฟรช
