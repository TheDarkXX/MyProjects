# [SEC] Facebook Account Integrity Incident & Stealth Content Policy Audit

## 📌 Context & Implementation (Compiled Truth)
- **Incident Overview:** หลังจากการเผยแพร่ EP.01 ของ The CEO Unfiltered บัญชีส่วนตัวหลัก (Anocha Pardon) ซึ่งเป็นแอดมินเพจ ถูกระงับการใช้งานชั่วคราวและขึ้นหน้าจอ `Confirm you're human to use your account` พร้อมตัวเลขนับถอยหลัง 180 วัน บังคับถ่าย 3D Video Selfie สแกนใบหน้า
- **Root Cause Analysis (RCA):**
  1. **Primary Trigger — Account Integrity & Bot Shield:** ไม่ได้เกิดจากเนื้อหาถูกรีพอร์ตหรือแบนเรื่องคำหยาบโดยตรง (ไม่มีอีเมลแจ้งเตือน Community Standards) แต่เกิดจากสคริปต์ `ceoupload.py` ทำการเรียก Meta Graph API (`graph.facebook.com/v25.0`) ผ่าน Python `requests` โดยใช้ Page Token ที่ผูกกับ User Token จากเครื่อง Local ส่งผลให้ระบบตรวจจับพฤติกรรมอัตโนมัติ (Anti-Automation / Anti-Scraping Shield) สงสัยว่าเป็น Infostealer Malware หรือ Unauthorized Botnet ควบคุมบัญชี
  2. **Page-Admin Coupling:** เพจเพิ่งสร้างใหม่มี Trust Score เป็น 0 และมีแอดมินคนเดียว การยิง API อัตโนมัติส่งผลให้ระบบระงับแอดมินเพื่อกักกันโรคทันที
  3. **Content Red Flags Audit (EP.01 & Drafts):** ตรวจพบคำสุ่มเสี่ยงระดับ Tier-1 ใน `EP01_self_help_habits.md` เช่น `ตบกะโหลก` (Violence & Incitement), `จุกสัส` (Profanity Tier-1), `หลอกแดกเงินคนขี้แพ้` (Harassment/Bullying) ซึ่งหากถูกสแกนในรอบสองจะโดนฟันซ้ำ
- **Resolution & Account Recovery:**
  - ยื่น 3D Video Selfie ยืนยันตัวตนสำเร็จ ระบบ Meta ปลดล็อกคืนบัญชี (`You're back on Facebook - Community Standards on account integrity`)
  - ติดโทษกักบริเวณชั่วคราว 24 ชั่วโมง: `You can't create multiple sessions` (หมดโทษ Oct 4, 2026) ป้องกันการล็อกอินซ้อนหรือเชื่อมต่อ 3rd party tools
- **Architectural Safeguards:**
  - แช่แข็งการรัน `ceoupload.py` ผ่าน Graph API จาก Local อย่างน้อย 7-14 วัน
  - เปลี่ยนผ่านไปสู่การโพสต์ด้วยมือ (Manual Post) ผ่าน Meta Business Suite เพื่อสะสม Human Trust Score
  - จัดทำพจนานุกรมคำหลบบอท (Stealth Content Dictionary) สำหรับ EP.01-EP.03 เช่น แปลง `ตบกะโหลก` เป็น `ตบสติ/ฉีกหน้ากาก`, `จุกสัส` เป็น `โคตรจุก`
