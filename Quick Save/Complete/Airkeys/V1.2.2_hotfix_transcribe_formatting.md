# AirKeys Formatting Hotfix (v1.2.2)

## 📌 Context (Compiled Truth)
- **Problem**: The smart formatting regex (`localSmartFormat`) successfully injected spaces before Thai conjunctions (เช่น " หรือว่า", " แต่ว่า"), but the output on the user's screen was always stripped of these spaces (e.g. "ขี้กากหรือว่าเทพ").
- **Root Cause**: The `stripFillers` function, which runs *after* transcription to remove hesitation words (e.g., "เอ่ออ", "อืมม"), contained a destructive regex `.replace(/([฀-๿])\s+(?=[฀-๿])/gu, '$1')`. This regex indiscriminately collapsed ALL spaces between any two Thai characters, completely neutralizing the smart formatting rules.
- **Solution**: Removed the space-collapsing line from `stripFillers.ts`. The smart formatting regex is now fully effective.
- **Bonus**: Switched the user back to the standard `whisper-large-v3` model instead of the `-turbo` version to improve transcription accuracy on Thai slang and fast speech, while maintaining sub-second latency via Groq's API.
- **Version**: Bumped app version to `1.2.2`.
