# AirKeys NSIS Migration & Startup Fix (v1.2.4)

## 📌 Context (Compiled Truth)
- **Problem**: The AirKeys `portable` build failed to launch at startup reliably because it registered the temporary extracted `%TEMP%` executable with Windows Startup instead of the actual downloaded `.exe`. Additionally, it would pop up the main window directly at startup, which is disruptive.
- **Root Cause**: `app.getPath('exe')` returns the temporary path for portable apps.
- **Solution**:
  - Used `process.env.PORTABLE_EXECUTABLE_FILE` to register the real portable `.exe` path.
  - Added `--hidden` argument to the startup registration.
  - Modified `app.whenReady()` to check for `--hidden` and avoid showing the main window at login.
- **Pivot**: The user requested a "Full Desktop App" experience.
- **Action**: Modified `package.json` to change the build target from `portable` to `nsis`. Set `oneClick: false`, `allowToChangeInstallationDirectory: true`, `createDesktopShortcut: true`, and `createStartMenuShortcut: true`.
- **Result**: Built `AirKeys Setup 1.2.3.exe` (NSIS Installer). History and logs automatically persist via `%APPDATA%` shared `userData` directory.

<details>
<summary>main.ts changes</summary>

```typescript
function applyLaunchAtStartup(enabled: boolean) {
  if (!app.isPackaged) return; // login item registration is unreliable for `electron .` dev launches
  
  // For electron-builder portable targets, the real exe is not app.getPath('exe') (which is in Temp)
  const exePath = process.env.PORTABLE_EXECUTABLE_FILE || app.getPath('exe');
  
  app.setLoginItemSettings({ 
    openAtLogin: enabled,
    path: exePath,
    args: ['--hidden']
  });
}

// In app.whenReady().then():
  // Open main window unless started at login (which passes --hidden)
  if (!process.argv.includes('--hidden')) {
    const initialRoute = getSettings().onboardingCompleted ? '/' : '/onboarding';
    console.log(`[DEBUG] Creating main window with route: ${initialRoute}`);
    createMainWindow(initialRoute);
    console.log('[DEBUG] Main window created.');
  }
```
