# 📈 [impl] Yahoo Finance & Dashboard Integration

## 📌 Context & Implementation (Compiled Truth)
The user noticed that the frontend Dashboard was still displaying empty/mock data ("เมนู setting ทำไมโล่ง ไม่มีอะไรเลย", "ระบบพล็อตกราฟย้อนหลังทำเรียบร้อยแล้วไหม") and asked if the historical graphing system was completely done, requesting a free API recommendation.

**The Problem:**
1. The `Dashboard.tsx` created in Phase 5 (Premium UI Revamp) was entirely static and filled with mock data.
2. The backend was using Polygon.io, which imposes a strict limit of 5 requests per minute on the free tier, severely restricting historical graph generation for multiple stocks.

**The Solution:**
1. **Backend Integration (`yahoo-finance2`)**
   - Installed `yahoo-finance2` locally and on the VPS (using `--ignore-scripts` to bypass unnecessary native C++ builds in Node 24).
   - Created `server/services/yahoo.js` exposing `fetchYahooHistorical` and `fetchYahooLatest`.
   - Updated `server/routes/historical.js` to call `fetchYahooHistorical` instead of Polygon.
   
2. **Frontend Data Wiring (`Dashboard.tsx`)**
   - Removed `mockChartData`.
   - Connected `usePortfolioStore`, `useTransactionStore`, and `usePriceStore`.
   - Built a deterministic derivation script inside `useMemo` that evaluates all `CONFIRMED` transactions from `transactionStore` to deduce:
     - `cashBalance` (starting from `initial_cash`, adjusted by BUY/SELL/DEPOSIT/WITHDRAW/DIVIDEND).
     - `holdings` (accumulated shares per symbol).
     - `totalNetWorth` (cash + current stock value based on `prices`).
     - `todaysProfit` (comparing current prices vs `prevPrice = price - change`).
   - Sliced the top 4 transactions sorted by date descending for the **Recent Activity** list.
   - Fetched `historical` data dynamically based on the current active holdings. Evaluated the historical store to construct `chartData` matching the Recharts formatting `[{ name: 'Oct 1', value: 12450 }, ...]`.
   - Handled a route bug where `api.ts` posted to `/prices/historical` but the backend served it at `/historical`.

3. **Deployment**
   - SCP'd `yahoo.js` and `historical.js` to the VPS.
   - Re-built Vite (`npm run build`) and SCP'd the `dist/` directory.
   - Restarted `pm2 restart stock-api` on the VPS.

#### [MODIFY] `server/routes/historical.js`
- เปลี่ยนจากการเรียก `polygon.js` ไปเรียก `yahoo.js`
