# X-Chart Compare: Stale-While-Revalidate Engine & VPS Production Deploy

## 📌 Context & Implementation (Compiled Truth)

### 1. Root Cause Analysis (สาเหตุที่แท้จริง)
- **Cache-First Failure**: In `useCompareData.ts`, `getCachedCandles(sym, '1D')` checked IndexedDB. If cached data existed (even from 7 days ago), the symbol was marked resolved and NOT added to `missingSymbols`.
- **Zero-API Invocations**: As long as symbols were previously cached, `api.chart.get(sym, 36500, '1D')` was never called in the Compare tab.
- **Asymmetric Single-Chart Behavior**: Single charts in `XChartPanel.tsx` always invoked `api.chart.get` in the background (stale-while-revalidate), which fetched today's live quotes and persisted to IndexedDB.
- **Flat 0.00% Lines**: When viewing 1W or other periods, symbols that were not individually opened lacked recent candles. In `normalizeTickerData`, dates missing from `priceMap` were forward-filled with the base price $P_0$, creating flat horizontal teal lines at $+0.00\%$.

### 2. Architecture & Engine Upgrades
- **Stale-While-Revalidate Engine**:
  - **Instant 0ms First Paint**: Reads memory/IndexedDB and renders available data immediately with zero UI flicker or blocking spinners.
  - **Staleness Heuristic**: Evaluates whether each symbol's cache age exceeds 60 seconds, or if its newest date lags behind the latest date in the comparison set (`symLastDate < maxKnownDate`).
  - **Concurrency-Controlled Pool**: Uses `fetchWithConcurrency(symbols, 4, ...)` to batch network requests across 4 parallel workers, preventing SQLite file locks and API throttling.
  - **60s Background Polling**: Continues revalidating active symbols in the background every 60 seconds while the tab is active.
- **Manual Toolbar Refresh**:
  - Added a dedicated Refresh button (`RefreshCw` icon with spin animation when active) next to the Fullscreen toggle on the sub-toolbar.
  - Clicking forces a direct re-fetch of all active and reference tickers.
- **IndexedDB Metadata Extension**:
  - Added `getCachedCandlesWithMeta` to `src/utils/chartIdbCache.ts` returning `{ data, cachedAt }` to allow millisecond-level staleness detection.
