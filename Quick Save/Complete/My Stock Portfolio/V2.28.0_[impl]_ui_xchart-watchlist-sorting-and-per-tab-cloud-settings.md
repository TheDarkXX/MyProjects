  - ในแถบ Tab Bar ด้านบนของ X-Chart ผู้ใช้เปิดหลายแท็บคู่ขนานกัน เช่น แท็บหุ้น (`META`), แท็บค่าเงิน (`USD/THB`), แท็บภาพรวม (`Market Heatmap`), และแท็บพอร์ต (`My Port`)

- **โจทย์ที่ 3 (Real-Time Live Candlestick & Pulse Engine ตอนตลาดเปิด):**
  - **ข้อสังเกตของผู้ใช้:** *"เพิ่งเห็นว่า chart ไม่ realtime แฮะ หลังตลาดเปิด แท่งเทียน ส่วนแท่งปัจจุบันแบบ realtime ไม่ขึ้น"*
  - **การสืบสวนรากเหง้าปัญหา (3 Root Causes):**
    1. *Backend (`server/routes/chart.js`)*: ข้อมูลย้อนหลังมาจาก `historical_prices` ของ Yahoo Historical ซึ่งเป็น Daily Closed Data ระหว่างที่ตลาดเปิด (เช่น 15 ก.ย.) ใน DB มีถึงแค่วานนี้ (14 ก.ย.) Backend ไม่ได้ดึงราคา Quote วันนี้มาฉีดเข้าต่อท้าย ส่งผลให้ Indicator (EMA, MCDX) ขาดแท่งวันนี้ไปด้วย
    2. *Frontend (`useChartLivePulse.ts`)*: โค้ดเดิมหยิบ `lastBar = displayBars[displayBars.length - 1]` แล้วเรียก `series.update({ time: lastBar.time })` ซึ่ง `lastBar.time` เป็นวันที่ของเมื่อวาน Lightweight Charts จึงไปแก้ไขแท่งของเมื่อวาน แทนที่จะ Append แท่งเทียนของวันนี้ขึ้นมา
    3. *Frontend (`XChartPanel.tsx`)*: `if (cacheByRes[key]) return;` ดึงจาก Memory แล้วรีเทิร์นทันที ไม่เกิดการ Revalidate ข้อมูลสดเมื่อเปิดกราฟ
  - **ผลลัพธ์ที่แก้ไข:** กราฟสามารถเรนเดอร์แท่งเทียนวันนี้ได้ตั้งแต่ 0ms แรก และกระตุกอัปเดต High/Low/Close/Volume สดทุก 12 วินาที พร้อมเชื่อมต่อ EMA และ MCDX ถึงแท่งปัจจุบัน 100%

  targetCollapsed: false,

```
- **ตรรกะการเปรียบเทียบ (Comparator Logic):**
  - **`Chg% desc (Default)`**: ติดลบมากสุดขึ้นก่อน `pctA - pctB` เช่น `-47.87%` -> `-2.52%` -> `-1.46%` -> `-0.16%` -> `+0.53%` -> `+2.44%`
  - **`Chg% asc`**: บวกมากสุดขึ้นก่อน `pctB - pctA`
  - **`Chg desc`**: เงินสดที่ลดลงมากสุดขึ้นก่อน `changeA - changeB`
  - **`Chg asc`**: เงินสดที่เพิ่มมากสุดขึ้นก่อน `changeB - changeA`
  - **`Price desc`**: ราคาสูงสุดขึ้นก่อน `priceB - priceA`
  - **`Price asc`**: ราคาต่ำสุดขึ้นก่อน `priceA - priceB`
  - **`Symbol asc`**: A -> Z `a.symbol.localeCompare(b.symbol)`
  - **`Symbol desc`**: Z -> A `b.symbol.localeCompare(a.symbol)`
- ประยุกต์ใช้ทั้งในอาร์เรย์ `sortedHoldings` (ส่วน Holdings) และ `sortedTargetStocks` (ส่วน Target · Project 2X)

### 3. Real-Time Live Candlestick & Pulse Engine Architecture (โค้ดจริงที่ปรับปรุง)

#### 3.1 Backend: `server/services/yahoo.js`
เพิ่มฟังก์ชัน `fetchYahooRealtimeQuote` ดึงราคา OHLC แบบ Real-time พร้อม 10s In-memory Cache:
```javascript
const realtimeQuoteCache = new Map();
const REALTIME_CACHE_TTL_MS = 10000;

export async function fetchYahooRealtimeQuote(symbol) {
  const upper = symbol.toUpperCase();
  const cached = realtimeQuoteCache.get(upper);
  const now = Date.now();
  if (cached && (now - cached.timestamp) < REALTIME_CACHE_TTL_MS) {
    return cached.data;
  }

  try {
    const q = await yahooFinance.quote(upper);
    if (!q || (!q.regularMarketPrice && !q.postMarketPrice)) {
      return null;
    }

    const price = q.regularMarketPrice || q.postMarketPrice || 0;
    const open = q.regularMarketOpen || price;
    const high = q.regularMarketDayHigh || Math.max(open, price);
    const low = q.regularMarketDayLow || Math.min(open, price);
    const volume = q.regularMarketVolume || 0;
    const change = q.regularMarketChange || 0;
    const percent_change = q.regularMarketChangePercent || 0;

    const rawTime = q.regularMarketTime || new Date();
    const marketDateObj = new Date(rawTime);
    const marketDate = !isNaN(marketDateObj.getTime())
      ? marketDateObj.toLocaleDateString('en-CA', { timeZone: 'America/New_York' })
      : new Date().toISOString().split('T')[0];

    const result = {
      symbol: upper,
      price,
      open,
      high,
      low,
      volume,
      change,
      percent_change,
      marketDate,
      marketState: q.marketState || 'REGULAR'
    };

    realtimeQuoteCache.set(upper, { timestamp: now, data: result });
    return result;
  } catch (err) {
    console.warn(`[Yahoo] Failed to fetch realtime quote for ${upper}:`, err.message);
    return null;
  }
}
```

#### 3.2 Backend: `server/routes/chart.js`
ทำการฉีดแท่งเทียนสดของวันนี้เข้า `dbCandles` ก่อนนำไปคำนวณ EMA & MCDX:
```javascript
if (resolution === '1D' || resolution === '4H') {
  const liveQuote = await fetchYahooRealtimeQuote(symbol);
  if (liveQuote && liveQuote.price > 0 && liveQuote.marketDate) {
    const lastBar = dbCandles[dbCandles.length - 1];
    const lastDate = lastBar ? lastBar.date : '';

    if (liveQuote.marketDate > lastDate) {
      dbCandles.push({
        date: liveQuote.marketDate,
        open: liveQuote.open,
        high: Math.max(liveQuote.high, liveQuote.price),
        low: Math.min(liveQuote.low, liveQuote.price),
        close: liveQuote.price,
        volume: liveQuote.volume
      });
    } else if (liveQuote.marketDate === lastDate && lastBar) {
      lastBar.close = liveQuote.price;
      lastBar.high = Math.max(lastBar.high, liveQuote.high, liveQuote.price);
      lastBar.low = Math.min(lastBar.low, liveQuote.low, liveQuote.price);
      if (liveQuote.volume > 0) lastBar.volume = liveQuote.volume;
    }
  }
}
```

```typescript
const liveQuote = batch[symbol.toUpperCase()];
if (liveQuote && liveQuote.price && liveQuote.price > 0) {
  const newPrice = liveQuote.price;
  const quoteOpen = liveQuote.open ?? newPrice;
  const quoteHigh = liveQuote.dayHigh ?? Math.max(quoteOpen, newPrice);
  const quoteLow = liveQuote.dayLow ?? Math.min(quoteOpen, newPrice);
  const quoteDate = liveQuote.marketDate;

  const nyMarketDate = quoteDate || new Intl.DateTimeFormat('en-CA', {
    timeZone: 'America/New_York',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  }).format(new Date());

  const lastBarDateStr = typeof lastBar.time === 'string' 
    ? lastBar.time 
    : typeof (lastBar.time as any)?.year === 'number' 
      ? `${(lastBar.time as any).year}-${String((lastBar.time as any).month).padStart(2, '0')}-${String((lastBar.time as any).day).padStart(2, '0')}`
      : String(lastBar.time);

  const isTodayBar = lastBarDateStr === nyMarketDate;

  if (isTodayBar) {
    const updatedHigh = Math.max(lastBar.high, newPrice, quoteHigh);
    const updatedLow = Math.min(lastBar.low, newPrice, quoteLow);
    candleSeriesRef.current.update({
      time: lastBar.time as Time,
      open: lastBar.open,
      high: updatedHigh,
      low: updatedLow,
      close: newPrice,
    });
  } else if (nyMarketDate > lastBarDateStr) {
    candleSeriesRef.current.update({
      time: nyMarketDate as Time,
      open: quoteOpen,
      high: Math.max(quoteHigh, newPrice),
      low: Math.min(quoteLow, newPrice),
      close: newPrice,
    });
  }

  usePriceStore.setState((state) => ({
    prices: {
      ...state.prices,
      [symbol.toUpperCase()]: {
        price: newPrice,
        change: liveQuote.change ?? 0,
        percent_change: liveQuote.percent_change ?? 0,
        last_updated: new Date().toISOString(),

  }));

## ภาพรวมของปัญหา (Root Cause Analysis)

ผู้ใช้สังเกตเห็นว่า **"หลังตลาดเปิด แท่งเทียนส่วนแท่งปัจจุบันแบบ realtime ไม่ขึ้น"**

จากการเจาะลึก Source Code ทั้งฝั่ง Backend (Node.js/Hono/SQLite) และ Frontend (React/Lightweight Charts v5) พบต้นตอสำคัญ 3 จุดที่ทำให้แท่งเทียนสดไม่ปรากฏ:

1. **Root Cause 1 (Backend — `server/routes/chart.js` & `historical_prices` ขาดแท่งวันนี้):**
   - API `GET /api/chart/:symbol` ดึงข้อมูลเฉพาะจากตาราง `historical_prices` ซึ่งดึงมาจาก Yahoo Historical Chart (`yahooFinance.chart`)
   - Yahoo Historical เป็นข้อมูลสรุปรายวันที่จะบันทึกเฉพาะวันที่ปิดตลาดแล้ว (Market Closed) **ระหว่างที่ตลาดกำลังเปิดเทรด (เช่น วันนี้ 15 ก.ย. เวลาสหรัฐฯ) ใน `historical_prices` จะมีแท่งเทียนถึงแค่วานนี้ (14 ก.ย.) เท่านั้น!**
   - Backend ไม่มีการนำราคา Real-time Quote ของวันนี้มารวมเข้าไปในอาร์เรย์ `dates`, `opens`, `highs`, `lows`, `closes` ทำให้ข้อมูลที่ส่งให้กราฟขาดแท่งของวันนี้ 100%
   - ส่งผลให้เส้น EMA 50/150/200 และ Banker MCDX คำนวณหยุดอยู่แค่วานนี้เช่นกัน

2. **Root Cause 2 (Frontend — `useChartLivePulse.ts` อัปเดตผิดแท่ง!):**
   - ใน `useChartLivePulse.ts` โค้ดเดิมเขียนไว้ว่า:
     ```ts
     const lastBar = displayBars[displayBars.length - 1]; // เป็นแท่งของเมื่อวาน (14 ก.ย.)!
     candleSeriesRef.current.update({
       time: lastBar.time as Time, // สั่ง update ไปที่วันที่ 14 ก.ย.!
       open: lastBar.open,
       high: updatedHigh,
       low: updatedLow,
       close: newPrice,
     });
     ```
   - ใน Lightweight Charts เมื่อเรียก `series.update({ time })`:
     - ถ้า `time` ตรงกับแท่งเดิม -> จะไป **แก้ไขแท่งเดิม**
     - ถ้า `time` เป็นวันที่ใหม่กว่า -> จะ **สร้างแท่งใหม่ (Append)**
   - โค้ดเดิมดันเอาวันที่ของ `lastBar.time` (เมื่อวาน) ไปใส่! **ผลคือมันไปแอบแก้วานนี้ แต่ไม่มีแท่งของวันนี้โผล่ขึ้นมาเลย!**

3. **Root Cause 3 (Frontend — `XChartPanel.tsx` React Cache Return ทันที):**
   - ใน `XChartPanel.tsx` บรรทัดที่ 148: `if (cacheByRes[key]) { setLoading(false); return; }`
   - เมื่อผู้ใช้เปิดกราฟแล้วสลับแท็บไปมา โค้ดจะอ่านค่าเก่าที่แคชไว้ในหน่วยความจำและ `return` ออกไปทันที ไม่เคยยิงดึงข้อมูลสดซ้ำ ทำให้แท่งเทียนไม่ขยับ

## 📋 รายละเอียดการแก้ไขแต่ละไฟล์

### 1. Backend: `server/services/yahoo.js`
- เพิ่มฟังก์ชัน `fetchYahooRealtimeQuote(symbol)`
  - ดึงข้อมูลจาก `yahooFinance.quote(symbol)`
  - สกัดค่า: `price`, `open`, `high` (dayHigh), `low` (dayLow), `volume`, `regularMarketTime` (แปลงเป็น YYYY-MM-DD), `change`, `percent_change`, `marketState`
  - มี In-memory Cache 10 วินาทีเพื่อป้องกัน Rate-limit จากการยิงซ้ำ

### 2. Backend: `server/routes/chart.js`
- ใน Route `GET /:symbol`:
  - หลังดึง `dbCandles` จาก SQLite:
  - เรียก `fetchYahooRealtimeQuote(symbol)`
  - **ถ้า `quote.date > lastDbDate`:** ทำการ Append แท่งเทียนสดของวันนี้เข้า `dbCandles` ทันที!
  - **ถ้า `quote.date === lastDbDate`:** อัปเดตแท่งสุดท้ายใน `dbCandles` ด้วยราคา Close, High, Low ล่าสุด
  - อัปเดตลงตาราง `latest_prices` ของระบบด้วย
  - นำ `closes` ที่มีแท่งเทียนวันนี้ไปคำนวณ `calcEMASeries` และ `calcMcdxSeries` ทำให้ Indicators ทุกตัวมีค่าของแท่งปัจจุบันพร้อมสรรพ

### 3. Backend: `server/routes/prices.js`
- ใน Endpoint `/prices/quote-batch`:
  - เพิ่มฟิลด์ `open`, `dayHigh`, `dayLow`, `marketDate`, `volume` ลงในออบเจ็กต์ตอบกลับ เพื่อให้ฝั่งหน้าบ้านมี OHLC ครบถ้วนสำหรับนำไปวาดแท่งเทียนสด

### 4. Frontend: `src/components/project2x/hooks/useChartLivePulse.ts`
- เปลี่ยนมาใช้ `api.prices.quoteBatch([symbol])` ซึ่งให้ OHLC ครบชุด
- ปรับตรรกะการ Update/Append แท่งเทียนใน Lightweight Charts:
  - ตรวจสอบวันที่ของแท่งสุดท้ายในชาร์ตเทียบกับ `quote.marketDate`:
    - ถ้า `lastBar.time === quote.marketDate`: สั่ง `update` แท่งปัจจุบันด้วย High, Low, Close ล่าสุด
    - ถ้า `lastBar.time < quote.marketDate`: สั่ง `update` ด้วย `time: quote.marketDate` เพื่อ **Append แท่งใหม่ของวันนี้ขึ้นมาบนกราฟทันที!**
- ปรับ Polling Interval จาก 30 วินาทีเป็น 12 วินาทีระหว่างตลาดเปิด เพื่อความลื่นไหลแบบ Real-time
- ซิงก์ค่าราคาใหม่เข้า `usePriceStore` เพื่อให้อัปเดตราคาใน Watchlist และ Position HUD ไปพร้อมกัน

### 5. Frontend: `src/components/xchart/XChartPanel.tsx`
- ปรับปรุงตรรกะแคช `fetchChartData` ให้เป็น **Stale-While-Revalidate**:
  - ถ้ามีข้อมูลแคชอยู่แล้ว ให้แสดงผลทันที (0ms)
  - ถ้าข้อมูลแคชมีอายุเกิน 30 วินาที ให้ Revalidate ดึงข้อมูลสดจาก Backend มาอัปเดตแท่งเทียนและ Indicators ต่อเนื่อง
