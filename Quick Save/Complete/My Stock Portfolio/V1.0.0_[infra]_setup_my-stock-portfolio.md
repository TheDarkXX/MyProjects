# 🏗️ [infra] Setup My Stock Portfolio

## 📌 Context & Implementation (Compiled Truth)
The user requested to scaffold a new project by cloning `https://github.com/TheDarkXX/My-Stock-Portfolio` into `C:\My Claw\MyProjects\My Stock Portfolio`. 

During the scaffolding, we encountered that the `/newpj` skill lacked instructions to automatically inject required skills into the new project based on its type (Brand, Content, Code/App). Thus, we updated `C:\My Claw\Openclaw-VPS\.agents\skills\newpj\SKILL.md` to map and copy the appropriate skills dynamically.

For a `Code/App` project, the skills mapped were: `dev`, `design`, `save`, `qc`, `evo`, `codex`, `reviewchat`, `web`, `webtest`. We injected these into `My Stock Portfolio/.agents/skills/`.

Since this is a local MyProjects repository and not Openclaw-VPS, we further customized the injected skills inside `My Stock Portfolio`:
1. **save:** Removed VPS deployment (`bump-cache.js`, `git push vps`) and replaced it with standard Git workflow (`git push origin master`) for MyProjects, and adjusted Quick Save directories.
2. **qc:** Re-pointed root directory scanning and locked files list to fit a standard Github Node/React app.
3. **evo:** Removed the `scp` upload to VPS database.
4. **design:** Mapped the design file lookup to the project's own `DESIGN.md`.
