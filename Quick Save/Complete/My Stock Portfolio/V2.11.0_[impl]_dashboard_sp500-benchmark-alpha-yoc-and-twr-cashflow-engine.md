# Dashboard S&P 500 Benchmark Strip, Alpha Spread, Yield on Cost (YoC), and TWR Net Cash Flow Engine (V2.11.0)

## 💡 Context & Implementation (Compiled Truth)

### 1. ปัญหาเดิมและความต้องการของผู้ใช้ (Context & Core Objectives)
ในเซสชันนี้ ผู้ใช้ต้องการยกระดับหน้า **Dashboard** ของ `My Stock Portfolio` ด้วย 3 วาระหลัก พร้อมทั้งแก้ปัญหาเชิงโครงสร้างของข้อมูลและสูตรคำนวณที่ซ่อนอยู่:
1. **MultiPeriodReturnStrip S&P 500 & Alpha Comparison**: ต้องการให้การ์ดช่วงเวลาในแถวแรก (1D, 1W, 1M, YTD, 1Y, TOTAL RETURN, CUSTOM) มีขอบล่างระบุผลตอบแทนของดัชนี **S&P 500** ประจำช่วงเวลานั้นๆ พร้อมค่า **Alpha ($\alpha$)** ที่คำนวณส่วนต่างระหว่างผลงานพอร์ตกับตลาด เพื่อให้เทียบหมัดต่อหมัดได้ทันที
2. **Total Dividends Yield on Cost (YoC) Badge**: ในแถวที่ 2 การ์ด `Total Dividends` ควรมีสัดส่วนเป็นเปอร์เซ็นต์กำกับเหมือนการ์ดอื่นๆ โดยผู้ใช้เลือก **Option A: Yield on Cost (YoC)** คำนวณจาก $\frac{\text{Total Dividends}}{\text{Net Invested}} \times 100$ เพื่อวัดผลตอบแทนเงินปันผลสะสมเทียบกับเงินต้นสุทธิที่ควักกระเป๋าลงทุน
3. **Database Split-Brain Restoration & Single Source of Truth**: ตรวจสอบพบพอร์ต Tiger ข้อมูลธุรกรรมและหุ้นหายไป เหลือเงินในพอร์ตแค่ $223.42 จากเดิมที่มีหลายพันดอลลาร์ พบต้นตอเกิดจากฐานข้อมูลซ้ำซ้อนระหว่าง `server/stock.db` (ไฟล์กำพร้าที่รูท) และ `server/db/stock.db` (ตำแหน่งจริงที่ระบบเรียกใช้) ทำการกู้คืน 109 ธุรกรรมแท้จริง และลบไฟล์ซ้ำซ้อนทิ้งถาวร
4. **Timeframe Period Calculation Bug (Naive Diff vs True Profit & TWR)**: ผู้ใช้เอะใจกับตัวเลขการ์ด `1Y` ที่โชว์กำไรพุ่งไปถึง **`+416.03% (+฿43,116)`** ขณะที่กำไรทั้งชีวิตพอร์ต (`TOTAL RETURN`) มีเพียง `+16.69% (+฿7,647)` ตรวจพบว่าโค้ดเดิมใช้ `endVal - startVal` ดิบๆ ทำให้เงินที่ผู้ใช้เติม DCA เข้าพอร์ตตลอด 1 ปี (~$1,087 / ฿35,700) ถูกระบบนับเป็น "กำไรจากการเทรดหุ้น"! แก้ไขปรับระบบเป็น **Net Cash Flow Adjusted Profit** และ **Daily Time-Weighted Return (TWR)** ตามมาตรฐานสากลระดับโลก (CFA / GIPS)
5. **Dashboard vs Performance Page Comparison Resolution**: แก้ข้อสงสัยความแตกต่างระหว่างตัวเลข Dashboard กับหน้ากราฟ Performance โดยผู้ใช้เลือก **Option B (คงไว้แบบนี้)**: กล่อง `TOTAL RETURN` สะท้อน Money-Weighted ROI เงินในกระเป๋าจริง (+16.69%) ส่วนช่วงเวลาย่อยใช้ TWR เทียบตลาด S&P 500 และหน้า Performance แสดงกราฟวิเคราะห์ TWR/MWR เชิงลึก

### 2. สถาปัตยกรรมและการคำนวณทางการเงิน (Financial Engineering & Architecture)

#### 1) การคำนวณ S&P 500 Benchmark & Alpha Spread
- รวมสัญลักษณ์ `SPY` เข้าไปใน `fetchPrices` และ `fetchHistorical` อัตโนมัติ:
  ```typescript
  const symbolsToFetch = useMemo(() => {
    return Array.from(new Set([...activeSymbols, 'SPY']));
  }, [activeSymbols]);
  ```
- **สูตร Alpha ($\alpha$)**:
  $$\alpha = \text{Portfolio Return \%} - \text{S\&P 500 Return \%}$$
- การดึงผลตอบแทน SPY ในแต่ละช่วงเวลา (`calcSpyMetric`):
  - `1D`: ดึงเปอร์เซ็นต์ราคาปิด/เปลี่ยนแปลงล่าสุดของ SPY จาก Yahoo Live API
  - `1W`, `1M`, `3M`, `YTD`, `1Y`: คำนวณเปอร์เซ็นต์การเปลี่ยนแปลงของราคาปิด SPY ระหว่างวันเริ่มต้นและวันสิ้นสุดของกรอบเวลานั้น
  - `TOTAL RETURN (All Time)`: คำนวณผลตอบแทน SPY ตั้งแต่วันเริ่มพอร์ตจริง (`earliestTxDate`) จนถึงวันปัจจุบัน ตามมาตรฐาน GIPS
  - `CUSTOM`: คำนวณผลตอบแทน SPY ในช่วงวันที่เลือก

#### 2) Total Dividends Yield on Cost (YoC)
- ใน `src/hooks/useHoldings.ts`:
  ```typescript
  const dividendYieldOnCost = netInvested > 0 ? (totalDividends / netInvested) * 100 : 0;
  ```
- แสดงผลด้วย Badge สีทองอำพันสดใสสไตล์ Neumorphic:
  `↗ 0.26% YoC` พร้อม Tooltip อธิบายชัดเจน

#### 3) สูตรคำนวณผลตอบแทนช่วงเวลามาตรฐานสากล (Net Cash Flow Deduction & Daily TWR)
- **Period True Dollar Profit**:
  $$\text{Period Profit} = (V_{\text{end}} - V_{\text{start}}) - \text{Net External Cash Flow in Period}$$
  โดยที่ $\text{Net External Cash Flow} = \sum \text{Deposits} - \sum \text{Withdrawals}$
  - เงินเติม DCA จะถูกหักออก ไม่ถูกนับเป็นกำไรมโน
  - เงินที่ถอนออก (เช่น พอร์ต Doctorbank Growth ที่ถอน $2,255) จะไม่ถูกนับเป็นขาดทุน
- **Daily Time-Weighted Return (TWR)**:
  สำหรับช่วงเวลา $N$ วันทำการ:
  $$R_i = \frac{V_i - C_i - V_{i-1}}{V_{i-1}}$$
  $$\text{TWR} = \left( \prod_{i=1}^N (1 + R_i) \right) - 1$$
  $$\text{TWR \%} = \text{TWR} \times 100$$
  - ตัดผลกระทบของขนาดและจังหวะเวลาการเติม/ถอนเงินออกอย่างสมบูรณ์
  - เทียบกับ S&P 500 (ซึ่งคิดแบบ TWR อยู่แล้ว) ได้อย่างยุติธรรมแบบ Apples-to-Apples

#### 4) Implementation ใน `Dashboard.tsx`
```typescript
    const chronologicalTxs = transactions
      .filter(t => t.status !== 'CANCELLED' && t.date)
      .sort((a, b) => new Date(a.date).getTime() - new Date(b.date).getTime());

    const calcMetric = (range: DashboardTimeRange, customStart?: string, customEnd?: string) => {
      let amount = 0;
      let percent = 0;

      if (range === 'ALL') {
        amount = totalPnl;
        percent = totalPnlPercent;
      } else if (range === '1D') {
        amount = todaysProfit;
        percent = todaysProfitPercent;
      } else {
        const startDate = getStartDateForRange(range, earliestTxDate, customStart);
        const endDate = customEnd || new Date().toISOString().split('T')[0];
        const pts = allDailyPoints.filter(p => p.date >= startDate && p.date <= endDate);
        
        if (pts.length > 0) {
          const startsBeforeInception = earliestTxDate ? startDate < earliestTxDate : false;
          const startVal = startsBeforeInception ? 0 : pts[0].value;
          const endVal = pts[pts.length - 1].value;

          // Cash flows: if startsBeforeInception include all up to endDate; else include cash flows occurring AFTER pts[0].date
          const cashFlowCutoffDate = startsBeforeInception ? startDate : pts[0].date;
          let periodNetCashFlow = 0;

          for (const tx of chronologicalTxs) {
            const txDate = tx.date.split('T')[0];
            const isIncluded = startsBeforeInception 
              ? (txDate >= cashFlowCutoffDate && txDate <= endDate)
              : (txDate > cashFlowCutoffDate && txDate <= endDate);

            if (isIncluded) {
              const isCash = tx.asset === 'Cash' || tx.symbol === 'CASH';
              const type = (tx.type || '').toUpperCase();
              if (type === 'DEPOSIT' || (type === 'BUY' && isCash)) {
                periodNetCashFlow += tx.amount;
              } else if (type === 'WITHDRAW' || (type === 'SELL' && isCash)) {
                periodNetCashFlow -= tx.amount;
              }
            }
          }

          // 1. True Dollar Profit = (End Value - Start Value) - Net External Deposits
          amount = (endVal - startVal) - periodNetCashFlow;

          // 2. Global Industry-Standard: Daily Time-Weighted Return (TWR)
          // Isolates investment performance from timing and size of deposits/withdrawals
          if (pts.length >= 2) {
            let cumTwr = 1.0;
            for (let i = 1; i < pts.length; i++) {
              const prevVal = pts[i - 1].value;
              const currVal = pts[i].value;
              const currDate = pts[i].date;

              let dayCf = 0;
              for (const tx of chronologicalTxs) {
                if (tx.date.split('T')[0] === currDate) {
                  const isCash = tx.asset === 'Cash' || tx.symbol === 'CASH';
                  const type = (tx.type || '').toUpperCase();
                  if (type === 'DEPOSIT' || (type === 'BUY' && isCash)) {
                    dayCf += tx.amount;
                  } else if (type === 'WITHDRAW' || (type === 'SELL' && isCash)) {
                    dayCf -= tx.amount;
                  }
                }
              }

              if (prevVal > 0) {
                const dayReturn = (currVal - dayCf - prevVal) / prevVal;
                cumTwr *= (1 + dayReturn);
              }
            }
            percent = (cumTwr - 1) * 100;
          } else {
            const base = startVal + Math.max(0, periodNetCashFlow);
            percent = base > 0 ? (amount / base) * 100 : 0;
          }
        }
      }

      const spyPercent = calcSpyMetric(range, customStart, customEnd);
      const alpha = percent - spyPercent;

      return { amount, percent, spyPercent, alpha };
    };
```
