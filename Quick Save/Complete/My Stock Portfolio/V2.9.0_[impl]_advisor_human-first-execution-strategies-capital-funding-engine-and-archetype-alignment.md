# Human-First Execution Strategies, Capital Funding Engine & Portfolio Archetype Alignment (V2.9.0)

## 💡 Context & Implementation (Compiled Truth)

### 1. ปัญหาเดิมและจุดบอดเชิงสถาปัตยกรรม (Root Causes & Flaws Addressed)

ในเวอร์ชัน V2.8.0 ระบบ AI Portfolio Advisor มีการวิเคราะห์เชิงลึก 4 เสาหลักและให้คำแนะนำแบบ Quant Engine แต่อย่างไรก็ดี ผู้ใช้งานจริงพบจุดบกพร่องทาง UX และ Logic สำคัญ 3 ประการ:
1. **Actionable Execution Strategies ซับซ้อนเกินไป (Too Complex / Technical-First):** การ์ดคำแนะนำกระโดดเข้าหาข้อมูลเทคนิคอลทันที (เช่น ATR Trailing, SMA) โดยไม่มีการบอกบริบทพื้นฐานสำคัญที่สุดของผู้ใช้ นั่นคือ **"ต้นทุนของฉันเท่าไหร่ vs ราคาตลาดปัจจุบันเท่าไหร่"** และไม่มีการบอกภาษาคนชัดเจนว่า **"รอซื้อที่ราคาเท่าไหร่ / รอรับที่ราคาเท่าไหร่ / จุดถอยตรงไหน"**
2. **คำแนะนำไม่ระบุแหล่งที่มาของเงินทุน (Missing Capital Funding Sources):** เมื่อ AI สั่ง `ADD` หรือ `SWAP` หุ้น ระบบไม่เคยบอกว่าเงินซื้อควรมาจากไหน — ควรขายตัวเก่า (Orphan/Trim), ใช้เงินสดสำรอง (Cash Buffer), หรือเติมเงินใหม่รายเดือน (Fresh DCA)
3. **AI ไม่เข้าใจ Objective ของพอร์ต (Archetype Misalignment):** พอร์ต *"Doctorbank Growth"* เป็นพอร์ตเน้น Capital Gain ระยะยาว แต่ถูก AI ตักเตือนและกดคะแนนในหมวดเงินปันผล (`dividendHealth` และเรดาร์แกน `income`) เพียงเพราะหุ้นกลุ่ม Tech/Semiconductor (เช่น NVDA, CRWD) จ่ายปันผลต่ำ ทั้งที่ความจริงบริษัทนำกระแสเงินสดไป Reinvest ขยาย Economic Moat ตามปรัชญาของพอร์ตเติบโต

### 2. 5 จุดบอดทางสถาปัตยกรรมที่มหาเทพชี้ชัด (The 5 Architectural Blind Spots Closed)

1. **Deterministic Funding Source (ปิดจุดบอดที่ 1):** ไม่พึ่งพา LLM ในการคำนวณตัวเลขเงินทุน เพราะ LLM จะ hallucinate ยอดเงินมั่ว — Backend ทำการคำนวณ `capitalFlowSummary` แบบ Deterministic ล่วงหน้า (รวมยอดขายหุ้นนอกแผน `orphanLiquidation`, ยอดตัดส่วนเกิน `trimSurplus`, และเงินสดคงเหลือ `cashAvailable`) แล้วส่งเป็น Ground Truth ให้ AI อ้างอิง
2. **Token Budget & Minification (ปิดจุดบอดที่ 2):** ย่อ `JSON.stringify(payloadData)` แบบ Minified ตัด indentation และใส่คำสั่ง Archetype แบบ Conditional ตามสายพอร์ต ประหยัด Token ไปกว่า 35%
3. **แก้ปัญหา `currentPrice` ขาดหายใน Frontend (ปิดจุดบอดที่ 3):** ใน `AIBlueprintAdvisor.tsx` เดิม `actualHoldingsMap` ส่งเฉพาะ `avgCost` และ `pnlPercent` แต่ลืมใส่ `currentPrice: h.lastPrice` ทำให้การ์ดเทรดไม่สามารถเปรียบเทียบต้นทุนกับราคาปัจจุบันได้
4. **Cache Invalidation รวม Archetype (ปิดจุดบอดที่ 4):** เพิ่ม `portfolioArchetype` เข้าไปในสูตร MD5 `createBlueprintHash(blueprints, archetype)` ทำให้เมื่อผู้ใช้ปรับเปลี่ยนสไตล์พอร์ต ระบบจะ Bust Cache เก่าทิ้งทันที ไม่ดึงผลวิเคราะห์ผิดสายมาแสดง
5. **Update `isOldSchema` และ Query Sort (ปิดจุดบอดที่ 5):** อัปเดตเงื่อนไขตรวจสอบแคชเก่าให้ตรวจจับ `portfolioArchetype` และ `fundingSource` พร้อมปรับ SQL query จาก `ORDER BY created_at DESC` เป็น `ORDER BY id DESC LIMIT 1` ป้องกันบั๊ก Timezone ทับซ้อน

### 3. Architecture & Core Code Implementation

#### 1) ระบบคำนวณ Capital Flow และ Archetype Detection ใน Backend (`server/routes/ai-advisor.js`)

```javascript
function detectArchetype(portfolioName = '', portfolioDesc = '', actualPortfolio = null) {
  const text = `${portfolioName || ''} ${portfolioDesc || ''}`.toLowerCase();
  if (/growth|เติบโต|capital gain|tech heavy|aggressive/i.test(text)) return 'GROWTH_CAPITAL_GAIN';
  if (/dividend|income|ปันผล|cashflow|yield/i.test(text)) return 'DIVIDEND_INCOME';
  // Fallback heuristic: If portfolio avg dividend yield < 1.0% and EPS growth > 15% -> GROWTH
  if (actualPortfolio && Array.isArray(actualPortfolio) && actualPortfolio.length > 0) {
    const avgDivYield = actualPortfolio.reduce((s, h) => s + (h.div_yield || 0), 0) / actualPortfolio.length;
    const avgEpsGrowth = actualPortfolio.reduce((s, h) => s + (h.eps_growth_next_year || 0), 0) / actualPortfolio.length;
    if (avgDivYield < 1.0 && avgEpsGrowth > 15) return 'GROWTH_CAPITAL_GAIN';
    if (avgDivYield > 2.5) return 'DIVIDEND_INCOME';
  }
  return 'BALANCED';
}

function createBlueprintHash(blueprints, archetype = '') {
  if (!blueprints || !Array.isArray(blueprints)) return '';
  const sorted = blueprints
    .map(b => `${b.symbol}:${b.target_percent}:${b.category}`)
    .sort()
    .join('|');
  const payload = archetype ? `${sorted}#${archetype}` : sorted;
  return crypto.createHash('md5').update(payload).digest('hex').slice(0, 12);
}
```

#### 2) การคำนวณ `capitalFlowSummary` แบบ Deterministic ใน `compressPromptData`:

```javascript
let capitalFlowSummary = null;
if (hasReal) {
  const totalNetWorth = actualHoldings.totalNetWorth || 0;
  const cashAvailable = Math.round(actualHoldings.cashBalance || 0);
  let orphanLiquidation = 0;
  let trimSurplus = 0;

  actualHoldings.items.forEach(item => {
    const sym = (item.symbol || '').toUpperCase();
    if (sym === 'CASH') return;
    const targetPct = blueprintMap.get(sym) ?? 0;
    const actualPct = item.actualPercent || 0;
    const diffPct = actualPct - targetPct;
    
    if (item.isOrphan) {
      orphanLiquidation += (item.marketValue || 0);
    } else if (diffPct > 0.5) {
      trimSurplus += (diffPct / 100) * totalNetWorth;
    }
  });

  orphanLiquidation = Math.round(orphanLiquidation);
  trimSurplus = Math.round(trimSurplus);
  const totalDeployable = cashAvailable + orphanLiquidation + trimSurplus;

  capitalFlowSummary = {
    cashAvailable,
    orphanLiquidation,
    trimSurplus,
    totalDeployable,
    dcaNeeded: totalDeployable < 500
  };
}
```
