# V2.8.0: 4 Pillars of Conviction, Consensus Momentum & Cloudflare Timeout Resilience

## 📌 Context & Implementation (Compiled Truth)

### 1. Institutional-Grade Conviction Engine Overhaul
ก่อนหน้านี้ใน `StockVerdictCard` คำแนะนำหุ้นรายตัวแสดงผลเพียง 1-2 ข้อสั้นๆ และมีข้อความ `futureOutlook` สั้นกุดที่ถูกตัดคำไว้ที่ 140 ตัวอักษร ทำให้ขาดมิติในการตัดสินใจลงทุนระยะยาว
ใน V2.8.0 ระบบได้รับการยกเครื่องสมองกลและส่วนแสดงผลสู่ **Institutional-Grade Conviction Engine**:

1. **Consensus Momentum Engine**:
   - ฟังก์ชัน `getConsensusMomentum(symbol)` ดึงข้อมูลเปรียบเทียบจากตาราง SQLite `consensus_history` ย้อนหลัง 2 จุด
   - ตรวจจับทิศทางสถาบัน: `UPWARD` (ปรับเป้าขึ้น >= +2%), `DOWNWARD` (ปรับเป้าลง <= -2%), `STABLE` (แกว่งตัวแคบ)
   - **Graceful Fallback (Cold-Start Safe)**: หากมีข้อมูลน้อยกว่า 2 วัน คืนค่า `INSUFFICIENT_DATA` แสดงป้าย `📊 กำลังสะสมข้อมูล (รอ 7+ วัน)` ป้องกันการหลอกผู้ใช้ด้วย `STABLE` ปลอม
2. **4 เสาหลักแห่งความเชื่อมั่น (4 Pillars of Conviction)**:
   - **🛡️ เสาหลัก 1: Core Thesis & Economic Moat (`coreThesis`)**: วิเคราะห์กำแพงผูกขาด (Moat: Network Effect, Switching Cost, IP, Cost Advantage) และกระแสเงินสดอิสระ (FCF) พร้อมทิศทาง 6-12 เดือน (รวม `futureOutlook` เข้ามาเพื่อลดความซ้ำซ้อน)
   - **🚀 เสาหลัก 2: Active Catalysts & Key Risks**: ปรับจากข้อความสั้นๆ เป็นโครงสร้าง `{ title, impact, timeframe }` ระบุผลกระทบเชิงตัวเลขต่อ Revenue/EPS/Margin อย่างชัดเจน และ `{ title, impact }` สำหรับความเสี่ยงเฉพาะตัว
   - **💥 เสาหลัก 3: Thesis Breaker (`thesisBreaker`)**: เงื่อนไขชี้ขาดเชิงโครงสร้างธุรกิจที่หากเกิดขึ้นจริง ต้องสั่งขายทิ้งทันที (Fundamental Breakdown) ไม่ใช่แค่ราคาผันผวน
   - **⚖️ เสาหลัก 4: Valuation Verdict (`valuationVerdict`)**: ฟันธง Underpriced, Fair, หรือ Overpriced พร้อม Margin of Safety เทียบเป้า Consensus และ Momentum สถาบัน
   - **🎯 Conviction Score (`convictionScore`)**: ตัวเลขสรุป 1-10 ชั่งน้ำหนักจาก Moat (30%), Catalyst (25%), Thesis Breaker (25%), และ Valuation (20%)
3. **Token Budget & Stack-Based JSON Repair Safety Net**:
   - ปรับ `max_tokens` ของ Strategist Mode เป็น **10,000** (จูนให้เสร็จใน 60-80s ป้องกันชนเพดาน Cloudflare)
   - พัฒนา **Stack-Based `repairJson()`**: แก้ปัญหา Token ถูกตัดกลางทาง โดยจำลอง Nesting Stack ของวงเล็บปีกกาและก้ามปู ปิดสตริงและวงเล็บตามลำดับโครงสร้างที่ถูกต้อง 100% ป้องกัน SyntaxError
4. **100% Backward Compatibility**:
   - หน้าบ้านมี Runtime Type Guards ที่รองรับทั้งแคชข้อมูลแบบเก่า (`string[]` และ `futureOutlook`) และแคชใหม่ (`object[]` และ `coreThesis`)
   - เช็ค Invalidation เพิ่มเติมด้วย `coreThesis` ใน DB Backend เพื่อบังคับสร้างผลวิเคราะห์ใหม่อัตโนมัติ

### 2. Cloudflare 524 Timeout Auto-Recovery & Timezone Fix (V2.8.1 Hotfix Integration)
ในการทดสอบใช้งานจริง พบปัญหาสำคัญ 2 ประการที่ได้รับการแก้ไข:
1. **Cloudflare 524 HTML Error & Auto-Recovery Polling**:
   - เมื่อ LLM ประมวลผลลึกเกิน 100 วินาที Cloudflare Edge จะตัดการเชื่อมต่อและส่งหน้าเว็บ HTML Error 524 มาให้ ทำให้หน้าบ้านพังเป็น `Unexpected token '<', "<!DOCTYPE "... is not valid JSON`
   - แก้ไข `src/services/api.ts` ให้ตรวจจับ Content-Type และรหัส 524/504 อย่างสุภาพ
   - เพิ่มระบบ **Auto-Recovery Polling** ใน `AIBlueprintAdvisor.tsx`: เมื่อพบ Timeout หน้าเว็บจะไม่ตกกลับไปหน้าเริ่ม แต่จะขึ้นสถานะกำลังประมวลผลเบื้องหลังและยิง Polling ดึงผลลัพธ์จากเซิร์ฟเวอร์มาแสดงผลอัตโนมัติทันทีที่เสร็จสิ้น
2. **UTC-to-Localtime Formatting Fix**:
   - เดิม `row.created_at` ใน SQLite บันทึกเป็นเวลาสากล UTC (`YYYY-MM-DD HH:mm:ss`) โดยไม่มีตัว `Z` กำกับ ทำให้เบราว์เซอร์ Chrome ตีความเป็นเวลาท้องถิ่น ทำให้ 18:00 กลายเป็น 11:00 AM
   - แก้ไข Backend ให้ส่ง ISO UTC String (`...Z`) และ Frontend มีฟังก์ชัน `formatAnalysisDate` แปลงเป็นเวลาไทย (+7 ชม.) ตรงเวลาจริง 100% พร้อมจัดเรียง `ORDER BY id DESC` ดึงตัวล่าสุดเสมอ
