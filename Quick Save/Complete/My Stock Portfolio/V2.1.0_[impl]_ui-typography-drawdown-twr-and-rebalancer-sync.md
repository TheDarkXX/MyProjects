# V2.1.0 Global Institutional Typography System, TWR Drawdown Engine, Capital Growth Aesthetics, and Streamlined Holdings Table

## 📌 Context & Implementation (Compiled Truth)

### 1. Global Institutional Typography System (The Prompt + Sarabun Matrix)
- **Problem Statement:** The previous default typography (`Inter`) looked generic, sterile, and uncomfortable for numeric financial dashboards. When reading small descriptions (10-12px) in dark mode, users experienced severe visual fatigue.
- **Systematic Font Exploration:**
  - Tested `Plus Jakarta Sans + Prompt` (Clean, but numbers felt slightly rigid to user).
  - Tested `Manrope + IBM Plex Sans Thai` (Corporate Wall Street feel).
  - Tested `Outfit + Prompt` (Luxury geometric).
  - Tested `Prompt` only (Excellent modern FinTech baseline, loopless Cadson Demak design).
  - **Final Golden Solution:** High-contrast, dual-engine typography:
    - **`Prompt` (Alpha Engine / Headings & Numbers):** Enforced globally on `h1-h6`, buttons, navigation, ticker symbols, tabular numbers, and table headers. Loopless, sharp, geometric, and zero numerical drift.
    - **`Sarabun` (Narrative Engine / Descriptions & Body Text):** Enforced on paragraphs (`p`), captions, card subtitles, explanations, and tooltips. Its traditional looped glyphs dramatically enhance reading comfort on dark backgrounds.
    - **Monospace Protection:** Protected `.font-mono, [class*="font-mono"], code, pre` with `!important` to prevent `Prompt` bold overrides from distorting monospaced tables, dates, and API keys.
- **Iron Rule Enforcement:**
  - **Size Floor:** All font sizes below 13px (`text-[10px]`, `text-[11px]`, `text-[12px]`) are raised to a minimum floor of 13px (`text-[13px]`) via `src/styles/index.css`.
  - **Perceptual Contrast Floor:** Text brightness on dark backgrounds is locked to `>= 70%` (`#CBD5E1` / `#E2E8F0` Slate-300). Low-contrast gray `#9898C8` is boosted globally.

### 2. Time-Weighted Return (TWR) Drawdown Calculation (CFA / GIPS Standard)
- **Problem Statement:** In `UnderwaterDrawdownChart` and `RiskPage`, cash withdrawals by the user caused artificial "crater" drawdowns (down to -51.90%), even though the market portfolio was actually near All-Time Highs.
- **Solution:** Re-architected `seriesData` in `RiskPage.tsx` using **Daily Valuation Time-Weighted Return (TWR)**:
  $$I_t = I_{t-1} \times \left(1 + \frac{V_t - C_t - V_{t-1}}{V_{t-1}}\right)$$
  - Starting index $I_0 = 100$.
  - Daily net cash flow $C_t$ (deposits minus withdrawals) is factored out of return calculations.
  - Result: Max Drawdown corrected from an artificial cash crater of -51.90% to the true market drawdown of **-21.73%**, with proper recovery to 0% at All-Time Highs.

### 3. Capital Growth & Organic Wealth Overhaul
- **Aesthetics:** Implemented luminous Yellow-Red theme (Gold `#FACC15` for Portfolio Value, Electric Coral `#FF4D6D` for Net Invested).
- **Clean Baselines:** Removed murky brown overlapping fills; invested capital is now a crisp dashed laser line.
- **Currency Sync:** Destructured `exchangeRate` directly from `usePriceStore` (with fallback fetch) rather than `useUiStore` where it was `undefined`.
- **4-Row Custom Tooltip:** Displays:
  1. Net Invested Capital (เงินต้นสุทธิ)
  2. Total Portfolio Value (มูลค่ารวม)
  3. Profit/Loss Value (ส่วนต่างกำไร/ขาดทุน)
  4. Return % (% Profit/Loss with dynamic green/rose pill badge)

### 4. Market Treemap Calibration (Golden Ratio Squarify & Typography Scale)
- **Ratio Correction:** Switched `d3.treemapSquarify` ratio from `1.15` (which forced rigid squares and created awkward narrow noodle strips) to the **Golden Ratio `(1 + √5) / 2 ≈ 1.618`** (Finviz / TradingView standard), generating aesthetically balanced landscape rectangular tiles.
- **Typography Scale:** Capped stock symbol font size from an oversized 26px font-black down to a refined **14px–18px**, return percentage to **12px–14px**, and allocation weight to **10px–12px** subtle slate. Dynamic vertical positioning prevents text clipping or overflowing cell borders.
- **Sector Header:** Streamlined sector header pill height to 18px to maximize vertical chart real estate.

### 5. Streamlined 5-Column Holdings Table (Robinhood / Dime UX Standards)
- **Column Reduction (6 -> 5 Columns):** Merged redundant `Market Price` column into the `Asset` column:
  - Line 1: `Symbol` (16px Bold White)
  - Line 2: `{quantity} shares • {lastPrice}` (13px Slate-300)
- **Fractional Share Cleanup:** Replaced 8-decimal noise (e.g. `9.03740917 shares`) with clean 2-decimal formatting (e.g. `9.04 shares`).
- **Visual Symmetry:** Removed the bulky, heavy opaque container on `Total P/L` and aligned both `Total P/L` and `1D Return` symmetrically with clean font hierarchy, arrows (`+` / `-`), and harmonious color coding.
- **Scannability:** Users can now scan: Symbol & Price ➡️ Portfolio Value & Cost ➡️ Total Return ➡️ Today's Return ➡️ Weight in a single effortless glance.

### 6. Smart Cashflow Rebalancer Currency & Data Linking Fixes
- Fixed critical bug where `exchangeRate` was destructured from `useUiStore` instead of `usePriceStore`, causing `~฿NaN` in THB view.
- Connected `useTransactionStore` and `usePriceStore` with auto-fetching on mount so data loads reliably even when refreshing directly on `#rebalance`.
- Made deposit input field dynamically convert between USD (`$`) and THB (`฿`), with quick chips updating to `+฿10k / +฿30k / +฿50k / +฿100k` in THB view.

### 7. Bloomberg Terminal & TradingView Pure Numeric Formatting (Symbol Clutter Elimination)
- **Problem Statement:** Every single row repeated currency symbols (`$` or `฿`) 6–8 times across stock prices, costs, totals, and daily returns. In THB view, the wide `฿` glyph dominated the cells and caused severe visual stutter ("Symbol Pollution").
- **Solution:**
  - Implemented `formatClean(usdVal, decimals)` helper function in `PortfolioTable.tsx` that performs dynamic USD/THB currency conversion without prefixing currency symbols.
  - Stripped repeated `$` and `฿` symbols from all individual holding cells, rendering pure, sharp, vertically aligned numbers.
  - Shifted currency indication to the table header level:
    - Dedicated badge: `Values in USD` / `Values in THB`.
    - Dynamic column headers: `Portfolio Value (USD)`, `Total P/L (USD)`, `1D Return (USD)` (automatically switches to `(THB)` on toggle).
  - Kept a single anchor currency symbol on the bottom-line `Total Net Worth` hero banner.
