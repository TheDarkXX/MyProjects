# 🚀 V2.38.1 [impl] X-Chart Watchlist 7-Tier Sorting, Section Context Menu, Reversal Icon Refine & Signal Matrix Guide V2.38.1 Sync

## 📌 Context & Implementation (Compiled Truth)

ในเซสชันนี้ ผู้ใช้ต้องการยกระดับและจัดระเบียบหน้าต่าง **Watchlist บน X-Chart** ให้สอดคล้องกับยุทธวิธีเทรดหน้างานจริง และลบล้างความสับสนระหว่างคู่มือกับสถาปัตยกรรมโค้ดจริง 4 ประการ:

1. **ระบบจัดเรียง 7-Tier Action Matrix (Tier Sorting):**
   - เพิ่มปุ่มจัดเรียงคอลัมน์ `Tier / Symbol` ใน Table Header (`XChartWatchlistDock.tsx`)
   - รองรับการเรียงตามลำดับความเร่งด่วนในการตัดสินใจ (**Action-Urgency Order**):
     - **คลิกที่ 1 (`asc` - Default):** `BUY NOW!! 🔥 (1)` $\rightarrow$ `GET READY ⏳ (2)` $\rightarrow$ `SLOW BLEED 🩸 (3)` $\rightarrow$ `FALLING KNIFE 🔪 (4)` $\rightarrow$ `MAYDAY EXIT ❌ (5)` $\rightarrow$ `RUNNER ⚡ (6)` $\rightarrow$ `TO THE MOON 🚀 (7)` *(หุ้นที่ไม่มี Tier อยู่ท้ายสุด)*
     - **คลิกที่ 2 (`desc`):** `TO THE MOON 🚀 (7)` $\rightarrow$ `RUNNER ⚡ (6)` $\rightarrow$ `MAYDAY EXIT ❌ (5)` $\rightarrow$ `FALLING KNIFE 🔪 (4)` $\rightarrow$ `SLOW BLEED 🩸 (3)` $\rightarrow$ `GET READY ⏳ (2)` $\rightarrow$ `BUY NOW!! 🔥 (1)`
     - **คลิกที่ 3:** ปลดการเรียง (กลับสู่ค่าปกติ)
   - ปรับให้หมวดหมู่หลัก (Dynamic Sections) สลับตำแหน่งจัดเรียงตามทิศทาง Tier Sorting อัตโนมัติ

2. **ระบบคลิกขวาที่แถบ Section (Right-Click Context Menu):**
   - พัฒนา Sleek Cyber Context Menu (Glassmorphic HUD) เมื่อผู้ใช้คลิกขวาที่แถบหัวข้อ Section:
     - ✏️ **เปลี่ยนชื่อหมวดหมู่ (Rename Section):** รองรับทั้ง Custom Section (อัปเดต Store + Cloud Sync) และ Dynamic Section (บันทึก Local Override)
     - 🗑️ **ลบหมวดหมู่นี้ (Delete Section):** มีระบบแจ้งเตือนคอนเฟิร์มความปลอดภัย (ลบ Custom Section พร้อมหุ้น หรือลบหุ้นทั้งหมดใน Dynamic Section นั้นออกจาก Watchlist)
     - ➕ **เพิ่มหุ้นเข้าหมวดนี้ (Add Symbol)**
     - ↕️ **พับ / กางหมวดหมู่นี้ (Toggle Collapse)**

3. **ปรับไอคอน `Ready: Reversal` เป็น `⏳`:**
   - ใน `TierBadgeIndicator.tsx` เปลี่ยนไอคอนจากเดิม `🔄` เป็น **`⏳`** เพื่อสื่อถึงการ "หมุนนาฬิกาทรายรอสัญญาณแท่งเขียวตัดผ่าน EMA 9" ตามหลักการ Get Ready
   - อัปเดตสถิติย่อยบน Header (`subStats`) จาก `🔄 Break/Rev` เป็น `⏳ Break/Rev`

4. **ปรับปรุงคู่มือ `SIGNAL_MATRIX_GUIDE.md` สู่ V2.38.1:**
   - ทำการประสานข้อมูล (Full Sync) 100% ให้ตรงกับหน้างานจริง:
     - ลบหมวดหมู่ตกค้าง `BUY ZONE 💰` และ `ON RADAR 📡` ออกจากคู่มือ
     - บันทึกการยุบโซนสะสมเข้าเป็นส่วนหนึ่งของ `GET READY ⏳` (แยก 2 ขา: `🧲 Ready: Dip Buy` vs `⏳ Ready: Reversal / Breakout`)
     - ปรับตารางแม่แบบ 7-Tier และ Cross-Reference Matrix ให้ตรงกับ Watchlist และ `project2xEngine.js`
     - เพิ่มหัวข้อสถาปัตยกรรม Watchlist Integration, Quick-Filter Bar และ Context Menu
