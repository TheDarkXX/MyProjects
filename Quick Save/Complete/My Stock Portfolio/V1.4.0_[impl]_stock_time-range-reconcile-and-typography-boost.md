# V1.4.0: Dashboard Hero Real Calculations, Holdings 6-Column Revamp, Sticky USD/THB Toggle with Live Yahoo FX, Cash Reconciliation, and Typography Boost

## 🧠 Context & Implementation (Compiled Truth)
This session resolved critical mathematical, UX, database reconciliation, visual contrast, and multi-currency requirements to bring the Stock Portfolio dashboard to production parity with institutional platforms like Dime, Robinhood, and TradingView.

1. **Dashboard Hero Calculations Audit & Fix:**
   * **Root Cause:** In `Dashboard.tsx`, the Hero StatCards were previously hardcoded with a temporary MVP formula: `const totalPnl = activePortfolio?.initial_cash ? totalNetWorth - activePortfolio.initial_cash : 0;`. Because `initial_cash` was 0 (or null) in the portfolio record, `totalPnl` and `overallChangePercent` always evaluated to `0`, displaying `$0.00` and `0.00%`.
   * **Fix:** Updated `useHoldings.ts` to compute true `netInvested` capital (accounting for all `DEPOSIT`, `WITHDRAW`, cash transactions, trade fees, and net dividends). Connected `Dashboard.tsx` to display true total PnL (`Total Net Worth - Net Invested Capital`) and return percentages.

2. **Global Time Range Selector (Top Bar):**
   * **Design:** Implemented a unified Global Filter bar at the top of the dashboard adhering to top-tier financial apps (Robinhood, Apple Stocks, Webull).
   * **Standard Timeframes:** `[ 1D | 1W | 1M (Default) | 3M | YTD | 1Y | ALL | 📅 Custom ]`.
   * **Global Wiring:**
     * **Hero Section:** Card 1 (Total Net Worth) badge dynamically switches to show the return of the selected period. Card 4 dynamically updates its title (e.g., `1M P/L`, `YTD P/L`, `Total P/L`), value, and percentage to reflect that timeframe.
     * **Performance Overview:** The area chart dynamically filters its date range and updates its period return badge in real-time.
     * **Activity:** Automatically filters transactions to only display operations executed within the active timeframe, with a graceful empty state and quick button to return to `ALL`.

3. **Transaction Parsing, ISRG Cleanup, and Full Cash Reconciliation:**
   * **17 New Transactions:** Parsed 28 records across 5 Dime app Discord receipts and inserted 17 unified records (BUYs, SELLs, Dividends with withholding tax, and CRWD 4:1 split) into `stock.db`.
   * **ISRG Zero Balance Cleanup:** Adjusted the sell transaction of ISRG to 0.02 shares to clear out the lingering 0.000486 dust position.
   * **Statement Decryption & Audit:** Decrypted password-protected KKP statements (`19051985`) for `Dime! Save` (THB) and `Dime! FCD` (USD).
   * **Discovered Missing Flows:**
     - Missing Deposit: `2025-10-31` | `DEPOSIT` | `+$462.25` (15,000 THB into FCD for META & RBRK buys).
     - Missing FCD Interest: `2025-12-31` (+$24.23) and `2026-06-30` (+$3.34).
     - Unrecorded Withdrawals: On `2026-04-13` (31,700 THB = -$983.33 USD) and on `2026-04-23` (41,000 THB = -$1,271.78 USD) transferred out to external Thai bank accounts.
   * **Result:** Inserted all 5 reconciliation records into `stock.db` on VPS and local machine. Cash balance reconciled from `$1,770.65` down to **exactly `$5.04 USD`** (perfect 100% match with Dime app: $1.32 USD Dime! USD + $3.72 USD Dime! FCD). Total Net Worth aligned to `$2,543.53 USD`.

4. **Global Typography & Contrast Boost:**
   * **Brightness (+4 levels):** Replaced muted/dim `#9898C8` and `text-gray-400/500` with high-contrast `#CBD5E1` (Slate-300) and `#E2E8F0` (Slate-200) across all pages, cards, tables, headers, and tooltips.
   * **Font Size (+2 levels):** Stepped up `text-xs` from 12px to 14px (`0.875rem`), and `text-sm` from 14px to 16px (`1rem`). Enlarged Recharts SVG tick labels and headers for effortless legibility.

5. **Holdings Table Complete Revamp (6-Column Stacked Architecture & Dedicated Timeframe):**
   * **Dedicated Timeframe Selector:** Added Pill Buttons `[ 1D (Default) | 1W | 1M | 3M | YTD | 1Y | ALL | 📅 Custom ]` specifically on the Holdings card header, allowing users to examine asset price movement on a 1-day basis without altering the global 1-month portfolio view.
   * **6 High-Density Stacked Columns:**
     1. **Asset:** Logo badge + Symbol (bold white) + Number of shares held (Slate-300).
     2. **Market Price:** Real-time stock price (bold white) + `Avg: $...` cost per share (Slate-300).
     3. **Portfolio Value:** Total current market value (bold white) + `Cost: $...` total cost basis (Slate-300).
     4. **Total Profit / Loss (Hero Metric):** High-contrast highlighted card (`bg-emerald-500/10` or `bg-rose-500/10`) with bold profit amount (`+$...`) and return percentage (`+...%`).
     5. **Period Return:** Dynamic return across the selected timeframe (e.g. 1D return) showing profit in currency and %.
     6. **Portfolio Weight:** Weight percentage + horizontal gradient micro-progress bar.
   * **3 Summary Rows:** Stocks Total row, Cash Balance row, and Grand Total Net Worth gradient banner.

6. **Sticky Global USD/THB Currency Toggle & Live Yahoo Finance FX Integration (`THB=X`):**
   * **Live FX Service:** Built `fetchYahooExchangeRate` in `server/services/yahoo.js` querying `THB=X` on Yahoo Finance API with fallback to Polygon and default rate. Fetched real-time rate `1 USD = ฿33.17`.
   * **Sticky Global Header Placement:** Moved the `[ 🇺🇸 USD | 🇹🇭 THB ]` toggle into `Header.tsx` immediately to the left of the notification bell. This ensures the toggle is permanently sticky and accessible across ALL application views (Dashboard, Analysis, Performance, Transactions, Settings).
   * **Zero Decimal Rule for THB:** Implemented `minimumFractionDigits: 0, maximumFractionDigits: 0` for THB (`Math.round(val * exchangeRate)`) so all Thai Baht figures display as clean integers (e.g. `฿84,836`), while USD maintains 2 standard decimal places.
   * **Universal Currency Wiring:** Dynamically toggles all 4 Hero StatCards, Performance Chart (badge, YAxis ticks, and Tooltip), Holdings Table, Top 5/Bottom 5 Performers, and Recent Activity.

### สรุปมาตรฐาน

- **TWR** = มาตรฐาน GIPS — วัด "กลยุทธ์ดีแค่ไหน" ตัดผลฝาก/ถอนออก
- **MWR (Modified Dietz / IRR)** = วัด "ผลตอบแทนจริงที่นักลงทุนได้" รวม timing ฝาก/ถอน
- **Simple Return** แบบที่เราใช้ → ไม่มีแอปไหนใช้ ต้องแทนที่ด้วย MWR

## 🐛 Bug Analysis

### TWR (`calculateTwr`) — Bug 2 จุด

**Bug 1: CASH flow ไม่ถูก normalize**
โค้ดเช็ค `tx.asset === 'Cash' || tx.symbol === 'CASH'` เพื่อแยก cash แต่ไม่ได้ถือว่ามันเป็น "external flow" สำหรับสูตร TWR → TWR factor ผิดเบี้ยวเมื่อมีเงินเข้า/ออก

**Bug 2: DEPOSIT/WITHDRAW/DIVIDEND/INTEREST ไม่ถูกจัดการ**
ตอนคำนวณ TWR จับแค่ `BUY/SELL` ของหุ้น กับ `CASH BUY/SELL` → ไม่มี logic สำหรับ DEPOSIT/WITHDRAW/DIVIDEND/INTEREST

### Simple Return — สูตรผิดพลาดรุนแรง (ลบทิ้ง)

ตัวหาร `netCapitalInvested = buyCost - sellProceeds` ไม่รวม initial_cash ผิดทั้งแนวคิด ไม่มีแอปไหนใช้

## ✅ Proposed Changes

### Component 1: แก้ TWR ให้ถูกต้อง 100%
#### `PerformanceChartPage.tsx` → `calculateTwr`
แก้ไขให้ตรงตามสูตรมาตรฐาน GIPS:
1. NAV_before = cash + Σ(holdings[s] × price[s][d])
2. daily_return = NAV_before / NAV_after_prev
3. cumulative_twr *= daily_return
4. ประมวล transactions ของวัน d (ทุก type)
5. NAV_after = cash + Σ(holdings[s] × price[s][d])

### Component 2: แทนที่ Simple Return ด้วย MWR (Modified Dietz)
#### `PerformanceChartPage.tsx` → ลบ `calculateSimpleReturnChartData` → สร้าง `calculateMwr`
MWR = (EMV − BMV − ΣCF) / (BMV + Σ(Wi × CFi))
Wi = (CD − Di) / CD

- Personal Return (MWR)
