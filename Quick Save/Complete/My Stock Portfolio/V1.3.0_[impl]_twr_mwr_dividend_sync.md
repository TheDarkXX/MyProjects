# V1.3.0: TWR, MWR, and Dividend Sync Implementation

## 🧠 Context & Implementation (Compiled Truth)
The performance charting logic was significantly overhauled to provide professional-grade calculations matching platforms like Interactive Brokers and Fidelity. 

1. **Time-Weighted Return (TWR):** Fixed the bug where CASH transactions recorded as `type: 'BUY'` were misclassified. TWR now correctly isolates investment performance by recalculating the return sub-period accurately across all valid transaction types (BUY, SELL, DEPOSIT, WITHDRAW, DIVIDEND, INTEREST) using strict geometric linking.
2. **Modified Dietz Method (MWR):** Completely removed the flawed "Simple Return" calculation and replaced it with the industry-standard Modified Dietz formula. This properly weights the timing of deposits and withdrawals (`Wi = (CD - Di) / CD`) to reflect the investor's true personal rate of return.
3. **Dividend Auto-Sync:** Integrated `yahoo-finance2` with a new backend service (`server/services/dividendSync.js`) and API endpoint (`POST /api/dividends/sync/:portfolioId`). This service scans historical holdings and auto-generates `DIVIDEND` transactions based on the exact shares held on ex-dividend dates.
4. **Data Standardization:** Created a migration script (`server/scripts/migrate-cash-types.js`) to convert legacy CASH `BUY`/`SELL` rows in SQLite to standard `DEPOSIT`/`WITHDRAW` types.

## 🐛 Bug Analysis

### TWR (`calculateTwr`) — Bug 2 จุด

**Bug 1: CASH flow ไม่ถูก normalize**
โค้ดเช็ค `tx.asset === 'Cash' || tx.symbol === 'CASH'` เพื่อแยก cash แต่ **ไม่ได้ถือว่ามันเป็น "external flow"** สำหรับสูตร TWR → TWR factor ผิดเบี้ยวเมื่อมีเงินเข้า/ออก

**Bug 2: DEPOSIT/WITHDRAW/DIVIDEND/INTEREST ไม่ถูกจัดการ**
ตอนคำนวณ TWR จับแค่ `BUY/SELL` ของหุ้น กับ `CASH BUY/SELL` → ไม่มี logic สำหรับ DEPOSIT/WITHDRAW/DIVIDEND/INTEREST

### Simple Return — สูตรผิดพลาดรุนแรง (ลบทิ้ง)

ตัวหาร `netCapitalInvested = buyCost - sellProceeds` ไม่รวม initial_cash ผิดทั้งแนวคิด ไม่มีแอปไหนใช้
