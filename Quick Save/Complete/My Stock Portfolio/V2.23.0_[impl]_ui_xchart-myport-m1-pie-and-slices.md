# 🚀 V2.23.0: X-Chart 'My Port' M1 Finance Interactive Canvas & Slices Revamp

> **Mission**: ยกเครื่องแท็บ `My Port` ภายในระบบ X-Chart Multi-tab ทั้งหมด จากเดิมที่แสดงกราฟแท่งเทียนแท่งเดี่ยวซ้ำซ้อนกับแท็บอื่น มาเป็น **M1 Finance Interactive Portfolio Command Canvas** ที่ผสาน **Interactive Donut Wheel (Pies & Slices)**, **Dynamic Center Hub**, **Pro Slices Holdings Table with Drift Tracking**, **Bento Glassmorphic Cards**, และ **Slide-over Quick Inspect Drawer** พร้อมปุ่มลัดเปิดดูกราฟแท่งเทียนตัวเต็มในคลิกเดียว

---

## 🧠 Context & Implementation (Compiled Truth)

### 1. ปัญหาเดิมและวิวัฒนาการสู่ M1 Finance Paradigm
- **ปัญหาเดิม:** ในหน้า `My Port` แท็บถูกเขียนให้เรนเดอร์ Candlestick Chart ของหุ้นตัวเดียว ทำให้เสียพื้นที่ และผู้ใช้ไม่สามารถเห็นภาพรวมของสินทรัพย์ทั้งหมดในพอร์ต
- **The M1 Finance Paradigm:**
  1. **The Iconic Interactive Donut Wheel:** ชิ้นพายคำนวณจาก **Actual Holdings Value ($)** ณ วินาทีจริง
  2. **Dynamic Center Hub:** เมื่อไม่มีการชี้ จะสรุปยอดพอร์ตรวม (Total Net Worth, Today's P&L, Total Return) แต่เมื่อเมาส์ชี้ Slice ไหน ชิ้นเค้กจะขยายขึ้น +8px เรืองแสง Glow และ Center Core จะสลับแสดงสถิติเจาะลึกของหุ้นตัวนั้นแบบ Real-time
  3. **Segmented Linear Allocation Bar:** หลอดแสดงสัดส่วนพอร์ตแนวนอน multi-color ใต้ Donut มองปราดเดียวรู้สัดส่วนพอร์ตทั้งหมด
  4. **Two-Way Hover Sync:** ชี้ในวงล้อ -> ไฮไลต์แถวในตาราง / ชี้ในตาราง -> ไฮไลต์ชิ้นเค้กบนวงล้อ
  5. **Slices Holdings Table:** แสดง 6 คอลัมน์หลัก สะอาดตา ไม่รก แสดง Actual Weight % เทียบ Target Weight % พร้อมป้ายกำกับ **Drift** (`+Over` / `-Under`)
  6. **Triple View Modes:** สลับมุมมองได้ 3 แบบตามต้องการ (`M1 Split`, `Full Table`, `Bento Cards`)
  7. **Slide-over Holding Drawer:** เลื่อนเปิดจากขอบขวาเมื่อคลิกหุ้น แสดงประวัติไม้ที่ซื้อทั้งหมด (Trade Lots) และเป้ากลยุทธ์ Blueprint

## 🔍 Root Cause Analysis (จาก Screenshot จริง)

### Problem 1: KPI Header Strip — "ของชิดจนหายใจไม่ออก"
- **สิ่งที่เห็น**: KPI กล่อง 5 ก้อน + Portfolio Selector + View Mode Switcher + Badge "M1 Interactive Canvas" ยัดอยู่ในแถบบรรทัดเดียว
- **Blast Radius**: แถบบนกินพื้นที่แนวตั้ง ~70px แต่ข้อมูลแน่นจน label ตัวเล็กอ่านไม่ทัน
- **Root Cause**: ทุก KPI อยู่ใน `border box` ที่เหมือนกันหมด → ไม่มี hierarchy → ตาวิ่งไปวนมา

### Problem 2: Table — "8 คอลัมน์เยอะเกินไปสำหรับ Split View"
- **สิ่งที่เห็น**: ในโหมด Split View (ด้านขวาที่มีตาราง) ยัด 8 คอลัมน์ลงไป: Symbol, Weight, Price, Cost, Value, P&L, Blueprint, Actions
- **Blast Radius**: ข้อความในแต่ละเซลล์ถูกบีบจนอ่านยาก ตัวเลขชิดกัน
- **Root Cause**: ไม่ได้แยก columns ตาม context — ในโหมด Split View ควรลดเหลือ 5-6 คอลัมน์หลัก ส่วน Blueprint + Cost ให้ไปอยู่ใน Drawer แทน

### Problem 3: Donut Legend Grid ล่าง — "ซ้ำซ้อนกับตาราง"
- **สิ่งที่เห็น**: Legend Grid 2 คอลัมน์ใต้ Donut แสดง Symbol + % + Value + Return% — ข้อมูลเดียวกับที่ตารางด้านขวาแสดงอยู่แล้ว
- **Root Cause**: ออกแบบ Legend เหมือนมันเป็น standalone view แต่จริง ๆ ตอน Split View มันอยู่ข้าง ๆ ตารางอยู่แล้ว

### Problem 4: Filter Chips Bar — "กินพื้นที่แนวตั้งโดยไม่จำเป็น"
- **สิ่งที่เห็น**: Search + Filter Chips (`All`, `Winners`, `Drawdowns`, `Overweight`, `Underweight`) อยู่ในแถบแยกกินพื้นที่ ~50px ก่อนถึง table header
- **Root Cause**: กรอง Filter มีข้อความยาว ปุ่ม icon + text เรียงยาว

### Problem 5: Visual Uniformity — "ไม่มีอะไรที่ดูพิเศษ"
- **สิ่งที่เห็น**: ทุก card, KPI box, pill, badge ใช้ `bg-[#141824] border border-slate-800 rounded-xl` เหมือนกันหมด → เฟลต, ไม่มีความลึก
- **Root Cause**: ขาด layering depth ที่ต่างกัน และขาด subtle gradient / glow ที่บอกว่า "ตรงนี้สำคัญกว่าตรงนั้น"
