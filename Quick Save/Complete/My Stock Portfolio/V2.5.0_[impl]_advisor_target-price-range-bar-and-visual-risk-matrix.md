# AI Portfolio Advisor: Target Price Range Bar, Crisis Drawdown Dollar Impact & Visual Risk Matrix (V2.5.0)

## 💡 Context & Implementation (Compiled Truth)

### 1. Why this was done:
In V2.4.0, the Executive Cockpit with segmented tabs was introduced to solve "long-scroll fatigue" and structure the output into 4 tabs (Plan, Stocks, Stress, Macro).
However, during comprehensive testing and user quality review, several major data visualization and structured data gaps were identified:
1. **Target Price Blind Spot:** Yahoo Finance provided `target_low_price` and `target_high_price` via batch fundamentals, but they were never rendered. The user only saw a single mean target number without the visual spectrum/corridor (Low—Current—Mean—High).
2. **Stress Test Lack of Dollar Dimension:** The `DrawdownMeter` rendered percentage ranges (e.g. `-20% ถึง -35%`), but lacked real dollar impact calculations (`💸 -$15,200 ~ -$22,000`) based on actual portfolio holdings (`totalNetWorth`), leaving users unable to gauge absolute portfolio monetary damage.
3. **Wall of Text in Qualitative Sections:** Tab 4 (Macro & Overview) presented Strengths, Weaknesses, and Missing Exposures as plain text bullets and flat pills without visual hierarchy or severity indicators.
4. **Backend Schema Gaps:** The LLM prompt lacked structured fields for `aiTargetPrice`, `aiTimeframe`, `catalysts[]`, and `risks[]`, forcing future outlook into a single truncated text string.

---

### 2. Core Implementations & Architecture:

#### A. Target Price Range Bar Component (`TargetPriceRangeBar.tsx`):
Created a dedicated horizontal spectrum component showing Wall Street analyst targets and AI price estimates:
- **Price Corridor Spectrum:** Visual gradient track spanning from `Low` (Bearish floor) to `High` (Bullish ceiling).
- **Non-Colliding Floating Badges:** Placed the **Current Price Pin** and **AI Target Badge** above the track with downward pointers, while anchoring **Low, Mean, High** values below the track to eliminate text overlap collisions when current price is near consensus.
- **Dynamic Domain Bounds:** Uses `minDomain = Math.min(...allPoints) * 0.95` and `maxDomain = Math.max(...allPoints) * 1.05` to provide breathing room and prevent edge-clipping.

```tsx
export const TargetPriceRangeBar: React.FC<TargetPriceRangeBarProps> = ({
  currentPrice,
  targetLow = 0,
  targetMean = 0,
  targetHigh = 0,
  aiTargetPrice,
  aiTimeframe,
  currency = '$'
}) => {
  if (!targetLow || !targetHigh || targetHigh <= targetLow) return null;

  const allPoints = [targetLow, targetHigh].filter(p => p > 0);
  if (targetMean > 0) allPoints.push(targetMean);
  if (currentPrice > 0) allPoints.push(currentPrice);
  if (numAiTarget && numAiTarget > 0) allPoints.push(numAiTarget);

  const minDomain = Math.min(...allPoints) * 0.95;
  const maxDomain = Math.max(...allPoints) * 1.05;
  const range = maxDomain - minDomain;

  const toPct = (val: number) => {
    if (range <= 0) return 50;
    return Math.max(4, Math.min(96, ((val - minDomain) / range) * 100));
  };
  ...
};
```

#### B. DrawdownMeter Dollar Impact Calculation (`DrawdownMeter.tsx`):
- Accepts optional `portfolioTotalValue?: number` and `currency?: string`.
- Computes estimated monetary drawdown:
  ```ts
  const hasDollarImpact = typeof portfolioTotalValue === 'number' && portfolioTotalValue > 0;
  const minDollarLoss = hasDollarImpact ? portfolioTotalValue * (minVal / 100) : 0;
  const maxDollarLoss = hasDollarImpact ? portfolioTotalValue * (maxVal / 100) : 0;

  const formattedDollarLoss = hasDollarImpact
    ? minVal !== maxVal
      ? `-${currSym}${Math.round(minDollarLoss).toLocaleString()} ~ -${currSym}${Math.round(maxDollarLoss).toLocaleString()}`
      : `-${currSym}${Math.round(minDollarLoss).toLocaleString()}`
    : null;
  ```
- **Fallback Rule:** If no actual portfolio value is available, gracefully falls back to displaying only `%` without breaking.
- **Inverted Range Bug Fix:** Utilizes `Math.min(...rawNums)` and `Math.max(...rawNums)` to guarantee `minVal <= maxVal` even if LLM outputs inverted text like `"-30% ถึง -15%"`.

#### C. Macro Theme Pills & Strengths/Weaknesses Cards (`AIBlueprintAdvisor.tsx`):
- **Macro Key Indicators:** Dynamically parses `macroAnalysis` text with regex rules to extract and display high-impact badges:
  - `🏦 วงจรอัตราดอกเบี้ย` (Interest Rate Cycle)
  - `📈 แรงกดดันเงินเฟ้อ` (Inflation Pressure)

  - `🌍 ความเสี่ยงภูมิรัฐศาสตร์` (Geopolitical Risk)
  - `🛢️ ความผันผวนพลังงาน` (Energy Volatility)
- **Strengths Tier Cards:** Replaced plain bullets with card grid and auto-tier badges:
  - `💎 Wide Moat Fortress` (Moat, ป้อมปราการ, ผูกขาด)
  - `🚀 High Compounder` (เติบโต, กำไร, Beat Streak)

  - `🟡 เฝ้าระวัง (Watch)` (เฝ้าระวัง, เริ่มชะลอ)

#### D. Missing Tactical Exposures Visual Cards (`AIBlueprintAdvisor.tsx`):

  - Category icon mapping (`🏥 Healthcare`, `⚡ Energy`, `🪙 Gold/Commodities`, `🛒 Staples`, `💡 Utilities`, `🏦 Financials`, `🏢 REITs`).

### 🐛 จุดที่ 1: บัค Inverted Number Range ใน DrawdownMeter.tsx
- **ปัญหาเดิม:** หาก AI ส่งข้อความจำลองวิกฤตที่มีตัวเลขกลับทิศ เช่น `"-30% ถึง -15%"` โค้ดเดิมจะจับคู่ `minVal = 30`, `maxVal = 15` ส่งผลให้การคำนวณความกว้างแถบสีติดลบ (`widthPct < 0`) และการแสดงมูลค่าเงินกลายเป็นช่วงกลับหัว (`-$30,000 ~ -$15,000`)
- **การแก้ไข:** ใช้ `Math.min(...rawNums)` และ `Math.max(...rawNums)` การันตี 100% ว่า `minVal <= maxVal` เสมอ และกรณีตัวเลขเท่ากันจะแสดงค่าเดียว ไม่แสดงช่วงซ้ำซ้อน

### 🎯 จุดที่ 2: Pin & Badge Collision ใน TargetPriceRangeBar.tsx
- **ปัญหาเดิม:** การวางป้ายราคาปัจจุบัน (Current Price) และราคา Mean Consensus อยู่ในระนาบล่างเหมือนกัน หากราคาปัจจุบันอยู่ใกล้เป้าหมายเฉลี่ย ป้ายข้อความจะทับกันจนอ่านไม่ออก
- **การแก้ไข:** ปรับสถาปัตยกรรมเลย์เอาต์ใหม่:
  - ย้าย **Current Price Pin & AI Target Badge** ขึ้นไปลอยอยู่ **ด้านบนของแถบสเปกตรัม** พร้อมลูกศรชี้ลงอย่างแม่นยำ
  - ตรึงราคา **Low, Mean, High** อยู่ **ด้านล่างของแถบสเปกตรัม**
  - ผลลัพธ์: การันตีว่าจะไม่มีการทับซ้อนกันของข้อความในทุกกรณี แม้ราคาปัจจุบันจะเท่ากับราคาเฉลี่ยพอดีก็ตาม

### 🛡️ จุดที่ 3: ป้องกัน Type Mismatch & Unhandled Exceptions
- **`StockVerdictCard.tsx`:** 
  - เพิ่ม Array Normalization ให้กับ `catalysts` และ `risks` รองรับทั้งกรณีที่ LLM ส่งมาเป็น Array, String เดี่ยว หรือ Null โดยไม่มีวันเกิด `TypeError: .map is not a function`
  - เพิ่ม Fallback ให้กับสัญลักษณ์หุ้นที่มีจุดหรือขีด เช่น `BRK.B` / `BRK-B` เพื่อให้ค้นพบข้อมูลพื้นฐานจาก Yahoo Finance ได้อย่างครบถ้วน
- **`AIBlueprintAdvisor.tsx`:**
  - เพิ่ม Defensive Check ให้กับ `strengths`, `weaknesses` และ `missingExposure` ดึงข้อความได้อย่างปลอดภัยแม้ประวัติแคชเก่าจะเก็บข้อมูลรูปแบบ String ล้วน
