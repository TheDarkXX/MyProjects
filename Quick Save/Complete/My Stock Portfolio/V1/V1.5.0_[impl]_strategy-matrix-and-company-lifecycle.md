# V1.5.0: Strategy Matrix & Company Lifecycle

## 📝 Context & Implementation (Compiled Truth)
- Renamed the "Speculative" strategy to "Small Cap" across the SQLite database, backend services, and frontend UI to better reflect the company lifecycle.
- Introduced the "Company Lifecycle" logic: Small Cap -> Hyper Growth -> Core Compounder -> Dividend Growth.
- Revamped Strategy Badges in `TransactionTable.tsx` to use solid vibrant colors (`bg-[color] text-white rounded-lg hover:scale-105`) instead of generic borders, providing high contrast and instant recognition.
- Separated conflicting colors (e.g., cyan/magenta/blue) into entirely distinct spectrums:
  - Dividend Growth: Deep Brown (`#854d0e`)
  - High Yield: Deep Pink (`#db2777`)
  - Index / ETF: Deep Cobalt Blue (`#1d4ed8`)
- Added `docs/STRATEGY_GUIDE.md` to document the 8 core strategies, their color codes, and the lifecycle rationale.
- Polished Portfolio Analysis (V1.4.1 follow-up) with larger font sizes, removed duplicate Performers table, fixed percentage calculations, and refined Treemap hovers.

## 🔍 รายละเอียดการอัปเกรดแต่ละส่วน

### 1. `AllocationPieChart.tsx` (Asset Allocation & Profit Contributor)
- **Currency Sync**:
  - ดึง `currency` จาก `useUiStore` และ `exchangeRate` จาก `usePriceStore`
  - แปลงตัวเลขทุกจุด: USD แสดง 2 ทศนิยม (`$xx.xx`), THB แสดงจำนวนเต็ม 0 ทศนิยม (`฿xx,xxx`)
- **Timeframe Sync**:
  - รับ `timeRange` จาก `AnalysisPage`
  - ในโหมด **Profit Contributor**: คำนวณกำไรตามช่วงเวลาที่เลือก (เช่น `1D` ดึงกำไรรายวัน, `1M/YTD` คำนวณจากประวัติราคา, `Total` กำไรรวม)
- **Beauty & Interactive Effects**:
  - **Center Stat Display**: ตรงกลางวงโดนัทแสดง Symbol, เปอร์เซ็นต์สัดส่วน, และมูลค่าเงินของชิ้นส่วนที่เอาเมาส์ชี้
  - **Active Glow Ring**: มีวงแหวนเรืองแสงและเอฟเฟกต์ขยายขนาดเมื่อ Hover
  - **Interactive Legend Grid**: รายการด้านขวามีแถบสีและแถบสัดส่วนย่อย Hover ไฮไลต์ร่วมกัน

### 2. `DistributionPieChart.tsx` (Multi-Dimensional Portfolio Distribution)
- **3 โหมดการกระจายความเสี่ยง**:
  - `Sector`: กระจายตามอุตสาหกรรม (Technology, Communication, Healthcare ฯลฯ ใช้ `SECTOR_MAP` ตัวใหม่)
  - `Asset`: สัดส่วน Stock, ETF, Cash
  - `Type`: สัดส่วน Growth, Compounder, Dividend, Small Cap
- **Currency Sync**:
  - ตรงกลางวงโดนัทแสดงมูลค่ารวมพอร์ตในสกุลเงินที่เลือก (`$xx.xx` หรือ `฿xx,xxx`)
- **Beauty & Interactive Effects**:
  - โทนสี Cyberpunk/Neon ที่ตัดกันชัดเจน
  - Glassmorphic Tooltip แสดงสัดส่วน %, มูลค่าเงินทั้ง USD และ THB

### 3. `CostValueBars.tsx` (Cost Basis vs Market Value Comparison)
- **Currency Sync**:
  - ตัวเลขแกน Y, ความสูงแท่งกราฟ, และ Tooltip แปลงตาม Currency อัตโนมัติ (เช่น `$1.2K` หรือ `฿40K`)
- **Timeframe Sync**:
  - ฟังก์ชันเรียงลำดับ `Profit $` และ `Profit %` จะคำนวณกำไรตาม Timeframe ที่เลือกใน Top Bar
- **Beauty & Interactive Effects**:
  - **Dual Gradient Bars**:
    - แท่ง Cost: เฉดสี Indigo-Slate นุ่มนวล (`#6366F1` -> `#4338CA`) พร้อมขอบมนด้านบน
    - แท่ง Market Value: เฉดสี Emerald เขียวมรกต (`#10B981` -> `#059669`) เมื่อกำไร หรือ Rose แดงทับทิม (`#F43F5E` -> `#E11D48`) เมื่อขาดทุน
  - **Pill Filter Bar**: ปุ่มเรียงลำดับแบบแคปซูลสวยงาม: `[ Value | Cost | Profit $ | Profit % | A-Z ]`
  - **Rich Glassmorphic Tooltip**: แสดงทั้ง Cost Basis, Current Value, กำไรตามช่วงเวลา ($ และ %), และกำไรรวมสะสม

### 4. `AnalysisPage.tsx` (Reordering & State Distribution)
- ย้ายตำแหน่งเลย์เอาต์:
  - **Row 1**: `AllocationPieChart` + `DistributionPieChart`
  - **Row 2**: `CostValueBars`
  - **Row 3**: `Heatmap` (Treemap สไตล์ Finviz)
  - **Row 4**: `PerformersTable`
- ส่ง `timeRange`, `currency`, `exchangeRate` ลงไปยังทุกคอมโพเนนต์อย่างสอดคล้องกัน

## ⏳ Timeline & Debugging Log
- The user initiated a session to redefine strategy categories.
- Migrated "Speculative" to "Small Cap" via a temporary SQLite script.

- User provided a key architectural logic: "The Company Lifecycle", where a stock starts as Small Cap, hits Hyper Growth, becomes a Core Compounder, and eventually transitions to Dividend Growth.
- Adjusted `Dividend Growth` to `#854d0e` (Deep Brown) and `High Yield` to `#db2777` (Deep Pink).
- Documented the lifecycle logic in `docs/STRATEGY_GUIDE.md`.
- User manually updated `Small Cap` badge in `TransactionTable.tsx` to `#facc15 text-black` for maximum high-contrast visibility.
- User inquired about the institutional standard for transactions with `Price = 1` (Cash Flows):
  - Decoupled share trading display from cash transactions (`DIVIDEND`, `INTEREST`, `DEPOSIT`, `WITHDRAW`, `FEE`).
  - Rendered `-` for Price and Quantity columns for cash flows in `TransactionTable.tsx`.
  - Added Net Cash Flow styling with `+`/`-` and emerald/rose text in Total ($).
  - Updated `TransactionFormModal.tsx` to automatically hide Quantity/Price and display a single "Total Value ($)" input for cash flows, enforcing `price: 1` on submit.
- Fixed a bug where clicking "Edit" caused a dark screen blur without displaying the modal:
  - Cause: Modal was mounted inside `<main overflow-y-auto>` and scrolled out of viewport, plus risk of date parsing error.
  - Solution: Portaled modal directly to `document.body` via `createPortal` with `z-[9999]`, added backdrop click-to-close, and created safe `formatDateForInput`.
- Added `Note` column to `TransactionTable.tsx` and `Note (Optional)` input to `TransactionFormModal.tsx`.
- Replaced dummy Bell and "AD" Admin avatar in `Header.tsx` with an enlarged (+3 levels) live Yahoo API LED Status Badge with pulsing green light and Last Updated timestamp (`Date + Time`), plus click-to-refresh.
- Audited TWR and MWR financial math and chart normalization:
  - Verified GIPS compliance: Dividends/Interest are correctly counted as investment gains and excluded from external cash flows.
  - Verified split adjustments in Yahoo Finance API quotes.
  - Verified chart base normalization: Chain-linked rebasing sets all benchmark lines to 0.0% at Day 0 with zero-gap carryover.
