# V2.70.3: XChart Watchlist Sidebar INDEX Friendly Display Names

## 📌 Context & Implementation (Compiled Truth)
- **Problem Statement:**
  - In V2.70.1, the sidebar INDEX section was stripped of its noisy parentheses descriptions to prevent ticker truncation, leaving only raw tickers (`USO`, `UUP`, `TLT`, `GLD`, `SMH`, `BTC-USD`, etc.).
  - While this fixed truncation, raw ETF tickers like `USO` (United States Oil Fund), `UUP` (Invesco DB US Dollar Index), and `TLT` (20+ Year Treasury Bond) were counter-intuitive for fast macro scanning at a glance.
- **Core Architecture & Solutions:**
  - **Smart Display Names (`displayName`):** In `MyPortWatchlist.tsx`, extended `IndexStockItem` interface with optional `displayName?: string`.
  - **Human-Centric Mapping:** Configured intuitive display names requested by user:
    - `USO` ➔ `Crude Oil`
    - `UUP` ➔ `US Dollar`
    - `TLT` ➔ `US Bond`
    - `GLD` ➔ `Gold`
    - `SMH` ➔ `Semicon ETF`
    - `BTC-USD` ➔ `Bitcoin`
    - `SPY`, `QQQ`, `SCHG` remain unchanged as standard industry benchmarks.
  - **Data Parity & Chart Continuity:** Underlying `symbol` fields (`USO`, `UUP`, `TLT`, etc.) remain 100% untouched, ensuring seamless Yahoo Finance batch polling in `xchartStore.ts` and correct TradingView chart symbol selection.
  - **Dynamic Symbol Sort Alignment:** Updated `sortedIndexItems` comparator so sorting by symbol respects `displayName || symbol`.
  - **Tooltip Enrichment:** Enhanced hover tooltips to show `${item.symbol} (${item.name})${item.sub ? ' · ' + item.sub : ''}` for full institutional detail without cluttering the 30px compact row.
- **Verification & Deployment:**
  - `npm run build` executed cleanly in 16.60s (0 errors).
  - Production cache bumped to `v=20261014_113322`.
