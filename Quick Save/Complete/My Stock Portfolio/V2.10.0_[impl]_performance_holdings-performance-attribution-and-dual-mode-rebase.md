# Holdings Performance Attribution (Dual Chart) with TradingView-Style Dynamic Window Rebasing & Inception Modes (V2.10.0)

## 💡 Context & Implementation (Compiled Truth)

### 1. ปัญหาเดิมและโจทย์ความต้องการของผู้ใช้ (Context & Core Objectives)

ในหน้า `PerformanceChartPage` เดิมมีกราฟเปรียบเทียบผลตอบแทนหลักของพอร์ต (Portfolio TWR) เทียบกับ Hurdle Rates ชั้นนำในตลาดโลก (SPY, QQQ, SCHG, Gold, Bitcoin) แต่ผู้ใช้พบข้อจำกัดสำคัญในการวิเคราะห์พอร์ตโฟลิโอ:
1. **ขาดมุมมอง Relative Contribution ของหุ้นรายตัว (No Holdings Trajectory):** ไม่สามารถมองเห็นได้ว่าในช่วงเวลาที่เลือก หุ้นตัวใดในพอร์ตเป็นตัวนำขบวน (Alpha Driver / The Carry) และตัวใดเป็นตัวฉุดผลงาน (Laggard / Dead Weight)
2. **ปัญหาการซื้อหุ้นต่างช่วงเวลา (Asynchronous Inception):** หุ้นแต่ละตัวในพอร์ตไม่ได้ถูกซื้อเข้ามาพร้อมกัน หากคำนวณแบบราคาปิดเฉยๆ หุ้นที่เพิ่งซื้อใหม่จะไม่มีบริบท หรือแสดงผลตอบแทนย้อนหลังไปยังช่วงเวลาก่อนที่ผู้ใช้จะซื้อมันเข้ามาจริง
3. **ความต้องการ Interactive Timeframe Zooming แบบ TradingView:** ผู้ใช้ต้องการย่อ-ขยายกรอบเวลาได้อย่างอิสระผ่านเมาส์ (`Ctrl + Scroll`) โดยไม่ต้องคลิกปุ่ม Timeframe ซ้ำไปซ้ำมา
4. **ความเข้าใจลึกซึ้งเรื่องสูตรคำนวณ (Inception vs TradingView Window Rebase):**
   - **Since Inception (พอร์ตจริง):** วัดกำไรสะสมตั้งแต่ "วันแรกที่ซื้อหุ้นตัวนั้นเข้ามาจริง" สะท้อนความจริงในกระเป๋าตังค์
   - **TradingView Compare (Window Rebase):** ไม่สนใจว่าซื้อเมื่อใด วันแรกสุดซ้ายมือที่กางจอออกมาดูจะถูกตั้งเป็น 0.00% ทันที เพื่อวัด Relative Momentum หมัดต่อหมัด
   - **User Resolution:** ออกแบบ **Dual Mode Switcher** ให้สลับดูได้ทั้ง 2 โลกในคลิกเดียว โดยตั้ง **`Since Inception` เป็นค่าเริ่มต้น (Default)**

### 2. สถาปัตยกรรมและการทำงาน (System Architecture & Highlights)

#### 1) 4/5 Line Chart + 1/5 Leaderboard Bar Chart (Dual Chart Layout)
- **อัตราส่วน 4 : 1:** บนหน้าจอขนาดใหญ่ แบ่งพื้นที่ 4/5 ให้กับกราฟเส้น Relative Trajectory และ 1/5 ทางขวาสำหรับ Leaderboard Ranking Bar Chart
- **Leaderboard โต้ตอบได้ (Interactive):** คลิกที่แถบหุ้นใน Ranking เพื่อเปิด/ปิดเส้นบนกราฟได้ทันที
- **Badge แท็กหุ้นใหม่ (`New`):** กำกับตัวที่เพิ่งซื้อในรอบเวลาที่ดู เพื่อความชัดเจนและโปร่งใส

#### 2) Dual Mode Engine (`Since Inception` vs `TradingView 0% Rebase`)
- **โหมด 1: `Since Inception` (Default):**
  - หุ้นทุกตัวเริ่มสตาร์ทที่ 0.00% ณ วันแรกที่ซื้อเข้าพอร์ตจริง (`firstBuyDate`)
  - ช่วงเวลาก่อนซื้อ เส้นจะเป็น `null` ไม่โผล่มากวนสายตา
  - เส้น `Portfolio (TWR)` แสดงผลตอบแทนรวมจริงตามพอร์ต
- **โหมด 2: `TradingView (0%)`:**
  - วันแรกสุดทางซ้ายของจอ (`effectiveDates[0]`) จะถูกเซ็ตเป็นฐาน 0.00% สำหรับทุกตัว
  - ทุกเส้นสตาร์ทพร้อมกันที่เส้นประสีขาว 0.00% กลางจอ
  - ตัวที่เพิ่งซื้อระหว่างทาง จะเริ่มโผล่ที่ 0.00% ในวันที่ซื้อมันเข้ามาจริง

#### 3) Pixel-Space Anti-Collision Badge Solver & Edge Clamping
- ปลายเส้นกราฟมี Floating Badge แสดง `+XX.X% - SYMBOL`
- พัฒนาอัลกอริทึมแก้ปัญหา Badge ทับกัน (Anti-Collision Displacement Solver) จัดระยะห่างแกน Y อัตโนมัติใน Pixel Space
- ป้องกันป้ายหลุดขอบบน/ล่างด้วย Hard Clamping: `targetY = Math.max(22, Math.min(290, y + yOffset))`
- เพิ่มขอบเขตด้านขวา `margin={{ top: 15, right: 155, left: -10, bottom: 5 }}` ป้องกันป้ายล้นออกนอกกราฟ

#### 4) Ctrl + Scroll Timeframe Zooming
- รองรับทั้งในกราฟหลัก (`PerformanceChartPage.tsx`) และกราฟรายตัว (`HoldingsPerformanceAttribution.tsx`)
- ตรวจจับ `e.ctrlKey || e.metaKey` เพื่อขยายหรือย่อจำนวนวันบนแกน X แบบ Smooth พร้อมปุ่ม `Reset Zoom` สีส้มอำพันเมื่อมีการซูม

#### 5) Easy Pick Chips เรียงตามกำไร ("มาก ไว้หน้า")
- ชิปเลือกหุ้นด้านบนถูกจัดเรียงตาม `% Return Descending` จากตัวกำไรมากสุดไปหาตัวน้อยสุด
- แต่ละชิปมี Pill Tag แสดง `% กำไร/ขาดทุน` พร้อมสัญลักษณ์บวก/ลบ และสีเขียวมรกต/แดงกุหลาบ

### 3. โค้ดหลักที่สำคัญ (Core Implementation Snippets)

#### 1) Calculation Engine ใน `HoldingsPerformanceAttribution.tsx`

```typescript
export type AttributionMode = 'inception' | 'tradingview';

// Dynamic Data Processing Hook
const { chartData, leaderboardData } = useMemo(() => {
  if (effectiveDates.length === 0 || activeHoldings.length === 0) {
    return { chartData: [], leaderboardData: [] };
  }

  const startDate = effectiveDates[0];
  const portfolioMap = new Map<string, number>();
  portfolioReturnData.forEach(p => {
    if (p.date && p.value !== undefined) {
      portfolioMap.set(p.date, p.value);
    }
  });

  const baselinePortfolio = portfolioMap.get(startDate) ?? 0;
  const basePriceMap: Record<string, number> = {};
  const effectiveStartMap: Record<string, string> = {};

  activeHoldings.forEach(sym => {
    const prices = priceData[sym] || {};
    const firstBuy = firstBuyDates[sym] || startDate;

    if (mode === 'tradingview') {
      // TradingView Mode: Left-most visible date is base 0%
      if (firstBuy <= startDate) {
        effectiveStartMap[sym] = startDate;
        if (prices[startDate]) {
          basePriceMap[sym] = prices[startDate];
        } else {
          const sortedDates = Object.keys(prices).filter(d => d <= startDate).sort();
          basePriceMap[sym] = sortedDates.length > 0 ? prices[sortedDates[sortedDates.length - 1]] : 0;
        }
      } else {
        effectiveStartMap[sym] = firstBuy;
        basePriceMap[sym] = prices[firstBuy] || 0;
      }
    } else {
      // Inception Mode: Return since actual first purchase
      effectiveStartMap[sym] = firstBuy;
      if (prices[firstBuy]) {
        basePriceMap[sym] = prices[firstBuy];
      } else {
        const sortedDates = Object.keys(prices).filter(d => d >= firstBuy).sort();
        basePriceMap[sym] = sortedDates.length > 0 ? prices[sortedDates[0]] : 0;
      }
    }
  });

  const series: any[] = [];
  const latestReturns: Record<string, number | null> = {};

  effectiveDates.forEach(date => {
    const point: any = { date };

    if (portfolioMap.has(date)) {
      const rawPort = portfolioMap.get(date) ?? 0;
      point['Portfolio'] = mode === 'tradingview'
        ? Number((rawPort - baselinePortfolio).toFixed(2))
        : Number(rawPort.toFixed(2));
    } else if (mode === 'tradingview' && date === startDate) {
      point['Portfolio'] = 0;
    }

    activeHoldings.forEach(sym => {
      const firstValidDate = effectiveStartMap[sym];
      const basePrice = basePriceMap[sym];
      const prices = priceData[sym] || {};

      if (date < firstValidDate) {
        point[sym] = null;
      } else if (date === firstValidDate) {
        point[sym] = 0;
        if (latestReturns[sym] === undefined) latestReturns[sym] = 0;
      } else if (basePrice && basePrice > 0) {
        let currentPrice = prices[date];
        if (currentPrice === undefined) {
          const pastDates = Object.keys(prices).filter(d => d <= date).sort();
          if (pastDates.length > 0) currentPrice = prices[pastDates[pastDates.length - 1]];
        }

        if (currentPrice !== undefined && basePrice > 0) {
          const pct = ((currentPrice - basePrice) / basePrice) * 100;
          point[sym] = Number(pct.toFixed(2));
          latestReturns[sym] = point[sym];
        } else {
          point[sym] = 0;
        }
      } else {
        point[sym] = null;
      }
    });

    series.push(point);
  });

  const ranking = activeHoldings.map(sym => ({
    symbol: sym,
    returnPercent: latestReturns[sym] ?? 0,
    color: colorMap[sym],
    isNew: mode === 'tradingview' ? (firstBuyDates[sym] || '') > startDate : (firstBuyDates[sym] || '') > (effectiveDates[0] || ''),
    firstBuyDate: firstBuyDates[sym],
  })).sort((a, b) => b.returnPercent - a.returnPercent);

  return { chartData: series, leaderboardData: ranking };
}, [mode, displayDates, effectiveDates, activeHoldings, priceData, firstBuyDates, portfolioReturnData, colorMap]);
```

#### 2) Anti-Collision Badge Displacement Solver

```typescript
const lineOffsets = useMemo(() => {
  if (!lastDataPoint) return {};
  const active = Object.entries(selectedSymbols)
    .filter(([sym, isSel]) => isSel && typeof lastDataPoint[sym] === 'number')
    .map(([sym]) => ({ name: sym, val: Number(lastDataPoint[sym]) }));

  if (showPortfolio && typeof lastDataPoint['Portfolio'] === 'number') {
    active.push({ name: 'Portfolio', val: Number(lastDataPoint['Portfolio']) });
  }

  const allVals = active.map(a => a.val);
  const minVal = Math.min(...allVals, 0);
  const maxVal = Math.max(...allVals, 0);
  const range = maxVal - minVal || 1;
  const chartHeight = 240;

  const items = active.map(item => ({
    name: item.name,
    rawY: chartHeight - ((item.val - minVal) / range) * (chartHeight - 40) - 20,
    currY: chartHeight - ((item.val - minVal) / range) * (chartHeight - 40) - 20,
  })).sort((a, b) => a.currY - b.currY);

  const minGap = 26;
  for (let iter = 0; iter < 12; iter++) {
    for (let i = 0; i < items.length - 1; i++) {
      const cur = items[i];
      const next = items[i + 1];
      const overlap = minGap - (next.currY - cur.currY);
      if (overlap > 0) {
        cur.currY -= overlap / 2;
        next.currY += overlap / 2;
      }
    }
  }

  const offsets: Record<string, number> = {};
  items.forEach(item => {
    offsets[item.name] = Math.round(item.currY - item.rawY);
  });
  return offsets;
}, [lastDataPoint, selectedSymbols, showPortfolio]);
```
