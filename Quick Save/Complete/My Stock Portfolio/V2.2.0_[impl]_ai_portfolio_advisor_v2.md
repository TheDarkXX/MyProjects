# AI Portfolio Advisor v2

## 💡 Context & Implementation (Compiled Truth)
This session implemented a complete architectural revamp and UI polish for the AI Portfolio Advisor feature.

**Key Features:**
1. **Model Switch & Proxy Setup**:
   - Replaced client-side Gemini Flash calls with **GPT-5.6 Terra-High** via a secure VPS proxy endpoint (`brain.doctorbankonline.com/api/ai/chat`).
   - Implemented `server/routes/ai-advisor.js` to handle the proxy connection, including proper `Bearer` token and `X-Agent-Id` headers.
   - Enforced a strict "Thai-only" System Prompt for the LLM to ensure all generated insights, strengths, weaknesses, and suggestions are in Thai (while allowing technical headers).

2. **Data Enrichment**:
   - Introduced `server/services/yahooFundamentals.js` with batch fetching and a 3-tier caching mechanism (Memory -> SQLite -> AI API).
   - Augmented AI prompts with deep Yahoo Fundamental data (P/E trailing/forward, ROE, Beta, Revenue Growth, Dividend Yield, etc.).

3. **Three-Tier Mode**:
   - `⚡ Quick Scan`: Rule-based scan using cached Yahoo data.
   - `🧠 Deep Analysis`: Sends combined Blueprint and Fundamentals data to the AI proxy.
   - `🎯 Full Strategist`: The deepest mode that also generates an **Ideal Blueprint** and provides an Action Roadmap for the user.

4. **UI/UX Polish**:
   - Rewrote `src/components/rebalance/AIBlueprintAdvisor.tsx` to include dynamic status updates and a progressive loading bar (e.g., "กำลังดึงข้อมูลพื้นฐาน...", "กำลังส่งให้ AI ประเมินเชิงลึก...").
   - Implemented multiple sub-components for data visualization: `HealthRadar.tsx`, `RiskGauge.tsx`, `SectorGapChart.tsx`.
   - Adhered strictly to typography rules (minimum 13px font) and high-contrast styling for the dark mode theme.

### ข้อมูล Yahoo ที่มีอยู่แล้ว
- `quote()` → ราคาปัจจุบัน, SMA 50/200, currency
- `quoteSummary(['assetProfile'])` → sector, industry
- `quoteSummary(['summaryDetail'])` → dividend yield, P/E trailing

### ข้อมูล Yahoo ที่ต้องเพิ่มเข้าไป (modules ใหม่)
```javascript
// quoteSummary modules ที่จะเพิ่ม

## 3 โหมดใน UI

### 🟢 Mode 1: Quick Scan (ไว ฟรี ไม่ต้องรอ)
**ไม่ต้องเรียก AI — ใช้ Rule Engine ล้วนๆ**

- ดึง Yahoo Fundamentals ทุกตัวใน Blueprint
- ตรวจสอบด้วย Rule Set:
  - Sector Overlap (>50% ใน sector เดียว = ⚠️)
  - Concentration Risk (ตัวเดี่ยว >30%)
  - Beta Concentration (avg beta >1.5 = high risk)
  - Dividend Coverage (มี dividend income ไหม)
  - Valuation Check (P/E ค่าเฉลี่ย สูงผิดปกติไหม)
- **Output:** Dashboard cards พร้อม pass/fail badges
- **ไม่ต้องเรียก AI เลย** — เร็ว ไม่เปลือง token

---

### 🟡 Mode 2: Deep Analysis (GPT-5.6 Terra-High)
**เรียก AI วิเคราะห์เชิงลึก**

- ดึง Yahoo Fundamentals ทุกตัว (เหมือน Quick Scan)
- **ส่งข้อมูลทั้งหมดให้ GPT-5.6 Terra-High** ผ่าน VPS AI Gateway:
  - Blueprint + Category Breakdown
  - Yahoo Fundamentals ทุกตัว (P/E, ROE, Beta, Revenue Growth, etc.)
  - HealthMetrics ที่คำนวณได้
- **AI Output:**
  - Overall Grade (A+ ถึง F)
  - 💪 Strengths (3-5 ข้อ)
  - ⚠️ Weaknesses (3-5 ข้อ)
  - 🔧 Suggestions (ADD/REDUCE/SWAP + reason) พร้อม [Apply] button
  - 🌍 Missing Exposure (sector ที่ขาด)
  - Risk Meter (visual bar)

---

### 🔴 Mode 3: Full Strategist (GPT-5.6 + Market Context)
**เรียก AI + ข้อมูลตลาดย้อนหลัง**

ทุกอย่างใน Mode 2 **บวก:**
- **Market Context:** ดึง performance 30 วันของ sector benchmarks (XLK, XLF, XLV, etc.) เทียบกับพอร์ต
- **Correlation Analysis:** คำนวณ simple correlation matrix จาก historical prices 90 วัน
- **Dividend Income Projection:** คำนวณ estimated annual income
- **AI ออกแบบ "Ideal Blueprint" ทางเลือก** → แสดง Before/After Donut เทียบ
- **Risk Score:** Sharpe-like metric จากข้อมูลจริง

## Data Persistence & Cache Management

### ปัญหาที่ต้องแก้

มึงจะไม่อยากให้ระบบ:
- ❌ ดึง Yahoo ซ้ำทุกครั้งที่กด AI Advisor (ช้า + เปลือง API)
- ❌ เรียก AI ซ้ำ ทั้งๆ ที่ Blueprint ไม่เปลี่ยน (เปลือง token)
- ❌ server restart แล้ว cache หาย ต้องดึงใหม่หมด
- ❌ ดูผลวิเคราะห์เก่าไม่ได้ ไม่มี history

### แผน: 3-Tier Cache Architecture

```
┌──────────────────────────────────────────────────────────┐
│                    TIER 1: In-Memory                      │
│              (ไว สุดๆ, หายเมื่อ restart)                    │
│                                                          │
│  Map<symbol, { data, timestamp }>                        │
│  TTL: 30 นาที                                             │
│  ใช้สำหรับ: hot path — ดึงซ้ำในเซสชันเดียวกัน               │
└──────────────────────┬───────────────────────────────────┘
                       │ cache miss
                       ▼
┌──────────────────────────────────────────────────────────┐
│                  TIER 2: SQLite Tables                     │
│              (ถาวร, อยู่แม้ restart)                        │
│                                                          │
│  symbol_fundamentals — Yahoo data ทั้งหมด                  │
│  ai_analysis_history — ผล AI ทุกครั้ง                      │
│  TTL: 24 ชั่วโมง (fundamentals)                            │
│  TTL: ตาม blueprint_hash (AI results)                     │
└──────────────────────┬───────────────────────────────────┘
                       │ cache miss / expired
                       ▼
┌──────────────────────────────────────────────────────────┐
│                TIER 3: External API                        │
│              (Yahoo Finance / GPT-5.6)                     │
│                                                          │
│  ดึงใหม่ → เก็บ Tier 2 → เก็บ Tier 1                       │
└──────────────────────────────────────────────────────────┘
```

### New SQLite Tables

#### Table: `symbol_fundamentals`

```sql
CREATE TABLE IF NOT EXISTS symbol_fundamentals (
    symbol TEXT PRIMARY KEY,
    sector TEXT,
    industry TEXT,
    current_price REAL,
    pe_trailing REAL,
    pe_forward REAL,
    pb_ratio REAL,
    roe REAL,
    revenue_growth REAL,
    profit_margin REAL,
    debt_to_equity REAL,
    beta REAL,
    div_yield REAL,
    annual_dividend REAL,
    fifty_two_week_high REAL,
    fifty_two_week_low REAL,
    sma50 REAL,
    sma200 REAL,
    market_cap REAL,
    short_percent REAL,
    fetched_at TEXT DEFAULT (datetime('now')),
    UNIQUE(symbol)
);
```

#### Table: `ai_analysis_history`

```sql
CREATE TABLE IF NOT EXISTS ai_analysis_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    portfolio_id TEXT NOT NULL REFERENCES portfolios(id),
    mode TEXT NOT NULL CHECK(mode IN ('quick', 'deep', 'strategist')),
    blueprint_hash TEXT NOT NULL,
    overall_grade TEXT,
    result_json TEXT NOT NULL,
    model_used TEXT DEFAULT 'gpt-5.6-terra-high',
    tokens_used INTEGER DEFAULT 0,
    created_at TEXT DEFAULT (datetime('now'))
);
```
