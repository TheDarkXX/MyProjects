### 2. เจาะลึกระบบเครื่องมือวาดเส้นแนวนอน (Horizontal Drawing Arsenal)

#### A. Institutional Dynamic Multi-Horizon Auto S/R Engine (`src/utils/drawingUtils.ts`)
- **Active Cycle Window (กรองเฉพาะรอบเทรดปัจจุบัน):** สแกนเฉพาะแท่งเทียน 250 แท่งล่าสุด (~1 ปีการเทรด) เพื่อไม่ให้ราคาในอดีต 10 ปีก่อนที่มีพฤติกรรมคนละแบบมาเบี่ยงเบนแนวรับ-แนวต้านปัจจุบัน
- **Dual-Horizon Pivot Detection:**
  - **Major Swings (`lookback: 8`):** สแกนจุดกลับตัวของยอดคลื่นใหญ่และก้นเหวลึก
  - **Minor Swings (`lookback: 4`):** สแกนฐานพักตัว, แนวก่อตัว (Consolidation Bases), และจุดเบรกเอาต์ระยะสั้น
- **Fixed-Anchor Clustering (แก้ปัญหา Centroid Drift):**
  - แทนที่จะใช้ค่าเฉลี่ย Center of Mass ซึ่งทำให้จุดรับที่ราคาเด้งหลายรอบเลื่อนไหล (Centroid Drift) ระบบจะล็อค "ราคาต่ำสุดจริงที่ทดสอบซ้ำบ่อยสุด" เป็น Anchor แล้วดึงยอด Minor อื่นๆ เข้ามาเกาะ
- **Dynamic ATR Spacing:**
  - กรองระยะห่างระหว่างเส้นแต่ละระดับอย่างน้อย `1.2x ATR` หรือ `2.5%` ของราคาหุ้น ป้องกันเส้นกระจุกตัวซ้อนทับกัน
- **Institutional Price Ladder (ขยายเป็น 4–6 ระดับ):**
  - **Resistance (R1, R2, R3):** วางแนวต้านไล่ระดับจากปัจจุบันขึ้นไปถึงยอด All-Time High / Swing High
  - **Support (S1, S2, S3):** วางแนวรับไล่ระดับลงไปถึงก้นฐานสำคัญ
- **Sub-Pane 0 Boundary Clipping:**
  - ล็อคพิกัดการวาดและป้ายราคาให้อยู่เฉพาะในขอบเขต Candlestick Pane (Pane 0) เท่านั้น โดยคำนวณ `subPaneTopOffset` ป้องกันไม่ให้ป้ายราคาหลุดทะลุลงไปกวนในช่อง Sub-Pane ของ MCDX หรือ RSI

#### B. Candle-Aware Magnet Snapping + Live Indicator Target (`src/utils/drawingUtils.ts`)
- เมื่อผู้ใช้กดปุ่มแม่เหล็ก 🧲 บนทูลบาร์ ระบบจะจับพิกัดเมาส์ X บน TimeScale แล้วถอดรหัสเป็นแท่งเทียนที่ชี้อยู่ (`timeScale.coordinateToLogical(mouseX)`)
- ดึงค่า OHLC ของแท่งเทียนนั้น แล้วดูดพิกัด Y ของเส้นเข้าหาจุด High, Low, Open หรือ Close ที่ใกล้เคียงเคอร์เซอร์ที่สุดแบบ 60fps
- แสดงแท็กเขียวมรกตพร้อม Pulse Dot กะพริบตามเมาส์ เช่น `🧲 High: 354.50` ให้ผู้ใช้เห็นชัดเจนก่อนคลิกวางเส้น

#### C. In-Canvas Micro-Badges 4 ระดับขนาด (`src/components/project2x/drawings/DrawingInCanvasBadges.tsx`)

- **ปลดล็อคลากปรับราคา (Manual Drag & Drop):**
  - กดปุ่ม `🔒 Unlock` บน Floating Toolbar เพื่อสลับเป็น `🔓 Drag Ready` แล้วคลิกลากเส้นขึ้น-ลงได้อิสระ
  - กดไอคอน `🔒` บนป้ายราคาขวาเพื่อปลดล็อคทันที
  - แจ้งเตือน Toast หากพยายามลากเส้นที่ล็อคอยู่ พร้อมเปลี่ยนเคอร์เซอร์เป็น `not-allowed`
- **แก้ปัญหา Chart Pan Drag Conflict:**
  - ดักจับ `mousedown` และ `mousemove` บนเส้นและป้ายราคาโดยเปิดโหมด Dragging และสั่งระงับ `handleScroll` ของ Lightweight Charts ชั่วคราว ทำให้ลากเส้นได้ลื่นไหล ไม่โยกกราฟทั้งชาร์ต

- เปิดผ่านปุ่มรูปฟันเฟือง ⚙️ บน `LeftDrawingToolbar`

  - สี (Color Palette 12 สีพรีเซ็ต)
  - ความหนา (1px, 2px, 3px, 4px)
  - สไตล์เส้น (Solid, Dashed, Dotted)
- ปรับขนาดป้ายราคา In-Canvas 4 ระดับ
- บันทึกค่าลง `localStorage` (`tv_drawing_settings_v1`) อัตโนมัติ พร้อมปุ่ม Reset Defaults

#### F. Dual-Tone Harmonic Chime Alerts & Banner (`src/utils/drawingAlerts.ts`)
- Web Audio API สร้างเสียงเตือนสไตล์ TradingView:
  - Breakout ขาขึ้น (`↗`): Harmonic Chime โน้ตคู่ D5 (587Hz) → A5 (880Hz)
  - Breakdown ขาลง (`↘`): Harmonic Chime โน้ตคู่ A5 (880Hz) → A4 (440Hz)
- แสดง Top Floating Alert Banner ด้านบนกราฟ และทำขอบจอ Strobe Pulse เตือนทันทีที่แท่งเทียนตัดผ่านเส้น

#### A. โค้ด Fixed-Anchor Clustering & Dynamic Round Numbers (`src/utils/drawingUtils.ts`)
```typescript
// สกัดสวิงแบบ Dual-Horizon พร้อม Fixed-Anchor ป้องกัน Centroid Drift
export function detectSupportResistance(
  bars: CandleData[],
  options: {
    maxLevels?: number;
    atrPeriod?: number;
    minSeparationATR?: number;
    recentBarsCount?: number;
  } = {}
): AutoSRResult {
  const {
    maxLevels = 6,
    atrPeriod = 14,
    minSeparationATR = 1.2,
    recentBarsCount = 250,
  } = options;

  if (bars.length < 20) return { resistanceLevels: [], supportLevels: [] };

  const currentPrice = bars[bars.length - 1].close;
  const analysisBars = bars.slice(-recentBarsCount);
  const atr = calculateATR(analysisBars, atrPeriod);
  const minSeparation = Math.max(atr * minSeparationATR, currentPrice * 0.025);

  // สกัด Pockets สวิงไฮ-โลว
  const majorPivots = extractPivots(analysisBars, 8);
  const minorPivots = extractPivots(analysisBars, 4);
  const allPivots = [...majorPivots, ...minorPivots];

  // คลัสเตอร์แบบ Fixed-Anchor ยึดก้น/ยอดจริง ไม่ใช้ Simple Average
  const clusters = formFixedAnchorClusters(allPivots, minSeparation);

  // จัดหมวดหมู่ Resistance (เหนือราคาปัจจุบัน) และ Support (ใต้ราคาปัจจุบัน)
  const resLevels = clusters.filter(c => c.price > currentPrice).slice(0, 3);
  const supLevels = clusters.filter(c => c.price < currentPrice).slice(-3);

  return { resistanceLevels: resLevels, supportLevels: supLevels };
}
```
