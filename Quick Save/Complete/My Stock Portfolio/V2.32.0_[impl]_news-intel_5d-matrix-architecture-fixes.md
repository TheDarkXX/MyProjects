# V2.32.0 [impl] News Intelligence: 5D Matrix Architectural Fixes & Multi-Source Consensus Enforcement

## 📌 Context & Implementation (Compiled Truth)
- **Content Truncation Fix:** Previously, `gfinSearcher.js` could scrape up to 7 distinct sources, but `newsRadar.js` arbitrarily truncated the total payload sent to GPT-5.6 Terra at 3,500 characters (~500 words), meaning only the first 1.5 sources were actually analyzed. Expanded to 8,000 characters.
- **Server-Side Ownership Enforcement:** The LLM was instructed to score the "ownership" dimension but frequently hallucinated or misapplied portfolio tags. This logic is now entirely deterministic on the server side (`(portfolioTag === 'tiger') ? 12 : 20`), stripping it from the AI prompt and saving tokens while guaranteeing accuracy.
- **Server-Side Multi-Source Consensus Bonus:** The AI was previously tasked with granting a multi-source bonus up to 10 points. To remove variability, the server now enforces `source = Math.min(20, source + (sourceCount * 2))` directly.
- **Fallback Score Tuning:** AI synthesis fallback scores for held stocks were originally hardcoded to 60 (CATALYST). Lowered to 45 (WATCHLIST) to eliminate false-positive push notifications when the AI gateway is down.
