### 2. เจาะลึก 10 สถาปัตยกรรมและฟีเจอร์หลัก (Deep Architecture & Implementation)

#### 2.1 Full 5-Year OHLCV Data Lake & Fixing Flat Dash Candles
- **ปัญหาเดิม**: แท่งเทียนในกราฟแสดงเป็นขีดแนวนอนแบน (Flat Dashes) ไร้เนื้อเทียนและไส้เทียน
- **ต้นตอ**: ตาราง `historical_prices` ใน SQLite (`stock.db`) ถูกสร้างขึ้นในยุคแรกที่มีเฉพาะคอลัมน์ `close` (ราคาปิด) ต่อมาเมื่อเพิ่มคอลัมน์ `open, high, low` ข้อมูลเก่าไม่มีค่า OHLC (เป็น `NULL`) ขณะที่ฟังก์ชัน `syncCandleDelta` เดิมตรวจสอบเพียง `count >= 50` จึงข้ามการดึงข้อมูลใหม่
- **การแก้ไข**:
  1. ปรับปรุงเงื่อนไข `syncCandleDelta` ให้ตรวจสอบแถวที่มี `NULL` หรือ `high <= low` เพื่อบังคับ Refresh ข้อมูลจริงจาก Yahoo Finance
  2. รัน Script `scripts/backfill-candles.js` ซิงค์ OHLCV ย้อนหลัง 5 ปี (1,825 วัน) ให้กับหุ้นทุกตัวในพอร์ตและ Watchlist บน VPS (มากกว่า 923 วันทำการต่อตัว)
  3. เพิ่ม Fallback Synthesis ในหน้าบ้าน ป้องกันแท่งแบนในทุกกรณี

#### 2.2 Banker MCDX Pine Script Standard Formula & Sub-pane Architecture
- ปรับสูตรการคำนวณ Banker MCDX ใน `technicalAnalysis.js` ให้ตรงตาม Pine Script ต้นฉบับ:
  ```javascript
  // Banker (Smart Money / Institutional): RSI-50 base scaled to 0-20
  // Formula: EMA(1.5 * (RSI(Close, 50) - 50), 10), clamped to [0, 20]
  // Hot Money (Speculative): RSI-40 base scaled to 0-20
  // Formula: EMA(0.7 * (RSI(Close, 40) - 50), 10), clamped to [0, 20]
  // Retail (Floating): Remaining balance up to 20
  // Formula: max(0, 20 - (Banker + Hot Money))
  ```
- **การแสดงผลแบบ 3-Tier Stacked Histogram (Scale 0 - 20)**:
  - ฐานล่าง (Base): สีแดงสด `#FF3D00` (เงินสถาบัน/เจ้ามือ)
  - ชั้นกลาง (Mid): สีเหลืองทอง `#FFD600` (เงินเก็งกำไร)
  - ชั้นบน (Top): สีเขียว `#2E7D32` (เงินรายย่อยลอยตัว)
- **Ultra-Dense Hairline Gap**: ปรับระยะห่างระหว่างแท่งฮิสโตแกรมให้ชิดกันแบบ Hairline Slit (~0.75px) ไม่เว้นช่องว่างหนาเตอะขัดตา
- **Header Space Isolation**: แยกส่วนหัวชื่ออินดิเคเตอร์ `BANKER MCDX FLOW (SUPER MONEY) • 20 SCALE` สูง 16px (`bankerBarsTopY = bankerTopY + 16`) ป้องกันแท่งกราฟเขียวล้นขึ้นมาทับตัวหนังสือ
- **White MA Curve (SMA 9)** & **Pink Trigger Threshold Line (#FC2D79)** ที่ระดับ 10.0 scale

#### 2.3 Major Bedrock Support EMA 200
- ปรับเส้นค่าเฉลี่ยสถาบัน 3 เส้น:
  - **EMA 50**: เส้นสีขาว `#FFFFFF` (2.2px) สำหรับโมเมนตัมระยะสั้น
  - **EMA 150**: เส้นสีน้ำเงินรอยัลบลู `#2962FF` (2.5px) สำหรับแนวรับแนวโน้มกลาง
  - **EMA 200**: **หนาพิเศษ 3.6px สีทองอำพัน `#FFB300`** เพื่อทำหน้าที่เป็น **"Bedrock Support (ฐานรากหินผาชี้เป็นชี้ตาย)"** พร้อมแถบเส้นประ Upper/Lower Channel

#### 2.4 กลยุทธ์สัญญาณเทรด 3 ระดับบนแท่งเทียน (3-Step Super Money Signals)
เพื่อเปลี่ยนกราฟให้กลายเป็นระบบชี้นำการเทรดอัตโนมัติ ออกแบบระบบตรวจจับแท่งเทียน 3 ขั้นตอน + 1 ขั้นตอนออก:
1. 🟡 **`••• READY` (เตรียมกระสุน / Setup Zone)**:
   - เงื่อนไข: ราคาลงมาจูบแนวรับใหญ่ EMA 150 หรือ EMA 200 ในระยะ +/-2.5% โดยที่ Banker MCDX ยังนิ่งสนิทอยู่ที่ 0 (อยู่ในช่วงสะสมพลังก่อนเจ้ามือเข้า)
   - ป้ายกำกับ: แคปซูลสีเหลืองมินิมอลเหนือแท่งเทียน
2. 🟢 **`▲ BUY` (จุดเข้าซื้อซุ่มยิง / Bedrock Strike)**:
   - เงื่อนไข: ราคายืนเหนือแนวรับ EMA 150 หรือ EMA 200 พร้อมกับการผงกหัวครั้งแรกของแท่ง Banker MCDX > 0 บนแท่งเทียนสีเหลือง (Bullish Candle)
   - ป้ายกำกับ: สามเหลี่ยมสีเขียวสดพร้อมคำว่า `▲ BUY`
3. ⭐ **`⭐ SUPER` (จุดเร่งเครื่อง Super Money / Acceleration Breakout)**:
   - เงื่อนไข: แท่ง Banker พุ่งทะลุเกินระดับ 10.0 scale (ตัดเส้นประสีชมพู) ยืนยันเงินเจ้ามือไหลเข้าทะลักเต็มพิกัด
   - ป้ายกำกับ: ดาวทองสีส้ม `⭐ SUPER`
4. 🔴 **`▼ EXIT` (สัญญาณถอนทัพ / Risk-Off Breakdown)**:
   - เงื่อนไข: ราคาหลุดแนวรับใหญ่ EMA 200 ลึกเกิน -4.0% หรือ Banker MCDX หดตัวเหลือ 0 อย่างกะทันหัน
   - ป้ายกำกับ: สามเหลี่ยมสีแดงเข้ม `▼ EXIT`
- **First-Bar Lock & Anti-Spam**: สัญญาณจะปรากฏเฉพาะ "แท่งแรกที่เกิดเงื่อนไข (Transition Bar)" เท่านั้น ไม่แสดงซ้ำซ้อนให้รกกราฟ
- **Toolbar Toggle**: มีปุ่มสวิตช์ `[ ⚡ Signals ON/OFF ]` บน Toolbar ให้ผู้ใช้เลือกเปิด/ปิดการแสดงผลได้ทันที

#### 2.6 Dynamic Interactive Scale Dragging (ลากแกน X / Y อิสระ)
- **แกน Y (แถบราคาฝั่งขวา - Right Price Scale)**:

```typescript
// 1. Nice Numbers Algorithm สำหรับแกนราคา Y-Axis แบบ TradingView
const priceGridLevels = useMemo(() => {
  if (priceRange <= 0) return [];
  const targetTickCount = Math.max(5, Math.min(18, Math.round(priceChartH / 42)));
  const rawStep = priceRange / targetTickCount;
  const power = Math.pow(10, Math.floor(Math.log10(rawStep)));
  const frac = rawStep / power;
  let niceStep = power;
  if (frac > 5) niceStep = 10 * power;
  else if (frac > 2.5) niceStep = 5 * power;
  else if (frac > 1.5) niceStep = 2.5 * power;
  else if (frac > 1) niceStep = 2 * power;

  const firstTick = Math.ceil(minPrice / niceStep) * niceStep;
  const levels: { price: number; y: number; label: string }[] = [];
  for (let p = firstTick; p <= maxPrice; p += niceStep) {
    const y = priceChartH - ((p - minPrice) / priceRange) * priceChartH;
    levels.push({ price: p, y, label: p >= 100 ? p.toFixed(0) : p >= 10 ? p.toFixed(1) : p.toFixed(2) });
  }
  return levels;
}, [minPrice, maxPrice, priceRange, priceChartH]);

// 2. สัญญาณ 3-Step Super Money บนแท่งเทียน
const signals = useMemo(() => {
  const list: { index: number; type: 'READY' | 'BUY' | 'SUPER' | 'EXIT'; text: string; candle: CandleData }[] = [];
  let prevBanker = 0;
  visibleCandles.forEach((cdl, i) => {
    const banker = cdl.banker ?? 0;
    const isBull = cdl.close >= cdl.open;
    const nearBedrock = cdl.ema200 ? Math.abs(cdl.close - cdl.ema200) / cdl.ema200 <= 0.025 : false;

    if (banker >= 10 && prevBanker < 10) {
      list.push({ index: i, type: 'SUPER', text: '⭐ SUPER', candle: cdl });
    } else if (nearBedrock && banker > 0 && prevBanker === 0 && isBull) {
      list.push({ index: i, type: 'BUY', text: '▲ BUY', candle: cdl });
    } else if (nearBedrock && banker === 0 && (!list.length || list[list.length - 1].index < i - 10)) {
      list.push({ index: i, type: 'READY', text: '••• READY', candle: cdl });
    } else if (cdl.ema200 && (cdl.close - cdl.ema200) / cdl.ema200 < -0.04 && prevBanker > 0) {
      list.push({ index: i, type: 'EXIT', text: '▼ EXIT', candle: cdl });
    }
    prevBanker = banker;
  });
  return list;
}, [visibleCandles]);
```

- **การแก้ไข**: ย้าย Fallback Return ลงไปไว้ล่างสุดหลังรัน Hooks ครบถ้วน พร้อมเพิ่ม Safe Fallback สำหรับ `rawMin`, `rawMax`, `isUp` ป้องกันค่า `NaN` หายขาด 100%
