## 1. Executive Summary & Problem Solved
- **Problem 1 (Fullscreen Tab Loss):** ในโหมดขยายเต็มจอ (Fullscreen Mode) ของ X-Chart ตัว Multi-Tab Bar ด้านบน (`[ AVGO ] [ USD/THB ] [ Market Heatmap ] [ My Port ] [ + ]`) จะหลุดออกไปนอกจอ ทำให้เวลาต้องการสลับไปดูกราฟหุ้นแท็บอื่น ผู้ใช้ต้องกด `ESC` ย่อจอกลับมาก่อน แล้วคลิกแท็บ จากนั้นต้องกด Fullscreen ใหม่อีกรอบ เสียเวลาและกระตุก Flow การวิเคราะห์
- **Problem 2 (Missing Macro Benchmarks in My Port Dock):** ใน Dock ด้านขวาของ X-Chart เมื่อเลือกโหมด "My Port" มีเพียง Section `HOLDINGS` และ `PROJECT2X` แต่ขาดดัชนีมหภาคอ้างอิงระดับโลก ทำให้ไม่เห็นภาพรวมตลาดขณะมอนิเตอร์พอร์ต
- **Solution:** 
  1. ย้าย Container ID `#xchart-terminal-container` ขึ้นไปครอบตั้งแต่ Root Wrapper (`XChartPage.tsx`) ส่งผลให้ `<XChartTabBar />` ถูกรวมเข้าไปอยู่ใน Fullscreen DOM ทันที กดสลับแท็บได้คลีนๆ โดยไม่ต้องออกจาก Fullscreen
  2. เพิ่ม Section `INDEX` ไว้ล่างสุดของ My Port Dock พร้อมดัชนีและสินทรัพย์อ้างอิง 9 ตัวเป๊ะตามลำดับความต้องการ: `SPY`, `QQQ`, `SCHG`, `BTC-USD`, `GLD`, `USO`, `UUP`, `SMH`, `TLT` เชื่อมต่อ Batch Quote Polling 30s และระบบคลิกเพื่อสลับดูกราฟ Candlestick ทันที

## 2. Context & Implementation (Compiled Truth)

### 2.1 Fullscreen Persistence Architecture
- **Root Cause:** เดิมที `id="xchart-terminal-container"` ถูกวางไว้ที่ `div` ด้านในใต้ `<XChartTabBar />` ใน `src/components/xchart/XChartPage.tsx`
- **Resolution:** ย้าย `id="xchart-terminal-container"` ไปที่ Root Container ด้านบนสุด ครอบทั้ง `<XChartTabBar />` และพื้นที่กราฟ/Dock
- เมื่อ `handleToggleFullscreen` ใน `XChartPanel.tsx` และ `LWChart.tsx` เรียก `target?.requestFullscreen?.()` ตัวเบราว์เซอร์จะ Render ทั้งแท็บบาร์และกราฟพร้อมกันใน Fullscreen 100vw x 100vh

### 2.2 Section `INDEX` ใน My Port Dock
- **โมเดลข้อมูล (`DEFAULT_INDEX_ITEMS`):**
  1. `SPY` (S&P 500) 🇺🇸 — US 500 Large Cap
  2. `QQQ` (Nasdaq 100) 💻 — Tech 100 Benchmark
  3. `SCHG` (US Large Growth) 🚀 — Large-Cap Growth
  4. `BTC-USD` (Bitcoin) ₿ — Crypto Flagship
  5. `GLD` (Gold - ทองคำ) 🪙 — SPDR Gold Trust
  6. `USO` (Crude Oil - น้ำมัน) 🛢️ — US Oil Fund
  7. `UUP` (US Dollar Index) 💵 — Invesco DXY Bullish ETF
  8. `SMH` (Semiconductor ETF) ⚡ — VanEck Semiconductor ETF
  9. `TLT` (20+ Yr Treasury Bond) 🏛️ — 20+ Year Treasury Bond
- **Quote Polling Engine:** ใน `src/stores/xchartStore.ts` ฟังก์ชัน `fetchWatchlistQuotes()` ได้ถูกเพิ่ม 9 Index Symbols เข้าไปในชุด Batch Query ทำให้ราคาล่าสุด ($), Day Change, และ Day Change% ได้รับการอัปเดตสดพร้อม Watchlist ทุก 30 วินาที
- **Preferences State:** เพิ่ม `indexCollapsed` ใน `MyPortWatchlistPreferences` พร้อม Action `toggleMyPortIndexCollapse` รองรับการย่อ/ขยาย Section และซิงก์สถานะ Preferences เข้า LocalStorage/Cloud
- **UI Design System:** ออกแบบด้วย Grid 12 คอลัมน์ เข้าคู่กับ `HOLDINGS` และ `PROJECT2X`, ใช้สี Badge Amber (`bg-amber-500/20 text-amber-300`), ฟอนต์ไม่เล็กกว่า 13px ตามมาตรฐาน Iron Rules, และรองรับ Right-Click Context Menu สั่ง Refresh Quotes และ Toggle Collapse

## 🗄️ 3. Backend & Data Pipeline Plan

### 3.1 YouTube Data Ingestion Update (`tools/yt-poster/sync_yt_stats.py`)
- ปรับ URL เรียก API จาก `part=snippet,statistics` เป็น `part=snippet,statistics,contentDetails`
- สกัด `contentDetails.duration` (ISO 8601 เช่น `PT58S` -> 58 วินาที, `PT1M12S` -> 72 วินาที)
- เพิ่มคอลัมน์ `duration_seconds INTEGER DEFAULT 0` ในตาราง `youtube_videos` (Auto-migrate if not exists)

### 3.2 Endpoint Expansion (`routes/tiktok-trends.js`)
อัปเกรด `/my-channels/analysis` ให้คำนวณและส่งข้อมูลครบ 7 ชุดวิเคราะห์:
1. **`velocity_curves`:** ดึง Time-Series จาก `tiktok_video_snapshots`, `youtube_video_snapshots`, `fb_post_metric_snapshots` สำหรับคลิปที่จับคู่ได้ เพื่อคำนวณการเติบโตชั่วโมงที่ 0, 6, 12, 24, 48, 72h
2. **`trust_quadrant`:** คำนวณพิกัด `(x: omni_views, y: share_rate_pct, code: code_id, title: title, category: 'unicorn'|'hidden_gem'|'empty_calorie'|'dead_wood')`
3. **`content_pillars`:** สกัดหมวดหมู่จากคีย์เวิร์ดใน Title (`นอนไม่หลับ/เบียร์`, `ลดไขมัน/IF/น้ำหนัก`, `ยาแก้แพ้/ตับ/ไต`, `อาหารเสริม/วิตามิน`, `ทั่วไป`) พร้อมคำนวณ Avg Views & Avg Share Rate
4. **`duration_efficiency`:** จัดกลุ่มคลิปตามความยาว (`<30s`, `30-45s`, `46-60s`, `>60s`) เทียบยอดวิวเฉลี่ยแยกแต่ละแพลตฟอร์ม
5. **`audio_lift`:** เปรียบเทียบยอดวิวเฉลี่ยระหว่างคลิป TikTok ที่ใช้ `sound` เสียงสด vs เพลงเทรนด์
6. **`golden_hour_heatmap`:** สร้าง Matrix 7 วัน x 24 ชม. ของช่อง โดยนับผลรวมการมีส่วนร่วม (Views/Engagement) ตามวันในสัปดาห์และชั่วโมงที่โพสต์
7. **`thumbnail_keywords`:** รวมคำฮิตจาก `thumbnail_text` และ `text_stickers` เพื่อดูว่าคำไหนทำยอดวิวเฉลี่ยสูงสุด

### 4.2 Native SVG Chart Engine (`public/tiktok-trends.js`)
สร้างฟังก์ชัน Utility วาด SVG น้ำหนักเบาในตัว:
- `renderSvgLineChart(curves, options)`: วาดเส้นโค้งพร้อม Gradient พื้นที่ใต้กราฟ (Area fill) และจุด Data points
- `renderSvgScatterQuadrant(points, options)`: วาดกราฟ 4 จตุภาค (Quadrant) แบ่งเส้นกึ่งกลางด้วยเส้นประ Deep Navy พร้อมลูกบอลพิกัดสี Ruby/Cyan

- `renderSvgHorizontalBars(bars, options)`: วาดแท่งเปรียบเทียบหมวดหมู่พร้อมตัวเลข Tabular
