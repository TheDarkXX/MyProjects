### 2. การกู้คืน LINE Flex Message & ยกระดับ Typography
สลับการส่ง Weekly Brief กลับมาใช้ **LINE Flex Message Bubble (`formatWeeklyBriefFlex`)**:
- **การเรนเดอร์ Vector แท้**: แสดงผลผ่าน Native Component ของแอป LINE โดยตรง คมชัด 100% ตัวหนังสือคมกริบ ไม่แตก ไม่โดนบีบอัดภาพ
- **กฎเหล็ก Typography (Iron Rules)**:
  - กำจัดฟอนต์ขนาดจิ๋ว `xxs` (9-11px) ออกทั้งหมด
  - ปรับขนาดตัวเลขพอร์ต `TOTAL PORTFOLIO VALUE` เป็น **`3xl`** (โดดเด่น ชัดเจนทันทีที่เปิดแชท)
  - กำหนดขนาดตัวอักษรย่อยขั้นต่ำที่ `xs` (12px) สำหรับ Badge และ `sm`/`md` (14-16px) สำหรับเนื้อหา
  - คอนทราสต์ตัวอักษรบนพื้นหลังดำ `#0B0E14` ปรับเป็น `#CBD5E1`, `#F1F5F9`, `#FFFFFF` (สว่าง $\ge 70\%$) ตัดปัญหาสายตาล้า
- **Decoupled Benchmark Companion Text**:
  - เพื่อไม่ให้การ์ด Flex อัดแน่นจนเกินไป ได้แยกข้อมูล Benchmark 3 สินทรัพย์โลก (S&P 500, BTC, Gold) ออกมาเป็นข้อความสรุปส่งต่อท้ายการ์ด

### 3. ระบบ Recheck Holding Status & กลยุทธ์ 5 เสาหลักฝั่งขาย
ติดตั้งระบบตรวจเช็คการถือครองหุ้นจริง (`owned_shares`) และสัดส่วนโควตา (`progress_percent`) ก่อนพ่นคำแนะนำ:

```
[ ตรวจจับสัญญาณ Signal ]
          │
    ┌─────┴────────────────────────────────┐
    ▼                                      ▼
[ สัญญาณซื้อ BUY NOW ]             [ สัญญาณขาย MAYDAY EXIT ]
    │                                      │
    ├─ ไม่มีหุ้น (0 หุ้น)                  ├─ ไม่มีหุ้น (0 หุ้น)
    │  ➔ เปิดสถานะไม้แรก (100% Size)       │  ➔ 🔪 FALLING KNIFE: ห้ามรับมีดเด็ดขาด!
    │                                      │
    ├─ ถืออยู่แต่ยังไม่เต็ม (< 100%)       └─ มีหุ้นในพอร์ต (> 0 หุ้น)
    │  ➔ สะสมไม้เพิ่มตามโควตา                  ├─ Core ทัพหลวง: Trim 50% หรือ Freeze ห้ามถัว
    │                                          └─ Moonshot: Cut Loss 100% สละเรือรักษากระสุน
    └─ มีครบโควตาแล้ว (>= 100%)
       ➔ นั่งทับมือ ห้ามซื้อเพิ่ม!
```

1. **`server/services/lineNotifier.js`**:
   - `formatBuyNowMessage`: ตรวจเช็ค `owned_shares` เทียบกับ `target_shares` ให้คำแนะนำแม่นยำ (เปิดไม้แรก / สะสมเพิ่ม / โควตาเต็มห้ามซื้อ)
   - `formatMaydayExitMessage`: หาก `owned_shares === 0` จะไม่พ่นคำว่า Cut Loss แต่จะเตือนเป็น `🔪 FALLING KNIFE ALERT: ห้ามรับมีด` หากมีหุ้นจะแยกคำแนะนำระหว่าง `Core` (Trim 50% / Freeze) และ `Moonshot` (Cut Loss 100%)
2. **`server/crons/weeklyBriefCron.js`**:
   - ฟังก์ชัน `findWeeklyMVPAndDrag`: กรองเฉพาะหุ้นที่มีอยู่ในพอร์ตจริง (`shares > 0.001`) มาเป็นตัวแทน MVP และ Drag
   - ฟังก์ชัน `getImpactDescription`: ดึงสถานะจริงจาก Radar Matrix (`GET_READY`, `BUY_NOW`, `MAYDAY_EXIT`) ป้องกันการติดป้ายมั่ว

## ⚡ 1. กฎการสับไกและรอบการแจ้งเตือน

```
                                  [ สัญญาณที่ระบบจะแจ้งเตือน ]
                                                │
                     ┌──────────────────────────┴──────────────────────────┐
                     ▼                                                     ▼
           🔥 BUY NOW! (เคาะซื้อ)                              🚨 MAYDAY EXIT (สละเรือ)
  • แจ้งทุกวันทำการจนกว่าจะเปลี่ยนสถานะ                    • แจ้งเฉพาะวันแรกที่หลุดเกณฑ์ (First-Day Only)
  • ป้องกันการลืมเข้าของช่วงสไนเปอร์ (1-3 วัน)            • เตือนหนีตายรักษาเงินต้น ไม่สแปมซ้ำ
```

| สัญญาณ | เงื่อนไข | ความถี่ | แอคชั่น |

| **🚨 MAYDAY EXIT** | Scenarios 1-3 + หุ้นที่มีของในพอร์ต | **เฉพาะวันแรก** ที่พลิกเข้ามา | ระบุจำนวนหุ้น, ขาดทุนปัจจุบัน, คำสั่งสละเรือ |

## 🗄️ 4. State Machine & Deduplication

```sql
CREATE TABLE IF NOT EXISTS project2x_cron_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    portfolio_id TEXT NOT NULL,
    date TEXT NOT NULL,
    type TEXT NOT NULL,          -- 'BUY_NOW' | 'MAYDAY_EXIT'
    symbol TEXT NOT NULL,
    scenario INTEGER,
    tier_id TEXT,
    price REAL,
    title TEXT NOT NULL,
    payload_json TEXT,
    created_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_p2x_cron_dedup 
    ON project2x_cron_logs(portfolio_id, symbol, type, date);
```

### Cadence Logic:
```javascript
// BUY_NOW: ส่งทุกวัน — เช็คแค่ว่าวันนี้ส่งไปยังหรือไม่
const sentToday = db.prepare(
  `SELECT 1 FROM project2x_cron_logs 
   WHERE portfolio_id=? AND symbol=? AND type='BUY_NOW' AND date=?`
).get(pid, symbol, today);
if (!sentToday) → SEND & LOG

// MAYDAY_EXIT: ส่งเฉพาะวันแรก — เช็คว่าเมื่อวานเคยส่งไปหรือไม่
const sentBefore = db.prepare(
  `SELECT 1 FROM project2x_cron_logs 
   WHERE portfolio_id=? AND symbol=? AND type='MAYDAY_EXIT' AND date>=?`
).get(pid, symbol, yesterday);
if (!sentBefore) → SEND & LOG   // วันแรกที่หลุดเกณฑ์
else → SKIP                      // เคยเตือนแล้ว ไม่สแปมซ้ำ
```
