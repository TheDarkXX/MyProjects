### 4. React Error #185 Elimination (Root Cause & Fix)
- **Problem**: When switching to My Port, React threw `Minified React error #185` (Maximum update depth exceeded).
- **Root Cause**: `useEffect` in `MyPortWatchlist.tsx` checked for missing prices of target stocks (`targetStocks.filter(!prices[s] && !watchlistPrices[s])`). Because `api.prices.latest` is asynchronous and Zustand's `fetchPrices` synchronously updates `set({ loading: true })`, the store state update triggered an immediate re-render of `usePriceStore()`. Before the API response could arrive, the component re-rendered with `symsToFetch` still non-empty, calling `fetchPrices` repeatedly in an unbuffered loop.
- **Solution**:
  - Injected `requestedPricesRef = React.useRef<Set<string>>(new Set())` to track all in-flight symbol quote requests and prevent duplicate/infinite fetching.
  - Added ref guards `lastFetchedRadarPortfolioRef` and `lastFetchedDataPortfolioRef` to avoid redundant calls to `fetchRadar`, `fetchBlueprints`, and `fetchQuotas`.
