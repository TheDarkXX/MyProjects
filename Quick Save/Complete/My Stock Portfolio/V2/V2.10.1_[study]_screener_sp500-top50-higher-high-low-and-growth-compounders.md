# S&P 500 Top 50 Higher High / Higher Low Screening & Non-Pharma Growth Compounders

## 🧠 Context & Implementation (Compiled Truth)

### 1. Objective & User Constraints
The user requested a strict, quantitative screen of the **Top 50 S&P 500 companies by Market Cap / Index Weight** based on 3 non-negotiable criteria:
1. **Higher Highs & Higher Lows (HH & HL) consistently without collapsing (ไม่ล้มคว่ำกลางทาง):** Price strictly above 200-day SMA, 50-day SMA > 200-day SMA, controlled Max Drawdown (< 25%), and ascending quarterly troughs.
2. **Capital Gain >= 15%/year:** 1-Year trailing return >= 15% (and multi-year CAGR >= 15%).
3. **Profitable every quarter in the last 4 quarters (Net Income > 0 in 4Q trailing):** Eliminating unprofitable hype or restructuring plays.

Furthermore, when discussing how to select stocks to **"Anchor a Growth Portfolio" (ค้ำพอร์ต Growth)**, the user imposed two critical tactical constraints:
- **No Pharma / Biotech:** Avoid drug stocks entirely due to binary FDA clinical trial risks, patent cliffs, and government price regulations.
- **Strict HH & HL Verification:** The user correctly identified that **Visa (V)** failed the strict Higher Low test because it peaked at $355 and round-tripped down to $294 due to the DOJ antitrust lawsuit.

#### Script 1: S&P 500 Top 50 Full Screener (`screen_sp500.py`)
```python
import yfinance as yf
import pandas as pd
import numpy as np
import requests
import io
import json

headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)'}
resp = requests.get('https://www.slickcharts.com/sp500', headers=headers)
df_sp = pd.read_html(io.StringIO(resp.text))[0]

top_candidates = df_sp.head(55)
seen_names = set()
tickers, company_map, weight_map = [], {}, {}

for _, row in top_candidates.iterrows():
    sym = str(row['Symbol']).replace('.', '-')
    comp = str(row['Company'])
    base_comp = comp.split(' Class')[0].strip()
    if base_comp in seen_names: continue
    seen_names.add(base_comp)
    tickers.append(sym)
    company_map[sym] = comp
    weight_map[sym] = row['Weight']
    if len(tickers) == 50: break

results = []
for idx, sym in enumerate(tickers, 1):
    try:
        t = yf.Ticker(sym)
        hist = t.history(period="18mo")
        if hist.empty or len(hist) < 200: continue
        close = hist['Close']
        curr_price = float(close.iloc[-1])
        lookback_1y = min(252, len(close)-1)
        price_1y_ago = float(close.iloc[-lookback_1y])
        ret_1y = ((curr_price - price_1y_ago) / price_1y_ago) * 100.0
        
        sma50 = float(close.rolling(50).mean().iloc[-1])
        sma200 = float(close.rolling(200).mean().iloc[-1])
        
        close_1y = close.iloc[-lookback_1y:]
        roll_max = close_1y.cummax()
        max_dd_1y = float(((close_1y - roll_max) / roll_max * 100.0).min())
        
        seg_len = len(close_1y) // 4
        seg_lows = [float(close_1y.iloc[i*seg_len:(i+1)*seg_len].min()) for i in range(4)]
        seg_highs = [float(close_1y.iloc[i*seg_len:(i+1)*seg_len].max()) for i in range(4)]
        
        strict_hl = all(seg_lows[i] < seg_lows[i+1] for i in range(3))
        tolerant_hl = all(seg_lows[i] <= seg_lows[i+1] * 1.03 for i in range(3))
        
        inc = t.quarterly_income_stmt
        q_net_incomes, all_4q_positive = [], False
        if inc is not None and not inc.empty:
            for r in ['Net Income', 'Net Income Common Stockholders', 'Net Income Continuous Operations']:
                if r in inc.index:
                    s = inc.loc[r].dropna().iloc[:4]
                    q_net_incomes = [float(v) for v in s]
                    all_4q_positive = all(v > 0 for v in q_net_incomes) and len(q_net_incomes) >= 4
                    break
                    
        results.append({
            'symbol': sym, 'company': company_map.get(sym, sym),
            'price': curr_price, 'ret_1y': ret_1y, 'max_dd_1y': max_dd_1y,
            'sma50': sma50, 'sma200': sma200, 'seg_lows': seg_lows, 'seg_highs': seg_highs,
            'strict_hl': strict_hl, 'tolerant_hl': tolerant_hl, 'all_4q_positive': all_4q_positive,
            'q_net_incomes': q_net_incomes
        })
    except Exception as e:
        pass
```

## 1. บทสรุปกลยุทธ์: หุ้นค้ำพอร์ต Growth ที่แท้จริง

### ⚠️ หลุมพรางที่ต้องระวัง:
1. ห้ามเอาหุ้นกลุ่ม Tech หรือ AI มาค้ำพอร์ต Growth: เพราะเวลาตลาดปรับฐาน (Tech Sell-off) หุ้นกลุ่มนี้จะร่วงไปด้วยกันทั้งพอร์ต
2. หลีกเลี่ยงหุ้นกลุ่มยา/ไบโอเทค (Pharma/Biotech): แม้ตัวเลขทางการเงินจะดูดี แต่มี Binary Risk จากการทดลองยาทางคลินิก (Phase 3 Trials), ปัญหาสิทธิบัตรหมดอายุ (Patent Cliff), และการคุมราคายาจากรัฐบาล ซึ่งคาดเดาไม่ได้
3. Compounder ไม่ใช่ว่าจะค้ำพอร์ตได้ทุกตัว: หุ้นอย่าง AVGO หรือ NVDA โตแรงทบต้นปีละ 40-60% แต่ Drawdown สูงถึง -40% มันคือ "ดาบเล่มยักษ์" ไม่ใช่ "โล่ป้องกัน"

### ✅ คุณสมบัติของ "หุ้นค้ำพอร์ตพันธุ์แท้" (The True Anchor):
- Drawdown แคบ: ตลาดตกใจ แต่ราคาตัวมันย่อตัวไม่เกิน 10% - 20%
- โครงสร้างกราฟทรงพลัง (HH & HL): ยก Higher High และ Higher Low ตลอดทั้งปี ไม่ทำ Lower Low ย้อนกลับมาที่เดิม
- กระแสเงินสดเกิดซ้ำ (Recurring Cash Flow): มีอำนาจผูกขาดด้านราคา (Pricing Power) ลูกค้าหนีไปไหนไม่ได้
- ผลตอบแทนทบต้น (CAGR): อย่างน้อย 15% ต่อปี ต่อเนื่อง 3 ปีขึ้นไป
