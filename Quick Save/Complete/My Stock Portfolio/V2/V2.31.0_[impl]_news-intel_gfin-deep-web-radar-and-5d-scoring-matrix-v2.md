# V2.31.0 [impl] News Intelligence: gfin Autonomous Deep Web Radar, Mozilla Readability Engine, Semantic Relevance Guard & 5D Matrix v2

## 📌 Context & Implementation (Compiled Truth)

### 1. ปัญหาและเป้าหมายเชิงสถาปัตยกรรม (Strategic Objectives)
1. **แก้ปัญหาคอขวดของสารตั้งต้น (The Paywall & Teaser Bottleneck):**
   - สารตั้งต้นหลักคือบทความจาก **`wethaiinvest.beehiiv.com`** ซึ่งคัดกรองหัวข้อระดับอ๋องของหุ้นสหรัฐฯ มาอย่างแม่นยำ
   - แต่ข่าวจำนวนมากติด Paywall ("Subscribe to Default to read the rest") หรือให้มาเพียงเนื้อหาสั้นๆ 2-3 บรรทัด ทำให้โมเดล AI ไม่มีเนื้อหาเชิงลึกเพียงพอในการประเมินคะแนนปัจจัยพื้นฐานจริง
2. **สร้างเครื่องยนต์ `gfinSearcher.js` สกัดเนื้อหาฉบับเต็มอัตโนมัติ:**
   - ค้นหาข่าวฉบับเต็มจากแหล่งข่าวฟรีระดับโลกผ่าน Google News RSS และ Yahoo Finance RSS
   - ใช้ **Mozilla Readability + Linkedom** สกัดเฉพาะเนื้อหาข่าวบริสุทธิ์ (800–2,500 คำ) ตัด Footer/Ads/Cookies/Sidebar ออกอัตโนมัติ
   - สร้างโมดูล `fetchHtmlWithLargeHeaders` รองรับ HTTP Header ขนาดใหญ่ (128KB) แก้ปัญหา `UND_ERR_HEADERS_OVERFLOW` จาก Yahoo Finance อย่างเด็ดขาด
3. **ปิด 7 จุดบอดวิกฤตของระบบข่าวการเงิน (The 7 Blind Spots Overhaul):**
   - **Semantic Relevance Guard:** AI ตรวจสอบว่าข่าวที่กวาดมาได้ตรงกับ Seed Headline จริงหรือไม่ (Threshold $\ge 65$) ปฏิเสธข่าวลือ/เก็งกำไรทันที
   - **Provenance Chain:** บันทึก `content_source`, `content_source_url`, `content_fetched_at`, `content_relevance_score` ลง SQLite เพื่อให้ตรวจสอบย้อนกลับได้
   - **Multi-Source Consensus:** นับจำนวนสำนักข่าว Tier-1 อิสระที่รายงานเรื่องเดียวกัน และให้คะแนนโบนัสใน Source Dimension
   - **Temporal Freshness Gate:** ตัดบทความที่เก่ากว่า 72 ชั่วโมงออกจากการประเมินผล
   - **72h Event Fingerprint Deduplication:** Normalized Hash ของ Ticker + Event Keywords ตรวจสอบและ Merge เนื้อหาแทนการสร้าง Record ซ้ำ
   - **Anti-Hallucination Evidence Quotes:** บังคับ AI ให้ Quote ประโยคจริงจากบทความมาเป็นหลักฐานอ้างอิงคะแนน Financial และ Moat
   - **Production Readiness:** ติดตั้งแพ็กเกจบน VPS, ทำ Migration SQLite Database และ Deploy ขึ้นเซิร์ฟเวอร์เสร็จสมบูรณ์

## 🔬 Timeline & Debugging Log

- **Challenge 1: Undici Header Overflow**: การ fetch ข่าวจาก Yahoo Finance ส่งผลให้เกิดข้อผิดพลาด `HeadersOverflowError (UND_ERR_HEADERS_OVERFLOW)` เนื่องจาก cookies และ tracking headers มีขนาดเกิน 16KB
  - *Solution:* สร้างฟังก์ชัน `fetchHtmlWithLargeHeaders` โดยใช้โมดูล `node:https` ร่วมกับพารามิเตอร์ `maxHeaderSize: 128 * 1024` และรองรับ redirect อัตโนมัติ 5 ระดับ ทำให้ดึง HTML ขนาด 800KB+ ได้อย่างสมบูรณ์
- **Challenge 2: Regex Backtracking ใน RSS XML**: การใช้ Regular Expression ตัวเดียวแบบ `[\s\S]*?` บน XML ข่าว 50+ รายการส่งผลให้การจับคู่ล้มเหลว
  - *Solution:* เปลี่ยนไปใช้การแยก block `<item>...</item>` ทีละก้อนด้วย `matchAll` แล้วสกัดฟิลด์ภายใน block ย่อย ทำให้ความเร็วและเสถียรภาพเพิ่มขึ้น 100%
- **Challenge 3: Semantic False Positives**: ข่าวที่ดึงมาจาก Ticker RSS มักปนข่าวลือ ข่าวปรับพอร์ต 13F หรือบทความเก็งกำไร
  - *Solution:* วางด่าน `checkSemanticRelevance` ส่ง Seed Headline และเนื้อหาบทความให้ AI วิเคราะห์ว่าเป็น corporate event เดียวกันจริงหรือไม่ โดยตั้ง threshold ไว้ที่ 65% ส่งผลให้ข่าวที่ไม่ตรงเรื่องถูกคัดออกทันที
