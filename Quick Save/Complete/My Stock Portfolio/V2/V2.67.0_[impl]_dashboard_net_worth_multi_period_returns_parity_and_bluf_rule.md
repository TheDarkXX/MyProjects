# Dashboard Net Worth Multi-Period Returns Parity & BLUF Rule

## 📌 Context & Implementation (Compiled Truth)
- **Problem Statement**:
  - The top Hero strip (`MultiPeriodReturnStrip`) and the Holdings table bottom row (`Total Net Worth`) showed mismatched returns for identical timeframes (1D: `+3.08%` vs `+3.09%`, 1W: `+4.60%` vs `+5.64%`, Total: `+153.69%` vs `+58.89%`).
- **Architectural Discrepancy & Root Causes**:
  1. **1D Return Cash-Drag Omission**: The Stocks Total row calculates today's gain relative to stock equity (`$63.84 / $2,064.59 = +3.09%`). However, the `Total Net Worth (Stocks + Cash)` row erroneously reused this value without incorporating cash balance (`$4.89`), whereas the top strip correctly computed Net Worth return including cash (`$63.84 / $2,069.47 = +3.08%`).
  2. **1W Return Scope Divergence**: The table calculated static holding-level price attribution across current shares (`+$113.63 / +5.64%`), while the top strip calculates true portfolio Time-Weighted Return (TWR) accounting for historical cash flows (`+$93.08 / +4.60%`).
  3. **Total P/L Definition Split**: The table summary displayed unrealized gain on current 4 open positions (`+$788.83 / +58.89%`), whereas the top strip displayed cumulative lifetime return since inception (`+$1,528.46 / +153.69%`).
- **Implementation & Remediation**:
  - Passed `periodMetrics`, `todaysProfit`, `todaysProfitPercent`, `totalPnl`, and `totalPnlPercent` from `Dashboard.tsx` to `PortfolioTable.tsx`.
  - In `PortfolioTable.tsx`, dynamically bound Row 3 (`Total Net Worth`) to the portfolio-level Net Worth metrics:
    - 1D Return % now computes from Net Worth base, yielding exact parity (`+3.08%`).
    - 1W and active/next ladder returns now accurately display actual portfolio NAV returns (`+4.60%`).
    - Holdings header pill clearly labeled `Stocks {activeRangeLabel}:` to clarify holding-specific basket attribution.
  - Codified the **Bottom-Line First (BLUF)** rule into `memory.md` and `corrections.md` to guarantee immediate 1-2 line non-technical conclusions upfront.
