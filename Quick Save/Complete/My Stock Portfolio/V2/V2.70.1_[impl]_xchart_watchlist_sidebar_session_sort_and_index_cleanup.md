# V2.70.1: XChart Watchlist Sidebar Session-Only Default Sort & INDEX Ticker Cleanup

## 📌 Context & Implementation (Compiled Truth)
- **Problem Statement:**
  1. Previously, user sorting selections in the Watchlist sidebar persisted across sessions/reloads via `localStorage`, preventing the intended default behavior (showing biggest losers / worst performers first: `-เยอะสุดขึ้นก่อน`).
  2. The INDEX section was hardcoded to a static array (`DEFAULT_INDEX_ITEMS.map`) and never respected sorting controls (`sortColumn`, `sortDir`), remaining frozen while Holdings and Project2X sorted.
  3. The INDEX row allocated only `col-span-5` for the symbol column, packing emoji, ticker, and full parenthesized names (e.g. `(Nasdaq 1...)`, `(Crude Oil (น้ำมัน))`). This squeezed the tickers into truncated stubs (`QQ...`, `SC...`, `U...`, `S...`, `T...`).
- **Core Architecture & Solutions:**
  - **Session-Only Sort with Hard Default:** In `xchartStore.ts`, updated `loadSavedMyPortPreferences()` so that upon page load/refresh, `sortColumn` strictly defaults to `'percentChange'` and `sortDir` to `'desc'`. During the active session, users can freely toggle sort columns in memory without polluting long-term defaults.
  - **Cloud Sync Isolation:** Guarded `applyCloudMyPortPreferences()` to only synchronize section collapse states (`holdingsCollapsed`, `targetCollapsed`, `indexCollapsed`), preventing remote cloud states from overwriting the active session's sort order.
  - **Dynamic INDEX Sorting:** Added `sortedIndexItems` memoized sorting in `MyPortWatchlist.tsx`, matching the exact sorting logic (`pctA - pctB` on `desc`) used for Holdings and Project2X. All 3 sections now stay perfectly in sync.
  - **Unclipped INDEX Tickers & Tooltip Offload:** Stripped `({item.name})` from the INDEX rows. Symbols are now rendered full width (`text-[13px] font-medium font-mono text-slate-100`) alongside their category emoji. Full names and benchmark descriptions are cleanly offloaded to native `title` hover tooltips.
- **Verification & Deployment:**
  - Full production build via `npm run build` completed cleanly in 37.16s (0 errors).

  - Transferred `dist/*` bundle to Production VPS (`185.250.38.247:/root/stock-portfolio/dist/`) via SCP.
