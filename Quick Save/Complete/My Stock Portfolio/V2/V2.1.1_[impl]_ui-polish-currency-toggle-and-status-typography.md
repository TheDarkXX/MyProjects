# V2.1.1 Sidebar Portfolio Cleanup, Global Currency Toggle Overhaul, and Prompt Status Typography

## 📌 Context & Implementation (Compiled Truth)

### 1. Sidebar Portfolio Switcher Removal (`Sidebar.tsx`)
- **Problem Statement:** The sidebar had a redundant portfolio dropdown (`Doctorbank Growth`), duplicating the primary portfolio selector pills situated prominently in the top header bar.
- **Solution:** 
  - Completely stripped the dropdown button and overlay menu from `src/components/layout/Sidebar.tsx`.
  - Removed unused imports and state (`usePortfolioStore`, `ChevronDown`, `Check`, `isPortfoliosOpen`).
  - Restored full vertical focus on core navigation items and daily top movers.

### 2. Global Currency Toggle Redesign (`Header.tsx`)
- **Problem Statement:** The previous toggle used emoji flags (`🇺🇸` and `🇹🇭`). On Windows platforms, national flag emojis fail to render and fall back to two-letter ISO country codes (`us` and `TH`), creating confusing and cluttered button labels (`us USD` / `TH THB`).
- **Solution:**
  - Removed broken emoji flags and engineered a bespoke, institutional segmented pill toggle.
  - Added dedicated high-contrast circular currency coin badges: `[$]` for USD (golden amber) and `[฿]` for THB (emerald green), switching to pure white on active states.
  - Enforced `font-heading` (`Prompt`) with 13px bold text across both buttons.
  - Active button features luminous brand gradient (`from-[#823AFD] to-[#FC2D79]`) with soft neon drop-shadow.

### 3. Market & API Status Widget Typography Standard (`Header.tsx`)
- **Problem Statement:** The timestamp in the status button inherited monospace font (`font-mono`), while label elements risked inheriting `Sarabun` from global color classes.
- **Solution:**
  - Stripped `font-mono` from the timestamp and explicitly assigned `.font-heading` (`Prompt`) with `tabular-nums` for crisp, aligned time rendering.
  - Enforced `.font-heading` across all internal elements (`US Market`, `CLOSED`/`LIVE` badge, `Yahoo API`, and timestamp).
  - Scaled typography up to comply with Iron Rules (min font floor): `LIVE`/`CLOSED` badge at 11px font-black, labels and timestamp at 12–13px Slate-300 (`#CBD5E1`).

### 4. Holdings Table Flat Single-Line Redesign (`PortfolioTable.tsx`)
- **Problem Statement:** The previous Holdings table used a 5-column multi-line layout with stacked labels, redundant icons (`TWST` square letter box), and gradient progress bars that created visual noise and broke vertical scanning rhythm.
- **Solution:**
  - Redesigned into an 8-column Flat Single-Line layout inspired by TradingView Watchlists: `Symbol | Shares | Price | Total Cost | Value | Total P/L | Period Return | Weight`.
  - Removed bulky stock symbol square badges; rendered tickers in crisp, high-contrast bold white (`font-heading`).
  - Stripped out heavy gradient weight progress bars; now displays pure, clean percentage figures (`text-[14px] font-bold text-slate-200`).
  - Standardized row height to a uniform 48px (`h-12`) with hover glow, making horizontal scanning effortless.
  - Formatted Total P/L and Period Return into a single inline line (`+$ / +%`) with Emerald/Rose color coding.
  - Aligned all summary footer rows (Stocks Total, Cash Balance, Total Net Worth) seamlessly with the new 8-column structure.
  - Fully compliant with Iron Rules (Prompt font, text >= 13px, contrast >= 70%).

### 5. Build, Cache Invalidation, and VPS Deployment
- Built production bundle with Vite chunk splitting (`npm run build`).
- Automated cache busting via `node bump-cache.js`, updating cache timestamps to `v=20260904_080230` in both `dist/index.html` and `index.html`.
- Deployed production artifacts to VPS (`root@185.250.38.247:/root/stock-portfolio/dist/`) via `scp`.
- Executed zero-downtime service reload on VPS.
