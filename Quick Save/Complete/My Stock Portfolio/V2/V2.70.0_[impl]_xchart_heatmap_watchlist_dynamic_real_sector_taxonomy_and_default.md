# V2.70.0: XChart Heatmap Watchlist Dynamic Real-Sector Taxonomy & Default View

## 📌 Context & Implementation (Compiled Truth)
- **Root Cause Analysis:** In `server/routes/market.js`, `getWatchlistSymbols()` queried a non-existent table `project2x_quotas` (actual table is `project2x_share_quotas`), causing an unhandled SQLite error that fell back to `SELECT DISTINCT symbol FROM stock_metadata LIMIT 20`, polluting the Watchlist with arbitrary cached mega-caps (AAPL, GOOG, KO, COST, CRM, etc.).
- **Strategic Watchlist Alignment:** Rebuilt `getWatchlistConstituents()` with:
  1. Base 3-Year Doublers (`THE_3_YEAR_DOUBLER_AUDIT.md`) + Active holdings (Doctorbank Growth & Tiger portfolios).
  2. Purged excluded symbols: `CLS`, `RKLB`, `SCHG`, `QQQM`, `CASH`.
  3. Resulting clean 13-stock universe:
     - `Semiconductors`: NVDA, TSM, AVGO, KLAC, ALAB
     - `Technology`: PLTR, CRWD, ANET, APH, RBRK
     - `Industrials`: VRT, STRL
     - `Consumer Cyclical`: MELI
- **True Sector Grouping:** Replaced hardcoded `'Watchlist'` sector label with true industry sector taxonomy (`Semiconductors`, `Technology`, `Industrials`, `Consumer Cyclical`), enabling proper multi-box treemap rendering when "Sector" grouping is active.
- **Top Ordering & Default State:**
  - Shifted `Watchlist` to the first item in the dropdown selector of `MarketHeatmap.tsx`.
  - Configured `scope` default initial state to `'watchlist'` in both frontend `MarketHeatmap.tsx` and backend `server/routes/market.js`.
- **Absolute % Move (|P/L|) Sizing Engine & Smart Adaptive Defaults:**
  - Added `absPerformance` to `SizeMetric` in `types.ts` and `MarketHeatmap.tsx`.
  - Implemented `Math.abs(getPercent(d))` in `heatmapEngine.ts` with a `0.3%` floor clamp to prevent d3 treemap zero-area crashes.
  - Implemented Smart Adaptive Defaults in `MarketHeatmap.tsx`: opening Heatmap tab or switching to `Watchlist` automatically defaults size to `Absolute % Move (|P/L|)`, switching to `S&P 500`/`Nasdaq 100` defaults to `Market Cap`, and switching to `My Portfolio` defaults to `Portfolio Value`.
  - Deployed `dist/*` bundle to Production VPS (`185.250.38.247`), bumped cache to `v=20261013_094506`, and reloaded PM2 `stock-api`.
