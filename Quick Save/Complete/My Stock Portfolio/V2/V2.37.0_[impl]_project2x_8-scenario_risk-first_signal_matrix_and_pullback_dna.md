1. **Dead Zone ช่องว่างมรณะ (Bug #1):** ช่วง `distEma200 = -4% ถึง -8%` ที่มี Banker 1-6 หลุดรอดจากทั้ง Falling Knife และ Dead Cat Bounce ตกไปอยู่ Default "Pullback" อย่างเงียบๆ
2. **ตัวแปรลอยไม่ได้ใช้ (Bug #2 & #3):** `ema50` และ `rsi14` ถูกคำนวณและส่งเข้ามาในฟังก์ชัน แต่ภายใน body ไม่เคยถูกเรียกใช้งานเลย
3. **ขาด EMA Alignment Regime Guard (Bug #4):** ตรวจแค่ระยะห่างของราคา แต่ไม่เคยตรวจว่า EMA เรียงตัวเป็นขาขึ้นจริงหรือไม่ (`EMA50 > EMA150 > EMA200`) ทำให้หุ้นขาลงใหญ่ (Bear Trend) ถูกมองว่าเป็น Golden Setup ได้
4. **ขาด Volume Confirmation (Bug #5):** ไม่มีการตรวจเช็ควอลุ่มเทียบค่าเฉลี่ย 20 วัน (20D SMA) ทำให้แยกการเด้งลม (Dead Cat) ออกจากการซื้อจริงของสถาบันไม่ได้
5. **Early Bird ให้ BUY_ZONE เร็วเกินไป (Bug #6):** ให้ซื้อ 25% ทั้งที่ Banker = 0 และยังไม่มีแท่งเขียวยืนยัน
6. **ช่วง Near EMA กว้างเกินไป (Bug #7):** `[-3%, +3%]` กว้างเกินไปสำหรับหุ้นที่ลอยอยู่เหนือเส้น
7. **Core Commanders ไม่มี Stop Loss (Bug #8):** Layer 2 ตรวจเฉพาะ Moonshot ทำให้แม่ทัพหลัก 83% ของพอร์ตไม่มีสัญญาณเตือนตัดขาดทุนเมื่อหลุดเส้น 200 ลึก
8. **Threshold แข็งทื่อ (Bug #9-11):** Overbought 15% คงที่สำหรับทุกประเภทหุ้น และ Default Fallback ไม่แยกความรุนแรงของการย่อตัว

### 2. สถาปัตยกรรม 8-Scenario Risk-First Evaluation Hierarchy
จัดลำดับการประเมินสัญญาณใหม่ทั้งหมดตามหลัก **"Risk-First Hierarchical Evaluation"** เพื่อความปลอดภัยสูงสุดของพอร์ต:

```
Tier 0 (DANGER VETO):
  - 🔴 Falling Knife: distEma200 < -4% && banker === 0 [DANGER]
  - 🔴 Dead Cat Bounce: distEma200 < -4% && banker 1-6 [DANGER]
  - ⚪ Slow Bleed: BEAR Regime && distEma200 < 0 && daysBankerZero >= 8 [WAIT]

Tier 1 (REVERSAL 100% CONVICTION):
  - 💎 Double Bottom Confirmed: Retest EMA 200 ในรอบ 15-45 วัน + Low วันนี้ยกสูง + Banker >= 1 + แท่งเขียว (ชนะ V-Shape เสมอ!) [BUY_ZONE 100%]

Tier 2 (CONFIRMED RECLAIM / BREAKOUT):
  - 🚀 Bear Trap Reclaim: หลุด < -4% แล้วดึงกลับมายืนเหนือ EMA200 ได้ >= 2 วันติด + Vol >= 1.2x [BUY_ZONE 75-100%]
  - ⚡ Base Breakout: ระเบิดทะลุ High ของกรอบสะสม EMA + Vol >= 1.4x + Banker >= 3 [BUY_ZONE 100%]

Tier 3 (STANDARD PULLBACK DIP):
  - 🟢 V-Shape Rebound: แตะ EMA 150/200 (-3% ถึง +1.5%) + แท่งเขียวเด้ง + BULL Regime + Vol >= 0.8x [BUY_ZONE 100%]
  - 🟡 Testing Support: ย่อแตะแนวรับแต่ยังโดนเทแท่งแดงติดกัน >= 2 แท่ง [WAIT รอแท่งเขียว]
  - 🟡 Shallow Dip (EMA50 Bounce): ย่อตื้นแตะ EMA 50 ในหุ้น Super Bull (ลอยเหนือ 150 > +4%) + Banker >= 6 [BUY_ZONE 50%]

Tier 4 (ACCUMULATION / WATCH):
  - 🔄 Regime Flip: Golden Cross EMA 50 ตัดขึ้นเหนือ EMA 200 รอบใหม่ + Banker >= 4 [BUY_ZONE 25%]
  - 📦 Sideway Base: กอดเส้น EMA 200 นิ่งๆ >= 5 วัน + Vol แห้งบีบตัว <= 1.1x [BUY_ZONE DCA 25%]
  - 🐣 Early Bird Watch: แตะแนวรับใหญ่แต่ Banker = 0 หรือยังเป็นแท่งแดง [WAIT เฝ้าจอ]

Tier 5 (OVERBOUGHT & DEFAULT):
  - ⚠️ Overbought: distEma150 > (Moonshot: 25%, Core: 14%) + Banker >= 15 [WAIT พักเงินใน Dime FCD]
  - ⚪ Consolidating / Healthy Dip (-1% ถึง -3%) / Deep Pullback (-3% ถึง -6%) / Approaching Bedrock (-6%+)
```
