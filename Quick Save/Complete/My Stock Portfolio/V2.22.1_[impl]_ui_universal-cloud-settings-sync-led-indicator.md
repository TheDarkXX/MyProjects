# 🚀 V2.22.1: Universal Cloud Settings Sync Real-time Yellow LED Status Indicator

> **Mission**: ต่อยอดระบบ Universal Cloud Settings Sync บน VPS SQLite ด้วยการสร้างชุดแสดงผลสถานะ **LED Status Indicator (สีเหลืองอำพัน Amber/Yellow สำหรับ Synced ตามคำสั่งผู้ใช้)** พร้อมกลไก Reactive State Layer ผ่าน Zustand เพื่อให้ผู้ใช้มองเห็นสถานะการบันทึกการตั้งค่า (Indicators, Tabs, Watchlist, Drawings, UI Prefs) ขึ้น Cloud ทันที 0 latency และคลิกเพื่อ Force Resync ข้ามเครื่องได้ในคลิกเดียว

---

## 🧠 Context & Implementation

### 1. Problem Statement
ในเวอร์ชัน V2.22.0 ระบบ Universal Cloud Settings Sync ทำงานเบื้องหลังแบบ Silent Sync 100% ทำให้ผู้ใช้ไม่สามารถทราบได้ว่า:
- การตั้งค่าล่าสุด (เส้น EMA, แถบแท็บหุ้น, Watchlist) ถูก Push สำเร็จหรือยัง
- มีข้อผิดพลาดในเน็ตเวิร์กหรือไม่
- เครื่องที่เปิดอยู่มีข้อมูลตรงกับ Cloud ล่าสุดเมื่อเวลาใด

### 2. Architecture & Design Decisions
- **Zustand Reactive Store (`src/stores/syncStatusStore.ts`)**:
  - `status`: `'idle' | 'syncing' | 'synced' | 'error'`
  - `operation`: `'push' | 'pull' | 'idle'`
  - `lastSyncedAt`: บันทึก Timestamp ล่าสุด
  - `lastError`: เก็บ Error message หากเกิดข้อผิดพลาด
- **Sync Color Specification (Yellow / Amber for Synced)**:
  - **Synced (สถานะปกติหลังซิงค์สำเร็จ)**: สีเหลืองนีออน (`bg-amber-400 shadow-[0_0_8px_rgba(251,191,36,0.9)]` + `text-amber-300`)
  - **Syncing (กำลัง Push / Pull)**: สีฟ้าไซแอน (`bg-cyan-400 animate-pulse shadow-[0_0_8px_rgba(34,211,238,0.9)]` + `<RefreshCw className="animate-spin" />`)
  - **Error (เน็ตเวิร์กหลุด/บันทึกไม่ผ่าน)**: สีแดง (`bg-rose-500 animate-pulse shadow-[0_0_8px_rgba(244,63,94,0.9)]` + `<CloudOff />`)
- **Typography & Accessibility**:
  - ตัวหนังสือขนาด `text-[13px]` ตาม Iron Rules (ห้ามเล็กกว่า 13px)
  - Contrast สูงกว่า 70% บนพื้นหลัง Dark Mode (`text-amber-300`, `text-slate-200`)
- **Dual Placement**:
  1. **XChartTabBar Capsule (`src/components/xchart/XChartTabBar.tsx`)**: อยู่ในกล่อง Floating Pills ขวามือติดกับ US LIVE และ Yahoo API
  2. **Global Header (`src/components/layout/Header.tsx`)**: อยู่ติดกับปุ่ม Market Status และ Live FX Rate
