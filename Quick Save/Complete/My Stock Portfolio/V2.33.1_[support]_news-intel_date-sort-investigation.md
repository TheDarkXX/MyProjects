# [Support] News Intel: Date Sort Investigation & Clarification

## 📌 Context & Implementation (Compiled Truth)
The user reported that the previously generated AVGO news ("CEO Doubles Down on Massive AI Growth Target") was missing from the UI, with only "old" (chatter/clickbait) articles visible.
- **Investigation:**
  - Queried `news_intelligence` table in `server/db/stock.db`.
  - Found the article correctly stored at ID 52 with `created_at` timestamp of `2026-09-15 19:28:39`.
  - Found newer chatter articles (e.g., ID 2, "มหาเศรษฐีขาย AVGO...") with `created_at` timestamp of `2026-09-16 03:43:15`.
- **Root Cause & Conclusion:**
  - The UI News Terminal was set to sort by `Date DESC`.
  - Because the high-priority AVGO article was generated on Sep 15, it was pushed further down the list by the newer chatter articles from Sep 16.
  - Advised the user to scroll down to Sep 15 entries or use the search/filter functions (e.g., filtering by `WATCHLIST` or searching "ซีอีโอ") to find the article.
  - No code changes were required.
