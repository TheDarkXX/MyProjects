## ⚡ Performance Optimization & Scope Filtering (Post-Launch Refinement)

### 1. 13.85MB Payload & 6-7s Table Latency Elimination
- **Root Cause 1:** Backend `scanRadarMatrix` was sending 14 full 2,500-day series per stock. Across 41 tickers, the response was 13.85 MB JSON. Browser `localStorage` quota (5MB) rejected the write, forcing cold network fetches on every single page open.
- **Root Cause 2:** Unprofitable growth stocks and ETFs (`ASTS, COIN, CRWV, GLD, HIMS, RBRK, RKLB, TWST, VKTX`) have `pe_trailing === null`. The cache condition `row.pe_trailing !== null` perpetually evaluated to false, causing 9 synchronous sequential Yahoo requests on every scan.
- **Root Cause 3:** Concurrent calls from `fetchDashboard` and `fetchRadar` on page load ran duplicate scans simultaneously without promise sharing.
- **Solutions Implemented:**
  1. Truncated sparkline payload to max 365 bars containing only `closes`, `ema150`, and `ema200` rounded to 2 decimal places. Payload plummeted from **13.85 MB down to 128.4 KB** (99.1% reduction).
  2. Fixed fundamentals cache check to 7 days regardless of whether `pe_trailing` is null.
  3. Preloaded all fundamentals in 1 bulk SQL query, enabling 0.0ms in-memory lookups.
  4. Parallelized indicator calculation via `Promise.all`.
  5. Implemented in-flight request deduplication and 60-second in-memory cache on the backend.
  6. Added 15-minute in-memory caching to `fetchYahooExchangeRate`.
  7. Client `localStorage` write now succeeds seamlessly, rendering the table in **0.00 seconds** on page open with a smooth skeleton shimmer fallback.

### 2. Strict Project 2X + 2-Portfolio Scope Filtering
- Replaced scanning of all 41 tickers from `historical_prices` with strict filtering:
  - **13 Project 2X Stocks:** Core Commanders (`NVDA, TSM, AVGO, VRT, MELI, APH, KLAC, ANET, CRWD`) + Moonshot Strikes (`STRL, ALAB, PLTR, CLS`).
  - **All Held Securities Across Both Portfolios:** Queries `portfolios` and includes any asset with `shares > 0.001` (`RBRK` from Doctorbank Growth, `SCHG` from Tiger).
  - All unrelated historical tickers (`COST, ISRG, GLD, ASTS, COIN, TWST, VKTX`, etc.) permanently pruned from the radar table.
- Added `Held` category filter button: `[ ALL | Core | Moonshot | Held ]` with distinct Emerald badge styling.
- Cold scan latency on VPS reduced to **676 ms** (warm scan **0.0 ms**).
