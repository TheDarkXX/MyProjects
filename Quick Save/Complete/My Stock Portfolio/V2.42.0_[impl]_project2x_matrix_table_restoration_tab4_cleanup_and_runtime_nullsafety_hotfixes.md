# V2.42.0: Project 2X Option A Matrix Table Restoration, Tab 4 Cockpit Cleanup & Runtime Null-Safety Hotfixes

   - Preserve the 7-Tier Cyber Action Matrix Legend Guide below the matrix table.
   - Permanently delete Tab 4 (`all` / `All-In-One Cockpit`) and its simulator panel to eliminate visual clutter.

### 2. Architectural Changes & Key Code Solutions

#### A. Hotfix 1: `isCatalyst` Aliasing in `NewsDetailModal.tsx`
Added resilient backward-compatible aliases and enhanced 5-tier pill color mapping:
```typescript
const isCatalyst = isHighImpact;
const isWatchlist = isGoodToKnow;
```

#### B. Hotfix 2: Defensive Null-Safety for `.toUpperCase()`
Safeguarded all potential undefined string properties across 6 critical components:
- `NewsIntelPage.tsx`: Ensured `(item.symbol || '').toUpperCase()`, `tag.toUpperCase()`, and search filters default gracefully.
- `NewsTickerDock.tsx`: Added `(h.symbol || '').toUpperCase()` across dynamic holdings and search inputs.
- `useChartDrawings.ts`: Added `(s || '').toUpperCase()` check in drawing hooks.
- `StockDetailDrawer.tsx` & `UpcomingDividendStrip.tsx`: Wrapped symbol Lookups in safe null-coalescing.
- `TierBadgeIndicator.tsx`: Safeguarded badge text transformations.

#### C. Option A: Tab 1 Radar Matrix Table Consolidation
- Replaced 12 cyber stock cards in Tab 1 with `Full Technical & Fundamental Radar Matrix Table`.
- Added seamless category filtering buttons (`ALL`, `Core`, `Moonshot`) on the table header bar.
- Connected multi-column sorting (`SYMBOL`, `PRICE`, `WEIGHT`, `EMA150`, `EMA200`, `BANKER`, `PE`, `PEG`, `CAGR`, `BEAT`, `STATUS`).
- Retained inline quick actions: `Chart` (X-Chart), `X-Ray` (Stock Dossier), `DNA` (10Y Pullback DNA Modal).
- Cleaned up Tab 3 (`inflow`) so it strictly contains the Dime Inflow Slip & FCD Cash Sweep without redundant tables.

#### D. Tab 4 Cockpit Removal
- Deleted Tab 4 switcher button from view switcher navigation.
- Deleted Section 7 Simulator Panel.
- Removed `'all'` from `useProject2xStore.ts` tab union types (`'radar' | 'vault' | 'inflow'`).

#### E. Sparkline Lifetime Leak Fix & 4-Period Lookback Selector (30D / 90D / 1Y / ALL)
- **Root Cause:** Backend `sparkline.closes` was shipping all 2,500+ lifetime candles (10 years) from `dbCandles`. The frontend was rendering the entire array without `.slice(-30)`, causing all sparklines to display a 10-year hockey stick curve (and falsely staying green by comparing today's price to 10 years ago).
- **Solution:** Added dynamic `getSparklineSlice` helper and integrated an interactive Lookback Selector (`[ 30D | 90D | 1Y | ALL ]`) on both the Matrix Table column header and Detail Modal. Slices both closes and EMA 150/200 concurrently, accurately rendering 30-day recent momentum, correct bullish/bearish color coding, and crisp EMA crossovers.
