# V2.26.0 [impl] UI: Native Mobile Phone Dashboard & iPad Master-Detail Split View Architecture

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการปฏิวัติเชิงสถาปัตยกรรม (Multi-Form Factor Revolution)
เดิมทีระบบ **My Stock Portfolio** ถูกออกแบบมาเพื่อการใช้งานแบบ **Desktop Workstation First** เน้นจอกว้าง การแสดงผลหลายคอลัมน์ และการเทรดบนจอใหญ่ แต่เมื่อผู้ใช้จำเป็นต้องติดตามพอร์ตผ่านอุปกรณ์พกพา เช่น **vivo X80 Pro (High-DPI Mobile Phone)** หรือ **iPad Air M2 13-inch (High-Resolution Tablet)** กลับพบปัญหา:
1. **Desktop Cramping:** การย่อหน้าจอ Desktop ลงมาในมือถือทำให้ Element ต่างๆ ถูกบีบจนเล็กเกินสัมผัส ปุ่มกดยาก ตัวหนังสือตกหล่น
2. **iPad Viewport Ambiguity:** หน้าจอ iPad Air M2 13 นิ้ว (ความละเอียด 1366x1024 ในแนวนอน) มักถูก Browser เข้าใจผิดว่าเป็นจอ Desktop ทั่วไป ทำให้ดึงเอา Layout คอมพิวเตอร์มาแสดงจนสัดส่วนผิดรูป และมีอาการ Jitter/Bounce เลื่อนหลุดขอบบน Safari
3. **ขาดจิตวิญญาณแบบ Native Touch App:** การดูพอร์ตบนมือถือและแท็บเล็ตต้องการ Flow การแตะที่รวดเร็ว ลื่นไหล ส่องกราฟได้ทันทีโดยไม่ต้องถ่างซูม

สถาปัตยกรรม **V2.26.0** จึงถือกำเนิดขึ้น เพื่อแยก Layer การแสดงผลของทั้ง 3 Form Factors ออกจากกันอย่างเด็ดขาด แต่แชร์ Data Layer และ State Management ร่วมกัน 100%

### 3. เสาหลักสถาปัตยกรรมทั้ง 3 ส่วน (Core Pillars)

#### Pillar A: กลไกตรวจจับอุปกรณ์ขั้นสูง (`useDeviceLayout.ts`)
- **การแยกแยะ iPad ที่แม่นยำ:** iPadOS มักรายงาน User-Agent เลียนแบบ macOS (`Macintosh; Intel Mac OS X`) ทำให้การตรวจผ่าน User-Agent แบบเดิมล้มเหลว ระบบจึงเพิ่มการตรวจสอบ 4 มิติควบคู่กัน:
  1. Regular Expression `/iPad/i.test(navigator.userAgent)`
  2. การมี Touch Points ควบคู่กับ User-Agent Mac (`navigator.userAgent.includes('Macintosh') && navigator.maxTouchPoints > 0`)
  3. ตรวจสอบ Physical Screen Dimensions เฉพาะทางของ iPad (`1366x1024` และ `1024x1366`)
  4. Media Query `(pointer: coarse)`
- **Manual Mode Override:** รองรับ Query Parameter เช่น `?mode=mobile` หรือ `?mode=desktop` เพื่อเปิดโอกาสให้นักพัฒนาทดสอบ Responsive ได้บนจอคอม และจำสถานะลง `localStorage ('stock_layout_mode')`
- **High-DPI Awareness:** คำนวณ Device Pixel Ratio (`dpr >= 2.0`) สำหรับจอเรตินาความละเอียดสูง (vivo X80 Pro ~3.5x, iPad Retina 2.0x)

ออกแบบภายใต้ปรัชญา **"One-Thumb Operations"** จัดวาง Component สำคัญให้สแกนสายตาจากบนลงล่างได้อย่างเป็นธรรมชาติ:
1. **[`MobileHeader.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/components/layout/MobileHeader.tsx):** แถบ Header บรรทัดเดียว มีปุ่มสลับพอร์ต (Dropdown), แสดงสถานะตลาดหุ้นสหรัฐฯ (Market Open/Closed Pulse), ค่าเงิน USD/THB และปุ่ม Fullscreen Toggle
2. **[`PortfolioHero.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/views/mobile/components/PortfolioHero.tsx):** แสดงยอดเงินรวมสุทธิ (Net Worth), วันนี้บวก/ลบ (Day Return), กำไรสะสมรวม (Unrealized P&L) ควบคู่กับ Interactive Mini Equity Curve (สีม่วง `#823AFD` สไตล์ PC Theme) พร้อมแถบเลือกช่วงเวลา (1D, 1W, 1M, 3M, YTD, 1Y, ALL)
3. **[`QuickStatsStrip.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/views/mobile/components/QuickStatsStrip.tsx):** แถบสรุป 4 มิติสำคัญ (Net Invested, Cash Balance, Total Dividends, Yield on Cost)
4. **[`WatchlistCard.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/views/mobile/components/WatchlistCard.tsx):** การ์ดหุ้นแต่ละตัวในพอร์ต แสดง Logo, Ticker, ราคาตลาดสด, % Change วันนี้, และ Total P&L เมื่อคลิกการ์ดจะสไลด์เปิด **`StockDetailDrawer`** ลอยขึ้นมาจากจอด้านล่างทันที
5. **[`MobileNavBar.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/components/layout/MobileNavBar.tsx):** Bottom Navigation Bar สไตล์แอปพลิเคชันมือถือ พร้อมปุ่ม More Sheet สำหรับเปิดโมดูลอื่นๆ

#### Pillar C: iPad / Tablet Master-Detail Split Architecture (`TabletDashboard.tsx`)
จำลองสถาปัตยกรรม **Split View ของ iPadOS** แบ่งจอออกเป็น 2 ส่วนอย่างเป็นเอกเทศ:
1. **[`MasterPanel.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/views/tablet/components/MasterPanel.tsx) (จอด้านซ้าย ความกว้างคงที่ 340-380px):**
   - แถบค้นหาหุ้นแบบ Real-time
   - ปุ่มลัดสลับไปดูภาพรวมพอร์ต (`Overview`)
   - ลิสต์หุ้นทั้งหมดในพอร์ต เรียงตามสัดส่วนน้ำหนัก (Weight %) แสดง Ticker, ชื่อบริษัท, มูลค่าที่ถือ, และกำไร/ขาดทุน
2. **[`DetailInspector.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/views/tablet/components/DetailInspector.tsx) (จอด้านขวา เต็มพื้นที่ที่เหลือ):**
   - **โหมด Portfolio Overview (เมื่อไม่เลือกหุ้นเดี่ยว):** กราฟเส้น Equity Curve ขนาดใหญ่, ตัวสลับ Timeframe, กล่องสถิติ Net Invested / Dividends / Cash Cushion และ Top Movers
   - **โหมด Stock Inspector (เมื่อคลิกเลือกหุ้น):**
     - แถบหัวข้อพร้อมปุ่มกด Back กลับไปหน้า Overview
     - ราคาตลาดสด, วันนี้บวก/ลบ, กราฟราคาแท่งเทียน/AreaChart ย้อนหลัง (1W ถึง ALL)
     - รายละเอียดการถือครอง (จำนวนหุ้น, ทุนเฉลี่ย, มูลค่าตลาด, Unrealized P&L, Portfolio Weight)
     - ตารางประวัติการซื้อขายของหุ้นตัวนั้น (BUY, SELL, DIVIDEND พร้อมวันที่, ราคา และค่าธรรมเนียม)

### 4. การจูนแต่งประสบการณ์ผู้ใช้บน iPad & Safari (Viewport & Engine Fixes)
- **100dvh Lock & Anti-Bounce:** ปรับแก้ใน [`index.css`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/styles/index.css) และ [`App.tsx`](file:///C:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/App.tsx) โดยใช้ `h-[100dvh]` และ `overflow-hidden` ที่ Container นอกสุด เพื่อล็อกไม่ให้หน้าจอเด้ง (Safari Elastic Scrolling Jitter) เมื่อลากนิ้ว
- **Auto-Collapse Indicator Legend:** บนแท็บเล็ต มีการปรับให้ Legend ของอินดิเคเตอร์ในหน้ากราฟพับเก็บอัตโนมัติเป็นค่าเริ่มต้น เพื่อเปิดพื้นที่ของ Canvas กราฟให้แสดงได้เต็มตา
- **Unification ของโทนสี (PC Palette Harmony):**
  - ปรับ Equity Curve บน Mobile/Tablet ให้ใช้โทนสีม่วงนีออน (`#823AFD`) สอดคล้องกับหน้าจอ PC
  - แท่งเทียนและกราฟหุ้นใช้สีเขียวเอเมอรัลด์ / แดงคริมสันมาตรฐาน
  - พื้นหลัง Dark Theme สไตล์ Slate ดำลึก (`#07090E`, `#0A0D15`) ตัดขอบด้วย `border-white/[0.08]`

## 📐 การปฏิบัติตามมาตรฐาน UI & Typography (Iron Rules)

- **Minimum Font Size (Iron Rule):** ทุกข้อความบน Mobile และ Tablet ใช้ขนาดไม่ต่ำกว่า 13px (`text-[13px]`) สำหรับเนื้อหาทั่วไป และ 12px (`text-xs`) สำหรับ Badge pills ขนาดเล็ก ปราศจากตัวอักษร 10px-11px ที่อ่านยาก
- **Perceptual Contrast (Iron Rule):** ข้อความหลักสว่างเกิน 70% (`text-slate-200`, `text-slate-300`, `#CBD5E1`) ปราศจากสีเทามืดที่ทำให้เมื่อยสายตาเมื่อเปิดดูกลางแจ้งหรือในที่มืด
