# [Impl] News Intel: Tiered Summary Prompt & VPS Sync

## 📌 Context & Implementation (Compiled Truth)
- **Investigation 1:** The user reported that previously generated AVGO news ("CEO Doubles Down on Massive AI Growth Target") was missing from the UI. Discovered that the news was correctly stored in the SQLite database but was pushed down the list because the UI was sorted by Date DESC.
- **Investigation 2 & VPS Sync:** The user sent a screenshot from the VPS showing the same news summarized into only 2 lines and missing the `full_content` accordion. The VPS AI had pulled the news independently, assigning it as `CHATTER` and omitting the full content. We generated a SQL script (`update_vps_52.sql`) locally and applied it to the VPS SQLite database via SSH to overwrite ID 52 with the full 19,565-character `full_content` and `WATCHLIST` priority.
- **Dynamic Tiered Summary Implementation:** The user pointed out that summarizing a massive 3-source aggregated article into just 3 short bullets was inefficient. We modified `server/services/newsRadar.js` to change the `summary_th` prompt from a fixed 3-bullet array to a dynamic "Tiered Summary" (2-7 points depending on priority). `THE_MUST/CATALYST` will now get 5-7 detailed points, while `CHATTER` will get 2-3 short points.
