# FluidTrades - SMC Lite Overlay, Dynamic Sub-Pane True Close, Trend Speed Analyzer & Anchored VWAP Architecture

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการตัดสินใจเชิงสถาปัตยกรรม (Architectural Decisions)
ในเซสชันนี้ ผู้ใช้ต้องการยกระดับ **X-Chart Trading Terminal** ให้รองรับอินดิเคเตอร์ระดับมืออาชีพเพิ่มเติม และแก้ปัญหาการทำงานของ Sub-Pane ในเชิงลึก:

1. **การแก้ปัญหา Sub-Pane Close พับเก็บ (True Pane Destroy Engine):**
   - **ปัญหาเดิม:** เมื่อผู้ใช้กดปุ่ม **X** บน Floating Toolbar ของ Sub-pane ระบบเดิมสั่งแค่ `toggleVisibility` ทำให้หน้าต่างย่อขนาดเหลือเส้นบาง 18px พร้อมข้อความ `(พับเก็บ)` ค้างอยู่บนชาร์ต
   - **การแก้ไข:** ปรับสถาปัตยกรรมใหม่ให้การกด **X** เป็นการ "ลบทิ้งจริง" (True Pane Destroy) โดยคำนวณ `activeSubPanes` แบบไดนามิก (เฉพาะ Indicator ที่เปิดอยู่) และทำ Dynamic Index Mapping ลงบน Panes 1..N ของ Lightweight Charts v5 โดยอัตโนมัติ หากไม่มี Sub-pane ใดเปิดอยู่เลย ชาร์ตหลัก Pane 0 จะขยายเต็มพื้นที่ 100% ทันที

2. **Trend Speed Analyzer by Zeiierman:**
   - ติดตั้งอินดิเคเตอร์วัดสปีดโมเมนตัมและแนวโน้มการวิ่งของแท่งเทียน แปลงจาก Pine Script v6
   - รองรับ Dynamic Trend EMA บน Pane 0, Trend Speed Histogram (เขียว/แดง 2 เฉด) บน Sub-pane, และ Dominance Wave Stats Table

3. **FluidTrades - SMC Lite (Smart Money Concepts Lite):**
   - พัฒนาระบบคำนวณและเรนเดอร์โครงสร้าง Smart Money Concepts ซ้อนทับลงบน Pane 0 (Candlestick Overlay) โดยตรง
   - **Mathematical Parity:** ถอดสมการคณิตศาสตร์จาก Pine Script v6:
     - `swingLength = 10`: ตรวจจับ Pivot High/Low
     - `ATR(50)`: คำนวณความกว้างกล่อง Supply/Demand ตามสัดส่วน `boxWidth`
     - `f_check_overlapping`: ป้องกันการสร้างโซนทับซ้อนกันในระยะ `2 * ATR`
     - `Break of Structure (BOS)`: เมื่อราคาปิดแท่งเทียนทะลุโซน จะตัดเป็นเส้นประแนวนอนพร้อมป้าย **BOS** ทันที
     - `Dual SMA Trend Filter`: Fast SMA (15) & Slow SMA (200) พร้อมสัญญาณ Strong Buy / Strong Sell Crossover
     - `Zigzag & Price Action Labels`: HH, LH, HL, LL
   - **Lightweight Charts v5 Custom Primitive (`SMCPrimitive`):**
     - ใช้งาน `ISeriesPrimitive<Time>` วาดลงบน Canvas Layer ของ Pane 0 โดยตรง
     - ใช้ `useMediaCoordinateSpace` ร่วมกับ `timeToCoordinate` และ `priceToCoordinate` ให้พิกัดมีความคมชัดระดับพิกเซล ไม่เบลอ ไม่กระตุก
     - วาดโซน Supply (สีกรมท่ากึ่งโปร่งแสง), โซน Demand (สีทองกึ่งโปร่งแสง), เส้นประ POI Equilibrium, ป้าย POI, ตัวหนังสือ SUPPLY / DEMAND ตรงกลางกล่อง, และป้าย BOS แนวนอน

4. **Anchored VWAP (Volume Weighted Average Price) Architecture & Brief:**
   - ออกแบบสเปกและสถาปัตยกรรมสำหรับ Anchored VWAP ถอดแบบ TradingView 1:1
   - รองรับการเลือกจุดเริ่มนับ (Anchor Date/Time Picker) และคำนวณสะสม $\frac{\sum (Source \times Volume)}{\sum Volume}$
   - รองรับ Standard Deviation Bands (Length 30) Multiplier

### 2. โครงสร้าง Data Flow และ Component Architecture

```
                                      [ Indicator Settings Store ]
                                                    │
                 ┌──────────────────────────────────┼──────────────────────────────────┐
                 ▼                                  ▼                                  ▼
           [ SMC Lite Engine ]             [ Multi-Pane Engine ]             [ Anchored VWAP ]
      (computeSMCLite in smcLite.ts)       (activeSubPanes 1..N)        (computeAnchoredVWAP)
                 │                                  │                                  │
                 ▼                                  ▼                                  ▼
         [ SMCPrimitive ]                 [ SubPaneHeaderToolbar ]              [ LWChart Pane 0 ]
   (ISeriesPrimitive on Pane 0)          (Live Values, True Close)             (Dual SMA & Overlay)
```

#### การทำงานของ Lightweight Charts Custom Series Primitive (`src/utils/indicators/smcPrimitive.ts`):
```typescript
export class SMCPrimitive implements ISeriesPrimitive<Time> {
  chart: any = null;
  series: any = null;
  requestUpdate: (() => void) | null = null;
  data: SMCResult | null = null;
  config: SMCLiteConfig | null = null;

  attached(param: SeriesAttachedParameter<Time, SeriesType>): void {
    this.chart = param.chart;
    this.series = param.series;
    this.requestUpdate = param.requestUpdate;
  }

  setData(data: SMCResult, config: SMCLiteConfig): void {
    this.data = data;
    this.config = config;
    this.requestUpdate?.();
  }

  paneViews(): readonly IPrimitivePaneView[] {
    return [this._paneView];
  }
}
```

# Implementation Plan: Anchored VWAP (Volume Weighted Average Price)

Implement **Anchored VWAP** matching TradingView 1:1 based on the provided Pine Script v5 and TradingView screenshots.

---

## 1. System Architecture & Mathematical Formulation

### 1.1 Core Formulas
1. **Source Price ($src$)**:
   - Default: `hlc3` = $(High + Low + Close) / 3$
   - Options: `close`, `hl2`, `hlc3`, `ohlc4`, `open`, `high`, `low`
2. **Cumulative VWAP from Anchor Point**:
   $$\text{VWAP}_t = \frac{\sum_{i=anchor}^{t} (src_i \times volume_i)}{\sum_{i=anchor}^{t} volume_i} \quad \text{for } t \ge anchor$$
   For bars before $anchor$, VWAP is `null` (not rendered).
3. **Standard Deviation Bands (Length 30)**:
   - Rolling 30-bar standard deviation of the VWAP series:
     $$\mu = \frac{1}{N} \sum_{k=0}^{N-1} \text{VWAP}_{t-k}, \quad \sigma = \sqrt{\frac{1}{N} \sum_{k=0}^{N-1} \text{VWAP}_{t-k}^2 - \mu^2}$$
   - **Upper Band**: $\text{VWAP}_t + (\text{multiplier} \times \sigma)$
   - **Lower Band**: $\text{VWAP}_t - (\text{multiplier} \times \sigma)$
   - Default multiplier = `0.5` (from user screenshot) / `1.0` (Pine default)

---
