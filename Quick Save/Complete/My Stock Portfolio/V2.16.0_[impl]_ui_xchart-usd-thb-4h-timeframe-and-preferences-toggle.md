# X-Chart USD/THB 4H Timeframe, 2-Year Aggregation Engine & Preferences Toggle

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการตัดสินใจเชิงสถาปัตยกรรม (Architectural Decision)
ผู้ใช้ต้องการขยายขีดความสามารถของ **X-Chart Trading Terminal** ให้รองรับ Timeframe ย่อย **4 ชั่วโมง (4H)** บนกราฟอัตราแลกเปลี่ยนค่าเงินบาท **USD/THB (`THB=X`)** โดยมีโจทย์สำคัญ 4 ข้อ:
1. **ขีดจำกัดความลึกของข้อมูล (Historical Lookback):** สามารถดึงข้อมูลย้อนหลังได้นานสุดเท่าไหร่?
2. **ขอบเขตการแสดงผล (Scope):** ให้ปุ่ม 4H ปรากฏเฉพาะกราฟ USD/THB เท่านั้น ไม่ให้โผล่กวนใจในกราฟหุ้นทั่วไป (เช่น AAPL, NVDA, DELTA)
3. **การจัดวางปุ่ม (Symbol-Aware vs Fixed Tab 2):** ผู้ใช้สอบถามว่าจะฟิกซ์ลง Tab 2 หรืออย่างไร — ทางเราตัดสินใจเลือกสถาปัตยกรรม **Symbol-Aware (`symbol === 'THB=X'`)** เพื่อไม่ให้ระบบพังเมื่อผู้ใช้สลับตำแหน่งแท็บ ปิดแท็บ หรือเปิดกราฟใหม่
4. **การควบคุมผ่าน Settings:** เพิ่มสวิตช์ On/Off สำหรับ Timeframe 4H นี้ในหน้า **System Settings (`Preferences`)** เพื่อให้ผู้ใช้เปิดหรือปิดการใช้งานได้ตามใจชอบ

### 2. ผลการวิจัยและข้อจำกัดของ API (Yahoo Finance Data Engine)
จากการทดสอบเจาะลึกผ่าน Yahoo Finance API โดยตรง:
- **Interval `4h`:** Yahoo Finance **ไม่มี** Native Resolution `4h` (ถ้าส่งไปจะ Error: `Invalid interval: 4h`)
- **Interval `1h` Lookback Limit:** Yahoo Finance กำหนดขอบเขตย้อนหลังเข้มงวดที่ **730 วัน (~2 ปี)** หากส่ง `period1` เกิน 730 วัน (เช่น 735d) ระบบจะรีเจกต์ทันทีด้วยข้อความ: `"The requested range must be within the last 730 days"`
- **ทางออกเชิงวิศวกรรม (1H to 4H Aggregator):** 
  - ดึงข้อมูลแท่ง 1 ชั่วโมง ย้อนหลัง **720 วันเต็ม** ได้แท่งเทียน 1h จำนวน ~12,338 แท่ง
  - เขียน Aggregation Algorithm ทำการรวมแท่ง 1h เป็นแท่ง 4H อิงตามรอบเวลาสากล UTC: `00:00`, `04:00`, `08:00`, `12:00`, `16:00`, `20:00`
  - คำนวณ OHLCV:
    - `open`: ราคาเปิดของแท่ง 1h แรกในรอบ
    - `high`: ราคาสูงสุดจากทุกแท่ง 1h ในรอบ
    - `low`: ราคาต่ำสุดจากทุกแท่ง 1h ในรอบ
    - `close`: ราคาปิดของแท่ง 1h สุดท้ายในรอบ
    - `volume`: ผลรวม Volume ในรอบ
  - ผลลัพธ์: ได้แท่งเทียน 4H ทั้งสิ้น **3,112 แท่งเทียน (2 ปีเต็ม)**

### 3. SQLite Intraday Cache Architecture
เพื่อแก้ปัญหา Latency ไม่ต้องวิ่งไปขูด Yahoo Finance ทุกครั้งที่มีการเปิดแท็บหรือสลับ Timeframe:
- ออกแบบตาราง `intraday_prices` ใน SQLite (`stock.db`)
- Composite Primary Key: `(symbol, resolution, time)` พร้อม Index เพื่อค้นหาด้วยความเร็วแสง
- **Cache Strategy:** หากในฐานข้อมูลมีข้อมูล `COUNT(*) >= 500` และเวลาแท่งล่าสุดห่างจากเวลาปัจจุบันน้อยกว่า 2 ชั่วโมง จะอ่านจาก SQLite ทันที
- **Benchmark:** วัดความเร็ว Cache Hit บนเครื่อง Local ได้ **14ms** และบน Production VPS (`185.250.38.247`) ได้ **38ms** (จากเดิมที่ต้องต่อ Yahoo Finance เสียเวลา 2-3 วินาที)

#### โค้ดฐานข้อมูล `server/db/init.js`:
```javascript
// Table: intraday_prices
db.exec(`
  CREATE TABLE IF NOT EXISTS intraday_prices (
    symbol TEXT NOT NULL,
    resolution TEXT NOT NULL,
    time TEXT NOT NULL,
    price REAL NOT NULL,
    open REAL NOT NULL,
    high REAL NOT NULL,
    low REAL NOT NULL,
    close REAL NOT NULL,
    volume REAL NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (symbol, resolution, time)
  );
  CREATE INDEX IF NOT EXISTS idx_intraday_sym_res_time ON intraday_prices(symbol, resolution, time);
`);
```

#### โค้ดตัวรวมแท่งเทียน `server/services/technicalAnalysis.js`:
```javascript
export async function sync4HCandles(symbol) {
  if (!symbol || symbol === 'CASH') return [];
  const upper = symbol.toUpperCase();

  // 1. Check existing 4H candles in SQLite
  const stats = db.prepare(
    'SELECT MAX(time) as max_time, MIN(time) as min_time, COUNT(*) as count FROM intraday_prices WHERE symbol = ? AND resolution = ?'
  ).get(upper, '4H');

  const maxTime = stats?.max_time;
  const count = stats?.count || 0;
  const now = Date.now();
  const maxDateTime = maxTime ? new Date(maxTime).getTime() : 0;
  const diffHours = (now - maxDateTime) / (1000 * 60 * 60);

  // If count >= 500 and data was fetched within 2 hours, return from DB immediately
  if (count >= 500 && diffHours < 2) {
    return db.prepare(
      'SELECT time, price, open, high, low, close, volume FROM intraday_prices WHERE symbol = ? AND resolution = ? ORDER BY time ASC'
    ).all(upper, '4H');
  }

  // 2. Fetch 1h candles from Yahoo Finance (720 days lookback)
  try {
    const p1 = new Date(now - 720 * 24 * 60 * 60 * 1000);
    const res = await yahooFinance.chart(upper, { interval: '1h', period1: p1 });

    if (res && res.quotes && res.quotes.length > 0) {
      const map4h = new Map();
      for (const q of res.quotes) {
        if (q.close === null || q.close === undefined || isNaN(q.close)) continue;
        const d = new Date(q.date);
        const blockHour = Math.floor(d.getUTCHours() / 4) * 4;
        d.setUTCHours(blockHour, 0, 0, 0);
        const key = d.toISOString();

        const close = Number(q.close);
        const open = q.open !== null && q.open !== undefined ? Number(q.open) : close;
        const high = q.high !== null && q.high !== undefined ? Number(q.high) : Math.max(open, close);
        const low = q.low !== null && q.low !== undefined ? Number(q.low) : Math.min(open, close);
        const volume = q.volume !== null && q.volume !== undefined ? Number(q.volume) : 0;

        if (!map4h.has(key)) {
          map4h.set(key, {
            symbol: upper,
            resolution: '4H',
            time: key,
            price: close,
            open,
            high,
            low,
            close,
            volume
          });
        } else {
          const bar = map4h.get(key);
          bar.high = Math.max(bar.high, high);
          bar.low = Math.min(bar.low, low);
          bar.close = close;
          bar.price = close;
          bar.volume += volume;
        }
      }

      const bars = Array.from(map4h.values()).sort((a, b) => a.time.localeCompare(b.time));

      if (bars.length > 0) {
        const insert = db.prepare(`
          INSERT OR REPLACE INTO intraday_prices (symbol, resolution, time, price, open, high, low, close, volume)
          VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
        `);
        const insertTx = db.transaction((items) => {
          for (const item of items) {
            insert.run(
              item.symbol,
              item.resolution,
              item.time,
              item.price,
              item.open,
              item.high,
              item.low,
              item.close,
              item.volume
            );
          }
        });
        insertTx(bars);
      }
    }
  } catch (err) {
    console.warn(`[sync4HCandles] Error fetching 1h data for ${upper}:`, err.message);
  }

  return db.prepare(
    'SELECT time, price, open, high, low, close, volume FROM intraday_prices WHERE symbol = ? AND resolution = ? ORDER BY time ASC'
  ).all(upper, '4H');
}
```

### 4. Lightweight Charts v5 Intraday Time Standard & Crosshair Support
Lightweight Charts v5 มีข้อกำหนดเรื่องชนิดข้อมูลเวลาที่เข้มงวดมาก:
- **โหมด Daily / Weekly:** รับ Date String เช่น `"2026-09-10"`
- **โหมด Intraday (4H):** **ห้ามส่ง Date String เด็ดขาด** เพราะ TradingView Canvas จะพังทันที ต้องส่งเป็น **Unix Timestamp ในหน่วยวินาที (`number as UTCTimestamp`)**
- ใน `src/components/project2x/LWChart.tsx` ได้เพิ่มฟังก์ชันแปลงเวลา:
```typescript
const formatBarTime = (t: string): Time => {
  if (t.includes('T') || t.includes(':')) {
    const sec = Math.floor(new Date(t).getTime() / 1000);
    return sec as UTCTimestamp;
  }
  return t.slice(0, 10);
};
```
- **Crosshair Hover Map (`rawBarsByDate`):** ทำการ Map ทั้ง Key แบบ ISO String และแบบ Numeric Seconds เพื่อให้เวลาที่ Hover เมาส์บนแท่งเทียน 4H สามารถค้นหาค่า OHLCV และคำนวณราคาได้แบบ $O(1)$ ไม่กระตุก

const fs = require('fs');
const path = require('path');

const indexHtmlPath = path.resolve(__dirname, '../../index.html');
if (fs.existsSync(indexHtmlPath)) {
  let content = fs.readFileSync(indexHtmlPath, 'utf8');
  const now = new Date();
  const timestamp = now.toISOString().replace(/[-:T.]/g, '').slice(0, 14);
  const updated = content.replace(/\?v=[^"']+/g, `?v=${timestamp}`);
