# 🚀 V2.21.0: X-Chart Anchored VWAP Custom Marker, In-Canvas Legend Dark Pills, and VPVR Config Integration

> **Mission**: ปรับแต่งและยกระดับ Institutional Charting Terminal สู่ความสมบูรณ์แบบสูงสุด: ปรับแต่งสัญลักษณ์จุด Anchor ของ Anchored VWAP ได้อิสระ (7 รูปแบบ, จานสี Hex, สเกล 5 ขนาด, ระยะห่างแนวดิ่ง Dynamic Safe Offset, และสวิตช์เปิด/ปิดป้ายข้อความ), แก้ไขเลเยอร์และพื้นหลัง Legend In-Canvas ด้วยเทคนิค Per-Row Sleek Dark Pills บล็อกเส้นกราฟไม่ให้แทงทะลุตัวหนังสือ, ขจัด Dummy Badges หลอกตา, แก้บัคสลับหุ้นแล้วกราฟค้าง 1 แท่ง, และรวมแผงตั้งค่า Volume Profile (VPVR) เข้าสู่ระบบอย่างสมบูรณ์แบบ

---

## 🧠 Context & Implementation (Compiled Truth)

### 1. Architectural Motivation & User Problem Statements
ในเซสชันนี้ ผู้ใช้ได้ระบุปัญหาและฟีดแบ็กจริงจากการใช้งาน X-Chart อย่างต่อเนื่อง:
1. **ภาพที่ 1 (Legend In-Canvas)**: ตอนกดปิดตา (Soft-Hide) มองแทบไม่เห็นเพราะสีจม และมีพื้นหลังสี่เหลี่ยมดำก้อนใหญ่บดบังชาร์ต ต้องการให้เป็นโปร่งใส แต่คงสีสันเดิมของตัวหนังสือไว้ที่ Opacity 75%
2. **ภาพที่ 2 (Symbol Switch Viewport Out-of-Sync)**: เมื่อกดเปลี่ยนหุ้นใน Watchlist กราฟไม่ขยายตัว เกิดอาการแท่งเทียนหดเหลือ 1 แท่งทางขวาสุด ต้องกดสลับ Timeframe ไป-มา ถึงจะรีเซ็ตกราฟกลับมาได้
3. **ภาพที่ 3 (Bogus Badges)**: มีป้ายกรอบแดงคำว่า "Setup" และปุ่ม "⚡ BUY ZONE" ลอยเด่นอยู่ ทั้งที่ไม่ได้มีความสำคัญหรือเป็นสัญญาณจริง สร้างความสับสน
4. **Volume Profile Config Routing**: กดรูปเฟืองของ Volume Profile ใน Legend In-Canvas แล้วเด้งไปหน้า Indicator Manager รวม แทนที่จะเปิดหน้าตั้งค่าของ Volume Profile โดยตรง
5. **Legend Z-Index Stacking**: เส้น Price Lines และเส้นประบน Canvas รวมถึงเครื่องมือวัด Ruler ทับตัวหนังสือใน Legend
6. **Anchored VWAP Custom Marker**: ต้องการปรับแต่งจุด Anchor บนกราฟได้ละเอียด: เลือกรูปทรงสัญลักษณ์ (Sign/Shape), สี (Color Picker), ขนาด (Size Scale), ระยะห่างจากแท่งเทียน (Vertical Padding Value), และสลับเปิด/ปิดตัวหนังสือ `"ANCHOR"` (Show Text Toggle)

### 2. Core Code Implementations

#### A. Anchored VWAP Marker Customization Engine (`src/components/project2x/hooks/useChartIndicators.ts`)
คำนวณและสร้างมาร์กเกอร์จุด Anchor แบบไดนามิก รองรับทั้ง Native Vectors (`arrowUp`, `arrowDown`, `circle`, `square`) และ High-Definition Text Glyphs (`star` ★, `diamond` ◆, `pin` 📍) พร้อมระบบ Dynamic Safe Vertical Offset ป้องกันมาร์กเกอร์ชนก้นแท่งเทียนหรือไส้เทียน:

```typescript
    if (indicatorConfig.anchoredVwap?.visible && anchoredVWAPResult?.anchorTime) {
      const avCfg = indicatorConfig.anchoredVwap;
      const aShape = avCfg.anchorShape ?? 'arrowUp';
      const aColor = avCfg.anchorColor ?? '#FFE600';
      const aSize = avCfg.anchorSize ?? 1.5;
      const aPadding = avCfg.anchorPadding ?? 0;
      const aShowText = avCfg.showAnchorText !== false;
      const aText = aShowText ? 'ANCHOR' : undefined;

      let resolvedShape: SeriesMarkerShape = 'arrowUp';
      let markerText = aText;
      let markerSize = aSize;

      if (aShape === 'arrowUp' || aShape === 'arrowDown' || aShape === 'circle' || aShape === 'square') {
        resolvedShape = aShape;
      } else {
        const glyphMap: Record<string, string> = {
          star: '★',
          diamond: '◆',
          pin: '📍',
        };
        const glyph = glyphMap[aShape] || '▲';
        resolvedShape = 'circle';
        markerText = aShowText ? `${glyph} ANCHOR` : glyph;
        markerSize = 0;
      }

      const t = formatBarTime(anchoredVWAPResult.anchorTime);

      if (aPadding > 0) {
        const anchorBar = aggregatedBars.find(b => formatBarTime(b.time) === t);
        const bLow = anchorBar && typeof anchorBar.low === 'number' && !isNaN(anchorBar.low)
          ? anchorBar.low
          : (anchoredVWAPResult.vwap[anchoredVWAPResult.anchorIndex] || 0);
        const bHigh = anchorBar && typeof anchorBar.high === 'number' && !isNaN(anchorBar.high)
          ? anchorBar.high
          : bLow;
        const candleSpread = Math.abs(bHigh - bLow);
        const localUnit = Math.max(candleSpread, (bLow || 1) * 0.015);
        const offset = localUnit * 0.6 + localUnit * (aPadding * 0.25);
        const safePrice = bLow - offset;

        list.push({
          time: t,
          position: 'atPriceBottom',
          price: safePrice,
          color: aColor,
          shape: resolvedShape,
          text: markerText,
          size: markerSize,
        });
      } else {
        list.push({
          time: t,
          position: 'belowBar',
          color: aColor,
          shape: resolvedShape,
          text: markerText,
          size: markerSize,
        });
      }
    }
```

### 5. Indicator Manager Dynamic Auto-Sorting Engine

#### [MODIFY] [IndicatorManagerPopover.tsx](file:///c:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/components/xchart/IndicatorManagerPopover.tsx)
- สร้างฟังก์ชันคำนวณการจัดเรียง `sortedIndicatorList`:
  ```typescript
  const sortedIndicators = useMemo(() => {
    return [...allIndicators].sort((a, b) => {
      // 1. Active items first
      if (a.isActive !== b.isActive) return a.isActive ? -1 : 1;
      // 2. Pane order: Pane 0 -> Pane 1 -> Pane 2
      if (a.paneIndex !== b.paneIndex) return a.paneIndex - b.paneIndex;
      // 3. Alphabetical order A-Z
      return a.title.localeCompare(b.title);
    });
  }, [indicatorConfig]);
  ```

## 1. การเปลี่ยนแปลงหลักที่ได้ทำไป

- **ปุ่ม [X] (Remove Button)**: เป็นการลบอินดิเคเตอร์ออกจาก Legend อย่างแท้จริง (Persist state ใน localStorage)
