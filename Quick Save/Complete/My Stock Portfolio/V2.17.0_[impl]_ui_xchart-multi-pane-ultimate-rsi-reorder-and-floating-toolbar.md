# X-Chart Dynamic Multi-Pane Engine, Ultimate RSI, Pane Reordering & On-Chart Floating Header Toolbar

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการตัดสินใจเชิงสถาปัตยกรรม (Architectural Decisions)
ผู้ใช้ต้องการยกระดับ **X-Chart Trading Terminal** ให้มีฟีเจอร์ระดับเดียวกับ TradingView Desktop/Web Pro ในการจัดการอินดิเคเตอร์แยกหน้าต่างย่อย (Multi-Pane System) โดยแบ่งการดำเนินงานเป็น 2 เฟสสำคัญ:
1. **Dynamic Multi-Pane Architecture & Ultimate RSI (Phase 1):**
   - รองรับ Sub-pane เพิ่มเติม (Pane 1 และ Pane 2) นอกเหนือจากชาร์ตหลัก (Pane 0)
   - นำเข้าสูตรและคำนวณ **My Ultimate RSI (DoctorBank)** ซึ่งเป็นสูตรดัดแปลงพิเศษ (Adaptive RSI, Volatility Bands, Signal Line) แปลงจาก Pine Script มาเป็น Pure TypeScript ทำงานแบบ Client-side 100%
   - ออกแบบระบบจัดสรรและสลับตำแหน่ง Pane (Pane Reordering System) ให้ผู้ใช้เลือก Dropdown หรือกดปุ่ม 🔼 / 🔽 สลับตำแหน่งระหว่าง MCDX และ Ultimate RSI ได้อย่างอิสระ พร้อมระบบ Auto-Swap อัตโนมัติ ป้องกันการชนกันของ Pane
2. **On-Chart Floating Header Toolbar & Maximize/Restore (Phase 2):**
   - สร้าง Floating Header Toolbar แบบ Glassmorphism ลอยอยู่บนมุมซ้ายบนของแต่ละ Sub-pane จริงบน Canvas ของ Lightweight Charts v5
   - **Live Crosshair Values:** แสดงตัวเลขสดตามตำแหน่งเมาส์ Crosshair ที่กำลังชี้ (Banker, Hot Money, Retail, Banker MA สำหรับ MCDX และ ARSI, Signal สำหรับ Ultimate RSI)
   - **Action Control Buttons:** 👁️ Toggle Visibility, ⚙️ Settings Deep-Link (เปิด Indicator Manager เจาะจงหน้าตั้งค่าตัวนั้นทันที), 🔼 / 🔽 Reorder บนผิวกราฟ, ⛶ Maximize/Restore (ขยาย Sub-pane เด่นเต็มกราฟ หรือคืนค่าขนาดเดิม), และ ✕ Close Pane
   - **Precision DOM Anchoring:** ใช้ `pane.getHTMLElement()` ร่วมกับ `getBoundingClientRect()` และ ResizeObserver เพื่อคำนวณตำแหน่งพิกเซล Y จริง ลอยแนบสนิทไปกับผิวกราฟอย่างไร้รอยต่อ

### 3. Dynamic Height Management & Maximize Mode
ใน `LWChart.tsx` สถาปัตยกรรมการจัดสรรความสูงของแต่ละ Pane ถูกยกระดับให้รองรับทั้งโหมดปกติและโหมด Maximize:
- **Normal Mode:**
  - เมื่อเปิดทั้ง 2 Sub-pane: Pane 0 (Main) ได้รับความสูงส่วนที่เหลือ (ประมาณ 60%), Pane 1 ได้รับ 135px, Pane 2 ได้รับ 135px
  - เมื่อเปิดเพียง 1 Sub-pane: Pane 0 ได้รับความสูงส่วนที่เหลือ (ประมาณ 75-80%), Sub-pane ได้รับ 140px
- **Maximize Mode (`maximizedPane !== null`):**
  - Sub-pane ที่ถูก Maximize จะขยายใหญ่เกือบเต็มพื้นที่ของคอนเทนเนอร์: `maximizedHeight = Math.max(160, containerH - 60)`
  - Pane 0 (Main Chart) ถูกบีบเหลือ 60px เพื่อให้คงเห็นเส้นราคาด้านบน
  - Sub-pane อื่นๆ ที่ไม่ได้ถูก Maximize จะถูกยุบความสูงเหลือ 0px ชั่วคราว
  - เมื่อกดปุ่ม Restore (หรือปิด Sub-pane นั้น) ความสูงของทุก Pane จะคืนสภาพกลับสู่สัดส่วนปกติทันที

### 4. Precision DOM Positioning ด้วย ResizeObserver
เนื่องจาก Lightweight Charts v5 เรนเดอร์ Canvas ภายใน DOM element ของแต่ละ Pane:
- ใช้ `chart.panes()` วนลูปดึง DOM element ด้วย `p.getHTMLElement()`
- หาค่าพิกเซลสัมพัทธ์เทียบกับ Chart Container:
  ```typescript
  const updatePaneOffsets = () => {
    if (!chartContainerRef.current || !chartRef.current) return;
    const containerRect = chartContainerRef.current.getBoundingClientRect();
    const panes = chartRef.current.panes();
    const offsets: Record<number, { top: number; height: number }> = {};
    panes.forEach((p: any, idx: number) => {
      try {
        const el = p.getHTMLElement?.();
        if (el) {
          const rect = el.getBoundingClientRect();
          offsets[idx] = {
            top: rect.top - containerRect.top,
            height: rect.height,
          };
        }
      } catch (e) {
        // ignore
      }
    });
    setPaneOffsets(offsets);
  };
  ```
- เชื่อมต่อ `ResizeObserver` เข้ากับ `chartContainerRef.current` ทำให้ Toolbar ลอยเกาะอยู่บนมุมซ้ายบนของ Sub-pane ตลอดเวลา แม้จะมีการ Resize หน้าต่างบราวเซอร์หรือปรับความสูงของหน้าต่าง

### 5. โค้ดคอมโพเนนต์หลักที่สร้างขึ้น (`SubPaneHeaderToolbar.tsx`)
```tsx
import React from 'react';
import { Eye, EyeOff, Settings, ChevronUp, ChevronDown, Maximize2, Minimize2, X } from 'lucide-react';

export interface SubPaneHeaderToolbarProps {
  title: string;
  paneId: number;
  topOffset: number;
  isMaximized: boolean;
  canMoveUp: boolean;
  canMoveDown: boolean;
  values?: Array<{
    label: string;
    value: string | number | null | undefined;
    color?: string;
  }>;
  onToggleVisibility: () => void;
  onOpenSettings: () => void;
  onMoveUp?: () => void;
  onMoveDown?: () => void;
  onToggleMaximize: () => void;
  onClose: () => void;
}

export const SubPaneHeaderToolbar: React.FC<SubPaneHeaderToolbarProps> = ({
  title,
  paneId,
  topOffset,
  isMaximized,
  canMoveUp,
  canMoveDown,
  values = [],
  onToggleVisibility,
  onOpenSettings,
  onMoveUp,
  onMoveDown,
  onToggleMaximize,
  onClose,
}) => {
  return (
    <div
      className="absolute left-2 z-20 flex items-center gap-2 px-2.5 py-1 rounded-md bg-slate-900/80 backdrop-blur-md border border-slate-700/60 shadow-lg text-[13px] text-slate-200 select-none pointer-events-auto transition-all duration-150"
      style={{ top: `${topOffset + 4}px` }}
    >
      {/* Title & Pane Badge */}
      <div className="flex items-center gap-1.5 font-semibold text-slate-100">
        <span>{title}</span>
        <span className="text-[12px] px-1.5 py-0.2 rounded bg-slate-800 border border-slate-700 text-slate-400 font-mono">
          P{paneId}
        </span>
      </div>

      {/* Live Crosshair Values */}
      {values.length > 0 && (
        <div className="flex items-center gap-2 pl-1 pr-1 border-l border-slate-700/60 font-mono text-[13px]">
          {values.map((v, idx) => (
            <div key={idx} className="flex items-center gap-1">
              <span className="text-slate-400">{v.label}:</span>
              <span style={{ color: v.color || '#F8FAFC' }} className="font-medium">
                {v.value !== null && v.value !== undefined ? v.value : '-'}
              </span>
            </div>
          ))}
        </div>
      )}

      {/* Action Buttons Group */}
      <div className="flex items-center gap-0.5 pl-1 border-l border-slate-700/60 text-slate-400">
        <button
          onClick={onToggleVisibility}
          title="Toggle Visibility"
          className="p-1 rounded hover:bg-slate-800 hover:text-slate-200 transition-colors"
        >
          <Eye className="w-3.5 h-3.5" />
        </button>
        <button
          onClick={onOpenSettings}
          title="Indicator Settings"
          className="p-1 rounded hover:bg-slate-800 hover:text-slate-200 transition-colors"
        >
          <Settings className="w-3.5 h-3.5" />
        </button>
        {canMoveUp && onMoveUp && (
          <button
            onClick={onMoveUp}
            title="Move Pane Up"
            className="p-1 rounded hover:bg-slate-800 hover:text-slate-200 transition-colors"
          >
            <ChevronUp className="w-3.5 h-3.5" />
          </button>
        )}
        {canMoveDown && onMoveDown && (
          <button
            onClick={onMoveDown}
            title="Move Pane Down"
            className="p-1 rounded hover:bg-slate-800 hover:text-slate-200 transition-colors"
          >
            <ChevronDown className="w-3.5 h-3.5" />
          </button>
        )}
        <button
          onClick={onToggleMaximize}
          title={isMaximized ? "Restore Pane Size" : "Maximize Pane"}
          className="p-1 rounded hover:bg-slate-800 hover:text-amber-400 transition-colors"
        >
          {isMaximized ? <Minimize2 className="w-3.5 h-3.5 text-amber-400" /> : <Maximize2 className="w-3.5 h-3.5" />}
        </button>
        <button
          onClick={onClose}
          title="Close Sub-pane"
          className="p-1 rounded hover:bg-rose-950/60 hover:text-rose-400 transition-colors"
        >
          <X className="w-3.5 h-3.5" />
        </button>
      </div>
    </div>
  );
};
```
