# V2.0.1 Hotfix: Smart Rebalance Crash (portfolioPercent vs weightPercent)

## 🎯 Context & Implementation (Compiled Truth)
The `SmartRebalancePage` in `V2.0.0` was crashing completely (Black Screen) on production. The root cause was a TypeScript/React TypeError inside `SmartRebalancePage.tsx`.

The file attempted to read `h.portfolioPercent`, expecting a number, and subsequently called `.toFixed(1)` on it:
```tsx
{h.symbol} (ถือ {h.quantity} หุ้น • {h.portfolioPercent.toFixed(1)}%)
```

However, `portfolioPercent` did not exist on the `Holding` interface exported by `useHoldings.ts`. The correct property calculated by `useHoldings` was `weightPercent`. Because `h.portfolioPercent` was `undefined`, calling `.toFixed(1)` immediately threw a `TypeError: Cannot read properties of undefined (reading 'toFixed')`, crashing the entire React component tree.

**Fix:**
Replaced all instances of `portfolioPercent` with `weightPercent` inside `SmartRebalancePage.tsx` and added safe navigation (`?.toFixed(1) ?? '0.0'`) as an extra precaution.
