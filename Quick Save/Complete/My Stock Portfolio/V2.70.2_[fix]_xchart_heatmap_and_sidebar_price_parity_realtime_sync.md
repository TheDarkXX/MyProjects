# V2.70.2: XChart Heatmap & Sidebar Price Parity Real-Time Sync

## 📌 Context & Implementation (Compiled Truth)
- **Problem Statement:**
  1. In XChart Heatmap, ticker tiles displayed fresh real-time Yahoo Finance data (e.g. ALAB: $312.91, -3.46%), while the Right Sidebar (MyPortWatchlist) showed stale numbers from October 5 (e.g. ALAB: $359.48, +2.61%).
  2. Root cause 1: `server/routes/prices.js` `/latest` route attempted to fetch missing/expired prices via Finnhub, which failed with 401 Unauthorized because `FINNHUB_API_KEY` was missing from `.env`. The database table `latest_prices` had not been updated since September 16.
  3. Root cause 2: Frontend `priceStore` loaded stale prices from `localStorage.getItem('stock_prices_cache_v1')` indefinitely with zero TTL expiration.
  4. Root cause 3: In `MyPortWatchlist.tsx`, row rendering and sorting prioritized `priceQuote = prices[sym]` over `wlQuote = watchlistPrices[sym]`. Because `priceQuote` had stale data, the live 30s Yahoo polling results from `wlQuote` were completely ignored.
- **Core Architecture & Solutions:**
  - **Backend Single Source of Truth:** Upgraded `/api/prices/latest` in `server/routes/prices.js` to batch-fetch quotes via `yahooFinance.quote()`, upserting fresh `price`, `change`, and `percent_change` into SQLite `latest_prices` table with `datetime('now')`. Added `forceRefresh` support.
  - **Frontend Cache Protection (TTL 10m):** Upgraded `priceStore.ts` to `stock_prices_cache_v2` with `stock_prices_cache_time_v2`. Automatically purged stale `stock_prices_cache_v1` and added 10-minute expiry to ensure stale quotes are discarded.
  - **Live Priority in Sidebar:** Updated `MyPortWatchlist.tsx` across Holdings, Target Stocks, Macro Benchmarks, and sorting comparators to prioritize `wlQuote` (live 30s polling) over `priceQuote`.
  - **Comprehensive Target Polling:** Updated `fetchWatchlistQuotes` in `xchartStore.ts` to include all Project2X Target Stock symbols (`ALAB`, `TSM`, `NVDA`, `ANET`, etc.) so all sidebar items are refreshed every 30s.
- **Verification & Deployment:**
  - `npm run build` executed with 0 errors.
  - `bump-cache.js` updated cache timestamp to `v=20261013_221342`.
  - Transferred `dist/*` and `server/routes/prices.js` to Production VPS (`185.250.38.247:/root/stock-portfolio/`).
  - Executed PM2 reload `pm2 reload stock-api` on VPS with zero downtime.
