# V2.25.0 [impl] UI: X-Chart Watchlist Target Section (Project 2X Quotas) & Universal Collapse/Expand All with Cloud Sync

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการปรับปรุงเชิงยุทธศาสตร์
- **โจทย์ที่ 1 (Project 2X Target Section ใน My Port Watchlist):**
  - ในหน้าต่าง Watchlist ฝั่งขวาของ X-Chart เดิมแท็บ `My Port` แสดงเฉพาะหุ้นที่ผู้ใช้ถืออยู่จริง (Holdings) ทำให้เวลาดูกราฟเทคนิคอล ไม่สามารถเปรียบเทียบกับ "พิมพ์เขียวหุ้นเป้าหมาย (Strategic Quota Targets)" ตามสูตร Project 2X ได้ทันที
  - เพิ่ม Section **`Target · Project 2X`** แยกเป็นสัดส่วนชัดเจนต่อจาก `Holdings`:
    - แสดง 13 หุ้นยุทธศาสตร์ แบ่งเป็น **9 Core Commanders (83%)** และ **4 Moonshot Strikes (11%)**
    - แสดงป้ายเปอร์เซ็นต์โควตาเป้าหมาย (เช่น `15%`, `10%`, `3%`)
    - แสดงจุดเขียว `Ownership Indicator` หากมีหุ้นตัวนั้นอยู่ในพอร์ตแล้ว เพื่อให้แยกแยะหุ้นที่ถือครอง vs หุ้นที่ยังต้องรอจังหวะเข้าซื้อ
    - แสดงราคาตลาดสด (Last Price), การเปลี่ยนแปลง ($ Chg), และเปอร์เซ็นต์ (% Chg) พร้อมสีเขียว/แดงตามตลาด
    - คลิกที่แถวหุ้นเพื่อสลับกราฟหลัก X-Chart ไปที่ตัวนั้นทันที (`onSelectSymbol`)
    - มีปุ่ม (ℹ️) เปิดดู Target Detail Modal: แสดงหมวดหมู่, โควตาสัดส่วน %, จำนวนหุ้นเป้าหมาย, และสถานะการสะสม
    - รองรับการทำงานแบบ Dynamic ทั้งพอร์ต **Doctorbank Growth** และ **Tiger Portfolio** ดึง Quotas ตาม Active Portfolio Id จาก SQLite `project2x_share_quotas` โดยอัตโนมัติ

- **โจทย์ที่ 2 & 3 (ปุ่มพับ/กางทั้งหมด & LocalStorage + Auto Cloud Sync):**
  - **ปัญหา:** เมื่อมี Watchlist หลายหมวดหมู่ หน้าจอจะยาวเป็นหางว่าว ต้องคอยเลื่อนหาตาลาย
  - **การแก้ปัญหาอย่างตรงจุด:**
    - **ปุ่ม "พับ/กางทั้งหมด (Collapse / Expand All)":** วางข้างปุ่มสร้างโฟลเดอร์ (`FolderPlus`) บนหัว Watchlist Dock
    - **พับทุกลิสต์เหลือแค่ชื่อหัวข้อ (28px bar):** คลิกเดียวพับทุก Section ทันที ไอคอนเปลี่ยนเป็น `ChevronsDownUp` ทำให้หน้าจอกระชับ คลีนตา ไม่รก
    - **อิสระในการกางเฉพาะหมวด:** ผู้ใช้สามารถคลิกหัวข้อเฉพาะหมวดที่ต้องการดู เพื่อกางหมวดนั้นออกมาตัวเดียวได้ทันที
    - **กางคืนทั้งหมด:** กดปุ่มเดิมอีกครั้ง (ไอคอนสว่างม่วง `ChevronsUpDown`) ทุกหมวดจะกางออกพร้อมกันทันที
    - **LocalStorage Persistence + Auto Cloud Sync:** บันทึกสถานะ `isCollapsed` ของทุกหมวดลงใน `localStorage` (`stock_xchart_watchlist_v3`) แบบ Real-time และส่งขึ้น VPS อัตโนมัติผ่าน `pushSettingDebounced` ค่าคงอยู่ข้ามการ Refresh และข้ามอุปกรณ์ 100%
    - **กฎเหล็กเรื่อง Stock List:** ไม่มีแตะต้อง ย้าย หรือตัดต่อหุ้นใน Watchlist ของผู้ใช้แม้แต่ตัวเดียวตามคำสั่งเด็ดขาด

### 3. ตรรกะการพับ/กางทั้งหมด & Persistence (`xchartStore.ts`)
```typescript
toggleAllSectionsCollapse: () => {
  const { watchlistSections } = get();
  if (watchlistSections.length === 0) return;
  // If at least one section is open, collapse all. If all are collapsed, expand all.
  const hasOpen = watchlistSections.some((sec) => !sec.isCollapsed);
  const nextSections = watchlistSections.map((sec) => ({
    ...sec,
    isCollapsed: hasOpen
  }));
  set({ watchlistSections: nextSections });
  persistSections(nextSections);
}
```
