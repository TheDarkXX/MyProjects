## 🚀 Key Implementations

### 1. Watchlist Context Menu Clean English Refinement (`XChartWatchlistDock.tsx`)
- Converted all right-click section context menu items to clean, modern TradingView-style English:
  - Header: `SECTION: {sectionName}`
  - `Rename Section` (with `Edit2` icon)
  - `Add Symbol` (with `Plus` icon)
  - Dynamic `Collapse Section` / `Expand Section` (with `ChevronDown` icon)
  - `Delete Section` (with `Trash2` warning icon)
- Replaced Thai `window.confirm` dialogs with clean English prompts (`Remove all X symbols in "..." from watchlist?`, `Delete section "..." and its symbols?`).

### 2. My Port 7-Tier Matrix Sorting Integration (`MyPortWatchlist.tsx` & `xchartStore.ts`)
- Added `'tier'` to `MyPortSortColumn` in `xchartStore.ts`.
- Configured `setMyPortSort` to default to `asc` when `'tier'` is selected, and seamlessly toggle between `asc` and `desc`.
- Split the first column header into `Tier / Symbol`:
  - `Tier`: Interactive button sorting by the 7-Tier Action Matrix (`BUY_NOW` -> `GET_READY` -> `SLOW_BLEED` -> `FALLING_KNIFE` -> `MAYDAY_EXIT` -> `RUNNER` -> `TO_THE_MOON`).
  - `Symbol`: Interactive button sorting tickers alphabetically (A-Z / Z-A).
- Updated both `sortedHoldings` and `sortedTargetStocks` to sort based on `TIER_SORT_ASC_RANKS` from `radarMap` / `compactTiers`.

### 3. My Port Cyber Context Menu (`MyPortWatchlist.tsx`)
- Added right-click context menu to `Holdings` and `Target · Project 2X` section headers.
- Context menu options:
  - `SECTION: HOLDINGS` / `SECTION: TARGET · PROJECT 2X`
  - `Collapse Section` / `Expand Section`
  - `Sort by 7-Tier Matrix` (triggers 7-tier sort directly)
  - `Sort by Day Change %` (triggers worst/best day change sort)
  - `Refresh Quotes` (eagerly fetches price store and batch watchlist quotes)
- Outside click & ESC key listener for frictionless dismissal.
