## 🚀 Summary of Changes & Shipped Features

### 1. Phase 1: High-Impact UX & Performance Engine
- **StockDetailDrawer (`src/components/portfolio/StockDetailDrawer.tsx`)**:
  - Slide-over drawer when clicking any stock in PortfolioTable.
  - Displays live quote, daily change, total return, lifecycle stage badge.
  - Interactive price area chart with dynamic Y-axis scaling (1M, 3M, 1Y, ALL).
  - Chronological transaction lots table showing Buy/Sell history for that specific stock.
- **MonthlyReturnHeatmap (`src/components/charts/MonthlyReturnHeatmap.tsx`)**:
  - 12-month calendar performance matrix (Jan–Dec + YTD).
  - Uses institutional compounding factor `(1 + r/100)` to accurately calculate monthly returns without zero-division issues.
- **Vite Code Splitting (`vite.config.ts`, `src/App.tsx`)**:
  - Configured `manualChunks` to split heavy libraries (`vendor-charts`, `vendor-d3`, `vendor-export`).
  - Implemented `React.lazy` and `<Suspense>` for all major route pages.
  - Reduced main bundle from **1.37 MB down to 263 kB** (>80% speedup).

### 2. Phase 2: Performance Expansion & Simplified Cashflow
- **CapitalGrowthChart (`src/components/charts/CapitalGrowthChart.tsx`)**:
  - Net Invested Capital vs Total Portfolio Value over time.
  - Tracks organic wealth spread created by compounding returns.
  - Range toggles: 1M, 3M, 6M, 1Y, ALL.
- **UpcomingDividendStrip (`src/components/scorecard/UpcomingDividendStrip.tsx`)**:
  - Compact horizontal forecast strip in Scorecard for upcoming held dividend payers (next 60–90 days).
  - Dynamic date logic automatically advances to the next quarter when the current month's ex-dividend date has passed.
- **Stock vs FX Gain/Loss Breakdown (`src/components/dashboard/PortfolioTable.tsx`)**:
  - Inline subtitle breakdown under Total P/L in THB view (`Stock: +X.X% • FX: +X.X%`).

### 3. Phase 3: Risk & Volatility Center
- **RiskPage (`src/components/risk/RiskPage.tsx`)**:
  - Dedicated `/risk` page accessible from Sidebar navigation.
  - Top hero gauges: Single-Stock Max Risk (Top 1 > 35% warning), Alpha Sweet Spot (Top 3 Weight 45-65%), Cash Buffer, and Top 5 Core Bedrock.
  - Institutional Risk Rulebook & Philosophy.
- **UnderwaterDrawdownChart (`src/components/charts/UnderwaterDrawdownChart.tsx`)**:
  - Running peak-to-trough drawdown percentage below 0% from All-Time High.
  - Tracks Max Drawdown %, Current Drawdown %, and Longest Days Underwater.
- **RiskMetricsCard (`src/components/risk/RiskMetricsCard.tsx`)**:
  - Calculates institutional GIPS metrics: Beta vs S&P 500 (SPY), Sharpe Ratio, Sortino Ratio, Annualized Volatility, and Win Rate %.
  - Complete plain-Thai investor-oriented explanations for every metric.

### 4. Phase 4: Smart Cashflow Rebalancer
- **SmartRebalancePage (`src/components/rebalance/SmartRebalancePage.tsx`)**:
  - Dedicated `/rebalance` page accessible from Sidebar navigation.
  - **Mode 1 (Cash-Flow DCA Rebalancing)**:
    - Input new cash deposit amount (USD / THB).
    - Presets: Shay Boloor Alpha (Top 3 = 55-60%), Lifecycle Balanced, Equal Weight.
    - Generates actionable buying order cards (BUY +X shares, $ cost, pre/post weight preview).
    - 1-Click Copy Buying Plan.
  - **Mode 2 (Target vs Actual Allocation Matrix)**:
    - Interactive target weight inputs and Gap Analysis (Underweight vs Overweight delta bars).
  - **Mode 3 (Smart Trim Simulator)**:
    - Emergency rebalancer slider to simulate trimming overweight winners to fund small caps.
