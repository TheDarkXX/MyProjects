# V2.27.0: Native Mobile Chart Minimal Architecture, Robinhood UX, and Viewport Hardening

## 🧠 Context & Implementation (Compiled Truth)

### 1. Root Cause Analysis (ทำไมรอบก่อนถึงเละ)
หลังจากผู้ใช้ทดสอบหน้างานจริงบนสมาร์ทโฟน **vivo X80 Pro** พบปัญหาสำคัญ 3 ประการ:
1. **Net Worth Portfolio Graph ไม่ขึ้น (กลายเป็นเส้นตรง / ค่าว่าง):** เกิดจากโค้ดคำนวณ `allDailyPoints` ใน `MobileDashboard.tsx` และ `TabletDashboard.tsx` เรียกใช้ฟิลด์ผิด `tx.quantity` แทนที่จะเป็น `tx.amount` และเช็ค Transaction type ผิด (`WITHDRAWAL` แทน `WITHDRAW`) ทำให้การคำนวณมูลค่าพอร์ตล้มเหลวกลายเป็น `NaN`
2. **จำนวนหุ้นใน Purchase History แสดงทศนิยมไม่เหมาะสม:** แสดงทศนิยมดิบยาวเกินความจำเป็น ผู้ใช้ต้องการให้แสดงสูงสุด 4 หลัก (`maximumFractionDigits: 4`)
3. **หน้า Charts เละเทะทับซ้อน 8 ชั้น:** ใน V2.26.0 แม้จะมีการแยกหน้า Dashboard สำหรับ Mobile/Tablet แต่ในหน้า Charts (`activeTab === 'xchart'`) ทั้งหมดยังคงวิ่งเข้าสู่ `<XChartPage />` ตัวเดียวกับ Desktop ซึ่งดึงเอา Desktop Terminal Cockpit ขนาด 1,706 บรรทัด (`LWChart.tsx`), Control Bar 4 แถว, In-Canvas Legend Overlay, Drawing Toolbar 40px, Sub-pane Toolbar ลอยตัวทุกตัว มายัดลงบนหน้าจอขนาด 390px โดยไม่มี Mobile Guard แม้แต่ตัวเดียว ทำให้กินพื้นที่ไปกว่า 54% ของจอ และบดบังแท่งเทียนจนแทบมองไม่เห็น

---

### 2. Architectural Decision: The Hybrid Architecture (ฟันธงระดับสถาปัตยกรรม)
การแก้ปัญหาครั้งนี้เลือกใช้แนวทาง **Hybrid Architecture** โดยแบ่งแยกความรับผิดชอบอย่างชัดเจน:
- **Reuse Engine & Data Layer:**
  - นำ `LWChart.tsx` (Lightweight Charts Engine) และ `XChartPanel.tsx` (Data fetching, IDB Caching, Portfolio Overlay) กลับมาใช้ซ้ำเพื่อไม่ให้เกิด Code Duplication ของแกนการคำนวณกราฟ
- **Build New Native Mobile Shell & Guards:**
  - สร้าง `views/mobile/MobileChartPage.tsx` เป็น Shell แยกเด็ดขาดสำหรับ Mobile 100% ปราศจาก Desktop `XChartTabBar` และ Sidebar Dock
  - ติดตั้ง `!isMobile` Guards ครอบ In-Canvas Overlays ทั้งหมด 11 ตัวใน `LWChart.tsx`
  - ออกแบบ `ChartControlBar.tsx` ใหม่สำหรับ Mobile ให้เหลือเพียง 1 แถวเดียวแบบ Minimal (~44px) สไตล์ Robinhood

### 3. Core Features & Specifications Implemented

#### A. Dedicated Mobile Shell (`MobileChartPage.tsx`)
- ตัด `XChartTabBar` ทิ้งบน Mobile ประหยัดพื้นที่แนวตั้ง 48px
- ฝัง `XChartWatchlistDock` แบบ Slide-over Drawer โดยเมื่อเปิด (`!watchlistCollapsed`) จะสไลด์ออกมาจากขอบขวาพร้อม Backdrop มืดด้านหลัง และเมื่อปิดจะซ่อนหายไปสนิท ไม่กินความกว้างหน้าจอ

#### B. Robinhood-Inspired Single-Row Control Bar (`ChartControlBar.tsx`)
- ยุบคอนโทรลทั้งหมดให้เหลือ 1 แถวความสูง 44px:
  `[SCHD ▼  $34.18  -0.23%]  ────────  [1D | 1W]  [⚙️ 4]  [⛶]`
- **Interactive Ticker Picker:** แตะที่ปุ่ม `[SCHD ▼]` เพื่อเรียกเปิด Watchlist Drawer สไลด์ออกมาเลือกหุ้นจาก Watchlist หรือ My Port ได้ทันที
- ซ่อนปุ่มที่ไม่จำเป็นบนมือถือ: Candle Style switcher, Live badge, Timeframe presets (10M/1Y/5Y/ALL), Canvas Undo/Redo/History, Reset Zoom, Position Overlay toggle, Allocate Inflow
- เก็บเฉพาะสิ่งที่จำเป็น: Symbol Picker, Current Price, %Change, Resolution switch `[1D | 1W | 4H]`, Indicator Manager icon button, Fullscreen toggle button

#### C. In-Canvas Overlays Guarding (`LWChart.tsx`)
ซ่อน Overlay 11 จุดเมื่ออยู่ในโหมด `isMobile`:
1. `ChartLegendBar` (แถบ OHLCV)
2. `LeftDrawingToolbar` (แถบเครื่องมือวาดรูปด้านซ้าย 40px)
3. `MainPaneIndicatorLegend` (กล่องลอย EMA Ribbon, Super Money Signal, VWAP)
4. `DrawingAlertBanner`
5. `DrawingInCanvasBadges`
6. `AnchoredVWAPHandle`
7. MCDX `SubPaneHeaderToolbar`
8. Ultimate RSI `SubPaneHeaderToolbar`
9. Trend Speed Analyzer `SubPaneHeaderToolbar`
10. `DominanceTableOverlay`
11. `ChartPositionHUD`

#### D. Sub-Pane Layout & Bottom-Sheet Modal
- ใน `chartLayoutUtils.ts` ปรับความสูง default ของ Sub-pane (MCDX, RSI) จาก 140px เหลือ **85px** เมื่อ `isMobile` ป้องกันการแย่งพื้นที่แท่งเทียน
- ใน `IndicatorManagerPopover.tsx` ปรับสไตล์ให้เป็น **Bottom-Sheet Modal** บนมือถือ (`rounded-t-2xl`, `h-[92vh]`, slide-in from bottom) ไม่ล้นขอบจอ

#### E. Viewport & Navigation Bar Clearance (`App.tsx`)
- ซ่อน `MobileHeader` เมื่ออยู่หน้า `activeTab === 'xchart' && isMobile` คืนพื้นที่ 55px
- เพิ่ม `pb-14 sm:pb-16` บน `<main>` เมื่อเปิดหน้า `xchart` บน Compact device เพื่อเว้นระยะให้ `MobileNavBar` ที่ติดอยู่ขอบล่าง ทำให้แกนวันที่ (Time Axis) และแท่งเทียนด้านล่างไม่ถูกบดบัง
- ขยาย Container ภายในเป็น `h-full flex flex-col min-h-0` กราฟจึงขยายเต็มพื้นที่จอแนวตั้งแบบ Edge-to-Edge พอดี 100%

#### F. Equity Curve & Share Precision Fixes
- ใน `MobileDashboard.tsx` และ `TabletDashboard.tsx` แก้ไขสูตรคำนวณ `allDailyPoints` ให้ใช้ `Number(tx.amount || 0)`, รองรับ `tx.asset === 'Cash' || tx.symbol === 'CASH'`, และรองรับทั้ง `WITHDRAW` และ `WITHDRAWAL`
- ใน `StockDetailDrawer.tsx` และ `DetailInspector.tsx` จัดการฟอร์แมตตัวเลขจำนวนหุ้นให้แสดงผลทศนิยมสูงสุด 4 ตำแหน่ง (`toLocaleString('en-US', { maximumFractionDigits: 4 })`)
- ใน `uiStore.ts` ตั้งค่า Default tab เริ่มต้นเมื่อเปิดเว็บครั้งแรกบน Mobile ให้เป็น `dashboard` (Portfolio)

```markdown
# Mobile Chart Minimal Architecture — ฉบับมหาเทพ 👁️‍🗨️ (v2)

## สาเหตุที่รอบก่อนเละ (Root Cause — ลึกกว่าที่มึงคิด)

### ทำไม "สัญญาว่าจะทำ Robinhood" แต่ได้ "Desktop ยัดลงมือถือ"

ปัญหาไม่ใช่แค่ "ลืมซ่อน Component" — มันคือ **สถาปัตยกรรมผิดตั้งแต่ต้น**

ดูหน้า Dashboard ที่ทำถูก (App.tsx L147-150):
isMobile  ? <MobileDashboard />    // views/mobile/ — โค้ดแยก 100%
isTablet  ? <TabletDashboard />    // views/tablet/ — โค้ดแยก 100%
           : <Dashboard />        // Desktop — โค้ดเดิม

ดูหน้า Chart ที่พัง (App.tsx L159):
activeTab === 'xchart' && <XChartPage />  // ← ทุก Device ใช้ตัวเดียวกัน!

ไม่มี MobileChartPage ไม่มี TabletChartPage ทุก device ตกไปที่ Desktop Pipeline เดียวกัน → Desktop Terminal 1,706 บรรทัดยัดลงจอ 390px

## คำตอบฟันธง: Build จากเดิม vs สร้างใหม่
คำตอบ: Hybrid — แยก Shell ใหม่ แต่ reuse Engine เดิม

สิ่งที่ต้อง REUSE (ห้ามสร้างใหม่):
- LWChart.tsx (Engine หลัก): wrapper lightweight-charts library จัดการ Candlestick, Sub-pane, Indicator ทั้งหมด
- XChartPanel.tsx (Data Layer): fetch candle data, holding, portfolio overlay, IndexedDB cache
- xchartStore.ts (State): tabs, activeTab, resolution

สิ่งที่ต้อง BUILD ใหม่:
- MobileChartPage.tsx [NEW]: Shell ใหม่ที่ห่อ XChartPanel — ไม่มี TabBar, ไม่มี WatchlistDock sidebar
- Mobile guards ใน LWChart.tsx: เพิ่ม isMobile prop เข้า LWChart เพื่อซ่อน overlay ต่างๆ ภายใน
- Mobile mode ใน ChartControlBar.tsx: ยุบเป็น 1 แถว: [Symbol $Price] ── [1D|1W] [⚙️] [⛶]
- IndicatorManager → Full-screen Modal: เปิดเป็น Bottom-up Modal บน Mobile
```
