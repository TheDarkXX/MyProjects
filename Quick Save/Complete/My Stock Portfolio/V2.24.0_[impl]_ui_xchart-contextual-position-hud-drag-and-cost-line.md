# V2.24.0 [impl] UI: X-Chart Contextual Position HUD, Bloomberg Nano-Strip, HTML5 Pointer Drag & Cost Line

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และภาพรวมเชิงยุทธศาสตร์ (Strategic Purpose)
ยกระดับหน้ากราฟ **X-Chart Candlestick (TradingView Lightweight Charts)** ให้กลายเป็น **Professional Trading Station** แบบสมบูรณ์แบบ:
- **Contextual Detection:** ตรวจจับหุ้นในพอร์ตอัตโนมัติ หากหุ้นตัวที่กำลังดูกราฟมีอยู่ในพอร์ต จะขีดเส้นต้นทุนเฉลี่ย (Cost Basis Price Line) + ปักหมุดลูกศรประวัติการเข้าซื้อ (BUY Markers) + แสดงแถบลอย **Position HUD** อัตโนมัติ หากเป็นหุ้นที่ไม่ได้ถืออยู่ หน้ากราฟจะคงความสะอาดตา 100%
- **Bloomberg Nano-HUD Strip (~30% Footprint):** จากเดิมที่เป็นกล่องยักษ์ (320x240px) กินพื้นที่บังแท่งเทียน ถูกผ่าตัดลดขนาดลง 85% เหลือเพียงแถบมินิมอลแนวนอนทรงบางเฉียบ (~250px x 44px ~11,000 px²) กระจกแก้วโปร่งแสง (`bg-slate-950/75 backdrop-blur-md`) มองทะลุเห็นแท่งเทียนด้านหลังได้
- **Top-Center Airspace Placement:** วางตำแหน่งเริ่มต้น (Default & Recycle Snap) ไว้ที่ **กึ่งกลางด้านบน (Top-Center: `top: 10px; left: 50%; transform: translateX(-50%)`)** ซึ่งเป็นน่านฟ้าที่โล่งและว่างที่สุดของหน้ากราฟ หลีกเลี่ยง Legend / OHLCV ด้านซ้าย และหลีกเลี่ยง Price Scale / แท่งเทียนราคาปัจจุบันด้านขวา
- **HTML5 Pointer Capture Drag & Drop:** ระบบคลิกลากย้ายตำแหน่งอิสระระดับ 60-120fps ลื่นไหลติดมือ ไม่หลุดขอบ ไม่ตกจอ รองรับ Mouse, Touchscreen (iPad/Tablet), และ Stylus Pen พร้อมระบบปักหมุดล็อค (`📌`) และปุ่มรีไซเคิล (`♻️`)
- **Compact Price Line Label (`NVDA (+10.6%)`):** ป้ายราคาบนเส้นต้นทุนเฉลี่ยเดิมที่ยาวเกินไป (`Avg Cost: $31.78 (+10.63%)`) ถูกย่อให้สั้นกระชับเหลือแค่ชื่อหุ้นและเปอร์เซ็นต์กำไร ประหยัดพื้นที่ในกราฟลงกว่า 65%
- **Universal Cloud Synchronization:** ซิงก์ตำแหน่งพิกัด X/Y, สไตล์เส้น (สี, ความหนา, รูปแบบเส้น), และสถานะ On/Off ขึ้น Cloud VPS Database อัตโนมัติผ่าน `pushSettingDebounced` ภายใน 800ms

### 4. สถาปัตยกรรม Pointer Capture Drag & Drop (`ChartPositionHUD.tsx`)
```typescript
// Clear manual inline styles when snapCorner or resetPosition is triggered (hudPosition is null)
useEffect(() => {
  if (!config.hudPosition && hudCardRef.current) {
    hudCardRef.current.style.left = '';
    hudCardRef.current.style.top = '';
    hudCardRef.current.style.right = '';
    hudCardRef.current.style.bottom = '';
    hudCardRef.current.style.transform = '';
  }
}, [config.hudPosition, config.snapCorner]);

// Handle Drag Pointer Down with setPointerCapture
const handlePointerDown = useCallback(
  (e: React.PointerEvent<HTMLDivElement>) => {
    if (config.isPinned) return;
    const target = e.target as HTMLElement;
    if (target.closest('button') || target.closest('input') || target.closest('a')) return;
    if (e.button !== 0) return;

    e.preventDefault();
    e.stopPropagation();

    const card = hudCardRef.current;
    const cont = containerRef.current;
    if (!card || !cont) return;

    try {
      card.setPointerCapture(e.pointerId);
    } catch (_) {}

    isDraggingRef.current = true;
    setIsDragging(true);
    dragStartPosRef.current = { x: e.clientX, y: e.clientY };

    const cardRect = card.getBoundingClientRect();
    const contRect = cont.getBoundingClientRect();

    const startX = cardRect.left - contRect.left;
    const startY = cardRect.top - contRect.top;
    hudStartPosRef.current = { x: startX, y: startY };

    card.style.left = `${startX}px`;
    card.style.top = `${startY}px`;
    card.style.right = 'auto';
    card.style.bottom = 'auto';
    card.style.transform = 'none';
  },
  [config.isPinned, containerRef]
);

// Pointer Move with Boundary Clamping
const handlePointerMove = useCallback(
  (e: React.PointerEvent<HTMLDivElement>) => {
    if (!isDraggingRef.current) return;
    const card = hudCardRef.current;
    const cont = containerRef.current;
    if (!card || !cont) return;

    const deltaX = e.clientX - dragStartPosRef.current.x;
    const deltaY = e.clientY - dragStartPosRef.current.y;

    const contRect = cont.getBoundingClientRect();
    const cardRect = card.getBoundingClientRect();

    const rawX = hudStartPosRef.current.x + deltaX;
    const rawY = hudStartPosRef.current.y + deltaY;

    const maxX = Math.max(0, contRect.width - cardRect.width);
    const maxY = Math.max(0, contRect.height - cardRect.height);

    const clampedX = Math.min(Math.max(6, rawX), maxX - 6);
    const clampedY = Math.min(Math.max(6, rawY), maxY - 6);

    card.style.left = `${clampedX}px`;
    card.style.top = `${clampedY}px`;
    card.style.right = 'auto';
    card.style.bottom = 'auto';
    card.style.transform = 'none';
  },
  [containerRef]
);

// Pointer Up: Release Capture & Persist to Store + Cloud
const handlePointerUp = useCallback(
  (e: React.PointerEvent<HTMLDivElement>) => {
    if (!isDraggingRef.current) return;
    isDraggingRef.current = false;
    setIsDragging(false);

    const card = hudCardRef.current;
    const cont = containerRef.current;
    if (card) {
      try {
        card.releasePointerCapture(e.pointerId);
      } catch (_) {}

      if (cont) {
        const contRect = cont.getBoundingClientRect();
        const cardRect = card.getBoundingClientRect();
        const finalX = Math.round(cardRect.left - contRect.left);
        const finalY = Math.round(cardRect.top - contRect.top);
        setHudPosition({ x: finalX, y: finalY }, 'custom');
      }
    }
  },
  [containerRef, setHudPosition]
);
```
