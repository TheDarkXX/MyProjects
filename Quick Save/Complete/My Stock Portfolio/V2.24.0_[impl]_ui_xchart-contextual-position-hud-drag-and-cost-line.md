### 1. วัตถุประสงค์และภาพรวมเชิงยุทธศาสตร์ (Strategic Purpose)
ยกระดับหน้ากราฟ **X-Chart Candlestick (TradingView Lightweight Charts)** ให้กลายเป็น **Professional Trading Station** แบบสมบูรณ์แบบ:
- **Contextual Detection:** ตรวจจับหุ้นในพอร์ตอัตโนมัติ หากหุ้นตัวที่กำลังดูกราฟมีอยู่ในพอร์ต จะขีดเส้นต้นทุนเฉลี่ย (Cost Basis Price Line) + ปักหมุดลูกศรประวัติการเข้าซื้อ (BUY Markers) + แสดงแถบลอย **Position HUD** อัตโนมัติ หากเป็นหุ้นที่ไม่ได้ถืออยู่ หน้ากราฟจะคงความสะอาดตา 100%
- **Bloomberg Nano-HUD Strip (~30% Footprint):** จากเดิมที่เป็นกล่องยักษ์ (320x240px) กินพื้นที่บังแท่งเทียน ถูกผ่าตัดลดขนาดลง 85% เหลือเพียงแถบมินิมอลแนวนอนทรงบางเฉียบ (~250px x 44px ~11,000 px²) กระจกแก้วโปร่งแสง (`bg-slate-950/75 backdrop-blur-md`) มองทะลุเห็นแท่งเทียนด้านหลังได้
- **Top-Center Airspace Placement:** วางตำแหน่งเริ่มต้น (Default & Recycle Snap) ไว้ที่ **กึ่งกลางด้านบน (Top-Center: `top: 10px; left: 50%; transform: translateX(-50%)`)** ซึ่งเป็นน่านฟ้าที่โล่งและว่างที่สุดของหน้ากราฟ หลีกเลี่ยง Legend / OHLCV ด้านซ้าย และหลีกเลี่ยง Price Scale / แท่งเทียนราคาปัจจุบันด้านขวา
- **HTML5 Pointer Capture Drag & Drop:** ระบบคลิกลากย้ายตำแหน่งอิสระระดับ 60-120fps ลื่นไหลติดมือ ไม่หลุดขอบ ไม่ตกจอ รองรับ Mouse, Touchscreen (iPad/Tablet), และ Stylus Pen พร้อมระบบปักหมุดล็อค (`📌`) และปุ่มรีไซเคิล (`♻️`)
- **Compact Price Line Label (`NVDA (+10.6%)`):** ป้ายราคาบนเส้นต้นทุนเฉลี่ยเดิมที่ยาวเกินไป (`Avg Cost: $31.78 (+10.63%)`) ถูกย่อให้สั้นกระชับเหลือแค่ชื่อหุ้นและเปอร์เซ็นต์กำไร ประหยัดพื้นที่ในกราฟลงกว่า 65%
- **Universal Cloud Synchronization:** ซิงก์ตำแหน่งพิกัด X/Y, สไตล์เส้น (สี, ความหนา, รูปแบบเส้น), และสถานะ On/Off ขึ้น Cloud VPS Database อัตโนมัติผ่าน `pushSettingDebounced` ภายใน 800ms
- **Composite Canvas Undo & Redo System (30-Level Command Stack):** ระบบประวัติคำสั่งย้อนกลับ/ทำซ้ำระดับเวิร์กสเตชัน รองรับทั้ง Drawing Tools (เส้นแนวนอน, เส้นแนวโน้ม, ลบทั้งหมด, สแกน S/R อัตโนมัติ) และ Indicators (MCDX, Ultimate RSI, Trend Speed, EMA, Volume Profile, SMC Lite ฯลฯ)
- **History Action Log Popover (Photoshop / Figma Style):** หน้าต่างประวัติ Dark Glassmorphism แสดงประวัติ 3 โซน (Future / Current Active / Past) พร้อมเวลาสัมพัทธ์ และสามารถคลิก **One-Click Jump to State** วาร์ปไปยังจุดใดก็ได้ในประวัติภายใน 1-2ms
- **Layout-Agnostic Hotkeys (Physical Scancode `e.code`):** ตรวจจับ `e.code === 'KeyZ'`, `'KeyY'`, `'KeyC'`, `'KeyV'`, `'KeyH'`, `'KeyT'`, `'KeyF'` ทำให้คีย์ลัดทำงานได้ 100% ไม่ว่าผู้ใช้จะเปิดแป้นพิมพ์ภาษาไทย (เช่น `ผ`, `ั`, `ด`, `แ`, `อ`) หรือภาษาอังกฤษ

### 3. สถาปัตยกรรม Canvas History Engine (`canvasHistoryStore.ts`)
```typescript
import { create } from 'zustand';
import { executeUndo, executeRedo } from './canvasHistoryDispatcher';

export const MAX_HISTORY = 30;

export type CanvasActionType =
  | 'ADD_LINE'
  | 'DELETE_LINE'
  | 'UPDATE_LINE'
  | 'ADD_TRENDLINE'
  | 'DELETE_TRENDLINE'
  | 'UPDATE_TRENDLINE'
  | 'CLEAR_ALL_DRAWINGS'
  | 'AUTO_DETECT_SR'
  | 'TOGGLE_INDICATOR';

export type CanvasIconType = 'line' | 'trend' | 'indicator' | 'trash' | 'sparkles';

export interface CanvasCommand {
  id: string;
  type: CanvasActionType;
  symbol: string; // Ticker symbol or 'GLOBAL' for indicators
  description: string;
  iconType: CanvasIconType;
  timestamp: number;
  forwardData: any;
  inverseData: any;
}

interface CanvasHistoryState {
  past: CanvasCommand[];
  future: CanvasCommand[];
  isRestoring: boolean;
  isHistoryOpen: boolean;

  pushCommand: (cmd: Omit<CanvasCommand, 'id' | 'timestamp'>) => void;
  undo: (currentSymbol?: string) => CanvasCommand | null;
  redo: (currentSymbol?: string) => CanvasCommand | null;
  jumpToPast: (targetId: string, currentSymbol?: string) => void;
  jumpToFuture: (targetId: string, currentSymbol?: string) => void;
  canUndo: () => boolean;
  canRedo: () => boolean;
  peekUndo: () => CanvasCommand | undefined;
  peekRedo: () => CanvasCommand | undefined;
  toggleHistoryOpen: () => void;
  setHistoryOpen: (open: boolean) => void;
  clearHistory: () => void;
}

export const useCanvasHistoryStore = create<CanvasHistoryState>((set, get) => ({
  past: [],
  future: [],
  isRestoring: false,
  isHistoryOpen: false,

  pushCommand: (cmdData) => {
    if (get().isRestoring) return;

    const newCommand: CanvasCommand = {
      ...cmdData,
      id: `cmd_${Date.now()}_${Math.random().toString(36).slice(2, 7)}`,
      timestamp: Date.now(),
    };

    set((state) => {
      const nextPast = [newCommand, ...state.past].slice(0, MAX_HISTORY);
      return {
        past: nextPast,
        future: [], // New action wipes redo stack
      };
    });
  },

  undo: (_currentSymbol?: string) => {
    const { past, future, isRestoring } = get();
    if (past.length === 0 || isRestoring) return null;

    const [cmdToUndo, ...remainingPast] = past;

    set({ isRestoring: true });
    try {
      executeUndo(cmdToUndo);
    } catch (err) {
      console.error('Failed to execute undo command:', err);
    } finally {
      set({
        past: remainingPast,
        future: [cmdToUndo, ...future],
        isRestoring: false,
      });
    }

    return cmdToUndo;
  },

  redo: (_currentSymbol?: string) => {
    const { past, future, isRestoring } = get();
    if (future.length === 0 || isRestoring) return null;

    const [cmdToRedo, ...remainingFuture] = future;

    set({ isRestoring: true });
    try {
      executeRedo(cmdToRedo);
    } catch (err) {
      console.error('Failed to execute redo command:', err);
    } finally {
      set({
        past: [cmdToRedo, ...past].slice(0, MAX_HISTORY),
        future: remainingFuture,
        isRestoring: false,
      });
    }

    return cmdToRedo;
  },

  jumpToPast: (targetId: string, currentSymbol?: string) => {
    const { past, isRestoring } = get();
    if (isRestoring || past.length === 0) return;

    const targetIdx = past.findIndex((c) => c.id === targetId);
    if (targetIdx === -1) return;

    const countToUndo = targetIdx + 1;
    for (let i = 0; i < countToUndo; i++) {
      get().undo(currentSymbol);
    }
  },

  jumpToFuture: (targetId: string, currentSymbol?: string) => {
    const { future, isRestoring } = get();
    if (isRestoring || future.length === 0) return;

    const targetIdx = future.findIndex((c) => c.id === targetId);
    if (targetIdx === -1) return;

    const countToRedo = targetIdx + 1;
    for (let i = 0; i < countToRedo; i++) {
      get().redo(currentSymbol);
    }
  },

  canUndo: () => get().past.length > 0,
  canRedo: () => get().future.length > 0,
  peekUndo: () => get().past[0],
  peekRedo: () => get().future[0],

  toggleHistoryOpen: () => set((state) => ({ isHistoryOpen: !state.isHistoryOpen })),
  setHistoryOpen: (open: boolean) => set({ isHistoryOpen: open }),

  clearHistory: () => set({ past: [], future: [], isHistoryOpen: false }),
}));
```

### 4. สถาปัตยกรรม Command Dispatcher (`canvasHistoryDispatcher.ts`)
```typescript
import { CanvasCommand } from './canvasHistoryStore';
import { useDrawingStore } from './drawingStore';
import { useIndicatorStore } from './useIndicatorStore';

export function executeUndo(cmd: CanvasCommand): void {
  switch (cmd.type) {
    case 'ADD_LINE':
      if (cmd.forwardData?.lineId) {
        useDrawingStore.getState().restoreDeleteLine(cmd.symbol, cmd.forwardData.lineId);
      }
      break;

    case 'DELETE_LINE':
      if (cmd.inverseData?.deletedLine) {
        useDrawingStore.getState().restoreAddLine(cmd.symbol, cmd.inverseData.deletedLine);
      }
      break;

    case 'UPDATE_LINE':
      if (cmd.inverseData?.lineId && cmd.inverseData?.previousState) {
        useDrawingStore.getState().restoreUpdateLine(cmd.symbol, cmd.inverseData.lineId, cmd.inverseData.previousState);
      }
      break;

    case 'ADD_TRENDLINE':
      if (cmd.forwardData?.trendLineId) {
        useDrawingStore.getState().restoreDeleteTrendLine(cmd.symbol, cmd.forwardData.trendLineId);
      }
      break;

    case 'DELETE_TRENDLINE':
      if (cmd.inverseData?.deletedTrendLine) {
        useDrawingStore.getState().restoreAddTrendLine(cmd.symbol, cmd.inverseData.deletedTrendLine);
      }
      break;

    case 'UPDATE_TRENDLINE':
      if (cmd.inverseData?.trendLineId && cmd.inverseData?.previousState) {
        useDrawingStore.getState().restoreUpdateTrendLine(cmd.symbol, cmd.inverseData.trendLineId, cmd.inverseData.previousState);
      }
      break;

    case 'CLEAR_ALL_DRAWINGS':
      useDrawingStore.getState().restoreFullDrawings(
        cmd.symbol,
        cmd.inverseData?.horizontalLines || [],
        cmd.inverseData?.trendLines || []
      );
      break;

    case 'AUTO_DETECT_SR':
      useDrawingStore.getState().restoreFullDrawings(
        cmd.symbol,
        cmd.inverseData?.previousHorizontalLines || [],
        cmd.inverseData?.previousTrendLines || []
      );
      break;

    case 'TOGGLE_INDICATOR':
      if (cmd.inverseData?.configDelta) {
        useIndicatorStore.getState().restoreIndicatorPartial(cmd.inverseData.configDelta);
      }
      break;
  }
}

export function executeRedo(cmd: CanvasCommand): void {
  switch (cmd.type) {
    case 'ADD_LINE':
      if (cmd.forwardData?.line) {
        useDrawingStore.getState().restoreAddLine(cmd.symbol, cmd.forwardData.line);
      }
      break;

    case 'DELETE_LINE':
      if (cmd.inverseData?.deletedLine?.id) {
        useDrawingStore.getState().restoreDeleteLine(cmd.symbol, cmd.inverseData.deletedLine.id);
      }
      break;

    case 'UPDATE_LINE':
      if (cmd.forwardData?.lineId && cmd.forwardData?.newState) {
        useDrawingStore.getState().restoreUpdateLine(cmd.symbol, cmd.forwardData.lineId, cmd.forwardData.newState);
      }
      break;

    case 'ADD_TRENDLINE':
      if (cmd.forwardData?.trendLine) {
        useDrawingStore.getState().restoreAddTrendLine(cmd.symbol, cmd.forwardData.trendLine);
      }
      break;

    case 'DELETE_TRENDLINE':
      if (cmd.inverseData?.deletedTrendLine?.id) {
        useDrawingStore.getState().restoreDeleteTrendLine(cmd.symbol, cmd.inverseData.deletedTrendLine.id);
      }
      break;

    case 'UPDATE_TRENDLINE':
      if (cmd.forwardData?.trendLineId && cmd.forwardData?.newState) {
        useDrawingStore.getState().restoreUpdateTrendLine(cmd.symbol, cmd.forwardData.trendLineId, cmd.forwardData.newState);
      }
      break;

    case 'CLEAR_ALL_DRAWINGS':
      useDrawingStore.getState().restoreFullDrawings(cmd.symbol, [], []);
      break;

    case 'AUTO_DETECT_SR':
      useDrawingStore.getState().restoreFullDrawings(
        cmd.symbol,
        cmd.forwardData?.newHorizontalLines || [],
        cmd.forwardData?.newTrendLines || []
      );
      break;

    case 'TOGGLE_INDICATOR':
      if (cmd.forwardData?.configDelta) {
        useIndicatorStore.getState().restoreIndicatorPartial(cmd.forwardData.configDelta);
      }
      break;
  }
}

const handleMouseUp = () => {

  return;

### 7. Dynamic 3-State P&L Cost Basis Line & Bloomberg Nano-HUD Status LED Dot
- **3 สถานะ P&L (Unrealized Profit & Loss):**
  1. **กำไร (Profit, `pnl > 0`):** สีเหลืองสว่าง (Bright Yellow `#FACC15` / `yellow-300`). ป้ายราคาเส้นประ เส้น และ Dot LED เรืองแสงสีเหลืองสว่างสะดุดตา
  2. **เท่าทุน (Break-Even, `pnl === 0` หรือ `±0.05%`):** สีเทาเข้มคอนทราสต์ชัด (Dark Slate Gray 70% darker `#64748B` / `bg-slate-500`) ให้ความรู้สึกเรียบนิ่ง ไม่กวนสายตา
  3. **ขาดทุน (Loss, `pnl < 0`):** สีแดงกุหลาบเตือนภัย (Rose Crimson `#F43F5E` / `rose-400`) แสดงจุดอันตรายชัดเจน
- **Auto-Migration ใน `usePositionOverlayStore`:** มีระบบตรวจสอบค่าสีเก่าที่ผู้ใช้เคยเซฟไว้ หากพบ Amber เก่า (`#F59E0B`) จะแปลงเป็น Bright Yellow (`#FACC15`) อัตโนมัติ และหากพบ Slate สว่างเดิม (`#94A3B8`) จะแปลงเป็น Dark Slate Gray (`#64748B`) ทันที

## 🔍 Architectural Review: 7 Critical Gaps & Fixes

> [!CAUTION]
> **GAP 1 — Symbol-Scoped History Isolation**
> - Drawings ถูก scope แยกตามหุ้น (`drawingsBySymbol[symbol]`), ส่วน Indicators เป็น Global
> - ทุก Command ใน History จะถูกแท็กด้วย `symbol` — เมื่อ Undo บนกราฟตัวไหน จะย้อนเฉพาะสิ่งที่เกี่ยวข้องกับตัวนั้นและ Global indicators อย่างถูกต้อง

> [!CAUTION]
> **GAP 2 — Snapshot Size vs Memory (Command Pattern)**
> - แทนที่จะ Deep-clone `IndicatorSettings` ขนาดใหญ่ (~6 KB ต่อ entry) เราใช้ **Command Pattern (Delta-based)** บันทึกแค่ Action Descriptor + Inverse Data (~0.2 KB)
> - ความจุ **30 ชั้น (Max 30 Entries)** กิน RAM รวมไม่ถึง **10 KB** ลื่นไหลระดับ 60 FPS

> [!WARNING]
> **GAP 3 — Cloud Sync Race Condition on Restore**
> - ใช้ `isRestoring` flag กันไม่ให้ restore path ดัน command ซ้ำเข้า history stack แต่ยังคง trigger Cloud Debounced Sync เพื่อให้สถานะอัปเดตตรงกันทุกอุปกรณ์

> [!WARNING]
> **GAP 4 — Keyboard Shortcut Collision Prevention**
> - รวมศูนย์ `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` ไว้ใน `useChartDrawings.ts` ที่เดียว พร้อม `e.preventDefault()` ป้องกันชนกับ Fullscreen หรือ native browser shortcut

> [!WARNING]
> **GAP 5 — Pane Re-creation & Reflow**
> - การเปิด/ปิด SubPane (MCDX, RSI) รองรับอัตโนมัติผ่าน `useEffect` watcher ใน `useChartIndicators.ts` และ re-trigger recalculation ของ pane heights

> [!IMPORTANT]
> **GAP 6 — Clear All Coalescing**
> - `clearLines(symbol)` เก็บ snapshot รวมทั้ง Horizontal + Trendlines ไว้ใน Command เดียว Undo ครั้งเดียวฟื้นครบทุกเส้น

> [!NOTE]
> **GAP 7 — Drag & Move Coalescing**
> - Snapshot ตอน `mousedown` (pre-drag state) และ push command ตอน `mouseup` ป้องกันประวัติขยะ 60 frames ระหว่างลากเส้น

### Component 1: Canvas History Store

#### [NEW] [canvasHistoryStore.ts](file:///c:/My%20Claw/MyProjects/My%20Stock%20Portfolio/src/stores/canvasHistoryStore.ts)
Zustand store จัดการคลังประวัติ 30 ชั้น พร้อมเมธอด Jump:

```typescript
export const MAX_HISTORY = 30;

export type CanvasActionType =
  | 'ADD_LINE'
  | 'DELETE_LINE'
  | 'UPDATE_LINE'
  | 'ADD_TRENDLINE'
  | 'DELETE_TRENDLINE'
  | 'UPDATE_TRENDLINE'
  | 'CLEAR_ALL_DRAWINGS'
  | 'AUTO_DETECT_SR'
  | 'TOGGLE_INDICATOR';

export interface CanvasCommand {
  id: string;
  type: CanvasActionType;
  symbol: string;
  description: string;
  iconType: 'line' | 'trend' | 'indicator' | 'trash' | 'sparkles';
  timestamp: number;
  forwardData: any;
  inverseData: any;
}

interface CanvasHistoryState {
  past: CanvasCommand[];       // สูงสุด 30 entries
  future: CanvasCommand[];
  isRestoring: boolean;
  isHistoryOpen: boolean;

  // Actions
  pushCommand: (cmd: Omit<CanvasCommand, 'id' | 'timestamp'>) => void;
  undo: (symbol: string) => CanvasCommand | null;
  redo: (symbol: string) => CanvasCommand | null;
  jumpToPast: (symbol: string, targetId: string) => void;
  jumpToFuture: (symbol: string, targetId: string) => void;
  canUndo: () => boolean;
  canRedo: () => boolean;
  peekUndo: () => CanvasCommand | undefined;
  peekRedo: () => CanvasCommand | undefined;
  toggleHistoryOpen: () => void;
  setHistoryOpen: (open: boolean) => void;
  clearHistory: () => void;
}
```

**Jump Logic:**
- `jumpToPast(symbol, targetId)`: ค้นหา index ของ command ใน `past` ➔ ลูปเรียก `executeUndo` จนกระทั่งย้อนมาถึงจุดที่เลือก
- `jumpToFuture(symbol, targetId)`: ค้นหา index ใน `future` ➔ ลูปเรียก `executeRedo` จนถึงจุดที่เลือก
- ตลอดการ Jump จะครอบด้วย `isRestoring = true` ครั้งเดียว และ trigger Cloud Sync ตอนจบเพื่อความเร็วสูงสุด

### 🌐 ระบบคีย์ลัดอิสระตามมาตรฐานสากล (Layout-Agnostic Hotkeys)
แก้ปัญหาคีย์ลัดกดไม่ติดเวลาเปิดแป้นพิมพ์ภาษาไทย โดยเปลี่ยนมาใช้ **`e.code` (Physical Key Scancode)** ควบคู่กับตัวอักษรไทย:
- **`Ctrl + Z` / `Ctrl + ผ` (Undo)** ➔ `e.code === 'KeyZ'` ย้อนกลับได้ทันทีไม่ว่าจะเปิดภาษาอะไร
- **`Ctrl + Y` / `Ctrl + ั` หรือ `Ctrl + Shift + Z` (Redo)** ➔ `e.code === 'KeyY'`
- **`Ctrl + C` / `Ctrl + แ` (Copy)** ➔ `e.code === 'KeyC'`
- **`Ctrl + V` / `Ctrl + อ` (Paste)** ➔ `e.code === 'KeyV'`
- **`Alt + H` / `Alt + ้` (Horizontal Line Tool)** ➔ `e.code === 'KeyH'`
- **`Alt + T` / `Alt + ะ` (Trendline Tool)** ➔ `e.code === 'KeyT'`
- **`F` / `ด` (Fullscreen Toggle)** ➔ `e.code === 'KeyF'`

- **การแก้ไข:** ย่อป้ายเหลือรูปแบบ `NVDA (+10.6%)` สั้นลง 65% ไม่บังกราฟ และตัวเลขราคายังคงแสดงอยู่บนแกนขวาสุดเหมือนเดิม

### Iteration 5: Composite Canvas Undo & Redo System (30-Level Command Stack)
- **ความต้องการ:** พัฒนาระบบ Undo & Redo ให้ครอบคลุมทั้ง Canvas รองรับการวาดเส้น (Horizontal Lines, Trendlines, Auto S/R, Clear All) และการเปิด/ปิด Indicators (Pane 0, Pane 1, Pane 2)
- **การออกแบบ & ดำเนินการ:**
  - ใช้ Command Pattern (Delta-based) เก็บเฉพาะคำสั่งผันกลับ (~0.2 KB ต่อ entry) ควบคุมความจุ 30 ขั้นเต็มพิกัด
  - สร้าง `canvasHistoryStore.ts` และ `canvasHistoryDispatcher.ts`
  - ติดตั้ง Hook ใน `drawingStore.ts` และ `useIndicatorStore.ts`
  - แก้ไขปัญหา Drag Flood ด้วย Drag Coalescing ใน `useChartDrawings.ts` ลากเส้น 60fps บันทึกเป็น 1 command ตอนปล่อยเมาส์

### Iteration 6: History Action Log Popover (Figma / Photoshop Style) & One-Click State Jumps
- **ความต้องการ:** เพิ่มหน้าต่างประวัติการกระทำ ให้ผู้ใช้เห็นสิ่งที่ทำไปแล้ว 30 ชั้น และคลิกกระโดดวาร์ปย้อนหลังหรือเดินหน้าได้ทันที
- **การดำเนินการ:**
  - สร้าง `CanvasHistoryPopover.tsx` แสดง Future, Current Active, และ Past รายการ
  - มีเวลาสัมพัทธ์ (Relative Time) และไอคอนแยกลักษณะคำสั่ง
  - เมธอด `jumpToPast` และ `jumpToFuture` ลูป execute ย้อนสถานะได้อย่างรวดเร็วใน 1-2ms พร้อม `isRestoring` guard
  - เพิ่มปุ่มชุด Undo, Redo, และ History Action Log Dropdown ใน `ChartControlBar.tsx`

### Iteration 7: Layout-Agnostic Hotkeys (Physical Scancode `e.code` for Thai/English Keyboards)
- **ปัญหา:** ผู้ใช้แจ้งว่ากด `Ctrl+Z` ไม่ติดเมื่อเปิดแป้นพิมพ์ภาษาไทย (`ผ`)
- **สาเหตุรากเหง้า (Root Cause):** `e.key` ส่งคืนตัวอักษรตาม Layout ปัจจุบัน (`'ผ'`) ทำให้เงื่อนไข `e.key === 'z'` เป็น `false`
- **การแก้ไข:** เปลี่ยนไปดักจับ `e.code` (Physical Scancode เช่น `KeyZ`, `KeyY`, `KeyC`, `KeyV`, `KeyH`, `KeyT`, `KeyF`) ควบคู่กับ Fallback ตัวอักษรไทย ทำให้คีย์ลัดกดติด 100% ทุกแป้นพิมพ์

### Iteration 8: Dynamic 3-State P&L Cost Basis Line & Bloomberg Nano-HUD Status LED Dot
- **ความต้องการ:** เพิ่มระบบสี 3 เฉดตามสถานะ P&L ของพอร์ต (กำไร / เท่าทุน / ขาดทุน) ให้เส้น Avg Cost Line และขอบการ์ด/ไฟ LED บน Nano-HUD ปรับสีเรืองแสงตามสถานะ
- **การปรับแต่งสี (Color Refinements):**
  - กำไร: ปรับเป็นเหลืองสว่างสดใส (`#FACC15` / `yellow-300`)
  - เท่าทุน: ปรับเป็นสีเทาเข้ม (ขาวมืด 70% `#64748B` / `bg-slate-500`) เพื่อความเงียบสงบ ไม่แย่งสายตา
  - ขาดทุน: สีแดงกุหลาบเตือนภัย (`#F43F5E` / `rose-400`)
- **การดำเนินการ:**
  - อัปเดต `positionOverlayConfig.ts` และเพิ่ม Auto-migration ใน `usePositionOverlayStore.ts` เพื่อแปลงค่า legacy amber และ slate
  - ติดตั้ง dynamic border glow และ status LED dot บน `ChartPositionHUD.tsx`

### Iteration 9: Decoupled Chart Visibility Architecture (Project 2X vs X-Chart)
- **การวิเคราะห์โจทย์:** ผู้ใช้สอบถามว่าการตั้งค่าต่างๆ ของกราฟระหว่างหน้า Project 2X กับ X-Chart ควรแยกกันหรือลิ้งก์กัน
- **ข้อสรุปเชิงยุทธศาสตร์:**
  - ข้อมูลจริง (Data Layer: Drawings, Portfolios, Color Scheme) **ต้องลิ้งก์เป็น Single Source of Truth ห้ามแยก** เพื่อให้การวิเคราะห์ต่อเนื่อง
  - การมองเห็น (View State Layer: Eyeball Toggles 👁️) **ต้องแยกกันเด็ดขาด** เพราะ Project 2X ต้องการความคลีน โฟกัสพอร์ต ส่วน X-Chart ต้องการเทอร์มินัลวิเคราะห์เต็มรูปแบบ
- **การดำเนินการ:**
  - สร้าง `useChartViewStore.ts` รองรับ Profile แยกตาม Context (`project2x` vs `xchart`) เก็บใน localStorage
  - เชื่อมต่อ `LWChart.tsx`, `LeftDrawingToolbar.tsx`, `useChartDrawings.ts`, `ChartPositionHUD.tsx`, `PositionSettingsPopover.tsx`
  - ติดตั้งแถบ Quick View Controls (`[👁️ HUD] [👁️ Drawings] [👁️ Toolbar] [👁️ SMC & VWAP]`) บน Project 2X เพื่อการสลับเปิด/ปิดตาแบบ 1-click
