# 🚀 Walkthrough: LazyRead (Phase 3 Text Editor)

The implementation for **Phase 3 (Text Editor)** using the **Isolated Read-Write** pattern is now complete. The LazyRead app has been upgraded from a read-only viewer to a fully functional markdown editor that syncs seamlessly back to its original source.

## 🛠️ What was Changed

- **Relocated Project:** The project was successfully moved to `C:\My Claw\MyProjects\LazyRead` to leverage better support systems.
- **Side-by-Side Editor (UI):** 
  - Added an **"Edit"** and **"Save"** button to the top navigation bar.
  - Implemented a `<textarea id="editor">` that sits next to the markdown preview (`#pv`) when in Edit mode.
  - Added CSS to cleanly toggle between a full-width preview and a 50/50 split side-by-side editing mode.
- **Editor Switcher (Basic vs Monaco):**
  - Added a dropdown in the top bar to seamlessly switch between the **Basic Editor** (`<textarea>`) and the **Monaco Editor** (Advanced, VS Code style). The content is preserved when switching.
- **Live Markdown Preview:**
  - Hooked an `oninput` (or `onDidChangeModelContent` for Monaco) event to the editor so that every keystroke instantly updates the parsed markdown preview on the right.
- **Auto-Save & Isolated Read-Write:**
  - **Auto-Save:** Added a debounced Auto-Save feature that automatically saves your file **5 seconds** after you stop typing, preventing API spam while ensuring no data loss.
  - Bound the **Ctrl+S** keyboard shortcut to intercept the browser's default save and fire our custom `saveFile()` API manually if desired.
  - The `saveFile()` logic dynamically calculates whether to hit the `/api/local/write` (Local Vault) or `/api/vps-db/write` (VPS Cloud) API depending on which source the file was opened from. This ensures zero cross-syncing conflicts.
  - Added visual "Saving..." and "Saved!" feedback directly in the topbar.

## 🧪 Verification Plan

You can now test this locally:
1. Open the project in `C:\My Claw\MyProjects\LazyRead`.
2. Run `start.bat` (or `node server.js`).
3. Click a `.md` file from either your local drive or the VPS Database.
4. Click **"Edit"** on the top right. The screen will split in half.
5. Type in the left pane and watch the right pane update instantly.
6. Press **Ctrl+S** to save the file back to its source.

# เป้าหมาย: Phase 3 (Text Editor) - ระบบ Isolated Read-Write

สร้าง Markdown Text Editor บนหน้าบ้าน (UI) ของ LazyRead โดยที่ระบบหลังบ้าน (API `local.js` และ `vps-db.js`) มีระบบ `PUT /write` รองรับไว้แล้ว เป้าหมายหลักคือการทำหน้าจอให้สามารถแก้ไขได้, ดูพรีวิวได้แบบ Real-time, และเซฟข้อมูลกลับไปยังแหล่งต้นทางได้โดยตรง (Isolated Read-Write)

## สิ่งที่ต้องการให้พิจารณา

> [!IMPORTANT]  
> โปรดรีวิวแนวทางด้าน UI นี้: 
> กูเสนอให้เพิ่มปุ่ม **"Edit / View"** (แก้ไข/ดูข้อมูล) บนเมนูด้านบน เมื่อกดแล้ว หน้าจอหลักจะถูกแบ่งครึ่งเป็นสองฝั่ง (Split Screen) โดยฝั่งซ้ายจะเป็น `<textarea>` สำหรับให้พิมพ์แก้โค้ด Markdown ดิบๆ ส่วนฝั่งขวาจะเป็นพรีวิวที่แสดงผลลัพธ์
> 
> การกดเซฟ จะสามารถทำได้ผ่าน **Ctrl+S** หรือกด **ปุ่ม Save** ซึ่งระบบจะยิง API ไปเซฟทับไฟล์เดิมในโฟลเดอร์ต้นทาง (ไม่ว่าจะเป็น Local หรือ VPS) ทันทีโดยใช้ช่องทาง `/write` ที่มีอยู่แล้ว

## คำถามที่ต้องตัดสินใจ

> [!WARNING]
> 1. มึงอยากได้แค่ช่อง `<textarea>` แบบบ้านๆ พิมพ์ง่ายๆ ไปก่อน หรือจะให้จัดเต็มใส่พวก Library โค้ดอีดิเตอร์อย่าง **Monaco Editor** หรือ **CodeMirror** ไปเลย? (แนะนำว่าเริ่มจาก `<textarea>` ธรรมดาไปก่อนสำหรับ MVP จะได้เร็ว)
> 2. มึงอยากให้มันมีระบบ "Auto-Save" (เซฟอัตโนมัติเมื่อหยุดพิมพ์ 2 วินาที) หรือจะบังคับให้กด "Ctrl+S" / "Save" ด้วยตัวเอง เพื่อป้องกันไม่ให้ยิง API ขยะเข้า VPS รัวเกินไป?
