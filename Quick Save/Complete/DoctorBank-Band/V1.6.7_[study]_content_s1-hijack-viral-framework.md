# V1.6.7 [study] System 1 Hijack Viral Framework

## 📌 Context (Compiled Truth)
**Why this was done:** 
The user engaged in a deep philosophical discussion about the value of reading books vs extracting actionable frameworks via AI. It was concluded that reading for "knowledge accumulation" is less effective than using AI to extract the "core mechanics" and applying them immediately to solve specific bottlenecks (Execution over Theory).

**What was decided:** 
We took the core concepts from Daniel Kahneman's *Thinking, Fast and Slow* and transformed them into a highly actionable marketing framework named **S1-Hijack**. The framework is designed to optimize short-form viral scripts (TikTok, Reels) for DoctorBank products like Lipo Gluta and MG Night.

**The Core Realization:**
Humans (and customers) use System 1 (fast, emotional, lazy) for 95% of their lives. System 2 (logical, analytical) is lazy and only used when forced. Therefore, attempting to sell via logic, specs, or dry facts will fail. Viral scripts must:
1. Hijack System 1 instantly (0-3s) using Loss Aversion or Pattern Interrupt.
2. Keep System 1 engaged using visual metaphors instead of jargon.
3. Provide a tiny fraction of logic at the end (CTA) just so System 2 can justify the emotional purchase and avoid Buyer's Remorse.

# Master Framework: S1-Hijack (System 1 Hijack Formula)

**Based on:** *Thinking, Fast and Slow (Daniel Kahneman)*
**Core Concept:** มนุษย์ตัดสินใจด้วย System 1 (อารมณ์, สัญชาตญาณ, ความกลัว) แล้วค่อยหาเหตุผลจาก System 2 (ตรรกะ, ข้อมูล) มารองรับการกระทำของตัวเอง ดังนั้น Viral Script ที่ดีต้อง **"กระชากคอ System 1 และโยนเศษเหตุผลให้ System 2"**

---

## 📖 ที่มาที่ไป (Background & Psychology)
ทำไมสูตรนี้ถึงเวิร์ก? ทฤษฎีจิตวิทยาเบื้องหลัง (จากหนังสือ Thinking, Fast and Slow) ที่คุณต้องจำไว้คือ:
1. **System 1 (โหมดออโต้):** ขี้เกียจ ใช้อารมณ์ ด่วนสรุป (มนุษย์ใช้โหมดนี้ 95% ของชีวิต)
2. **System 2 (โหมดเหตุผล):** มีตรรกะ วิเคราะห์ลึก แต่กินพลังงานสมองสูงมาก มนุษย์จึงหลีกเลี่ยงที่จะใช้มันถ้าไม่จำเป็น
3. **Loss Aversion (ความกลัวเสียของ):** มนุษย์เกลียดความพ่ายแพ้ "มากกว่า" ดีใจที่ชนะถึง 2 เท่า! (ถ้าเสียเงิน 10,000 จะเจ็บปวดมากกว่าตอนได้เงิน 10,000 สองเท่า)
4. **WYSIATI (What You See Is All There Is):** สมอง System 1 จะด่วนสรุปจาก "ข้อมูล/ภาพ ที่เห็นตรงหน้าเท่านั้น" โดยไม่สนว่ามีข้อมูลอะไรซ่อนอยู่หรือหายไป

**สรุป:** หน้าที่ของคนทำ Content/Marketing ไม่ใช่การยัดเยียดเหตุผลให้ System 2 แต่คือการ **"แฮ็ก System 1"** ให้โลภหรือกลัว แล้วค่อยโยนตรรกะให้ System 2 เอาไปใช้เป็นข้ออ้างตอนจ่ายเงิน!

## 🧠 The 3-Step S1-Hijack Formula

### STEP 1: The Hijack (0-3 Seconds)
**เป้าหมาย:** หยุดการทำงานของ System 2 ชั่วคราว และกระชาก System 1 ให้ออกมาทำงาน
**กลไก:** ใช้ **Loss Aversion (ความกลัวเสียของ/เจ็บปวด)** หรือ **Pattern Interrupt (ความขัดแย้งที่คาดไม่ถึง)**

* ❌ **ห้ามทำ:** เปิดด้วยคำทักทาย, ข้อมูลเชิงลึก, สเปคสินค้า (System 2 จะตื่นแล้วปัดทิ้ง)
* ✅ **วิธีทำ:**
  - *ทิ่มปมความเจ็บปวด:* "คุณกำลังเสียเงินเดือนละหมื่นไปฟรีๆ เพราะ..."
  - *ขัดแย้งความเชื่อเดิม:* "อย่าเพิ่งกินกลูต้า ถ้าคุณยังไม่รู้เรื่องนี้..."
  - *ท้าทายสัญชาตญาณ:* "สิ่งที่หมอผิวหนังไม่เคยบอกคุณ..."

### STEP 2: The Emotional Rollercoaster (3-30 Seconds)
**เป้าหมาย:** เลี้ยง System 1 ให้อยู่ในภวังค์ ไม่ให้มีช่องว่างเดดแอร์จน System 2 มีเวลาแทรกตัวขึ้นมาคิดวิเคราะห์
**กลไก:** ย่อยความรู้ยากๆ (ตรรกะ) ให้กลายเป็น **"ภาพจำ (Visual Metaphors)"**

* ❌ **ห้ามทำ:** อธิบายกลไกทางเคมี, ใช้ศัพท์แสงเฉพาะทาง (Jargon), แช่กล้องมุมเดียวนานๆ
* ✅ **วิธีทำ:**
  - *ใช้ภาษาภาพ (Visual Metaphor):* แทนที่จะพูดว่า "Phospholipid bilayer" ให้ใช้คำว่า **"เกราะกันกระสุน"**
  - *เปรียบเทียบกับชีวิตประจำวัน:* แทนที่จะพูดว่า "ปรับสมดุลระบบประสาทส่วนกลาง" ให้ใช้คำว่า **"สับคัตเอาต์ปิดสวิตช์สมอง"**
  - *กระตุ้น Dopamine ต่อเนื่อง:* เปลี่ยนมุมกล้อง (B-Roll), ใส่ Sound Effect กระแทกอารมณ์ทุกๆ 2-3 วินาที

### STEP 3: The Justification (CTA / Closing)
**เป้าหมาย:** ปิดการขายโดยอนุญาตให้ System 2 เข้ามามีบทบาท เพื่อลดความรู้สึก "รู้สึกผิดที่จ่ายเงินด้วยอารมณ์ (Buyer's Remorse)"
**กลไก:** โยน **"ตรรกะหรือเหตุผลสั้นๆ"** เข้าไปรองรับการตัดสินใจของ System 1

* ❌ **ห้ามทำ:** จบแบบดื้อๆ หรือสั่งให้ซื้อโดยไม่มีเหตุผลสนับสนุนเลย
* ✅ **วิธีทำ:**
  - *อ้างอิงความคุ้มค่า:* "คุ้มกว่าการเอาเงินไปฉี่ทิ้งหลักหมื่น..."
  - *สร้างความเร่งด่วน (Scarcity):* "นวัตกรรมตัวนี้เพิ่งเข้าไทย ล็อตแรกเหลือไม่ถึง 100 เซ็ต..."
  - *อ้างอิงหลักฐาน (Social Proof / Authority):* "มีงานวิจัยรับรองจาก..." (ไม่ต้องอธิบายลึก แค่โยนชื่อให้ System 2 รู้สึกปลอดภัย)
