# DrView Extension v1.4.0 — Full Feature Suite & Critical Mermaid Bugfix

## 📌 Context (Compiled Truth)
DrView underwent a comprehensive cleanup and feature implementation cycle covering all outstanding P0-P4 roadmap items from the Claude Opus 4.6 recheck audit alongside resolving a critical runtime Mermaid rendering failure.

### 1. Critical Mermaid v11 Global Scope Crash (Root Cause & Fix)
- **Problem**: In `media/mermaid.min.js` (v11.16.1 esbuild bundle), line 3587 executed `globalThis["mermaid"] = globalThis.__esbuild_esm_mermaid_nm["mermaid"].default;`. Because `__esbuild_esm_mermaid_nm` was declared via `var` at script scope rather than directly on `globalThis`, this threw an uncaught `TypeError: Cannot read properties of undefined (reading 'mermaid')` on initialization in the sandboxed VS Code webview. This silently aborted script execution, leaving diagrams in raw markdown `<pre><code>` format.
- **Solution**: Patched `media/mermaid.min.js` and `media/viewer.js` to safely resolve the instance from `__esbuild_esm_mermaid_nm["mermaid"].default` with robust fallbacks and graceful per-card error banners.

### 2. Memory Leak Remediation (`retainContextWhenHidden`)
- Changed `retainContextWhenHidden` to `false` in `src/mdViewerProvider.js`.
- Implemented state restoration in `media/viewer.js` via `vscodeApi.getState()` / `vscodeApi.setState()` to persist scroll positions across tab transitions without pinning heavy DOM instances in background RAM.

### 3. Two-Way TSV Sync Back to Markdown Files
- Implemented `saveTsvToFile()` in `media/viewer.js` with a dedicated **💾 Save File** button on each spreadsheet card.
- In `src/mdViewerProvider.js`, message command `saveTsv` finds the target ```` ```tsv ```` or ```` ```csv ```` code fence in the active document and applies surgical text replacements via `vscode.WorkspaceEdit`.

### 4. Interactive Clickable Links
- Bound delegated click handler on `#pv` in `media/viewer.js`.
- Web links (`http://`, `https://`, `mailto:`) route to system browser via `vscode.env.openExternal`.
- Local workspace files (e.g. `./subfolder/target.md`) resolve relative paths and open natively in VS Code via `vscode.commands.executeCommand('vscode.open')`.

### 5. Task List Checkbox Rendering
- Processed `<li>[ ] ` and `<li>[x] ` patterns in `mdViewerProvider.js` into styled `.drview-task-checkbox` elements with custom dark emerald check styling in `media/viewer.css`.

### 6. Workspace File Fuzzy Search & Direct Data Export
- Added `drview.searchFiles` command in `src/extension.js` and `package.json` with a search icon `$(search)` in the DrView Explorer sidebar header for instant workspace file fuzzy searching.
- Added **📥 TSV** export button on tables to save raw TSV files via native VS Code save dialogs.
