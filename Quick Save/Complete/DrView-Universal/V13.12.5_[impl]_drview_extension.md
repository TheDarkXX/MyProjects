# DrView Extension (V1.1.0) - VS Code Markdown & Spreadsheet Viewer

## 📌 Context (Compiled Truth)
DrView is a custom VS Code extension developed for the DoctorBank-Brand workspace. It replaces the default markdown editor for `.md` files, providing a Dark Theme Markdown Viewer, Mermaid Diagram renderer, and an interactive TSV Spreadsheet viewer.
It features a custom sidebar (`DrView Explorer`) with categorized file trees (Products, Content, Brand, docs) and Favorites management.

Version 1.1.0 introduces:
- **Mermaid Smart Converter**: Preserves original raw markdown data across 5 diagram types, with an `Original Diagram` mode to restore raw markdown and prevent data mutation.
- **Excel-Grade TSV Spreadsheet Engine**: Multi-cell range selection, row/column header picking, and Excel-style copy/paste functionality.
- **Language-Agnostic Keyboard Handling**: Uses `e.code` instead of `e.key` to ensure hotkeys (Ctrl+C, Ctrl+V) work seamlessly regardless of the user's active keyboard layout (e.g., Thai/English).
- **Architecture**: `viewer.js` serves as the central runtime controller. The extension logic is in `src/extension.js` and `src/mdViewerProvider.js`.

### 5. VSIX ขนาด 37MB — ใหญ่เกินไป 10 เท่า

| ส่วน | ขนาด | ควรจะเป็น |
|---|---|---|

1. สร้าง `.vscodeignore` เพื่อ exclude `node_modules/`, `*.vsix` เก่า, `package-lock.json`

3. ใช้ `esbuild` bundle `extension.js` + dependencies เป็น single file → ลด VSIX จาก 37MB เหลือ ~4MB

```
.vscodeignore:
node_modules/**
*.vsix
package-lock.json
```

> [!WARNING]
> ปัจจุบัน `marked` ถูก require ผ่าน `node_modules/marked/` — ถ้าใส่ `.vscodeignore` จะพัง ต้อง bundle ก่อน

# DrView v1.3.0 — Export JPG + Settings Panel

## Overview

3 ฟีเจอร์ใหม่:
1. **📥 Export Mermaid → JPG** (ปุ่มใหม่ข้าง zoom controls)
2. **📥 Export TSV → JPG** (ปุ่มใหม่ข้าง Copy TSV)
3. **⚙️ Settings Panel** (dropdown จาก top-bar gear icon)

---

## 1. Export Mermaid → JPG

**Pipeline:** SVG innerHTML → `<canvas>` → `canvas.toBlob('image/jpeg')` → download link

**Implementation:**
- เพิ่มปุ่ม `📥 JPG` ใน Mermaid toolbar (ข้าง zoom +/−)
- Function `exportMermaidJpg(idx)`:
  1. อ่าน SVG จาก `mermaid-content-{idx}`
  2. แปลง SVG เป็น data URL → โหลดเป็น `Image`
  3. วาดลง `<canvas>` ขนาดเท่า SVG (scale 2x สำหรับ retina)
  4. เติม background สีขาว (JPG ไม่มี transparency)
  5. `canvas.toBlob('image/jpeg', 0.95)` → trigger download

**ข้อดี:** ไม่ต้องเพิ่ม dependency ใหม่ — ใช้ native Canvas API

---

## 2. Export TSV → JPG

**Pipeline:** Clone table DOM → render ลง `<canvas>` → download

**Implementation:**
- เพิ่มปุ่ม `📥 JPG` ใน TSV toolbar (ข้าง Copy TSV)
- Function `exportTsvJpg(idx)`:
  1. อ่าน table element จาก `tsv-table-{idx}`
  2. สร้าง `<foreignObject>` SVG ที่ wrap table HTML + inline styles
  3. แปลงเป็น data URL → `Image` → `<canvas>`
  4. เติม background #0d1117 (dark theme)
  5. `canvas.toBlob('image/jpeg', 0.95)` → trigger download

# DrView Extension — Walkthrough

ระบบ TOC ได้ถูกอัปเกรดเป็น **VS Code Extension (DrView)** เรียบร้อยแล้ว! มึงสามารถคลิกเปิดไฟล์ `.md` แล้วเข้าสู่ระบบ Dashboard สุดล้ำนี้ได้โดยอัตโนมัติ

## 🌟 สิ่งที่ทำไปแล้ว
- **Custom Markdown Viewer:** เสียบเข้ากับ VS Code เลย คลิก `.md` ไฟล์ไหนก็จะเป็น Dark Theme สวยๆ + Outline + Zoom + Focus Mode (แทนที่ Raw Markdown ธรรมดา)

## 🚀 วิธีใช้งาน

2. ไฟล์จะถูกเปิดขึ้นมาใน **DrView Markdown Viewer** ทันที
