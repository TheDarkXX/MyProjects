# DrView Custom CSS Setting

## 📌 Context (Compiled Truth)
The user requested a way to easily inject custom CSS into the DrView Markdown viewer so that AI-generated UI tweaks can be quickly copy-pasted and previewed.

### Decisions Made:
- Added a new configuration key `customCss` to the internal `drviewSettings` object which synchronizes with the webview's `localStorage`.
- Added a multi-line `textarea` in the settings panel (rendered by `mdViewerProvider.js`) to input the CSS.
- Added logic in `applyAllSettings()` (`viewer.js`) to inject a `<style id="drview-custom-css">` tag dynamically and update its contents whenever the settings change.
- Added CSS `.setting-textarea` and `.setting-row-col` in `viewer.css` to format the textarea properly in the settings overlay.
- Bumped extension version to `1.4.2` and repackaged to `drview-1.4.2.vsix`.
