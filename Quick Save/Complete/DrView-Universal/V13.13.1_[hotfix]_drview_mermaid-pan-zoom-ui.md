# DrView Mermaid Pan, Zoom, and Code Header Fixes

## 📌 Context (Compiled Truth)
The DrView Markdown Viewer Extension had UI interaction bugs in its Mermaid rendering component (`viewer.js`):
1. **Zoom Propagation Bug:** When holding `Ctrl` and scrolling over a Mermaid diagram, the event propagated to the global window listener, causing the entire preview pane to change its font size (zoom).
2. **Pan Init Bug:** The drag-to-pan feature failed because `attachMermaidPan` captured the `.mermaid-content` DOM element *before* it was appended to the viewport.
3. **Ghost Code Header Bug:** The `enhanceCodeBlocks` function automatically wrapped all `<pre>` tags. Since the new `mermaid-code-view` (used to store the raw mermaid string for the Code tab) didn't have a `<code>` child with a language identifier, `enhanceCodeBlocks` defaulted it to `CODE` and rendered a visible header, even though the `pre` itself was hidden.

### Decisions Made:
- Added `e.stopPropagation()` in `handleMermaidWheel` to prevent global zoom.
- Refactored `attachMermaidPan` to dynamically query `.mermaid-content` on `mousedown` and `mousemove`.
- Added an exclusion check in `enhanceCodeBlocks` to skip elements with `mermaid-code-view` or `tsv-code-view` classes.
- Added a visual `.mermaid-divider` in CSS to cleanly separate the Zoom controls from the Export controls.
- Bumped extension version to `1.4.1`.
