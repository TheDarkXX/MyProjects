# V2.22.2 [design] UI: X-Chart 'My Port' Executive Canvas Revamp & M2 Architecture

## 🧠 Context & Implementation (Compiled Truth)

### 1. วัตถุประสงค์และการปรับปรุงเชิงยุทธศาสตร์ (Why & Strategy)
- **ปัญหาเดิม:** ในหน้า `X-Chart` เมื่อคลิกเปิดแท็บ `My Port` ระบบเดิมดึงเอาคอมโพเนนต์ `XChartPanel` (กราฟแท่งเทียน Candlestick ขนาดใหญ่ของหุ้นตัวใดตัวหนึ่ง) มาแสดงตรง Main Canvas แล้วมีแท็บ Watchlist เล็กๆ ด้านขวา ซึ่งเป็นการ **"เสียพื้นที่โดยใช่เหตุ"** เพราะผู้ใช้มีแท็บแยกสำหรับดูกราฟเทคนิคอลของหุ้นแต่ละตัวอย่างเต็มตาอยู่แล้ว
- **ยุทธศาสตร์ใหม่:** แปลง Main Canvas ของแท็บ `My Port` ให้กลายเป็น **Executive Portfolio Command Canvas** ที่สมบูรณ์แบบ — ตอบโจทย์สิ่งที่นักลงทุน/เทรดเดอร์ต้องการเห็นใน 3 วินาทีแรก:
  1. สุขภาพพอร์ตรวม (Total Net Worth ทั้ง USD และ THB)
  2. กำไร/ขาดทุนวันนี้ (Today's P&L) เทียบกับกำไรสะสมสุทธิ (Unrealized Return)
  3. สภาพคล่องเงินสดคงเหลือ (Cash Cushion & Buying Power)
  4. การกระจายน้ำหนักหุ้น (Asset Allocation & Concentration Risk)
  5. ระยะห่างของราคาปัจจุบันเทียบกับเป้าหมาย Blueprint (Take Profit / Target Price)

---

### 2. ผลการวิเคราะห์ Benchmark จาก Top Trade Apps ระดับโลก
- **Robinhood / Webull:** เด่นเรื่อง Hero Metric Cards สแกนเข้าใจง่ายในเสี้ยววินาที มี Badge สีเขียว/แดงชัดเจน
- **TradingView Desktop:** เด่นเรื่อง Pro Data Table ที่มี Data Density สูง คอลัมน์ครบครัน Sort ได้ทุกมิติ
- **Koyfin / Bloomberg Terminal:** เด่นเรื่อง Segmented Weight Ribbon (แถบสีสัดส่วนน้ำหนักพอร์ต) ช่วยคุม Concentration Risk
- **Copilot Money / Apple:** เด่นเรื่อง Bento Glassmorphic Cards สำหรับสายมินิมอล หรูหรา สบายตา

### 4. M2 Compatibility & Health Audit

#### A. Apple Silicon M2 (MacBook Air / Pro / Mac mini M2)
- **Viewport Scaling:** สเกลหน้าจอ M2 ส่วนใหญ่แสดงผลที่ `1470 x 956 px` (Retina 2x Scaling) ต้องใช้ `min-h-0`, `flex-1`, และ `overflow-hidden` ควบคู่กับ Inner Scrollbar เพื่อป้องกันปัญหา Double Scrollbar บน macOS
- **Safari / WebKit Parity:** 
  - รองรับ `-webkit-backdrop-filter: blur(...)` ควบคู่กับ Tailwind `backdrop-blur`
  - ป้องกัน Safari Flexbox min-height bug
  - ปรับแต่ง Custom Thin Scrollbar สี Slate หรูหรา ไม่สะดุดกับ Apple Trackpad Scrolling
- **Retina Typography & Contrast (Iron Rules):**
  - ตัวอักษรห้ามเล็กกว่า 13px (`text-[13px]`)
  - คอนทราสต์บนพื้นหลัง Dark Canvas (`#0B1220`) ใช้ `text-slate-200` (#E2E8F0) และ `text-slate-300` (#CBD5E1) สว่างเกิน 75% คมชัด ไม่จม

#### B. VPS PM2 Health Check (`185.250.38.247`)
- ตรวจสอบผ่าน SSH:
  - `stock-api` (PM2 ID: 9): สถานะ **Online**, CPU: 0%, Memory: 114.9 MB, Uptime 15h+
  - Health Check API: `http://localhost:3100/api/health` -> `{"status":"ok"}`
  - ไม่พบปัญหาค้างหรือ Restart loop
