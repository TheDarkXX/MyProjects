# แผนแยก Step 07 เป็น 3 Sub-steps (ป้องกัน AI Fatigue)

## สถานะปัจจุบัน

Step 07 ตอนนี้ (`07-scene-generator.py`) ทำทุกอย่างในไฟล์เดียว:
- หั่น Scene ตาม duration (~3.5s)
- แบ่ง A/B Roll แบบ **pattern สลับตายตัว** (A→B→B→วน) ← ไม่มี AI คิด
- สร้าง Prompt MD ให้ AI ไปเขียน B-Roll prompt ทีหลัง

**ปัญหา:** ไม่มี AI วิเคราะห์ว่า Scene ไหนเหมาะ A-Roll หรือ B-Roll จริงๆ, ไม่มีการวางแผน emphasis/snap zoom, และถ้าจะให้ AI ทำทุกอย่างในรอบเดียว → AI Fatigue ได้

```
07a  AI วิเคราะห์ + วางแผน Editorial

07b  แบ่ง A/B-Roll ตามแผน AI

07c  สร้าง B-Roll Prompt (ตามสูตรเดิม)

### 07a — AI Scene Analyzer (ใหม่)

**หน้าที่:** ให้ AI อ่านบทพูดทั้งหมด แล้ววิเคราะห์ว่า Scene ไหนเหมาะทำอะไร

**Input:** `*.grouped.json` (ข้อมูลบทพูดหั่นแล้วจาก Step 06)

**AI Prompt:** ส่ง transcript ให้ AI วิเคราะห์ว่า:
1. **จังหวะ Hook** อยู่ตรงไหน (0-5 วินาทีแรก)
2. **จุดเน้นย้ำ** (Emphasis) → ตัวเลขสถิติ, งานวิจัย, สรุปสำคัญ
3. **จุด Transition** ระหว่างหัวข้อ → เหมาะตัด B-Roll
4. **Emotional Beat** → ตื่นเต้น, สงบ, หักมุม
5. **Snap Zoom Direction** → zoom_in (เน้น) / zoom_out (เปิดมุมกว้าง) / null

**Output:** `scene_plan.json`
```json
[
  {
    "id": "S01",
    "role": "hook",
    "emphasis": "snap_zoom_in",
    "emphasis_reason": "Hook ดึงความสนใจ ตัวเลข 7 อย่าง",
    "emotional_beat": "excitement",
    "pacing": "fast"
  },
  {
    "id": "S04",
    "role": "keypoint",
    "emphasis": "snap_zoom_in",
    "emphasis_reason": "สถิติลดเสียชีวิต 70%",
    "emotional_beat": "authority",
    "pacing": "medium"
  },
  {
    "id": "S05",
    "role": "proof",
    "emphasis": null,
    "emotional_beat": "inform",
    "pacing": "medium"
  }
]
```

> [!TIP]
> Step นี้เป็น AI Call เดี่ยว โฟกัสแค่ "วิเคราะห์" ไม่ต้องสร้าง prompt ยาวๆ → ลด fatigue

### 07b — A/B-Roll Assignment (ปรับจากเดิม)

**หน้าที่:** อ่านผลวิเคราะห์จาก 07a แล้วแบ่ง A-Roll / B-Roll ตามแผน

**Input:** `scene_plan.json` (จาก 07a) + `*.grouped.json`

**Logic (ไม่ใช้ AI ← ลดค่าใช้จ่าย):**
- `role: hook` → **A-Roll** (หมอพูดเอง ดึงความสนใจ)
- `role: keypoint` → **A-Roll** (เน้นตัวหมอ สร้าง authority)
- `role: proof` → **B-Roll** (ตัดไปภาพประกอบเสริม)
- `role: transition` → **B-Roll** (ตัดภาพให้ breathe)
- `role: summary` → **A-Roll** (หมอสรุป CTA)

**Output:** `scene_table.json` (เหมือนเดิม แต่ฉลาดกว่า + มี `emphasis` field)
```json
{
  "id": "S04",
  "start": 12.872,
  "end": 17.462,
  "duration": 4.59,
  "visual_type": "A-Roll (Main Clip)",
  "subtitle_text": "กาแฟดำการดื่มกาแฟ...",
  "emphasis": "snap_zoom_in",
  "emphasis_reason": "สถิติลดเสียชีวิต 70%"
}
```
